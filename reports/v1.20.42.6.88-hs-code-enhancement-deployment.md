## 一、功能增强概述

### 1.1 页面标题升级
- **旧标题**: 全球海关HS编码查询引擎
- **新标题**: HS Code 商品归类辅助查询助手
- **英文副标题**: HS Code Classification Assistant
- **定位说明**: 输入商品中文名、英文名或 HS 编码，查询可能的商品归类结果，辅助填写商业发票、报价单和集运申报资料

### 1.2 敏感商品检测与提示
- **检测关键词**: 
  - 英文: battery, batteries, liquid, powder, food, medicine, medicinal, cosmetic, chemical, aerosol, flammable, lithium
  - 中文: 电池, 液体, 粉末, 食品, 药品, 药物, 化妆品, 化学品, 喷雾, 易燃, 锂电
- **提示内容**: 
  - 特殊商品监管要求说明
  - 锂电池 UN38.3 测试报告要求
  - 食品/药品安全标准
  - 液体/粉末航空运输限制
  - 化妆品成分表和安全评估要求

### 1.3 匹配度标识系统
- **高匹配**: 编码完全匹配或中文描述精确匹配
- **可能匹配**: 英文描述匹配
- **需确认**: 部分匹配或模糊匹配
- **显示位置**: 每个搜索结果卡片右上角

### 1.4 收藏功能
- **存储方式**: localStorage (key: hs-code-favorites)
- **容量限制**: 最多 20 条
- **功能特性**:
  - 点击星号图标收藏/取消收藏
  - 独立收藏列表区块
  - 支持清空所有收藏
  - 收藏项显示查询来源和时间
  - 快速复制收藏的 HS 编码

### 1.5 商品资料库占位功能
- **存储方式**: localStorage (key: hs-code-product-candidates)
- **容量限制**: 最多 50 条
- **数据结构**:
  ```json
  {
    "hsCode": "9503.00",
    "descriptionZh": "玩具",
    "descriptionEn": "Toys",
    "query": "toys",
    "source": "hs-code-tool",
    "createdAt": 1718445600000
  }
  ```
- **用途**: 为后续商品资料库功能做准备，用户可保存感兴趣的 HS 编码和商品描述

### 1.6 带入报价单/商业发票功能
- **存储方式**: localStorage (key: jueshi.hsCode.selectedProduct.v1)
- **有效期**: 30 分钟
- **数据结构**:
  ```json
  {
    "hsCode": "9503.00",
    "descriptionZh": "玩具",
    "descriptionEn": "Toys",
    "query": "toys",
    "source": "hs-code-tool",
    "createdAt": 1718445600000,
    "expiresAt": 1718447400000
  }
  ```
- **功能**: 点击按钮后自动复制到剪贴板，可在报价单或商业发票页面粘贴使用

### 1.7 增强风险提示
- **位置**: 页面顶部（主免责声明）和每个结果卡片内
- **内容**:
  - HS Code 查询结果仅供参考，不构成海关、税务或法律意见
  - 正式报关前请以目的国海关、报关行或专业归类意见为准
  - 同一商品可能因材质、用途、规格不同而归入不同编码
  - 不同国家/地区可能采用不同位数和扩展编码

### 1.8 优化无结果页面
- **建议提示**:
  - 使用不同的关键词（中文或英文）
  - 使用 HS 编码前缀查询（如 9503、8471）
  - 简化搜索词（如 "杯" 而非 "不锈钢保温杯"）
- **快速查询按钮**: 显示 6 个常用示例

### 1.9 扩展快速查询示例

### 4.4 部署问题与解决
**问题**: VPS 构建时遇到 `@tailwindcss/postcss` 模块缺失错误

**原因**: `npm ci` 在生产环境下跳过了 devDependencies

**解决方案**: 
```bash
# 使用 --ignore-scripts 安装所有依赖（包括 devDependencies）
npm install --ignore-scripts

# 然后手动执行 postinstall 脚本
export NODE_ENV=production
source .env.production
npx prisma generate
npm run build
```
