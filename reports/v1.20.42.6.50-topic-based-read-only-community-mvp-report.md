```typescript

{
  eventType: "community_list_view",
  toolName: "community",
  action: "view",
  path: "/community"
}

// 社区文章浏览
{
  eventType: "community_article_view",
  toolName: "community",
  action: "view",
  path: "/community/[slug]",
  metadata: { slug }
}

// CTA 点击（预留）
{
  eventType: "community_cta_click",
  toolName: "community",
  action: "click",
  path: "/community/[slug]",
  metadata: { slug, toolSlug }
}

// 继续到工具（预留）
{
  eventType: "community_tool_continue",
  toolName: "community",
  action: "click",
  path: "/community/[slug]",
  metadata: { slug, toolSlug }
}
```

## 十三、VPS 部署问题

### 问题 1: PM2 环境变量缓存

**现象**: PM2 环境变量中的 DATABASE_URL 包含 `?schema=public`

**原因**: PM2 从 dump.pm2 或其他地方读取了旧的环境变量

**解决方案**:
```bash
pm2 kill
rm -rf ~/.pm2
cd /home/deploy/xixiong-saas
set -a && . ./.env.production && set +a
pm2 start ecosystem.config.js
```

### 问题 2: pm2-start.sh 执行权限

**现象**: pm2-start.sh 没有执行权限

**解决方案**:
```bash
chmod +x /home/deploy/xixiong-saas/scripts/pm2-start.sh
```

### 问题 3: PM2 daemon 状态异常

**现象**: PM2 报错 "Cannot read properties of undefined"

**解决方案**:
```bash
pm2 kill
sleep 2
rm -rf ~/.pm2
pm2 start ecosystem.config.js
```
