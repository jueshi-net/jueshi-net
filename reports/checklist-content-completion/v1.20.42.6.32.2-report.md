## 2. /api/events 原问题根因

**前端发送（analytics.ts）：**
```json
{
  "eventType": "checklist_view",
  "toolName": "checklist",
  "action": "view_student-first-abroad-packing-checklist",
  "path": "/checklists/...",
  "sessionId": "..."
}
```

**后端解构（修复前）：**
```ts
const { event, toolName, path, sessionId, ...rest } = body;
// ❌ event = undefined（因为键名是 eventType，不是 event）
// ❌ eventType 进入 ...rest，被 JSON.stringify 存入 action 列
// ❌ eventType 列被设为 "unknown"
```

**修复后：**
```ts
const { eventType, action, toolName, path, sessionId, ...rest } = body;
// ✅ eventType 正确映射到 EventLog.eventType
// ✅ action 正确映射到 EventLog.action
// ✅ checklistSlug/toolSlug/sourcePath 追加为 metadata JSON
```

---

## 3. EventLog 持久化实现说明

- `eventType?.toString()` → `EventLog.eventType`
- `action?.toString()` → `EventLog.action`（如同时有 metadata 则追加 `| metadata: {...}`）
- `toolName?.toString()` → `EventLog.toolName`
- `path?.toString()` → `EventLog.path`
- `sessionId?.toString()` → `EventLog.sessionId`
- 其余字段（checklistSlug, toolSlug, sourcePath 等）→ JSON 追加到 action
- 写库失败时：catch 返回 500，但不影响前端体验
