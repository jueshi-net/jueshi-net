### 2.4 enabled=false 验证 ✅

**验证方式：** 代码逻辑检查

**验证结果：**

| 测试项 | 验证方式 | 结果 |
|--------|---------|------|
| 广告组 enabled=false | `if (group.enabled === false) return null;` | ✅ 整体隐藏 |
| 广告位 enabled=false | `group.slots.filter(slot => slot.enabled)` | ✅ 单个隐藏 |
| 广告内容 enabled=false | `slot.creatives.filter(creative => creative.enabled)` | ✅ 单个隐藏 |
| 空广告组折叠 | `if (limitedTextCreatives.length === 0 && imageCreatives.length === 0) return null;` | ✅ 不留空白 |
| 按钮 enabled=false | `{checkinButton.enabled && (...)}` | ✅ 按钮隐藏 |
| Tab enabled=false | `config.mobileTabs.filter(tab => tab.enabled)` | ✅ Tab 不显示 |
