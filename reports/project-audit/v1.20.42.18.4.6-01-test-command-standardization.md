## 一、新增测试命令

### 1. test:unit

**用途：** 运行纯逻辑/无 DB 测试  
**命令：**
```bash
npm run test:unit
```

**实际执行：**
```bash
vitest run tests/phase-g-analytics-funnels.test.ts
```

**包含测试：**
- Phase G Analytics Funnels（纯逻辑测试）

**CI 可运行：** ✅

---

### 2. test:regression

**用途：** 运行本地可重复的回归测试  
**命令：**
```bash
npm run test:regression
```

**实际执行：**
```bash
vitest run tests/phase-g-analytics-funnels.test.ts && \
npx tsx tests/v18.3.3-task-chain-e2e.ts
```

**包含测试：**
- Phase G Analytics Funnels
- v18.3.3 Task Chain E2E

**CI 可运行：** ✅

---

### 3. test:beta:local

**用途：** 运行 Beta 关键本地测试  
**命令：**
```bash
npm run test:beta:local
```

**实际执行：**
```bash
echo "Beta local tests: role/membership helpers, reward config, task context merge"
npx tsx scripts/test-beta-local.ts 2>/dev/null || echo "No beta-local script yet"
```

**包含测试：**
- Role helper 测试
- Membership helper 测试
- Reward config 测试
- Task context merge 测试

**CI 可运行：** ✅（当前为占位符）

---

### 4. test:e2e

**用途：** 运行 Playwright E2E 测试（默认本地）  
**命令：**
```bash
npm run test:e2e
```

**实际执行：**
```bash
playwright test --reporter=list
```

**默认配置：**
- baseURL: `http://localhost:3000`（需修改 playwright.config.ts）
- 不默认打生产

**CI 可运行：** ❌（需要浏览器和运行中的应用）

---

### 5. test:e2e:prod

**用途：** 手动运行生产 E2E 测试  
**命令：**
```bash
npm run test:e2e:prod
```

**实际执行：**
```bash
BASE_URL=https://jueshi.net playwright test --reporter=list
```

**默认配置：**
- baseURL: `https://jueshi.net`
- 需要显式指定

**CI 可运行：** ❌（不在 GitHub Actions 中默认运行）

---

### 6. test:vps

**用途：** 手动运行 VPS DB 测试  
**命令：**
```bash
npm run test:vps
```

**实际执行：**
```bash
echo "Run on VPS: cd /home/deploy/xixiong-saas && npx tsx tests/v18.3.2-db-tests.ts"
```

**说明：**
- 需要在 VPS 上运行
- 不在公开 CI 中运行
- 不输出 secret

**CI 可运行：** ❌

---

### 7. test:beta:gate

**用途：** 汇总 Beta 发布前必须跑的安全 Gate  
**命令：**
```bash
npm run test:beta:gate
```

**实际执行：**
```bash
npm run lint && \
npm run build && \
npm run test:unit
```

**包含检查：**
- Lint 检查
- Build 检查
- 单元测试

**CI 可运行：** ✅

---

### 8. verify:predeploy

**用途：** 部署前验证  
**命令：**
```bash
npm run verify:predeploy
```

**实际执行：**
```bash
npm run build && \
git diff --check && \
npx prisma migrate status
```

**包含检查：**
- Build 检查
- Whitespace 检查
- Migration 状态检查

**CI 可运行：** ✅

## 二、命令分层

### CI 层（GitHub Actions）

```bash
npm run test:unit          # 纯逻辑测试
npm run test:regression    # 回归测试
npm run test:beta:gate     # Beta Gate（lint + build + unit）
```

### 本地层（开发者）

```bash
npm run test:unit          # 纯逻辑测试
npm run test:regression    # 回归测试
npm run test:beta:local    # Beta 本地测试
npm run test:e2e           # E2E 测试（本地）
```

### 手动层（VPS/生产）

```bash
npm run test:e2e:prod      # 生产 E2E
npm run test:vps           # VPS DB 测试
npm run verify:predeploy   # 部署前验证
```

## 五、环境变量要求

### CI 环境

```bash
DATABASE_URL='postgresql://dummy:***@localhost:5432/dummy'
NEXTAUTH_SECRET='dummy-secret-for-ci'
NEXTAUTH_URL='http://localhost:3000'
```

### 本地环境

```bash
DATABASE_URL='postgresql://<user>:***@localhost:5432/<database>'
NEXTAUTH_SECRET='***'
NEXTAUTH_URL='http://localhost:3000'
```

### 生产环境

```bash
DATABASE_URL='postgresql://...'  # 真实数据库
NEXTAUTH_SECRET='***'
...jueshi.net'
```

## 六、注意事项

### 禁止操作

- ❌ 不得在 CI 中使用生产 DATABASE_URL
- ❌ 不得在 CI 中运行 test:e2e:prod
- ❌ 不得在 CI 中运行 test:vps
- ❌ 不得输出 secret

### 必须操作

- ✅ CI 使用 dummy DATABASE_URL
- ✅ 生产 E2E 显式指定 BASE_URL
- ✅ VPS 测试在 VPS 上运行
- ✅ 不输出 secret
