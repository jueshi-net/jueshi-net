## 判断结论: C - MRE 正常但 App 不正常

## App 具体差异

### 差异 1: 单位系统（严重）
**MRE**:
```css
width: 100mm;
height: 100mm;
font-size: 16pt;
```

**App**:
```css
width: 378px;  /* 100mm * 3.7795275591 */
height: 378px;
font-size: 15.996px;  /* 12pt * 1.333 */
```

**问题**: 
- App 将所有单位转换为 px，使用浮点数近似值
- Safari 打印时，px 到物理尺寸的映射可能不准确
- 浮点数精度问题导致累积误差

### 差异 2: iframe 隔离（中等）
**MRE**: 直接打印主文档  
**App**: 使用隐藏 iframe

**问题**:
- Safari 对 iframe 打印可能有特殊处理
- iframe 的 `window.print()` 可能触发不同的打印行为
- 某些浏览器对 iframe 打印的支持不完整

### 差异 3: 样式污染（中等）
**MRE**: 纯净的打印样式  
**App**: 注入所有外部样式（Tailwind CSS 等）

**问题**:
- Tailwind CSS 的 `@media print` 规则可能干扰
- 外部样式可能与打印样式冲突
- 样式优先级问题（`!important` 冲突）

### 差异 4: 浮点数精度（轻微）
**MRE**: 使用整数或简单小数  
**App**: 大量浮点数（如 `75.590551182px`）

**问题**:
- Safari 渲染引擎对浮点数处理可能不一致
- 累积误差导致布局偏移

## 最小修复方案

### 修复 1: 改用原生单位（必须）

**当前代码** (canvas-editor-full.tsx:894-905):
```typescript
const styleCSS = `
  position: absolute;
  left: ${xPx}px;
  top: ${yPx}px;
  width: ${widthPx}px;
  height: ${heightPx}px;
  font-size: ${fontSizePx}px;
  ...
`;
```

**修复后**:
```typescript
const styleCSS = `
  position: absolute;
  left: ${element.x}mm;
  top: ${element.y}mm;
  width: ${element.width}mm;
  height: ${element.height}mm;
  font-size: ${element.style.fontSize || 12}pt;
  ...
`;
```

**影响**: 
- 消除单位转换误差
- Safari 可以直接使用 mm/pt 单位
- 打印尺寸更准确

### 修复 2: 移除 iframe（推荐）

**当前代码** (canvas-editor-full.tsx:928-938):
```typescript
const iframe = document.createElement("iframe");
iframe.id = "canvas-print-iframe";
iframe.style.position = "fixed";
iframe.style.left = "-9999px";
// ...
document.body.appendChild(iframe);
```

**修复后**:
```typescript
// 创建临时打印容器
const printContainer = document.createElement("div");
printContainer.id = "print-container";
printContainer.style.position = "absolute";
printContainer.style.left = "-9999px";
document.body.appendChild(printContainer);

// 渲染打印内容
printContainer.innerHTML = pagesHTML;

// 直接打印主文档
window.print();

// 清理
document.body.removeChild(printContainer);
```

**影响**:
- 消除 iframe 兼容性问题
- 简化打印流程
- 减少 Safari 特殊处理

### 修复 3: 最小化样式注入（可选）

**当前代码** (canvas-editor-full.tsx:943-948):
```typescript
const styleElements = Array.from(
  document.head.querySelectorAll("style, link[rel='stylesheet']")
).map((el) => el.outerHTML).join("\n");
```

**修复后**:
```typescript
// 只注入必要的打印样式
const styleElements = `
  <style>
    @page {
      size: ${paperWidthMm}mm ${paperHeightMm}mm;
      margin: 0;
    }
    * {
      -webkit-print-color-adjust: exact !important;
      print-color-adjust: exact !important;
    }
  </style>
`;
```

**影响**:
- 消除样式冲突
- 减少样式优先级问题
- 提高打印一致性

## 结论

**修复路线**: C - MRE 正常但 App 不正常

**核心问题**: App 使用了 px 单位和 iframe 隔离，导致 Safari 打印异常

**解决方案**: 改用原生单位（mm/pt），移除 iframe，最小化样式注入

**风险等级**: 中（需要充分测试）
