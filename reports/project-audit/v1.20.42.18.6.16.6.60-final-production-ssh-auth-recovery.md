4. SSH 没有尝试 `jueshi-prod-v2`，因为：
   - 直接使用 `deploy@104.250.109.99` 不触发 SSH config 中的 Host alias

## PHASE 6 — 修复方案总结

### 根因

SSH 直接使用 `deploy@104.250.109.99` 时，只尝试默认 key 文件，没有使用 SSH config 中配置的 `jueshi-prod-v2` key。

### 解决方案

**方案 1：使用 Host Alias（推荐）**

```bash
ssh jueshi-new 'command'
```

**方案 2：显式指定 Key**

```bash
ssh -i ~/.ssh/jueshi-prod-v2 deploy@104.250.109.99 'command'
```

**方案 3：修改默认 SSH 行为**

在 `~/.ssh/config` 中添加：

```
Host 104.250.109.99
    User deploy
    IdentityFile ~/.ssh/jueshi-prod-v2
    IdentitiesOnly yes
```

然后可以直接使用：

```bash
ssh deploy@104.250.109.99 'command'
```
