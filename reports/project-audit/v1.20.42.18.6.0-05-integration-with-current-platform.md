# v1.20.42.18.6.0 — Phase 5: 与现有项目集成设计

**生成时间:** 2026-06-22

---

## 1. 与 User 模型集成

### 现状
- ForumPost.userId → User.id (已有外键)
- ForumComment.userId → User.id (已有外键)

### 扩展
- ForumReaction.userId → User.id (新增)
- ForumReport.reporterId → User.id (新增)
- ForumBookmark.userId → User.id (新增)

### 权限集成
- 使用现有 `requireAuth()` 中间件验证登录
- 使用现有 `session.user.role` 判断 admin 权限
- 使用现有 `session.user.id` 获取用户 ID
- 不需要新增 auth 逻辑

## 2. 与 membershipTier 集成

### 设计
- 社区功能不直接依赖 membershipTier
- 所有登录用户均可发帖（不限会员等级）
- 二期可增加：高等级用户发帖频率限制更宽松
- 不修改 User 模型的 membershipTier 字段

## 3. 与积分/成长值集成

### 现状
- ForumPost 和 ForumComment 都有 `rewardGrantedAt` 字段
- 已有成长值奖励机制（发帖/回帖获得成长值）

### 一期设计
- 发帖奖励：+2 成长值（已有，通过 rewardGrantedAt 防重复）
- 回帖奖励：+1 成长值（已有）
- 点赞不奖励成长值
- 被采纳为精华帖：+5 成长值（二期）
- 举报被采纳：+3 成长值（二期）

### 实现方式
- 使用现有 GrowthLog / PointLedger 模型记录
- 不创建新的积分系统

## 4. 与任务链集成

### 设计
- ForumPost 新增 `relatedTaskChainType` 字段
- 任务链完成页显示"分享经验"按钮 → 跳转到发帖页，预填任务链类型
- 帖子详情页显示关联的任务链入口 CTA

### 一期范围
- 帖子可标记关联任务链类型（shipping 等）
- 任务链完成页引导分享
- 不做任务链数据自动填充到帖子内容

## 5. 与 Guide/Checklist/Topic 内容系统集成

### 设计
- ForumPost 新增 `relatedGuideId`, `relatedChecklistId` 字段
- Guide 页面底部显示"相关讨论"（查询 relatedGuideId 匹配的帖子）
- Checklist 页面底部显示"相关讨论"
- Topic 页面底部显示"相关讨论"

### 一期范围
- 帖子可关联 Guide/Checklist
- 内容页面显示相关讨论列表（最多 5 条）
- 不做自动关联推荐

## 6. 与工具页面集成

### 设计
- ForumPost 新增 `relatedTool` 字段（工具 slug）
- 工具页面底部显示"相关讨论"区
- 帖子详情页显示"使用此工具"CTA

### 一期范围
- 帖子可关联工具
- 工具页面显示相关讨论
- 工具使用遇到问题时引导发帖（tools-help 分类）

## 7. 与 Beta 反馈流程集成

### 现状
- 已有 Feedback 模型（type, subject, content, page, status）
- Feedback 是独立提交，不公开

### 设计
- Beta 反馈分类（beta-feedback）引导用户发帖
- 帖子可标记为 "beta-feedback" 类型
- Admin 可将 Feedback 转为 ForumPost（二期）
- Beta 反馈帖子在 admin 面板聚合显示

### 一期范围
- beta-feedback 分类发帖
- Admin 面板显示该分类帖子列表
- 不做 Feedback → ForumPost 自动转换

## 8. 与通知系统集成

### 现状
- 已有 Notification 模型（userId, title, message, type, link, isRead）

### 一期范围
- 帖子被回复时创建 Notification（type: "forum_reply"）
- 帖子被点赞时不通知（减少噪音）
- 举报被处理时通知举报人（type: "forum_report_resolved"）

### 二期范围
- @提及通知
- 关注用户发帖通知
- 实时推送（SSE）

## 9. 与 Admin 权限集成

### 设计
- 使用现有 admin role 检查
- Admin 可访问 `/admin/community/*` 路由
- Admin 可审核/隐藏/删除/置顶帖子和评论
- Admin 可管理分类
- Admin 可处理举报

### 一期不做
- Moderator 角色（一期 admin 兼任）
- 分类级权限（一期所有 admin 管理所有分类）

## 10. 与 SEO/index/noindex 集成

### 设计

| 页面 | index | 理由 |
|------|-------|------|
| /community | index | 社区首页，有利于 SEO |
| /community/c/[slug] | index | 分类页，有利于 SEO |
| /community/t/[slug] | index | 帖子详情页，用户生成内容利于长尾 SEO |
| /community/new | noindex | 发帖页，不需要索引 |
| /community/search | noindex | 搜索页，不需要索引 |
| /admin/community/* | noindex | 管理后台，禁止索引 |

### 实现
- 使用 Next.js `metadata` 对象设置 `robots: { index: true/false }`
- 帖子详情页生成结构化数据（JSON-LD QAPage）
- sitemap.xml 包含已发布帖子 URL
