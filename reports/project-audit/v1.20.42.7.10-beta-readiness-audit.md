## ⚠️ 需修复项（2 项 P1）

### P1-1: NEXT_PUBLIC_APP_URL 未配置

**问题**:
- 生产环境未设置 `NEXT_PUBLIC_APP_URL`
- 导致 `twitter:image` 使用 fallback `http://localhost:3000/og/default-og.png`
- 订阅 API 也依赖此变量生成确认链接

**影响**:
- SEO 和社交分享图片链接错误
- 邮件订阅确认链接可能错误

**修复方案**:
```bash
# 在 VPS 生产环境添加
NEXT_PUBLIC_APP_URL=https://jueshi.net
```

**优先级**: P1（Beta 前必须修复）

### P1-2: 外部 Uptime 监控未配置

**问题**:
- 无外部 uptime 监控服务
- 无法及时发现生产环境宕机

**影响**:
- 生产环境故障时无法及时感知
- 依赖用户报告发现问题

**修复方案**:
1. 注册 UptimeRobot（免费）或 BetterStack
2. 添加监控：`https://jueshi.net/`
3. 配置告警：Telegram / Email

**优先级**: P1（Beta 前建议修复）
