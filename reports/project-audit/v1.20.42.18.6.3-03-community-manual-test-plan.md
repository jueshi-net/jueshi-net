# v1.20.42.18.6.3 — Phase 3: 社区人工测试脚本

## A. 访客路径

1. 打开 /community → 看到社区首页、分类、种子帖
2. 点击分类 → 进入分类页，看到该分类帖子
3. 点击帖子 → 进入帖子详情，看到内容和作者
4. 点击发帖 → 跳转登录页
5. 点击回帖 → 提示登录
6. 点击举报 → 提示登录

## B. 登录用户路径

1. 登录普通用户（test@jueshi.net / Test123456!）
2. 打开 /community/new → 看到发帖表单
3. 填写标题、选择分类、输入内容 → 点击发布
4. 打开帖子详情 → 看到自己的帖子
5. 在回帖框输入内容 → 点击回复
6. 点击点赞按钮 → 点赞数 +1
7. 点击收藏按钮 → 显示"已收藏"
8. 点击举报按钮 → 选择原因 → 提交
9. 访问 /u/[自己的id] → 看到资料卡
10. 检查是否获得 first_post / first_reply 勋章

## C. 管理员路径

1. 登录 admin (9833416@qq.com)
2. 打开 /admin/community → 看到统计面板
3. 打开 /admin/community/posts → 看到帖子列表
4. 点击置顶按钮 → 帖子置顶状态切换
5. 点击加精按钮 → 帖子加精，作者荣誉 +20
6. 点击隐藏按钮 → 帖子隐藏
7. 打开 /admin/community/comments → 看到评论列表
8. 点击隐藏评论 → 评论隐藏
9. 打开 /admin/community/flagged → 看到举报列表
10. 点击"举报成立" → 被举报人 -10 荣誉，举报人 +5
11. 点击"驳回" → 无荣誉变动
12. 检查 HonorLog 是否写入

## D. 移动端路径

1. 375 宽度打开 /community → 无横向溢出
2. 375 宽度打开分类页 → 无横向溢出
3. 375 宽度打开帖子详情 → 无横向溢出
4. 375 宽度发帖 → 表单可用
5. 375 宽度回帖 → 回帖框可用
6. 确认无横向溢出
