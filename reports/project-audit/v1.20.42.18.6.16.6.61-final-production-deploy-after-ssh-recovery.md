## SSH 认证恢复

### SSH 是否成功

✅ **是**

### 根因分析

**SSH_AUTH_ROOT_CAUSE:** SSH 直接使用 `deploy@104.250.109.99` 时，只尝试默认 key 文件（id_ed25519），没有使用 SSH config 中配置的 `jueshi-prod-v2` key。

### 解决方案

1. 使用 Host Alias: `ssh jueshi-new`
2. 或显式指定 Key: `ssh -i ~/.ssh/jueshi-prod-v2 deploy@104.250.109.99`
3. 在 production server 上配置 SSH config 和 GitHub SSH key

### Production Server SSH 配置

```bash
# ~/.ssh/config
Host github.com-nnrwsm
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_nnrwsm
    IdentitiesOnly yes
```

### GitHub SSH Key

- 从本地复制 `id_ed25519_nnrwsm` 到 production server
- 配置 SSH config 使用正确的 key
- 测试: `ssh -T git@github.com-nnrwsm` ✅ 成功
