# v1.20.42.18.6.0 — Phase 6: 反垃圾和安全设计

**生成时间:** 2026-06-22

---

## 1. 新用户发帖频率限制

### 规则

| 用户类型 | 每日发帖上限 | 每日回帖上限 | 发帖间隔 | 链接限制 |
|---------|-------------|-------------|---------|---------|
| 注册 < 24h | 3 帖 | 10 条 | 5 分钟 | 每帖 1 个 |
| 注册 < 7 天 | 5 帖 | 20 条 | 2 分钟 | 每帖 2 个 |
| 注册 ≥ 7 天 | 10 帖 | 30 条 | 无 | 每帖 5 个 |
| Admin/Moderator | 无限制 | 无限制 | 无 | 无限制 |

### 实现方式
- 基于 `User.createdAt` 计算注册时长
- 当日发帖/回帖计数：查询 `ForumPost` / `ForumComment` 当日创建数量
- 不使用 Redis 计数器（一期用数据库查询，5-10 人 Beta 足够）
- 超限时返回 429 状态码 + 友好提示

## 2. 敏感词基础过滤

### 一期方案
- 维护敏感词列表（admin 后台配置，存入社区配置表或 JSON 文件）
- 发帖/回帖时检查内容是否包含敏感词
- 命中敏感词时：帖子状态设为 `pending`（需 admin 审核）
- 不自动删除（避免误杀）

### 敏感词来源
- 基础政治敏感词
- 广告垃圾词（"代购" "加微信" "免费领取" 等）
- 可由 admin 在后台增删

### 实现
- 中间件函数 `containsSensitiveWords(content: string): boolean`
- 在 POST /api/forum/posts 和 POST /api/forum/posts/[slug]/comments 中调用

## 3. 举报机制

### 流程
1. 用户点击"举报"按钮 → 弹出举报原因选择
2. 提交举报 → 创建 ForumReport 记录
3. Admin 在后台看到举报队列 → 审核
4. Admin 决定：隐藏内容 / 驳回举报
5. 举报人收到通知

### 举报原因选项
- 垃圾广告
- 不当内容
- 人身攻击
- 虚假信息
- 政治敏感
- 其他

### 防滥用
- 每人每日最多举报 10 次
- 同一内容同一用户只能举报 1 次

## 4. 后台审核

### 审核队列
- 新帖子默认 `pending` 状态（一期可改为 `published` 自动发布，降低门槛）
- 举报内容进入审核队列
- Admin 可批量操作：隐藏/恢复/删除

### 审核操作
| 操作 | 效果 |
|------|------|
| 通过 | status → published |
| 隐藏 | status → hidden（对普通用户不可见，作者可见） |
| 恢复 | status → published |
| 删除 | status → deleted（软删除，数据保留） |
| 置顶 | isPinned → true |
| 取消置顶 | isPinned → false |
| 精华 | isFeatured → true |
| 锁定 | isLocked → true（禁止回帖） |
| 解锁 | isLocked → false |

## 5. 软删除

### 设计
- 帖子/评论删除时 `status = 'deleted'`，不物理删除
- deleted 内容对普通用户不可见
- Admin 可查看 deleted 内容（用于审计）
- 30 天后可物理清理（二期定时任务）

## 6. IP/设备信息

### 现状
- ForumPost 和 ForumComment 已有 `ipHash`（SHA256 前 16 位）和 `userAgent` 字段
- **不存储原始 IP**，只存 hash
- hash 不可逆，无法还原原始 IP

### 隐私保护
- ✅ 不存储原始 IP
- ✅ ipHash 不可逆
- ✅ userAgent 仅用于反垃圾分析，不公开
- ✅ 不在 API 响应中返回 ipHash/userAgent
- ✅ 不在用户主页显示 IP 信息

## 7. 防 XSS

### 设计
- 帖子内容存储为**纯文本**（已有 ForumPost.content 为纯文本）
- 前端渲染时使用 React 自动转义（不使用 dangerouslySetInnerHTML）
- 评论内容同样为纯文本
- 不允许 HTML 标签
- 一期不支持 Markdown 渲染（纯文本 + 换行）

### 二期 Markdown 支持
- 使用 `react-markdown` 渲染（自动 XSS 防护）
- 使用 `rehype-sanitize` 清洗 HTML
- 禁止 `<script>`, `<iframe>`, `onclick` 等

## 8. 图片上传

### 一期：不做
- 帖子内容为纯文本，不支持图片
- 减少攻击面和存储成本

### 二期：受限上传
- 限制 1MB / 张，最多 3 张/帖
- 仅允许 JPEG/PNG/WebP
- 存储到 public/uploads/forum/
- 服务端图片重编码（去除 EXIF + 恶意 payload）

## 9. 防广告垃圾帖

### 多层防护

| 层级 | 措施 |
|------|------|
| 第一层 | 新用户发帖频率限制（24h 内 3 帖） |
| 第二层 | 链接数量限制（新用户每帖 1 链接） |
| 第三层 | 敏感词过滤（广告关键词 → pending） |
| 第四层 | 举报机制（用户举报 → 审核队列） |
| 第五层 | Admin 人工审核 |
| 第六层 | IP hash 关联分析（同一 hash 大量发帖 → 可疑） |

### 自动标记
- 帖子包含 3+ 外部链接 → 自动 pending
- 帖子内容重复率 > 80%（与近期帖子对比）→ 自动 pending
- 新用户首发帖包含链接 → 自动 pending
