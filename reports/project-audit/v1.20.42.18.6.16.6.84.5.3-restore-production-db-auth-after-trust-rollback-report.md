## 根因分析

### 问题: 数据库密码丢失
**根因**: 系统级密码隐藏机制导致无法在 .env.production 文件中写入正确的密码。

**症状**:
- psql 连接失败: "password authentication failed for user bxb_user"
- 应用日志: "Authentication failed against the database server"
- PrismaClient 初始化失败: P1000

**证据**:
```
pm2 logs xixiong-saas:
0|xixiong- |     driverAdapterError: Error [DriverAdapterError]: AuthenticationFailed
0|xixiong- | Authentication failed against the database server, the provided database credentials for `bxb_user` are not valid
```

**解决方案**: 需要用户手动更新 .env.production 中的 DATABASE_URL

### 步骤 4: 测试 Bridge API
```bash
# 读取 secret
SECRET=*** CONTENTOPS_BRIDGE_SECRET .env.production | cut -d= -f2 | tr -d "\""'"'"')

# 准备请求
BODY='{"contentType":"topic","title":"Test","gatewayLocation":"local_mac","localHermesRunId":"test-001","planningUsed":true,"fallbackUsed":false,"validateOnly":true}'

# 生成签名
SIG=*** echo -n "$BODY" | openssl dgst -sha256 -hmac "$SECRET" | cut -d" " -f2'"'"')

# 发送请求
curl -X POST http://localhost:3000/api/internal/contentops/drafts \
  -H "Content-Type: application/json" \
  -H "x-contentops-signature: $SIG" \
  -d "$BODY"
```
