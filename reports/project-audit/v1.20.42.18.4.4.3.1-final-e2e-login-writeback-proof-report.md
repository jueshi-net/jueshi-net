## 四、登录超时根因

### 4.1 根本原因

**测试用户没有 credentials 账号**

```sql
-- users 表中有用户
SELECT email, role FROM users WHERE email = 'e2e-task-chain-20260621@jueshi.net';
-- 结果：e2e-task-chain-20260621@jueshi.net | user

-- accounts 表中没有 credentials 记录
SELECT COUNT(*) FROM accounts WHERE provider = 'credentials' AND "userId" IN (...);
-- 结果：0
```

### 4.2 次要原因

**环境变量配置错误**
- `.env.local` 端口错误（5555 而不是 5432）
- `.env.local` 数据库密码与 `.env.production` 不一致
- 导致应用无法连接数据库
