## 四、风险点

### 1. 公司资料后端限制
- **风险**：后端没有限制检查，可绕过前端限制
- **影响**：免费用户可创建多个公司资料
- **解决方案**：在 POST API 添加限制检查

### 2. 日程/任务前端缺失
- **风险**：UserTask 模型存在，但缺少前端页面
- **影响**：用户无法使用日程/待办功能
- **解决方案**：创建日程/待办前端页面

### 3. 通知分组不清晰
- **风险**：通知按 type 字段存储，但前端没有分组展示
- **影响**：用户难以区分不同类型的通知
- **解决方案**：前端按 type 分组展示

### 4. 真实登录态验收
- **风险**：v1.20.42.8.1 只做了代码验证，未真实登录态验收
- **影响**：可能存在未发现的布局问题
- **解决方案**：使用测试账号真实登录验收
