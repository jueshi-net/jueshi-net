## 三、运费按立方不更新的根因

### 3.1 问题描述
选择"按立方"计费方式后，主运费不会自动按立方计算，仍然显示按重量计费的结果。

### 3.2 根本原因
在 v1.20.42.7.04 修复 CBM 公式时，`calcResults()` 函数中的 `totalCBM` 已经正确转换为 m³：
```javascript
// v1.20.42.7.04 修复后
const singleCbm = (l * w * h) / 1000000;  // cm³ 转 m³
const cbm = singleCbm * q;
```

但在主运费计算函数中，又错误地再次除以 1,000,000：
```javascript
// 错误代码（v1.20.42.7.04 遗留）
const totalCbmM3 = results.totalCBM / 1000000;  // 又除了一次！
```

这导致：
- 输入：50×40×30×10
- `results.totalCBM` = 0.6 m³（正确）
- `totalCbmM3` = 0.6 / 1000000 = 0.0000006 m³（错误！）
- 按立方运费 = 0.0000006 × 1000 = 0.0006 CNY（几乎为 0）

### 3.3 修复方案
移除多余的除法，因为 `results.totalCBM` 已经是 m³：
```javascript
// 修复后
const totalCbmM3 = results.totalCBM; // Already in m³ from calcResults
```

## 五、修复后计费方式 value / state / switch 逻辑

### 5.1 Switch 逻辑（修复后）
```javascript
const totalCbmM3 = results.totalCBM; // ✅ Already in m³ from calcResults

switch (billingMode) {
  case 'weight':
    mainFee = results.totalGW * ppk;
    mainFeeLabel = '按实重计费';
    mainFeeDetail = `${results.totalGW.toFixed(1)} kg × ${ppk} ${currency}/kg`;
    break;
  case 'volume':
    mainFee = results.totalVW * ppk;
    mainFeeLabel = '按体积重计费';
    mainFeeDetail = `${results.totalVW.toFixed(1)} kg × ${ppk} ${currency}/kg`;
    break;
  case 'higher':
    mainFee = results.chargeableWeight * ppk;
    mainFeeLabel = '二者取高计费';
    mainFeeDetail = `${results.chargeableWeight.toFixed(1)} kg × ${ppk} ${currency}/kg`;
    break;
  case 'cbm':
    mainFee = totalCbmM3 * ppcb;  // ✅ 现在正确
    mainFeeLabel = '按立方计费';
    mainFeeDetail = `${totalCbmM3.toFixed(4)} m³ × ${ppcb} ${currency}/m³`;
    break;
}
```
