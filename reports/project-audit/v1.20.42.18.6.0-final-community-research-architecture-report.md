## 3. License 风险结论

| 项目 | License | 风险 | 结论 |
|------|---------|------|------|
| Discourse | GPL v2 | 传染性 copyleft | 仅借鉴设计，不复制代码 |
| Flarum | MIT | 无风险 | 可复制但 PHP 代码无用 |
| NodeBB | GPL v3 | 传染性 copyleft | 仅借鉴设计 |
| Forem | AGPL v3 | 最严格 copyleft | 仅借鉴设计，绝对不复制 |

**总结:** 所有 4 个项目都只适合借鉴设计理念。jueshi.net 社区论坛基于现有 Next.js + Prisma + PostgreSQL 技术栈自研，不引入任何第三方论坛代码。

## 4. jueshi.net 社区定位

海外华人实用问题社区 — 围绕跨境发货、清关、地址、邮编、物流工具的实用问答和经验分享平台。

一期 10 个频道：
1. 公告与更新（仅 admin 发帖）
2. Beta 反馈
3. 跨境发货
4. HS 编码与申报
5. 地址邮编与收件格式
6. 国家/城市生活
7. 工具使用问题
8. 经验分享
9. 问答求助
10. 建议与投票

## 5. 现有基础设施

**重大发现:** 项目已有论坛基础设施，不是从零开始：

- `ForumCategory` 模型 + 5 个已 seed 分类
- `ForumPost` 模型（slug, status, isPinned, isLocked, viewCount, commentCount, ipHash, userAgent, rewardGrantedAt）
- `ForumComment` 模型（status, ipHash, userAgent, rewardGrantedAt）
- 7 个 API 路由（categories, posts CRUD, comments CRUD, admin moderation, stats）
- Admin 审核 API（帖子管理 + 评论管理）
- 成长值奖励集成（rewardGrantedAt 防重复）
- IP hash 反垃圾（SHA256 前 16 位，不可逆）
- 当前 0 帖 0 评论（等待内容填充）

## 7. 数据模型设计

### 新增表（3 个）
- `forum_reactions` — 点赞/有用
- `forum_reports` — 举报
- `forum_bookmarks` — 收藏

### 扩展现有表
- `forum_posts`: +8 字段（tags, isFeatured, likeCount, relatedTool, relatedGuideId, relatedChecklistId, relatedTaskChainType, bookmarkCount）
- `forum_comments`: +1 字段（likeCount）

### Migration 风险
- **零风险**: 所有操作都是 additive（添加表/字段）
- 不修改现有数据
- 不影响 User / role / membershipTier
- 使用 `prisma migrate dev`（不是 db push）

## 8. 前后台页面设计
