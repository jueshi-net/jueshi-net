- **是否可复现：** 是 / 否 / 偶尔

**严重等级评估：**

[其他相关信息，如错误提示、控制台日志等]

**分流决策：**
- **归属模块：** [任务链/奖励/登录/后台/公开页面/其他]

## Bug 编号规则

**格式：** BUG-YYYYMMDD-NNN

**示例：**
- BUG-20260621-001
- BUG-20260621-002
- BUG-20260622-001

**说明：**
- YYYYMMDD: 报告日期
- NNN: 当日序号（001, 002, 003...）

## 严重等级定义

### P0 - 立即修复（Critical）

**定义：** 影响核心功能或安全，必须立即修复

**示例：**
- 登录/登出失败
- 数据丢失
- 权限绕过
- 生产环境崩溃
- 9833416@qq.com 被修改
- role 被会员覆盖

**处理流程：**
1. 立即停止用户测试
2. 最小改动修复
3. 测试验证
4. 紧急部署
5. 写 hotfix 报告
6. 通知用户继续测试

**响应时间：** 立即  
**修复时间：** 2-4 小时

### P1 - Beta 前建议修复（High）

**定义：** 影响用户体验，但不影响核心功能

**示例：**
- UI 细节问题
- 文案误导
- 功能不完整
- 移动端适配
- 文档缺失

**处理流程：**
1. 记录问题
2. 准备修复代码
3. 测试验证
4. 等待用户测试结束
5. 统一发版部署

**响应时间：** 24 小时内  
**修复时间：** 1-3 天

### P2 - Beta 后必须做（Medium）

**定义：** 功能完善，不影响 Beta 测试

**示例：**
- 新奖励权益实现
- 权限审计日志
- 内容中心后台化
- CI 自动测试
- Schema 拆分

**处理流程：**
1. 记录需求
2. 设计文档
3. 等待 Beta 结束
4. 排期开发

**响应时间：** Beta 结束后  
**修复时间：** 根据排期

## Bug 分流决策树

```
用户报告 Bug
    ↓
是否影响核心功能？
    ├─ 是 → P0
    │       ↓
    │   是否需要立即 hotfix？
    │       ├─ 是 → 立即修复
    │       └─ 否 → 记录，等待统一发版
    │
    └─ 否 → 是否影响用户体验？
            ├─ 是 → P1
            │       ↓
            │   Beta 前能修复吗？
            │       ├─ 是 → 准备修复，等待统一发版
            │       └─ 否 → 记录，Beta 后修复
            │
            └─ 否 → P2
                    ↓
                记录需求，排期开发
```

## Bug 状态定义

| 状态 | 说明 |
|------|------|
| 待处理 | 已记录，未开始处理 |
| 处理中 | 正在修复 |
| 已修复 | 代码已修复，待验证 |
| 已验证 | 用户或测试已验证 |
| 已关闭 | 确认无问题，关闭 |
| 已拒绝 | 不是 bug 或暂不修复 |

## Bug 验收方式

### 用户验收

**适用场景：**
- 用户报告的问题
- 影响用户体验的问题
- 需要真实场景验证的问题

**验收流程：**
1. 修复代码
2. 部署到测试环境
3. 通知用户验证
4. 用户确认修复
5. 关闭 bug

### 自动化测试

**适用场景：**
- 可自动化的测试场景
- 回归测试
- 性能测试

**验收流程：**
1. 修复代码
2. 编写自动化测试
3. 运行测试
4. 测试通过
5. 关闭 bug

### 人工验证

**适用场景：**
- 无法自动化的测试场景
- 需要人工判断的问题
- UI/UX 问题

**验收流程：**
1. 修复代码
2. 人工验证
3. 验证通过
4. 关闭 bug

## Bug 归档

### 归档条件

- Bug 状态为"已关闭"
- 用户确认修复
- 测试验证通过

### 归档内容

- Bug 报告
- 修复代码
- 测试证据
- 验收记录

### 归档位置

```
reports/bugs/
  └── BUG-20260621-001/
      ├── report.md
      ├── fix.patch
      ├── test-results.md
      └── acceptance.md
```
