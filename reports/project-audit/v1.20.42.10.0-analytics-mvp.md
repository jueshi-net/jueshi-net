## 五、采集 API 清单

### 增强的事件接收 API

**文件**: `src/app/api/events/route.ts`

**新增功能**:
1. **Rate Limit** - 每分钟最多 100 次/IP
2. **Body Size 限制** - 最大 10KB
3. **Bot 过滤** - 检测并丢弃 bot 请求
4. **User-Agent 解析** - 设备类型、浏览器、OS
5. **Referrer 解析** - 提取来源域名
6. **UTM 解析** - 从 URL 提取 UTM 参数
7. **IP 匿名化** - 只存 SHA-256 哈希（前 16 位）
8. **事件类型白名单** - 验证事件类型合法性
9. **Metadata 清理** - 移除敏感信息，只允许安全字段
10. **用户关联** - 自动关联登录用户 userId

**支持的事件类型**:
- 访问统计: `page_view`, `session_start`, `session_heartbeat`, `page_exit`
- 工具使用: `tool_view`, `tool_click`, `tool_start`, `tool_calculate`, `tool_success`, `tool_error`, `tool_save`, `tool_copy`, `tool_export`, `tool_query`, `tool_favorite`
- 资源: `resource_click`, `search_submit`
- 转化: `signup_start`, `signup_success`, `login_success`, `password_reset_request`, `feedback_submit`, `invite_register_success`
- 其他: `article_click`, `memo_action`, `checklist_view`, `community_*`

## 十一、隐私与 IP 匿名化说明

### IP 匿名化策略

**实现**:
- 提取真实 IP（支持 x-forwarded-for、x-real-ip、cf-connecting-ip）
- 使用 SHA-256 哈希
- 只存储前 16 位（`ipHash` 字段）
- **不存储明文 IP**

### Metadata 白名单

**允许的字段**:
- `itemCount`, `hasWeight`, `hasRate`, `formulaType`
- `success`, `errorCode`, `carrier`, `trackingNumberHash`
- `resultStatus`, `country`, `queryType`, `resultCount`
- `resourceId`, `category`, `queryLength`
- `slug`, `toolSlug`, `checklistSlug`, `sourcePath`

**禁止的字段**:
- 完整地址、电话、邮箱、身份证
- 物流单号明文
- 用户密码、token、session cookie
- 完整 Authorization header

### 数据保留建议

- **原始事件**: 保留 90-180 天
- **聚合数据**: 长期保存
- **后续方案**: 定期清理老数据（可手动执行 SQL）
