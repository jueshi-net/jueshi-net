### 三类 Payload Schema

**Checklist Schema**:
```json
{
  "title": "string",
  "slug": "string",
  "summary": "string",
  "steps": [
    { "title": "string", "description": "string", "optional": "boolean", "toolLink": "string" }
  ],
  "metadataJson": {
    "contentOps": {
      "primaryKeyword": "string",
      "secondaryKeywords": ["string"],
      "seo": {
        "metaKeywords": "string",
        "searchIntent": "string",
        "targetAudience": "string",
        "audienceStage": "string",
        "targetCountries": ["string"],
        "targetSearchEngines": ["string"]
      },
      "qualityScore": "number",
      "faq": [{ "question": "string", "answer": "string" }],
      "internalLinks": [{ "slug": "string", "title": "string", "reason": "string" }]
    }
  }
}
```

**Guide Schema**: 类似 checklist，但使用 body 而不是 steps  
**Topic Schema**: 类似 checklist，但包含 items 和 sections

## 用户下一步

### 用一句自然语言创建第二篇草稿

**示例**:
```
请帮我创建一篇关于"美国留学行前准备清单"的内容。

目标用户：准留学生和留学生家长
目标国家：美国
受众阶段：准备出国阶段
```

**Hermes 会自动**:
1. 判断类型：checklist
2. 生成 payload（包含完整 SEO/GEO 字段）
3. 验证 payload
4. 输出 dry-run 摘要
5. 在 production 创建 draft
6. 返回 draftId 和编辑链接

**用户操作**:
1. 登录后台: https://jueshi.net/admin/content/checklists
2. 找到新创建的 draft
3. 点击编辑
4. 审核内容
5. 手动发布
