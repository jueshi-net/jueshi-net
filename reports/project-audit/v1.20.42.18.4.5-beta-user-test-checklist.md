## 二、跨境发货任务链

### B1. 新建发货任务

- [ ] 进入任务链页面
- [ ] 点击"新建发货任务"按钮
- [ ] 输入任务标题（如：测试任务-保温杯）
- [ ] 点击创建
- [ ] 验证成功创建并跳转到任务详情

**预期结果：**
- 成功创建任务
- 跳转到任务详情页
- 任务标题显示正确

---

### B2. 填商品信息

- [ ] 在任务详情页找到"商品信息"步骤
- [ ] 输入商品名称（如：Stainless Steel Vacuum Bottle）
- [ ] 输入商品描述（如：Vacuum flasks）
- [ ] 输入数量（如：100）
- [ ] 输入单价（如：10）
- [ ] 点击保存
- [ ] 验证数据保存成功

**预期结果：**
- 商品信息保存成功
- 刷新页面后数据仍在

---

### B3. 从 HS 工具加入任务链
