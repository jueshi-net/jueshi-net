## 2. 印章生成器实现方式

印章生成器使用 **SVG + textPath** 技术：

- **组件**: `src/lib/template-studio/seal-generator.tsx` (183 行)
- **SVG viewBox**: `0 0 120 120` (120×120 像素，可缩放)
- **外圈**: `<circle r="54" stroke-width="2.5">` — 实线圆环
- **内圈**: `<circle r="50" stroke-width="1">` — 细线内环
- **顶部弧线**: SVG `<path>` 定义弧形路径，`<textPath>` 将公司名沿弧线排列
  - 路径: `M 18,62 A 44,44 0 0,1 102,62` (从左到右沿上半圆)
  - `startOffset="50%"` + `textAnchor="middle"` 居中
- **底部弧线**: 反向弧形路径
  - 路径: `M 24,62 A 38,38 0 0,0 96,62` (从左到右沿下半圆)
- **中心**: `<text x="60" y="64" textAnchor="middle" dominantBaseline="middle">` 放置星号或缩写
- **装饰线**: 中心文字下方水平线

### 字体自动缩放

```typescript
function calcTopFontSize(text, maxFontSize=11, arcLength=95) {
  const charWidth = 0.55;
  const neededLength = text.length * charWidth * maxFontSize;
  if (neededLength <= arcLength) return maxFontSize;
  return Math.max(5, arcLength / (text.length * charWidth));
}
```

- 顶部弧线长度 ≈ 95 SVG 单位
- 底部弧线长度 ≈ 72 SVG 单位
- 长公司名自动缩小字号，最小 5px，**不裁切**

## 3. SVG/textPath 安全策略

| 安全措施 | 实现方式 |
|----------|----------|
| 文本渲染 | React JSX `<textPath>{safeTop}</textPath>` — React 自动转义 |
| 无 dangerouslySetInnerHTML | 印章组件不使用任何 innerHTML |
| 控制字符过滤 | `sanitizeSealText()` 移除 `\x00-\x1F` 和 `\x7F` |
| 长度限制 | 顶部 50 字符，底部 20 字符，中心 6 字符 |
| SVG 命名空间 | React 的 JSX 使用标准 SVG 命名空间，防止 namespace confusion |
| XSS 验证 | 审计测试 TS-SEAL-SVG-SECURITY: 注入 `<script>alert("xss")</script>` → 渲染为纯文本，无新 script DOM 元素 |

## 18. PARTIAL 原因

判定为 `PARTIAL_READY_FOR_REVIEW` 而非 `READY` 的原因：
- SVG textPath 在 html2canvas (PNG 导出) 中的兼容性需要用户在实际浏览器中确认
- 印章颜色用户自定义的 color picker 在不同浏览器中的外观需要确认
- 长公司名 (50+ 字符) 的极端情况需要用户视觉确认
- 这些都是浏览器渲染差异，需要真实用户在 staging 环境视觉审核后才能升级为 READY
