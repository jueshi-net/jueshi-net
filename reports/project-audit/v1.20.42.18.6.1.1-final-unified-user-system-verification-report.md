## 社区与网站用户体系一体化说明

### 1. 是否复用现有 User 表？

**是。** 社区论坛完全复用现有 `User` 模型，不创建任何独立论坛用户表。

### 2. 是否创建独立论坛用户？

**否。** 不存在 `ForumUser`、`CommunityUser`、`ForumAccount` 等独立用户模型。全仓库搜索 0 匹配。

### 3. 是否创建独立论坛登录？

**否。** 不存在 `/forum/login`、`/community/login`、`/forum/register`、`/community/register` 页面。所有认证通过现有 `requireAuth()` / `requireAdmin()`（来自 `@/lib/auth-guard`）。

### 4. ForumPost 如何关联用户？

`ForumPost.userId` → `User.id`，外键 `@relation(fields: [userId], references: [id], onDelete: Cascade)`。字段名为 `userId`（非 `authorId`），功能等价。

### 5. ForumComment 如何关联用户？

`ForumComment.userId` → `User.id`，外键 `@relation(fields: [userId], references: [id], onDelete: Cascade)`。

### 6. 荣誉值如何关联用户？

`HonorLog.userId` → `User.id`，外键 `@relation(fields: [userId], references: [id], onDelete: Cascade)`。`User.honorScore` 是 User 表的扩展字段（`Int @default(0)`），不是独立表。

### 7. 勋章如何关联用户？

`UserBadgeAward.userId` → `User.id`，外键 `@relation(fields: [userId], references: [id], onDelete: Cascade)`。`UserBadgeAward.badgeId` → `UserBadge.id`（勋章定义表）。`UserBadge` 不代表用户，仅存储勋章定义（key, name, icon, color 等）。

### 8. 注册时间从哪里来？

`User.createdAt`（DateTime，不可手动伪造）。公开资料页 `/u/[id]` 通过 `getUserCommunityInfo()` 读取 `User.createdAt`，展示精度可通过 `UserCommunityProfile.joinedAtDisplayMode` 配置（date/month/year/hidden）。

### 9. 积分从哪里来？

`User.points`（Int）。积分是可消费资产，通过 `PointLedger` 记录变动。积分余额**不公开**，仅在本人查看自己页面时显示。

### 10. 成长值从哪里来？

`User.growthValue`（Int）。成长值是等级经验，不可消费，通过 `GrowthLog` 记录变动。来自签到、任务、发帖、回帖、工具使用。公开显示。

### 11. 会员状态从哪里来？

`User.membershipTier`（String: free/member/premium/enterprise）+ `User.memberUntil`（DateTime）。来自现有会员系统，社区不修改这两个字段。

### 12. 管理员权限从哪里来？

`User.role === "admin"`。社区管理 API 通过 `requireAdmin()` 验证（来自 `@/lib/auth-guard`），该函数调用 `requireAuth()` 检查 NextAuth session 并验证 `role === "admin"`。社区不创建独立的管理员角色。

### 13. 如何保护用户隐私？

- API `/api/community/user/[id]` 不返回 email、password、points、phone
- `UserTrustCard` 组件不引用 `user.email`、`user.password`
- 积分余额仅在 `isOwnProfile === true` 时显示
- `UserCommunityProfile.isPublic` 可隐藏整个资料
- 注册时间精度可配置（date/month/year/hidden）

### 14. 如何避免 role/membership/honor 混淆？

| 概念 | 字段 | 表 | 可消费？ | 来源 |
|------|------|-----|---------|------|
| 角色 | User.role | users | 否 | NextAuth 注册 |
| 会员 | User.membershipTier | users | 否 | 会员系统 |
| 积分 | User.points | users + point_ledgers | ✅ 是 | 签到/任务/兑换 |
| 成长值 | User.growthValue | users + growth_logs | ❌ 否 | 签到/任务/发帖 |
| 荣誉值 | User.honorScore | users + honor_logs | ❌ 否 | 被采纳/加精/举报 |
| 等级 | User.levelKey | users + user_levels | ❌ 否 | growthValue 计算 |
| 勋章 | UserBadgeAward | user_badge_awards | ❌ 否 | 自动/手动授予 |

- `adjustHonor()` 仅在 admin API 调用
- `requireAdmin()` 阻止普通用户修改荣誉/勋章
- 管理员身份不自动展示为社区荣誉（需显式标记）
- 违规用户不会展示为高信誉（violationCount 影响荣誉值）
