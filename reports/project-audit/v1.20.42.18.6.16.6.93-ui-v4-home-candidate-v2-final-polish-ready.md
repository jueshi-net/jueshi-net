## 三、修复说明

### 1. Footer Logo 白块修复 ✅

**问题：** Footer 左侧 Logo 显示为白色空块

**原因：** 使用 CSS `brightness-0 invert` 滤镜在深色背景上显示白色 Logo，但滤镜效果不稳定

**解决方案：**
- 移除 CSS 滤镜
- 使用白底圆角容器包裹 Logo
- 确保 Logo 在深色背景上清晰可见

**Logo 文件路径：** `/images/brand/jueshi-logo-crab.jpg`

**代码变更：**
```tsx
// Before
<Image
  src="/images/brand/jueshi-logo-crab.jpg"
  className="h-[38px] w-auto object-contain brightness-0 invert"
/>

// After
<div className="inline-flex items-center justify-center bg-white rounded-lg px-3 py-2 shadow-sm">
  <Image
    src="/images/brand/jueshi-logo-crab.jpg"
    className="h-[32px] w-auto object-contain"
  />
</div>
```

### 2. Header 响应式优化 ✅

**问题：** iPad / 1024-1366 宽度下 Header 元素拥挤

**解决方案：**
- 将导航项分为 `core` 和 `extended` 两类
- `lg` 断点（1024px+）：只显示核心导航（首页/工具/清单/指南/资源）
- `2xl` 断点（1536px+）：显示全部导航（包括专题/社区）
- 减少导航项内边距（`px-4` → `px-3`）

**导航项分类：**
```tsx
const navItems = [
  { id: 'home', label: '首页', priority: 'core' },
  { id: 'tools', label: '工具', priority: 'core' },
  { id: 'checklist', label: '清单', priority: 'core' },
  { id: 'guides', label: '指南', priority: 'core' },
  { id: 'topics', label: '专题', priority: 'extended' },
  { id: 'resources', label: '资源', priority: 'core' },
  { id: 'community', label: '社区', priority: 'extended' },
];
```

### 3. Hero 标题断行修复 ✅

**问题：** 标题可能断成"海外华人的 / 实用工具箱"，不美观

**解决方案：**
- 移除"的"字
- 改为"海外华人实用工具箱"
- 确保关键词"实用工具箱"保持完整

**代码变更：**
```tsx
// Before
<h1>海外华人的<span>实用工具箱</span></h1>

// After
<h1>海外华人<span>实用工具箱</span></h1>
```

### 4. Hero 面板融合度优化 ✅

**问题：** 右侧面板像独立弹窗，与 Hero 背景融合度不够

**解决方案：**
- 减轻阴影（`shadow-xl` → `shadow-lg`）
- 使用更透明背景（`bg-white/90` → `bg-white/80`）
- 增强毛玻璃效果（`backdrop-blur-sm` → `backdrop-blur-md`）
- 淡化边框（`border-[#E8ECF3]` → `border-[#E8ECF3]/60`）

### 5. 工作台模块压缩 ✅

**问题：** 工作台模块过重，像完整 Dashboard

**解决方案：**
- 勋章数量从 6 个减少到 4 个
- 保留"查看全部"链接
- 整体高度压缩 15%-25%

**代码变更：**
```tsx
// Before
{user.badges.slice(0, 6).map(...)}

// After
{user.badges.slice(0, 4).map(...)}
```

### 6. 高频工具主次层级 ✅

**问题：** 所有工具卡片过于平均，没有主次

**解决方案：**
- 前 4 个核心工具（运费计算器、HS编码查询、汇率换算、邮编查询）为重点
- 后 4 个（发票生成、地址格式化、报价单、集装箱尺寸）为普通卡
- 重点卡：更大的图标（`w-12 h-12`）、更完整的描述（`line-clamp-2`）、更强的阴影
- 普通卡：更小的图标（`w-10 h-10`）、更简洁的描述（`line-clamp-1`）、更轻的阴影

**代码变更：**
```tsx
const isPrimary = index < 4; // 前 4 个为核心工具

<div className={`... ${isPrimary ? 'w-12 h-12' : 'w-10 h-10'}`}>
  <Icon className={`... ${isPrimary ? 'w-6 h-6' : 'w-5 h-5'}`} />
</div>

<h3 className={`... ${isPrimary ? 'text-sm' : 'text-xs'}`}>
<p className={`... ${isPrimary ? 'text-xs line-clamp-2' : 'text-[11px] line-clamp-1'}`}>
```

### 7. 任务链按钮降噪 ✅

**问题：** 每张任务链都有大渐变按钮，视觉重复

**解决方案：**
- 前 2 个核心任务链保留强按钮（渐变背景）
- 其他任务链使用轻按钮（灰色背景）
- 统一按钮高度，减少视觉噪音

**代码变更：**
```tsx
const isPrimary = index < 2; // 前 2 个为核心任务链

{isPrimary ? (
  <button className="... bg-gradient-to-r from-[#6C5DD3] to-[#3F8CFF] ...">
    <Zap /> 开始任务
  </button>
) : (
  <button className="... bg-[#F3F5FA] text-[#6C5DD3] ...">
    <ArrowRight /> 查看详情
  </button>
)}
```
