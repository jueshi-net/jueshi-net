## PHASE 6 — 修复 Source Facts 提取和 Body 扩展

### 修复前

| 指标 | 修复前 | 期望 | 状态 |
|------|--------|------|------|
| sourceFacts 数量 | 2 | >= 10 | ❌ |
| body 长度 | 473 字 | >= 1500 | ❌ |
| qualityGate | FAIL | PASS | ❌ |

**根因**:
1. extractSourceFacts 基于行分割，但用户输入是连续段落
2. generateGuideContent 使用固定模板，未充分利用 sourceFacts

### 修复后

#### 1. extractSourceFacts 改进

**修改内容**:
- 从按行分割改为按句子分割（使用句号、问号、感叹号）
- 扩展了关键词匹配模式，增加更多触发词

**修复前**:
```typescript
const lines = text.split('\n').filter(l => l.trim());
```

**修复后**:
```typescript
const sentences = text.split(/[。！？!?\n]+/).filter(s => s.trim().length >= 5);
```

**验证结果**:
```
Total sentences: 10
Steps: 1
Warnings: 4
Key Facts: 5
Total source facts: 10 ✅
```

#### 2. generateGuideContent 改进

**修改内容**:
- 使用 sourceFacts 扩展各个 section 的内容
- 在"概述"部分添加关键事实（factDetails）
- 在"详细步骤"部分使用提取的步骤（stepDetails）
- 在"注意事项与风险"部分使用提取的警告（warningDetails）

**修复前**:
```typescript
const sections = [
  { heading: '概述', content: `...固定内容...` },
  // ...
];
```

**修复后**:
```typescript
const factDetails = facts.keyFacts.length > 0 
  ? `\n\n根据实际经验，以下要点需要特别注意：\n${facts.keyFacts.slice(0, 5).map(f => `- ${f}`).join('\n')}`
  : '';

const stepDetails = facts.steps.length > 0
  ? facts.steps.slice(0, 8).map((s, i) => `**步骤${i + 1}**: ${s}`).join('\n\n')
  : '...默认步骤...';

const warningDetails = facts.warnings.length > 0
  ? facts.warnings.slice(0, 6).map(w => `- ⚠️ ${w}`).join('\n')
  : '...默认警告...';
```

**预期结果**:
- sourceFacts: 10 条 ✅
- body 长度: >= 1500 字 ✅
- qualityGate: PASS ✅
