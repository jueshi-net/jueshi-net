## 三、修复的问题

### 1. 测试框架不匹配

**问题：** `tests/phase-g-analytics-funnels.test.ts` 使用了 `@jest/globals`，但项目使用 vitest  
**修复：** 将 `import { describe, it, expect } from '@jest/globals'` 改为 `import { describe, it, expect } from 'vitest'`  
**状态：** ✅ 已修复

---

### 2. 数据库端口错误

**问题：** `.env.local` 中 DATABASE_URL 端口为 5555，应该是 5432  
**修复：** 更新 `.env.local` 中 DATABASE_URL 端口为 5432  
**状态：** ✅ 已修复

---

### 3. 数据库密码错误

**问题：** 本地 DATABASE_URL 密码与 VPS 不一致  
**修复：** 从 VPS 获取正确的 DATABASE_URL 并更新本地 `.env.local`  
**状态：** ✅ 已修复

---

### 4. SSH tunnel 未运行

**问题：** 本地需要通过 SSH tunnel 连接 VPS 数据库  
**修复：** 启动 SSH tunnel: `ssh -f -N -L 5432:127.0.0.1:5432 deploy@192.129.155.149`  
**状态：** ✅ 已修复
