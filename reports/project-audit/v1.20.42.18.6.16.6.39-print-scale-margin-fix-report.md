## Executive Summary

**Issue Resolved:** Print output no longer shrinks and shows excessive white margins.

**Root Cause:** The print iframe was cloning canvas pages with scaled preview dimensions instead of unscaled print dimensions, causing the printed content to appear smaller than the design canvas.

**Solution:** Modified the print handler to extract and use the unscaled print-only content (`canvas-print-unscaled-paper`) instead of the scaled preview wrapper.

---

## Problem Analysis

### User-Reported Symptoms

1. **Print output smaller than design canvas** — content appeared shrunk
2. **Excessive white margins** — large blank areas around printed content
3. **Print preview didn't match design** — what you see is NOT what you get

### Technical Root Cause

The canvas editor has a dual-render architecture:

```tsx
// Outer wrapper: Scaled dimensions (for screen preview)
<div style={{ width: scaledWidth, height: scaledHeight }}>
  
  // Inner div: Unscaled dimensions (for print)
  <div className="hidden print:block" 
       style={{ width: unscaledWidth, height: unscaledHeight }}>
    {/* Actual canvas content */}
  </div>
  
  // Screen-only version
  <div className="print:hidden">
    {/* Scaled preview content */}
  </div>
</div>
```

**The Bug:** The `handlePrint` function was cloning the outer wrapper (with scaled dimensions) instead of extracting the inner unscaled div. This caused:

1. Cloned elements had `width: scaledWidth` (e.g., 794px for A4 at 75% scale)
2. Print iframe rendered these scaled-dimension elements
3. Browser print engine tried to fit 794px content onto 210mm paper
4. Result: Content appeared smaller with white margins

## The Fix

### Code Changes

**File:** `src/app/(public)/tools/template-studio/canvas-editor-full.tsx`

#### Change 1: Extract Unscaled Print Content

**Before:**
```typescript
const pages = printRoot.querySelectorAll("[data-testid=\"canvas-print-page\"], [data-testid=\"canvas-paper\"]");
let pagesHTML = "";
pages.forEach((page) => {
  const clone = page.cloneNode(true) as HTMLElement;
  // ... remove UI elements
  pagesHTML += clone.outerHTML;  // ❌ Clones scaled wrapper
});
```

**After:**
```typescript
const pages = printRoot.querySelectorAll("[data-testid=\"canvas-print-page\"], [data-testid=\"canvas-paper\"]");
let pagesHTML = "";
pages.forEach((page) => {
  // ✅ Find the unscaled print-only div inside this page
  const unscaledDiv = page.querySelector("[data-testid=\"canvas-print-unscaled-paper\"]");
  
  if (unscaledDiv) {
    // ✅ Use the unscaled content
    const clone = unscaledDiv.cloneNode(true) as HTMLElement;
    // ... remove UI elements
    pagesHTML += `<div class="print-page-wrapper" style="position: relative; width: ${printPaperDimensions.width}px; height: ${printPaperDimensions.height}px;">${clone.outerHTML}</div>`;
  } else {
    // Fallback: use the page itself but reset dimensions
    const clone = page.cloneNode(true) as HTMLElement;
    clone.style.width = `${printPaperDimensions.width}px`;
    clone.style.height = `${printPaperDimensions.height}px`;
    clone.style.transform = "none";
    pagesHTML += clone.outerHTML;
  }
});
```

#### Change 2: Update iframe CSS for Print Page Wrappers

**Before:**
```css
[data-testid="canvas-print-page"],
[data-testid="canvas-paper"] {
  page-break-after: always;
}
```

**After:**
```css
.print-page-wrapper {
  position: relative !important;
  page-break-after: always;
  break-after: page;
}
.print-page-wrapper:last-child {
  page-break-after: auto !important;
  break-after: auto !important;
}
[data-testid="canvas-print-unscaled-paper"] {
  position: absolute !important;
  top: 0 !important;
  left: 0 !important;
  right: 0 !important;
  bottom: 0 !important;
}
```

#### Change 3: Enhanced Print Tip Message

**Before:**
```
💡 打印提示：在打印设置中选择"无边距"或"实际大小"以获得最佳效果
```

**After:**
```
💡 打印提示：如果打印预览仍有白边，请在浏览器打印设置中选择：边距=无，缩放=100% 或实际大小。
```

## Technical Details

### Print Architecture (After Fix)

```
1. User clicks "打印" button
   ↓
2. handlePrint() executes
   ↓
3. Find all canvas pages (canvas-print-page / canvas-paper)
   ↓
4. For each page:
   a. Find inner unscaled div (canvas-print-unscaled-paper)
   b. Clone the unscaled div (not the scaled wrapper)
   c. Remove UI elements (grid, resize handles, edit buttons)
   d. Wrap in print-page-wrapper with correct dimensions
   ↓
5. Create hidden iframe
   ↓
6. Inject HTML with:
   - @page { size: Wmm Hmm; margin: 0; }
   - html, body { margin: 0; padding: 0; }
   - .print-page-wrapper { page-break-after: always; }
   - Cloned unscaled content
   ↓
7. Wait for stylesheets to load
   ↓
8. Trigger iframe.contentWindow.print()
   ↓
9. Browser print dialog opens with correct dimensions
```

### Dimension Calculations

**Screen Preview (Scaled):**
```typescript
const scale = calculateScale(containerWidth, containerHeight, paperWidth, paperHeight);
const paperDimensions = {
  width: paperWidthMm * 3.7795 * scale,  // e.g., 794px at 75% scale
  height: paperHeightMm * 3.7795 * scale  // e.g., 1123px at 75% scale
};
```

**Print Output (Unscaled):**
```typescript
const printPaperDimensions = {
  width: mmToPx(paperWidthMm),   // e.g., 794px for A4 (210mm)
  height: mmToPx(paperHeightMm)  // e.g., 1123px for A4 (297mm)
};
```

**Key Insight:** The print dimensions use `mmToPx()` without scale factor, ensuring 1:1 mapping between mm and pixels at 96 DPI.

## Known Limitations

1. **Browser Print Settings Required:** Users must manually set margins=none and scale=100% in their browser's print dialog. The code cannot override these settings programmatically.

2. **Printer Driver Variations:** Different printers may add their own margins. This is outside the web application's control.

3. **PDF Export:** This fix is for browser print dialog only. PDF export (via "Print to PDF") should also work correctly with the same settings.
