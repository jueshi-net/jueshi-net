## 5. Document Runtime 架构

**核心设计**：统一底座 + 自由模板

```
Capability Layer (统一底座)     Template Layer (自由模板)
├── Company Adapter             ├── StandardDocumentTemplate
├── Product Adapter             ├── CustomFormShell
├── Draft Adapter               ├── LabelPrintTemplate
├── Export Adapter              ├── ScriptGeneratorTemplate
├── Entitlement Adapter         ├── User Custom Templates
├── Audit Adapter               └── Enterprise Templates
├── Chain Adapter
└── BBS/Content Adapter
         ↓                              ↓
         └──────────┬───────────────────┘
                    ▼
           Tool Runtime (运行时协调)
```

**架构文档**: `docs/DOCUMENT_TEMPLATE_RUNTIME_ARCHITECTURE.md`

## 8. 定制模板安全方案

**文档**: `docs/CUSTOM_FORM_TEMPLATE_SANDBOX_SPEC.md`

| 规则 | 实现 |
|------|------|
| ❌ 禁止任意 JS | 模板 JSON 配置，无代码执行 |
| ✅ 允许变量绑定 | 白名单变量，`{{}}` 语法 |
| ✅ 允许有限 CSS | 白名单 design tokens |
| ✅ 允许官方 block | 10 种预定义安全组件 |
| ❌ 禁止访问 cookie/session | 变量白名单排除 |
| ❌ 禁止网络请求 | 无 fetch/XHR 能力 |
| ✅ XSS 防护 | 全局转义 + 标签移除 |
| ✅ 文件上传限制 | 类型+大小+内容扫描 |
| ✅ 模板版本化 | 版本号+状态机 |
| ✅ 审核机制 | 自动扫描+人工审核 |
