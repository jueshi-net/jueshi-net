# v1.20.42.7.00 后台联动与广告后台化审计报告

**日期**: 2026-06-16
**状态**: ✅ 审计完成（本版本不开发）

## 已有后台管理能力

| 管理页面 | 路径 | 能力 |
|----------|------|------|
| 广告管理 | /admin/ads | 完整 CRUD，支持 DIRECT/NETWORK 类型，国家定向，多广告位 |
| 广告位管理 | /admin/ad-placements | CRUD 广告位位置，页面类型，区域，设备定向 |
| 文章管理 | /admin/cms | Markdown 编辑器，分类标签，SEO，发布流程 |
| 落地页管理 | /admin/landing-pages | 多类型页面，结构化清单编辑器，SEO |
| 系统设置 | /admin/settings | 站点名称/描述，注册开关，维护模式，Logo |
| 工具管理 | DB Tool 表 | 工具列表（通过 Prisma） |
| 首页配置 | HomepageConfig 表 | maxDisplay，广告位开关 |

## 已动态化的内容

## 后续后台化路线图

### Phase 1（无需 migration）
- Footer 链接 → 复用 Settings JSON 字段
- Promo/Premium 文案 → 复用 Settings
- Partner logos → 复用 Settings JSON

### Phase 2（需 migration）
- Hero 搜索 TAB/标签 → 新增 HomepageConfig JSON 字段
- Category cards → 新增 CategoryConfig 表或 JSON
- Workflow path → 新增 HomepageConfig JSON 字段

### Phase 3（需 migration）
- Identity cards → 新增 AudienceConfig 表

- Quick tools → 新增 Tool.featured 字段
