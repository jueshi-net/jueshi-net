## 优先级矩阵

```
紧急 + 重要 → 一期 (v18.6.1)
  - 基础发帖/回帖
  - 安全防护
  - Admin 管理

重要 不紧急 → 二期 (v18.6.2)
  - 通知系统
  - 用户主页
  - Markdown

紧急 不重要 → 快速迭代
  - 敏感词配置
  - 频率限制调优

不重要 不紧急 → 三期 (v18.6.3)
  - 推荐流
  - 专家认证
  - 多语言
```

## v18.6.1 推荐实施范围

### 必须实施
1. 社区首页 + 分类页 + 帖子详情页 + 发帖页
2. 点赞 + 举报 + 收藏
3. Admin 管理面板 + 举报审核
4. 频率限制 + 敏感词
5. 回复通知
6. 工具/指南相关讨论

### 可选实施（如时间允许）
- 标签系统
- 精华帖
- SEO 结构化数据

### 不建议一期实施
- Markdown 渲染（增加 XSS 风险面）
- 图片上传（增加存储和安全复杂度）
- 实时通知（SSE 增加服务器负载）
- 推荐流（数据量不足）
