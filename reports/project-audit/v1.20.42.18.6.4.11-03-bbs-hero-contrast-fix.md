# v1.20.42.18.6.4.11-03 — BBS Hero Contrast Fix

## Root Cause

BBS pages used `text-brand-light/80` for description text on a `bg-gradient-to-br from-brand via-brand-light to-accent` background. Since `brand-light` is part of the gradient, text in `text-brand-light/80` was nearly invisible where the gradient passed through `brand-light`.

## Files Fixed

### `/bbs` (page.tsx)
- `text-brand-light/80` → `text-white/80` (hero description)

### `/bbs/new` (new/page.tsx)
- `text-brand-light` → `text-white/80` (back link)
- `text-brand-light` → `text-white/90` (badge text)
- `text-brand-light/80` → `text-white/80` (description)

### `/bbs/[slug]` (topic page)
- No `text-brand-light` found — already uses `text-brand` on light backgrounds (good contrast)

## Contrast Verification

| Element | Old Color | New Color | Background | Contrast |
|---------|-----------|-----------|------------|----------|
| Hero description | brand-light/80 | white/80 | dark gradient | ✅ Clear |
| Back link | brand-light | white/80 | dark gradient | ✅ Clear |
| Badge text | brand-light | white/90 | white/15 blur | ✅ Clear |
