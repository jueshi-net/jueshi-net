## 根因修复

### Bug 1: API `country || 'US'` 默认值
- 马来西亚邮编 50000 被当美国邮编搜索 → 返回美国结果
- 修复: 移除 US 默认值，改为国家隔离查询

### Bug 2: `detectCountryFromPostal` 忽略用户选择
- 5位数字邮编被猜测为美国 → 返回美国结果
- 修复: 用户已选国家时跳过格式猜测

### Bug 3: 客户端只查静态映射不查真实数据库
- 邮编查询走 region search（静态城市映射）而非 DB search
- 修复: 邮编查询同时触发 DB search + region search
