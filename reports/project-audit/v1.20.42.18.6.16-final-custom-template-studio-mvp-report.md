## 1. v18.6.15 Demo 产品缺口

v18.6.15 的 Document Runtime 架构仅实现了 Demo 页面和类型注册，缺少：
- 用户可操作的模板编辑器
- 真实数据绑定（公司/商品/单据字段）
- 保存/重新打开功能
- 安全渲染（仅文档方案，无运行时实现）
- 导出能力

v18.6.16 Template Studio MVP 填补了上述全部缺口。

## 11. 已知限制

1. **WORD_TEMPLATE_EXPORT_NEXT** — Word 导出仍使用现有 generate-docx，未集成模板配置。下版本将实现模板化 Word 导出。
2. **localStorage 存储** — 用户模板存储在浏览器 localStorage，不跨设备同步。需 DB schema 支持后迁移到服务端。
3. **无自定义 CSS 编辑器** — 模板不支持用户自定义 CSS（安全优先，白名单已就绪但 UI 未开放）。
4. **3 个官方模板** — 仅覆盖报价单/商业发票/供应链报价单。后续增加入库单/交接单/标签等。
