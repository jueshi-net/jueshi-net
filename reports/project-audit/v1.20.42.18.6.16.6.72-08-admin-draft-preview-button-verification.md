## Known Limitations

1. **Preview Authentication:**
   - Currently, anyone with the preview URL can access draft content
   - Future enhancement: Add admin session check for preview access
   - Mitigation: Preview URLs are not discoverable (not in sitemap, not in public pages)

2. **Preview Button Visibility:**
   - Button only shows when status=draft
   - If user changes status to "published" in the form, button disappears
   - User must save first, then button will reappear if status is still draft
