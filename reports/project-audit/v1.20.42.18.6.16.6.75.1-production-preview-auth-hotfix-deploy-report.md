## PHASE 9 — API E2E 认证问题处理计划

### 当前状态

**API E2E 测试被阻止**: Admin API 需要认证，无法通过 curl 获取 session cookie

**根因**: NextAuth session cookie 受 secure flag 保护，需要浏览器环境

### 下一步方案

#### 方案 A: 服务器内受控 CLI Draft Creator（推荐）

**脚本位置**: `scripts/create-contentops-draft.ts`

**安全特性**:
- ✅ 权限校验：需要 CONTENTOPS_CLI_SECRET 环境变量
- ✅ 审计日志：所有操作记录到 logs/contentops-draft-creation.log
- ✅ 输入验证：检查必填字段
- ✅ 不输出 secret：只在服务器本地使用

**使用方式**:
```bash
ssh jueshi-new
cd /home/deploy/xixiong-saas
export CONTENTOPS_CLI_SECRET="***"
echo '{"title":"...","slug":"...","metadataJson":{...}}' > /tmp/draft.json
npx ts-node scripts/create-contentops-draft.ts /tmp/draft.json
```

#### 方案 B: Admin-Only Server Action

**路由**: `src/app/api/admin/internal/create-draft/route.ts`

**安全特性**:
- ✅ 权限校验：只接受 localhost 请求
- ✅ 审计日志：记录 IP 和操作
- ✅ 输入验证：检查必填字段
- ✅ 不暴露到外网：只能通过 localhost 访问

**使用方式**:
```bash
ssh jueshi-new
curl -X POST http://localhost:3000/api/admin/internal/create-draft \
  -H "Content-Type: application/json" \
  -d '{"title":"...","slug":"...","metadataJson":{...}}'
```

#### 方案 C: Signed Internal Job Endpoint

**路由**: `src/app/api/admin/jobs/create-draft/route.ts`

**安全特性**:
- ✅ 权限校验：HMAC 签名验证
- ✅ 审计日志：记录所有操作
- ✅ 输入验证：检查必填字段
- ✅ 防篡改：签名验证确保 payload 未被修改

**使用方式**:
```bash
# 本地生成签名
JOB_SECRET="***"
PAYLOAD='{"title":"...","slug":"...","metadataJson":{...}}'
SIGNATURE=$(echo -n "$PAYLOAD" | openssl dgst -sha256 -hmac "$JOB_SECRET" | awk '{print $2}')

# Production 调用
curl -X POST https://jueshi.net/api/admin/jobs/create-draft \
  -H "Content-Type: application/json" \
  -H "x-job-signature: $SIGNATURE" \
  -d "$PAYLOAD"
```

**推荐**: 方案 A（CLI Script）最适合当前场景
