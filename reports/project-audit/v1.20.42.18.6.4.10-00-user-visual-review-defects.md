## User Review Findings (v18.6.4.9)

### Postal Code Issues (FAILED)

1. **胡编邮编仍返回结果** — Random fake postal codes (e.g. ZZZ999) returned results via prefix matching
2. **有数据库但无匹配时显示"无数据库"** — Countries with DB (JP, CA) showed "当前国家暂未接入可查询邮编数据库" when input had no match
3. **日本 Tokyo 城市查询失败** — Input "Tokyo" with JP selected returned no results, even though JP has 142,577 records
4. **日本 10000 可查** — Confirmed JP has database (10000 returns results)
5. **马来西亚查询通过** — MY results correct, no US cross-contamination
6. **加入任务链仍 404** — "加入任务链" button on postal page redirected to /auth/signin which 404s

### BBS Issues (BASIC PASS)

1. **BBS 五项基本通过** — Topic readability, author card, composer formatting, emoji, preview all passed
2. **菜单文字与背景同色** — Menu text color too similar to background, unreadable

### Root Causes Identified

| Issue | Root Cause |
|-------|-----------|
| Fake postal codes | Advanced API used `startsWith(prefix)` without format validation |
| "No database" for DB countries | `noMatchForSelectedCountry` always set to `true` when results=0 |
| Japan Tokyo no results | API only searched `city` and `areaName`, not `province` where "Tokyo To" is stored |
| Japan 10000 no results | API used exact match only, "10000" doesn't equal "1000000" |
| Task chain 404 | Used `/auth/signin` route which doesn't exist; correct route is `/login` |
| BBS menu contrast | `text-gray-400/500/600` on white background = insufficient contrast |
