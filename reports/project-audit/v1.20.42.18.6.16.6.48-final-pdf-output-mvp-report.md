## 1. PDF Renderer 方案说明

### 使用库
**@react-pdf/renderer** (版本 4.5.1)

**选择原因**:
- React/Next 技术栈接入成本低
- 支持 Document/Page/View/Text 组件
- 支持多页、绝对定位
- 适合当前文本、公司信息块、商品表格、序号标签
- 已在 package.json 中安装

### 架构
```
Canvas Template Data → PDF Renderer → PDF Blob → Download
```

**核心原则**:
- ✅ PDF 从模板数据生成，不依赖 DOM
- ✅ 不使用 iframe
- ✅ 不注入 Tailwind/外部样式
- ✅ 不依赖 window.print / @page
- ✅ 坐标从数据映射到 PDF 物理尺寸（mm）

## 3. 坐标映射公式

### 核心原则
**Canvas 元素坐标已经是 mm 单位，无需转换**

```typescript
// canvas-schema.ts 定义
interface CanvasElement {
  x: number;      // mm
  y: number;      // mm
  width: number;  // mm
  height: number; // mm
  style: {
    fontSize: number;     // pt
    padding: number;      // mm
    borderWidth: number;  // mm
    borderRadius: number; // mm
  }
}
```

### PDF 坐标转换
```typescript
// PDF 使用 pt 单位 (1mm = 2.83465pt)
const xPt = element.x * 2.83465;
const yPt = element.y * 2.83465;
const widthPt = element.width * 2.83465;
const heightPt = element.height * 2.83465;
const fontSizePt = element.style.fontSize; // 直接使用 pt
```

### 集中管理
所有坐标转换集中在 `coordinate.ts`：
- ✅ 无散落的转换常量
- ✅ 无 screen px 当 PDF pt
- ✅ 单位转换清晰
