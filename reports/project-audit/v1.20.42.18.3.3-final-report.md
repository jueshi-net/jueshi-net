### 2. Critical Bug Fix

**Issue**: PATCH API was overwriting context when both `context` and `currentStep` were provided.

**Root Cause**: In `src/app/api/task-chains/[id]/route.ts`, the code was:
```typescript
if (context !== undefined) {
  updateData.context = context;
}
if (currentStep !== undefined || completedSteps !== undefined) {
  const currentContext = (existing.context as Record<string, unknown>) || {};
  const newContext = { ...currentContext };
  // ... this overwrites updateData.context!
}
```

**Fix**: Use `updateData.context` as base if already set:
```typescript
const baseContext = (updateData.context as Record<string, unknown>) || 
                    (existing.context as Record<string, unknown>) || {};
```

**Impact**: This bug prevented task chain data from being saved correctly. Without this fix, all PATCH operations would lose previously saved data.
