### After

```
Input: 帮我创建一个"新加坡留学生租房注意事项清单"。
Title: 新加坡留学生租房注意事项清单
Slug: checklist-a1b2c3d4 (hash-based)
```

### Implementation

1. **Title Extraction:** Prioritizes quoted content (Chinese or English quotes)
   ```typescript
   const quotedMatch = text.match(/['"""\u201c\u201d]([^'"""\u201c\u201d]+?)['"""\u201c\u201d]/);
   if (quotedMatch) {
     title = quotedMatch[1].trim();
   }
   ```

2. **Slug Generation:** Hash-based for Chinese titles
   ```typescript
   const hasChinese = /[\u4e00-\u9fa5]/.test(title);
   if (hasChinese) {
     const hash = createHash('md5').update(title).digest('hex').substring(0, 8);
     slug = `${type}-${hash}`;
   }
   ```
