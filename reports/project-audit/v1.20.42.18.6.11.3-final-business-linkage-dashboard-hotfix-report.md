## 2. Issues Reproduced & Fixed

### 2.1 Company Profile Linkage Inconsistency

**Reproduced:** ✅ Yes
**Root Cause:** `CompanyProfilePicker` 读取 membership API 字段路径错误 — `d.isMember` 应为 `d.data.isActiveMember`，导致会员状态永远为 false。
**Fix:** 修正字段路径 `d?.data?.isActiveMember`
**Tools Fixed:** 报价单 (quote-sheet), 商业发票 (commercial-invoice), 装箱单 (shipping-label), 交接单 (handover-note), 借记单 (debit-note), 入库单 (inbound-receipt) — 所有使用 CompanyProfilePicker 的工具

### 2.2 Membership Linkage Inconsistency

**Reproduced:** ✅ Yes
**Root Cause:** 4 个文件使用 `role === 'member'` 判断会员状态，但 membership 应由 `memberUntil` 日期决定：
- `workspace/member/page.tsx` line 19
- `workspace/member/member-client.tsx` line 174
- `workspace/company-profiles/page.tsx` line 22
- `dashboard/dashboard-client.tsx` line 237

**Fix:** 全部改为 `Boolean(memberUntil && new Date(memberUntil) > new Date())`
**role=member 依赖:** 已消除

### 2.3 Workspace 7-Card Layout Truncation

**Reproduced:** ✅ Yes
**Root Cause:**
1. Grid 使用 `grid-cols-2 md:grid-cols-3 lg:grid-cols-6` — 桌面端 6+1 排版，第 7 卡片独占一行过窄
2. ActionCard 标题 `truncate` class 截断文字

**Fix:**
1. Grid 改为 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4` — 手机 1 列 / 平板 2 列 / 笔记本 3 列 / 桌面 4+3
2. 移除 ActionCard `truncate` class
3. 添加 8 个 `data-testid` 测试标记
