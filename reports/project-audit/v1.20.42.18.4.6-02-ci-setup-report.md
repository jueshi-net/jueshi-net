### Job 1: test-and-build

**名称：** Test & Build Gate  
**运行环境：** ubuntu-latest

#### 步骤

1. **Checkout code**
   - 使用 actions/checkout@v4
   - 拉取代码

2. **Setup Node.js**
   - Node.js 版本：20
   - 启用 npm cache

3. **Install dependencies**
   - `npm ci`
   - 安装依赖

4. **Generate Prisma Client**
   - `npx prisma generate`
   - 生成 Prisma 客户端

5. **Run unit tests**
   - `npm run test:unit`
   - 使用 dummy DATABASE_URL
   - **CI 可运行：** ✅

6. **Run regression tests**
   - `npm run test:regression`
   - 使用 dummy DATABASE_URL
   - **CI 可运行：** ✅

7. **Type check**
   - `npx tsc --noEmit`
   - TypeScript 类型检查

8. **Build application**
   - `npm run build`
   - 使用 dummy 环境变量
   - **CI 可运行：** ✅

9. **Check for whitespace errors**
   - `git diff --check`
   - 检查空白字符错误

10. **Check migration status (dry run)**
    - `npx prisma migrate status`
    - 使用 dummy DATABASE_URL
    - `continue-on-error: true`
    - **CI 可运行：** ✅（允许失败）

## 三、CI 环境变量

### 使用的 dummy 环境变量

```yaml
DATABASE_URL: 'postgresql://dummy:***@localhost:5432/dummy'
NEXTAUTH_SECRET: 'dummy-secret-for-ci'
NEXTAUTH_URL: 'http://localhost:3000'
NEXT_PUBLIC_APP_URL: 'http://localhost:3000'
```

### 安全说明

- ✅ 所有密码都是 `dummy`
- ✅ 所有 secret 都是 `dummy-secret-for-ci`
- ✅ 所有 URL 都是 `localhost` 或 `dummy.com`
- ❌ 不包含真实生产 secret
- ❌ 不包含真实数据库连接

## 五、CI 与手动 Gate 分工

### CI 自动运行

```bash
# GitHub Actions 自动运行
npm run test:unit          # 纯逻辑测试
npm run test:regression    # 回归测试
npm run build              # 构建验证
npx tsc --noEmit           # 类型检查
```

### 手动运行（部署前）

```bash
# 开发者手动运行
npm run test:e2e:prod      # 生产 E2E
npm run test:vps           # VPS DB 测试
npm run verify:predeploy   # 部署前验证
```

### VPS 手动运行

```bash
# VPS 上运行
cd /home/deploy/xixiong-saas
```

## 六、CI 失败处理

### 如果 test:unit 失败

1. 检查测试输出
2. 修复代码或测试
3. 重新提交

### 如果 build 失败

1. 检查构建错误
2. 修复代码
3. 本地运行 `npm run build` 验证
4. 重新提交

### 如果 security-scan 失败

1. 检查扫描结果
2. 移除硬编码 secret
3. 使用环境变量
4. 重新提交

### 如果 migration status 失败

1. 这是允许的（continue-on-error）
2. 手动检查 migration
3. 在 VPS 上运行 `npx prisma migrate status`
4. 确认 migration 正确
