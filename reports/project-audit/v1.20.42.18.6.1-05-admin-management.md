# v1.20.42.18.6.1 — Phase 5: 后台管理

## 管理页面

| 路由 | 功能 |
|------|------|
| /admin/community/reputation | 用户荣誉列表 + 手动调整 + HonorLog |
| /admin/community/badges | 勋章列表 + 启用/停用 |
| /admin/community/users/[id] | 用户社区身份详情 + 授予/移除勋章 + 荣誉日志 |

## API 路由

| 路由 | 方法 | 功能 |
|------|------|------|
| /api/admin/community/honor | POST | 管理员调整荣誉值（必须填原因）|
| /api/admin/community/honor | GET | 荣誉变动日志列表 |
| /api/admin/community/reputation | GET | 用户荣誉排名列表 |
| /api/admin/community/badges/grant | POST | 管理员授予勋章 |
| /api/admin/community/badges/grant | DELETE | 管理员移除勋章 |
| /api/community/user/[id] | GET | 公开社区资料 |

## 权限
- Admin only（auth() + role check + redirect）
- 普通用户不能访问
- 未登录 redirect /login
- 所有手动调整写日志
