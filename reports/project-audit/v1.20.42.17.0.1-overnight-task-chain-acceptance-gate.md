## 三、Commit 差异解释

### 3.1 Commit 链

```
5b2c710 feat: v1.20.42.17.0 overnight task chain MVP + address helper upgrade + SEO guides (MAIN CODE)
d75a240 fix: remove duplicate breadcrumb keys (FIX)
6a21591 docs: v1.20.42.17.0 final overnight task chain report (DOCS ONLY)
```

### 3.2 deploy-version.json 应该记录哪个 commit

**正确答案：** `d75a240`（最后的应用代码 commit）

**原因：**
- `5b2c710` 是主要功能代码
- `d75a240` 是修复 breadcrumb 重复键的 bug fix
- `6a21591` 是纯文档 commit，不包含代码变更

**deploy-version.json 应指向 `d75a240`**，因为这是实际构建的代码版本。

### 3.3 VPS Git HEAD 为什么是 8403ed9

**原因：** VPS 使用 rsync 部署，不是 git pull。VPS 的 git 仓库没有同步到最新 commit。

**解决方案：** deploy-version.json 记录的是实际部署的代码 commit，与 VPS git HEAD 无关。
