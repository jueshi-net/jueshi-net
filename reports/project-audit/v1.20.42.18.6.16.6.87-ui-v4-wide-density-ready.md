## 九、宽屏适配说明

**布局方案：**

```css
/* Desktop 1200px - 1599px */
.desktop-layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
}

/* Wide 1600px+ */
@media (min-width: 1600px) {
  .desktop-layout {
    grid-template-columns: 248px minmax(0, 1fr) 320px;
  }
}

/* Ultra-wide 1920px+ */
@media (min-width: 1920px) {
  .desktop-layout {
    grid-template-columns: 260px minmax(0, 1240px) 340px;
    max-width: 1840px;
    margin: 0 auto;
  }
}
```

**Right Rail 显示规则：**
- 1600px 以下：隐藏
- 1600px 及以上：显示
