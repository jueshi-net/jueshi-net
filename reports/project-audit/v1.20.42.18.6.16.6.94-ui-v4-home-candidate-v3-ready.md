## 三、V3 核心改进

### 1. Hero 首屏重排 - 工作台嵌入左侧 ✅

**问题：** V2 Hero 左侧存在大量空白区域，空间利用率不高

**解决方案：**
- 将"我的工作台"从独立大模块改为 Hero 内嵌紧凑信息卡
- 放置在左侧下半部分空白区域
- 包含：头像、昵称、等级、经验进度、今日任务、未完成清单、签到/查看工作台 CTA

**视觉设计：**
- 白底半透明背景（`bg-white/85`）
- 毛玻璃效果（`backdrop-blur-md`）
- 轻阴影（`shadow-lg`）
- 圆角 20px
- 小螃蟹头像
- 紧凑布局，不撑破 Hero

### 2. 社区论坛模块新增 ✅

**模块名称：** 社区论坛

**位置：** 热门任务链之后，推荐内容之前

**内容结构：**
- 左侧：社区总览卡（今日讨论 128、活跃用户 3,280、新增经验帖 24）
- 右侧：热门讨论列表（5 条帖子）
- 分类标签：集运物流、留学生活、跨境电商、官方资源、外贸单据、支付收款
- 帖子标签：热门讨论、最新回复、精华帖

**视觉设计：**
- 社区入口风格，非普通文章列表
- 卡片密度适中
- 入口明显：进入社区 / 查看更多

### 3. 广告位占位系统 ✅

**组件名称：** JueshiV4AdSlot

**广告位 slotKey 列表：**

1. `home_after_hero_banner` - Hero 下方横幅广告位
2. `home_tools_inline` - 高频工具区后信息流广告
3. `home_task_chain_inline` - 热门任务链后广告位
4. `home_community_sidebar` - 社区模块旁边广告位（预留）
5. `home_before_footer_banner` - Footer 前大横幅广告位
6. `mobile_home_mid_card` - 移动端中部卡片广告（预留）
7. `mobile_home_before_footer` - 移动端 Footer 前广告（预留）

**广告位变体：**
- `banner` - 横幅
- `card` - 卡片
- `inline` - 内联
- `mobile` - 移动端
- `footer` - Footer 前

**视觉要求：**
- 明确标记"广告"标识（右上角）
- 白底或浅渐变背景
- 细边框
- 小标签：广告 / 推广
- UI Lab 提示：右下角显示 slotKey（仅开发环境）
- 不接真实广告脚本，仅 UI 占位

**Mock 广告内容：**
- 跨境服务推荐
- 集运线路推广
- 留学服务推荐
- 外贸工具会员
- 官方合作推荐
- 资源合作位

### 4. 原工作台模块处理 ✅

**方案：** 移除 Hero 下方的大型工作台模块，替换为轻量提示条

**提示条内容：**
- 标题：登录后可保存工具、清单进度和勋章成长
- 副标题：个性化你的工作台，随时访问常用功能
- CTA：进入我的工作台

**优势：**
- 避免首页出现两个工作台模块
- 降低重复感
- 保持信息密度
