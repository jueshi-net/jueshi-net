```prisma
model Resource {
  id          String   @id @default(cuid())
  name        String
```

**缺失字段**:

- ❌ `featuredWeight`: 推荐位权重

## 二、方案 A：无 Schema 变更方案（推荐）

### 2.1 方案概述

**核心思路**: 复用现有 `sortOrder` 和 `qualityScore` 字段实现推荐位

**实现方式**:
1. 使用 `sortOrder < 0` 标识推荐位资源
2. 使用 `qualityScore >= 80` 标识高质量资源
3. 前台渲染时优先显示推荐位资源

### 2.2 推荐位规则

| 条件 | 说明 | 优先级 |
|------|------|--------|
| sortOrder < 0 | 推荐位资源 | P0（最高） |
| isAd = true | 广告资源 | P1 |
| qualityScore >= 80 | 高质量资源 | P2 |
| sortOrder = 0 | 普通资源 | P3（默认） |
| sortOrder > 0 | 降权资源 | P4（最低） |

### 2.3 前台渲染逻辑

**文件**: `src/app/(public)/resources/page.tsx`

**当前逻辑**:
```typescript
const resources = await prisma.resource.findMany({
  where: { isActive: true },
  orderBy: [
    { isAd: "desc" },
    { sortOrder: "asc" },
    { createdAt: "desc" },
  ],
});
```

**优化后逻辑**:
```typescript
const resources = await prisma.resource.findMany({
  where: { isActive: true },
  orderBy: [
    { sortOrder: "asc" },  // sortOrder < 0 的推荐位排在最前
    { isAd: "desc" },      // 广告资源次之
    { qualityScore: "desc" }, // 高质量资源再次之
    { createdAt: "desc" },
  ],
});
```

### 2.4 后台管理界面

**文件**: `src/app/(admin)/admin/resources/page.tsx`

**当前功能**:
- ✅ 可以编辑 sortOrder
- ✅ 可以编辑 qualityScore
- ✅ 可以编辑 isAd

**优化功能**:
- ✅ 添加"推荐位"快捷按钮（设置 sortOrder = -1）
- ✅ 添加"取消推荐"快捷按钮（设置 sortOrder = 0）
- ✅ 添加推荐位筛选（sortOrder < 0）

### 2.5 实施步骤

**Phase 1: 代码更新（无需数据库变更）**
1. 更新前台渲染逻辑（调整 orderBy）
2. 更新后台管理界面（添加推荐位快捷按钮）
3. 更新 category-config.ts（移除静态推荐位配置）

**Phase 2: 数据初始化（需要数据库更新）**
1. 将当前静态推荐位资源设置 sortOrder = -1
2. 验证推荐位显示效果

### 2.6 优缺点分析

**优点**:
- ✅ 无需修改 Prisma schema
- ✅ 无需执行 migration
- ✅ 无需执行 prisma db push
- ✅ 实现简单，风险低
- ✅ 可以立即实施

**缺点**:
- ⚠️ sortOrder 字段被复用，语义不够清晰
- ⚠️ 无法设置多个推荐位权重级别
- ⚠️ 无法按分类管理推荐位

### 2.7 风险评估

**风险等级**: 低

**风险点**:
- ⚠️ sortOrder 字段被复用，可能影响其他排序逻辑
- ⚠️ 需要验证所有使用 sortOrder 的地方

**缓解措施**:
- ✅ 充分测试所有排序场景
- ✅ 文档说明 sortOrder 的新语义

## 三、方案 B：需要 Schema 变更的正式方案

### 3.1 方案概述

**核心思路**: 新增 `isFeatured` 和 `featuredWeight` 字段

**实现方式**:
1. 新增 `isFeatured` 字段（Boolean）
2. 新增 `featuredWeight` 字段（Int，0-100）
3. 前台渲染时优先显示 isFeatured = true 的资源

### 3.2 Schema 变更

**Prisma Schema**:
```prisma
model Resource {
  // ... 现有字段
  
  // 推荐位字段
  isFeatured     Boolean @default(false) @map("is_featured")
  featuredWeight Int     @default(0) @map("featured_weight") // 0-100，数值越高越靠前
  
  @@index([isFeatured, featuredWeight])
}
```

**Migration SQL**:
```sql
ALTER TABLE resources
ADD COLUMN is_featured BOOLEAN NOT NULL DEFAULT false,
ADD COLUMN featured_weight INT NOT NULL DEFAULT 0;

CREATE INDEX idx_resources_featured ON resources(is_featured, featured_weight);
```

### 3.3 推荐位规则

| 条件 | 说明 | 优先级 |
|------|------|--------|
| isFeatured = true AND featuredWeight >= 80 | 顶级推荐 | P0 |
| isFeatured = true AND featuredWeight >= 50 | 高级推荐 | P1 |
| isFeatured = true | 普通推荐 | P2 |
| isAd = true | 广告资源 | P3 |
| qualityScore >= 80 | 高质量资源 | P4 |
| 其他 | 普通资源 | P5 |

### 3.4 前台渲染逻辑

```typescript
const resources = await prisma.resource.findMany({
  where: { isActive: true },
  orderBy: [
    { isFeatured: "desc" },
    { featuredWeight: "desc" },
    { isAd: "desc" },
    { qualityScore: "desc" },
    { createdAt: "desc" },
  ],
});
```

### 3.5 后台管理界面

### 3.7 优缺点分析

**优点**:
