## 完成内容

### 1. 数据库 Migration ✅

**File**: `prisma/migrations/20260620_add_ad_applications/migration.sql`

创建 `ad_applications` 表：
- `id` - 主键
- `user_id` - 用户 ID
- `reward_grant_id` - 关联的奖励发放
- `placement_key` - 广告位
- `description` - 投放说明
- `material_url` - 素材 URL
- `material_type` - 素材类型（image/video/html）
- `start_date` / `end_date` - 投放时间
- `status` - 状态（PENDING/APPROVED/REJECTED/USED）
- `review_note` - 审核备注
- `reviewed_by` / `reviewed_at` - 审核信息

索引：
- `user_id` - 用户查询
- `status` - 状态过滤
- `placement_key` - 广告位查询

### 2. 用户端申请流程 ✅

**File**: `src/app/(workspace)/workspace/member/member-client.tsx`

用户端功能：
- 显示可用广告权益天数
- 显示已使用/已过期天数
- 选择广告位（placement_key）
- 填写投放说明
- 上传素材（URL）
- 选择素材类型
- 设置投放时间
- 提交申请

验证：
- 必须有可用权益
- 必须选择广告位
- 必须填写说明
- 不能重复消耗权益

### 3. 后台审核流程 ✅

**Files**:
- `src/app/(admin)/admin/ad-entitlements/page.tsx`
- `src/app/(admin)/admin/ad-entitlements/ad-entitlements-client.tsx`
- `src/app/api/admin/ad-entitlements/route.ts`
- `src/app/api/admin/ad-entitlements/[id]/route.ts`

后台功能：
- 申请列表（支持状态过滤）
- 查看详情（用户信息、权益信息、申请材料）
- 批准申请（标记权益已使用）
- 拒绝申请（填写拒绝原因）
- 审核记录

权限：
- 仅管理员可访问
- 继承 admin layout

### 4. API 路由 ✅

**用户端 API**:
- `GET /api/workspace/ad-entitlements` - 获取权益和申请列表
- `POST /api/workspace/ad-entitlements` - 提交申请

**后台 API**:
- `GET /api/admin/ad-entitlements` - 获取申请列表（管理员）
- `PUT /api/admin/ad-entitlements/[id]` - 审核申请（批准/拒绝）

- `ad_entitlement_reject` - 拒绝申请
- `ad_entitlement_use` - 使用广告权益
