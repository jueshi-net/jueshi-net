## 执行摘要

v6.41 引入了打印布局回归问题：使用全局 hidden override 强制显示所有画布元素，导致标题/序号重叠、隐藏元素被显示、可能有多层重复打印。

**根因：** iframe CSS 使用了全局选择器 `[data-testid^="canvas-element"]` 和 `[data-testid="canvas-print-unscaled-paper"] *` 强制显示所有元素，破坏了原有的隐藏逻辑。

**修复：** 移除全局 hidden override，使用精确的隐藏规则，只隐藏应该隐藏的元素（`.print\:hidden`、`canvas-sequence-hidden`、页面指示器）。

---

## 修复内容

### 1. 移除全局 hidden override

**修复前（v6.41）：**
```css
/* Force all children to be visible */
[data-testid="canvas-print-unscaled-paper"] * {
  display: revert !important;
}
/* Ensure canvas elements are visible */
[data-testid^="canvas-element"],
[data-testid="canvas-text-element"],
[data-testid="canvas-company-info-block"],
[data-testid^="canvas-company-field-"] {
  display: block !important;
  visibility: visible !important;
}
```

**修复后（v6.42）：**
```css
/* Hide elements marked for print (page indicators, UI elements) */
.print\:hidden {
  display: none !important;
}
/* Hide hidden sequence elements */
[data-testid="canvas-sequence-hidden"] {
  display: none !important;
}
/* Hide page count and sequence indicators */
[data-testid="canvas-print-page-count"],
[data-testid="canvas-print-page-sequence"] {
  display: none !important;
}
```

### 2. 改进克隆逻辑

在 `handlePrint` 函数中，克隆内容时主动移除不应该打印的元素：

```typescript
// Remove hidden sequence elements (v6.42 fix: prevent duplicate sequences)
clone.querySelectorAll("[data-testid=\"canvas-sequence-hidden\"]").forEach(el => el.remove());
// Remove page count and sequence indicators
clone.querySelectorAll("[data-testid=\"canvas-print-page-count\"], [data-testid=\"canvas-print-page-sequence\"]").forEach(el => el.remove());
// Remove any elements with print:hidden class
clone.querySelectorAll(".print\\:hidden").forEach(el => el.remove());
```

## 技术细节

### 根因分析

**PRINT_LAYOUT_REGRESSION_ROOT_CAUSE：**

v6.41 为了解决"打印 iframe 元素不可见"的问题，使用了全局 CSS 规则强制显示所有画布元素。这导致：

1. **标题/序号重叠：** 隐藏的序号元素（`canvas-sequence-hidden`）被强制显示
2. **重复序列：** 多个序号元素同时显示
3. **破坏隐藏逻辑：** `.print\:hidden` 类的元素也被强制显示

### 修复方案

采用精确的隐藏规则，而不是全局的显示规则：

1. **只隐藏应该隐藏的元素：**
   - `.print\:hidden` - 标记为打印时隐藏的元素
   - `canvas-sequence-hidden` - 隐藏的序号元素
   - `canvas-print-page-count` - 页面计数指示器
   - `canvas-print-page-sequence` - 页面序号指示器

2. **在克隆时移除不需要的元素：**
   - 主动移除隐藏元素，而不是依赖 CSS 隐藏
   - 确保打印 DOM 中只包含需要打印的内容

3. **保持单一打印层：**
   - 每个页面只有一个 `canvas-print-unscaled-paper`
   - 没有重复的打印内容
