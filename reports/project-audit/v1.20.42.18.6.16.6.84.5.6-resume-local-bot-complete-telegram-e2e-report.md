## 用户下一步操作

### 步骤 1：获取 Telegram Bot Token

1. 在 Telegram 中搜索 @BotFather
2. 发送 `/newbot` 或 `/mybots` 查看现有 Bot
3. 获取 Bot Token（格式：`123456789:ABCdefGHIjklMNOpqrsTUVwxyz`）

### 步骤 2：配置本地环境变量

在 `/Users/chq/xixiong-saas/.env.local` 中添加：

```bash
CONTENTOPS_TELEGRAM_BOT_TOKEN=your_bot_token_here
CONTENTOPS_TELEGRAM_ALLOWED_CHAT_IDS=your_chat_id
```

### 步骤 3：启动本地 Bot

```bash
cd /Users/chq/xixiong-saas
CONTENTOPS_BOT_ENABLED=true \
CONTENTOPS_DRAFT_ALLOW_PRODUCTION=true \
CONTENTOPS_PUBLICATION_ALLOWED=false \
tsx scripts/contentops/contentops-telegram-bot.ts
```

### 步骤 4：进行 Telegram E2E 测试

1. 在 Telegram 中向 Bot 发送"取消"
2. 发送 reference rewrite 文本
3. 发送修改标题指令
4. 发送"确认创建"
5. 验证返回的 Draft ID、slug、Admin URLs 等

### 步骤 5：更新状态

测试通过后，更新状态为：
- `CONTENTOPS_V2_LOCAL_HERMES_READY`（如果所有测试通过）
- `CONTENTOPS_V2_LOCAL_HERMES_READY_USER_RETEST_PENDING`（如果需要用户手动测试）
