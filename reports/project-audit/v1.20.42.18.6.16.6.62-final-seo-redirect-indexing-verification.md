## 建议改进（非阻塞）

### 1. 添加 Canonical 标签

**优先级:** 中  
**影响:** 明确规范 URL，避免重复内容问题

**实施方案:**

在 `next.config.ts` 中添加：

```typescript
const nextConfig = {
  // ... 其他配置
  
  async headers() {
    return [
      {
        source: '/:path*',
        headers: [
          {
            key: 'Link',
            value: '<https://jueshi.net/:path*>; rel="canonical"',
          },
        ],
      },
    ]
  },
}
```

或在页面组件中添加：

```tsx
// app/layout.tsx
export const metadata = {
  metadataBase: new URL('https://jueshi.net'),
  alternates: {
    canonical: './',
  },
}

// app/page.tsx
export const metadata = {
  alternates: {
    canonical: '/',
  },
}

// app/tools/page.tsx
export const metadata = {
  alternates: {
    canonical: '/tools',
  },
}
```
