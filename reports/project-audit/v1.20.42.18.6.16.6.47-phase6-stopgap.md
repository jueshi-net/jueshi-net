# PHASE 6: 止损建议

**日期**: 2026-06-30  
**版本**: v1.20.42.18.6.16.6.47

---

## 背景

v6.39-v6.46 多轮打印修复均未通过用户真实验收。当前打印渲染器存在以下问题：
- 使用 px 单位而非原生 mm/pt 单位
- 使用 iframe 隔离打印
- 注入大量外部样式（Tailwind CSS）
- 浮点数精度问题

---

## 方案 1: 浏览器打印作为轻量功能（短期）

### 描述
将浏览器打印定位为"快速预览"功能，优先保证页数正确、格式不乱，不追求像素级精确。

### 实施步骤
1. 改用原生单位（mm/pt）
2. 移除 iframe，直接打印
3. 最小化样式注入
4. 添加打印提示："如需精确打印，请使用导出 PDF 功能"

### 优点
- ✅ 工作量小（2-3 小时）
- ✅ 风险低
- ✅ 快速止损

### 缺点
- ❌ 无法保证像素级精确
- ❌ 不同浏览器可能有差异
- ❌ 用户仍需手动调整打印设置

### 适用场景
- 快速预览打印内容
- 临时打印需求
- 对精度要求不高的场景

---

## 方案 2: 新增"导出 PDF"功能（中期）

### 描述
使用专业的 PDF 生成库，在服务端或客户端生成精确的 PDF 文件，作为正式的输出方式。

### 技术选型

#### 选项 A: jsPDF（客户端）
```javascript
import { jsPDF } from 'jspdf';

const doc = new jsPDF({
  format: [100, 100], // 100mm x 100mm
  unit: 'mm'
});

// 添加文本
doc.setFontSize(16);
doc.text('标签 1', 50, 10, { align: 'center' });

// 添加序号
doc.setFontSize(24);
doc.text('1/11', 50, 40, { align: 'center' });

// 保存
doc.save('label-1.pdf');
```

**优点**:
- ✅ 纯客户端，无需服务端
- ✅ 精确控制 PDF 尺寸和内容
- ✅ 支持多页

**缺点**:
- ❌ 需要学习 jsPDF API
- ❌ 复杂布局实现困难
- ❌ 中文字体需要额外配置

#### 选项 B: @react-pdf/renderer（客户端）
```javascript
import { Document, Page, Text, View, StyleSheet } from '@react-pdf/renderer';

const styles = StyleSheet.create({
  page: {
    width: 100,
    height: 100,
    padding: 5
  },
  title: {
    position: 'absolute',
    top: 5,
    left: 5,
    right: 5,
    textAlign: 'center',
    fontSize: 16
  }
});

const LabelDocument = ({ data }) => (
  <Document>
    {data.map((item, idx) => (
      <Page size={[100, 100]} key={idx}>
        <View style={styles.page}>
          <Text style={styles.title}>标签 {idx + 1}</Text>
          <Text style={styles.sequence}>{idx + 1}/11</Text>
        </View>
      </Page>
    ))}
  </Document>
);
```

**优点**:
- ✅ React 组件化，易于维护
- ✅ 精确控制布局
- ✅ 支持复杂布局

**缺点**:
- ❌ 需要学习新库
- ❌ 包体积较大
- ❌ 中文字体配置复杂

#### 选项 C: Playwright 服务端生成（服务端）
```javascript
// 服务端 API
app.post('/api/export-pdf', async (req, res) => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  
  // 渲染 HTML
  await page.setContent(generatePrintHTML(req.body));
  
  // 生成 PDF
  const pdf = await page.pdf({
    width: '100mm',
    height: '100mm',
    margin: { top: 0, right: 0, bottom: 0, left: 0 }
  });
  
  await browser.close();
  res.send(pdf);
});
```

**优点**:
- ✅ 与浏览器打印完全一致
- ✅ 精确控制
- ✅ 支持复杂布局

**缺点**:
- ❌ 需要服务端资源
- ❌ 并发性能问题
- ❌ 增加服务端负载

### 推荐方案
**短期**: jsPDF（快速实现）  
**长期**: @react-pdf/renderer（组件化）或 Playwright（精确控制）

### 工作量估算
- jsPDF: 1-2 天
- @react-pdf/renderer: 2-3 天
- Playwright: 1-2 天（含服务端部署）

## 方案 3: 固定 PDF 渲染管线（长期）

### 描述
标签打印采用固定的 PDF 渲染管线，完全不依赖浏览器 print preview。

### 架构
```
用户操作 → 生成打印数据 → PDF 渲染引擎 → 下载 PDF → 用户打印
```

### 实施步骤
1. 定义打印数据格式（JSON）
2. 实现 PDF 渲染引擎（服务端或客户端）
3. 提供"导出 PDF"按钮
4. 禁用或弱化浏览器打印功能

### 优点
- ✅ 完全控制打印输出
- ✅ 跨浏览器一致性
- ✅ 精确控制尺寸和布局
- ✅ 可以添加水印、条形码等

### 缺点
- ❌ 工作量大（1-2 周）
- ❌ 需要维护 PDF 渲染引擎
- ❌ 用户需要额外步骤（下载 → 打印）
