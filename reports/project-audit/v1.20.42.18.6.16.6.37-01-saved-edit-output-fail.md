## P0 根因分析

### 问题：已保存模板编辑页打不开

**根因：** 路由不匹配

- `/tools/template-studio/canvas/new` 使用 `CanvasEditorFull`（可视化画布编辑器）
- `/tools/template-studio/[id]/edit` 使用 `TemplateStudioClient`（结构化表单编辑器）

用户用画布编辑器创建的模板，保存后编辑链接指向结构化编辑器，但结构化编辑器无法正确渲染画布模板数据，导致页面崩溃或显示空白。

**证据：**

```
Testing template ID: user-1782534104413

=== SINGLE TEMPLATE API ===
Response: {"success":true,"data":{"id":"user-1782534104413",...}}

=== EDIT PAGE CONTENT ===
Contains template name: true
Contains "模板工作室": false
Contains "画布": false
Contains "保存": true
Contains "导出": false
Canvas elements found: 0
```

页面加载了模板名称，但画布元素数量为 0，说明结构化编辑器无法渲染画布模板。
