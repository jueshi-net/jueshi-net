    "currentStep": 0,
    "completedSteps": []

- **现象：** 同上，context 中没有 CBM 数据

#### 发票草稿失败
- **现象：** 草稿中没有包含任务链数据

#### 权限隔离失败
- **现象：** 清除 cookie 后仍然可以访问任务链（返回 200 而不是 401）

## 二、问题诊断

### 2.1 工具互通数据流分析

**预期流程：**
1. 用户在工具页面（HS/CBM/地址）输入数据
2. 点击"加入任务链"按钮
3. 弹出任务选择对话框
4. 选择目标任务
5. 数据写入任务链 context
6. 跳转到任务链页面

**实际问题：**
- 步骤 1-4 可能正常
- **步骤 5 失败** - 数据没有写入 context
- 步骤 6 可能正常

### 2.2 可能的原因

1. **前端问题：**
   - "加入任务链"按钮的 onClick 事件没有正确调用 API
   - 任务选择对话框的 onSelect 回调没有更新 context
   - API 调用失败但没有错误提示

2. **后端问题：**
   - PATCH /api/task-chains/[id] API 没有正确更新 context
   - 权限校验失败
   - 数据库写入失败

3. **测试问题：**
   - 测试等待时间不足
   - 选择器不正确
   - Cookie 对话框阻止操作
