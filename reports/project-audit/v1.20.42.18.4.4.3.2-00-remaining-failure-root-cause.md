```

  "currentStep": 0,
  "completedSteps": []
```

### 1.2 可能原因

1. **按钮没有被点击**
   - 测试使用 `page.locator('button:has-text("加入任务链")')` 查找按钮

3. **API 调用失败**
   - `importToolDataToTaskChain()` 可能返回错误
   - 或者 payload 为空

4. **字段路径错误**
   - 写入的字段可能是 `context.hsCode` 或其他路径
   - 但测试读取的是 `context.hsCode`

## 五、统一修复方案

### 5.1 添加 data-testid

为所有关键元素添加稳定的 data-testid：

**HS 工具：**
- `data-testid="hs-add-to-task-chain"` - 加入任务链按钮
- `data-testid="hs-writeback-dialog"` - 写回对话框
- `data-testid="hs-writeback-task-option"` - 任务选项
- `data-testid="task-chain-hs-code"` - HS code 显示

**地址工具：**
- `data-testid="postal-add-to-task-chain"` - 加入任务链按钮
- `data-testid="postal-result-option"` - 地址结果选项
- `data-testid="postal-writeback-dialog"` - 写回对话框
- `data-testid="task-chain-address-city"` - 城市显示
- `data-testid="task-chain-address-postal-code"` - 邮编显示

**文档工具：**
- `data-testid="invoice-generate-button"` - 发票生成按钮
- `data-testid="invoice-draft-content"` - 发票草稿内容
- `data-testid="packing-list-generate-button"` - 装箱单生成按钮
- `data-testid="packing-list-draft-content"` - 装箱单草稿内容

### 5.2 修复测试选择器

更新测试文件，使用 data-testid 而不是 className：

```typescript
// 旧选择器（不稳定）
page.locator('.draft-content, .invoice-preview')

// 新选择器（稳定）
page.locator('[data-testid="invoice-draft-content"]')
```

### 5.3 修复按钮点击

确保按钮可见并正确点击：

```typescript
// 滚动到按钮位置
await button.scrollIntoViewIfNeeded();
await button.click();
```

### 5.4 修复对话框选择

确保对话框正确加载并选择任务：

```typescript
// 等待对话框出现
await dialog.waitFor({ state: 'visible' });
// 等待任务列表加载
await taskOption.waitFor({ state: 'visible' });
// 点击任务
await taskOption.click();
```
