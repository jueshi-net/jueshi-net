- 记录每个检查项的当前状态和最后检查时间

**去重机制**:
- 只在状态变化时发送告警（从 ok → warning/critical）
- 同一错误不会重复刷屏

**恢复通知**:
- 当检查项从 failure 恢复到 ok 时，发送恢复通知
- 避免"只告警不恢复"的问题

**告警内容**:
- 时间戳
- 主机名
- 失败项目列表
- 错误详情
- 当前磁盘使用率
- PM2 状态

- 监控间隔: 5 分钟
- 告警渠道: 邮件、Slack、Webhook

- 网址: https://betterstack.com
- 监控间隔: 1 分钟
- 告警渠道: 邮件、Slack、Webhook、SMS
- 配置步骤:
  1. 注册账号
  2. 创建监控
  3. 输入 URL 和检查间隔
  4. 配置告警规则

**方案 3: 自建监控**
- 使用外部 VPS 运行简单 curl 脚本
- 通过 Telegram/Discord 告警
- 需要额外服务器资源

### 本机监控局限性

**当前 health-check.sh 无法覆盖**:
- ❌ VPS 整机宕机（SSH 不可达）
- ❌ 网络中断（本机无法连接 VPS）
- ❌ Cloudflare 配置错误（本机 curl 可能成功但用户访问失败）

**建议**: 必须配置外部 uptime 监控作为补充
