## 四、修复建议

### 4.1 表格横向滚动（P0）

**适用页面**: 所有包含表格的工具页面

**修复方案**:
```typescript
<div className="overflow-x-auto">
  <table className="min-w-full">
    {/* 表格内容 */}
  </table>
</div>
```

**预计工时**: 每个页面 30 分钟

### 4.2 商品明细列表优化（P0）

**适用页面**: 报价单、商业发票、装箱单、形式发票

**修复方案**:
```typescript
<div className="space-y-2">
  {items.map((item, index) => (
    <div key={index} className="flex flex-col gap-2 p-3 border rounded">
      <div className="flex justify-between">
        <span className="font-medium">{item.name}</span>
        <span className="text-gray-500">x{item.quantity}</span>
      </div>
      <div className="flex justify-between text-sm">
        <span>单价: ${item.price}</span>
        <span>小计: ${item.price * item.quantity}</span>
      </div>
    </div>
  ))}
</div>
```

**预计工时**: 每个页面 1 小时

### 4.3 分类 Tab 滚动优化（P1）

**适用页面**: /resources

**修复方案**:
```typescript
<div className="flex gap-2 overflow-x-auto pb-2 scrollbar-hide snap-x snap-mandatory">
  {categories.map((cat) => (
    <button
      key={cat.id}
      className="shrink-0 snap-start"
    >
      {cat.label}
    </button>
  ))}
</div>
```

**预计工时**: 30 分钟

- iPhone 14 Pro Max (430px)

### 5.2 测试场景

**每个页面必须测试**:
1. 横向溢出：左右滑动页面，检查是否有内容超出屏幕
2. 按钮可点击性：点击所有按钮，检查是否可以正常触发
3. 输入框焦点：点击输入框，检查是否可以正常输入
4. 滚动性能：上下滚动页面，检查是否流畅
5. 表格滚动：左右滚动表格，检查是否可以正常查看

### 5.3 测试工具

**推荐工具**:
- Chrome DevTools（设备模拟器）
- Safari Web Inspector（iOS 设备）
- Chrome Remote Debugging（Android 设备）
