## 四、根因分析

### 审计失败根因

**核心问题：** Playwright 无头浏览器登录状态管理问题

1. **登录函数等待 URL 匹配 `**/tools**`**
   ```javascript
   await page.waitForURL("**/tools**", { timeout: 15000 });
   ```
   登录后重定向到 /tools，但后续导航到 /tools/template-studio 时，登录状态可能丢失。

2. **Cookie 清除后重新登录**
   ```javascript
   // TEST 3: Clear cookies to simulate unauth
   await context.clearCookies();
   ```
   测试 3 清除 cookies，测试 4 重新登录。但重新登录后，cookies 可能未正确设置。

3. **页面认证检查**
   /tools/template-studio 页面有客户端认证检查：
   ```javascript
   if (!authChecked) return <div>加载中...</div>;
   if (!isAuthenticated) return <div>请先登录</div>;
   ```
   如果认证检查失败，页面显示 "请先登录"。
