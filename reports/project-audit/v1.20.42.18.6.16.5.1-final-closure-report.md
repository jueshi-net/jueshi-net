## 1. 修复内容

### 1.1 TS-SEAL-SVG-SECURITY — 审计逻辑修复

**原问题**：
- 审计脚本判断条件过于严格
- 要求 `sealText.includes("script")`，但实际 sealText 只有 "<"
- scripts before/after 都是 9，实际安全

**修复方式**：
- 移除错误的 `renderedAsText` 判断
- 新增多重安全断言：
  - `noNewScripts`: scripts before/after 数量相同
  - `noSvgScripts`: SVG 内无 script 标签
  - `noEventHandlers`: 无 onerror/onload 等可执行属性
  - `noJsUrls`: 无 javascript: URL
- 综合判断：`safeRendering = noNewScripts && noSvgScripts && noEventHandlers && noJsUrls`

**修复结果**：✅ PASS
```
Evidence: Scripts before: 9, after: 9, SVG scripts: 0, event handlers: false, js URLs: false
```

### 1.2 TS-STYLE-PRESET-SAVE-RESTORE — 审计逻辑修复

**原问题**：
- 审计脚本未显式设置 preset 为 "minimal-black" 就保存
- 依赖前一个测试的状态，导致保存的 preset 不确定
- 查找模板编辑链接的逻辑不正确（查找 `a:has-text('预设保存恢复测试')`，但链接文本是"编辑"）

**修复方式**：
- 保存前显式设置 preset 为 "minimal-black"
- 从当前 URL 提取 template ID
- 通过 `data-testid="edit-template-${templateId}"` 查找编辑链接
- 备选方案：通过模板卡片查找编辑链接

**修复结果**：✅ PASS
```
Evidence: Preset: minimal-black, Color: #1f2937
```
