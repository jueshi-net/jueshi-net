## 一、Schema 变更

### 1.1 RewardItem 扩展

**新增字段:**
- `stockLimit` (Int?) - 总库存限制
- `stockUsed` (Int) - 已使用库存
- `perUserLimit` (Int) - 每人限兑次数
- `cooldownHours` (Int) - 冷却期（小时）
- `startAt` (DateTime?) - 开始时间
- `endAt` (DateTime?) - 结束时间
- `requiresApproval` (Boolean) - 需要审核
- `fulfillmentType` (String?) - 履约类型
- `fulfillmentStatus` (String?) - 履约状态
- `inactiveReason` (String?) - 禁用原因说明

### 1.2 UserReward 扩展

**新增字段:**
- `auditStatus` (String) - 审核状态 (auto/pending/approved/rejected)
- `auditNote` (String?) - 审核备注
- `pointsCost` (Int) - 消耗积分
- `grantId` (String?) - 关联的 RewardGrant ID
- `failureReason` (String?) - 失败原因

**修改字段:**
- `status` 默认值从 "active" 改为 "pending"

### 1.3 CouponEntitlement 新增

**新增模型:**
- `id` (String) - 主键
- `userId` (String) - 用户 ID
- `couponType` (String) - 券类型 (word_export/no_branding)
- `quantity` (Int) - 券数量
- `usedCount` (Int) - 已使用数量
- `status` (String) - 状态 (active/used/expired)
- `expiresAt` (DateTime?) - 过期时间
- `sourceRewardId` (String?) - 来源 UserReward ID
- `createdAt` (DateTime) - 创建时间
- `updatedAt` (DateTime) - 更新时间

### 1.4 User 模型扩展

**新增关系:**
- `couponEntitlements` (CouponEntitlement[]) - 券类权益

## 三、代码实现

### 3.1 兑换 API 重构

**文件:** `src/app/api/rewards/redeem/route.ts`

**新增功能:**
1. **限制检查函数:**
   - `checkTimeWindow()` - 时间窗口检查
   - `checkStock()` - 库存检查
   - `checkPerUserLimit()` - 限兑检查
   - `checkCooldown()` - 冷却期检查
   - `validateRedemption()` - 综合验证

2. **履约函数:**
   - `fulfillMemberTrial()` - 会员体验履约
   - `fulfillGrowth()` - 成长值履约
   - `fulfillWordExportCoupon()` - Word导出券履约
   - `fulfillNoBrandingCoupon()` - 去品牌券履约
   - `fulfillAdSlotDays()` - 广告权益（抛出错误，保持 inactive）
   - `fulfillReward()` - 履约分发

3. **事务保护:**
   - 所有操作在 $transaction 中执行
   - 积分扣减、库存增加、权益创建原子性
   - 失败时自动回滚

### 3.2 履约模块
