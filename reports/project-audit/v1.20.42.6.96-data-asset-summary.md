## 附录：数据查询 SQL

### Resource 统计

```sql
-- 基础统计
SELECT 
  COUNT(*) as total,
  SUM(CASE WHEN "isActive" = true THEN 1 ELSE 0 END) as active,
  SUM(CASE WHEN "isActive" = false THEN 1 ELSE 0 END) as inactive,
  SUM(CASE WHEN is_ad = true THEN 1 ELSE 0 END) as ads,
  COUNT(DISTINCT category) as categories
FROM resources;

-- 分类分布
SELECT category, COUNT(*) as count
FROM resources
WHERE "isActive" = true
GROUP BY category
ORDER BY count DESC;

-- 来源类型分布
SELECT "sourceType", COUNT(*) as count
FROM resources
GROUP BY "sourceType"
ORDER BY count DESC;
```

### PostalCode 统计

```sql
-- 国家覆盖
SELECT "countryCode", COUNT(*) as count
FROM postal_codes
GROUP BY "countryCode"
ORDER BY count DESC
LIMIT 10;
```

### LandingPage 统计

```sql
-- 状态分布
SELECT status, COUNT(*) as count
FROM "landing_pages"
GROUP BY status
ORDER BY count DESC;

-- 页面类型分布
SELECT "pageType", COUNT(*) as count
FROM "landing_pages"
GROUP BY "pageType"
ORDER BY count DESC;
```

### Topic 统计

```sql
-- 发布状态
SELECT 
  COUNT(*) as total,
  SUM(CASE WHEN "publishedAt" IS NOT NULL THEN 1 ELSE 0 END) as published
FROM topics;
```

### User 统计

```sql
-- 角色分布
SELECT role, COUNT(*) as count
FROM users
GROUP BY role
ORDER BY count DESC;
```
