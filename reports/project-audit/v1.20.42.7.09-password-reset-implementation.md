model PasswordResetToken {
  id         String    @id @default(cuid())

## 五、API 路由说明

### 5.1 POST /api/auth/forgot-password

**功能**: 请求密码重置邮件

**请求体**:
```json
{
  "email": "user@example.com"
}
```

**响应**（成功/失败统一）:
```json
{
  "success": true,
  "message": "如果该邮箱已注册，我们会发送密码重置邮件。"
}
```

**行为**:
1. 验证邮箱格式
2. 检查 IP 和邮箱限频（IP: 5次/15分钟，邮箱: 3次/小时）
3. 查找用户（不存在则返回相同成功消息，防枚举）
4. 失效该用户所有未使用的旧 token
5. 生成 32 字节随机 token（SHA256 哈希存储）
6. 设置 30 分钟有效期
7. 通过 Resend 发送重置邮件
8. 记录请求 IP 和 User-Agent

**安全措施**:
- ✅ 统一响应（防邮箱枚举）
- ✅ IP 和邮箱限频
- ✅ Token 只存哈希
- ✅ 旧 token 自动失效

---

### 5.2 POST /api/auth/reset-password

**功能**: 使用 token 重置密码

**请求体**:
```json
{
  "token": "...",
  "password": "...",
  "confirmPassword": "..."
}
```

**响应**（成功）:
```json
{
  "success": true,
  "message": "密码重置成功，请使用新密码登录"
}
```

**行为**:
1. 验证输入（token、密码、确认密码）
2. 验证密码强度（至少 8 位，包含字母和数字）
3. 哈希 token 并查找记录
4. 验证 token 未过期
5. 验证 token 未使用
6. 使用 bcrypt 哈希新密码（salt rounds: 10）
7. 更新用户密码
8. 标记 token 为已使用
9. 失效该用户其他未使用的 token

**安全措施**:
- ✅ Token 一次性使用
- ✅ Token 过期验证
- ✅ 密码强度校验
- ✅ bcrypt 密码哈希
- ✅ 旧 token 自动失效

## 八、安全措施说明

### 8.1 Token 安全

| 措施 | 实现 |
|---|---|
| 随机性 | `crypto.randomBytes(32)` - 32 字节安全随机数 |
| 存储 | 只存 SHA256 哈希，不存明文 |
| 有效期 | 30 分钟 |
| 一次性使用 | 使用后写入 `usedAt` 时间戳 |
| 旧 token 清理 | 新请求时自动失效旧 token |

### 8.2 密码安全

| 措施 | 实现 |
|---|---|
| 哈希算法 | bcrypt（salt rounds: 10） |
| 强度要求 | 至少 8 位，包含字母和数字 |
| 确认密码 | 必须与新密码一致 |

### 8.3 防枚举

| 措施 | 实现 |
|---|---|
| 统一响应 | 无论邮箱是否存在，返回相同成功消息 |
| 不暴露错误 | 不提示"邮箱不存在" |

### 8.4 限频

| 维度 | 限制 | 时间窗口 |
|---|---|---|
| IP | 5 次 | 15 分钟 |
| 邮箱 | 3 次 | 1 小时 |

### 8.5 日志安全

| 措施 | 实现 |
|---|---|
| Token 日志 | 只记录哈希前 8 位（用于调试） |
| API Key 日志 | 不输出 |
| 密码日志 | 不输出 |
