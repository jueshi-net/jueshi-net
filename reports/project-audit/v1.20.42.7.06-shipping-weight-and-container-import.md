## 二、运费计算器：新增"单件重量"

### 2.1 功能说明

- 新增 `unitWeight` 字段到 `CalcRow` 接口
- 每行输入区新增"单件重量 (kg)"输入框
- "实重合计"改为只读自动计算显示（灰色背景）
- 公式：**实重合计 = 单件重量 × 件数**
- 多行时：**总实重 = Σ(单件重量 × 件数)**
- 向后兼容：旧数据如有 `actualWeight` 但无 `unitWeight`，自动回退

### 2.2 自动计算公式

```
单行实重合计 = unitWeight × quantity
总实重 = Σ(unitWeight_i × quantity_i)
```

## 三、集装箱计算器：批量导入

### 3.1 功能说明

- 新增折叠式"批量导入货物规格"面板
- 支持 CSV 逗号分隔、Tab 分隔、空格分隔、星号/× 分隔
- 支持格式：`长,宽,高,件数,单件重量`
- 自动解析并生成货物行表格
- 显示每行：单件体积、总体积、总重量
- 显示合计：总件数、总体积、总重量
- 支持清空导入结果
- 导入后自动更新集装箱利用率
- 输入错误时显示具体行号和错误信息

### 3.2 批量导入格式说明

```
支持的分隔符: 逗号、Tab、空格、星号(*)、乘号(×)
顺序: 长(cm) 宽(cm) 高(cm) [件数] [单件重量kg]
件数默认: 1
重量可选: 未提供时为 0（不参与重量估算）
```
