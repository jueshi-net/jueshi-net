## 三、根因说明

### 根因 1（最关键）：`window.print()` 打印整页

```typescript
// 旧代码（v6.19-v6.22）
const handlePrint = useCallback(() => {
    window.print();
}, []);
```

`window.print()` 打印**整个浏览器页面**，包括：
- `<Header />`（导航栏）
- `<FooterNew />`（footer：工具中心、社区、帮助中心、联系方式）
- `<CookieConsent />`
- `<CommandPalette />`
- 所有 canvas 编辑器 UI（侧边栏、按钮等）

### 根因 2：`@media print` CSS 隔离不完整

canvas 组件内的 `@media print` CSS 只隐藏了组件**内部**的 UI 元素（侧边栏、按钮、resize handle 等），但**没有覆盖**组件外部的站点级元素（Header、FooterNew、CookieConsent 等）。

### 根因 3：无 dedicated print 隔离机制

没有 iframe、没有 print-only route、没有任何将画布内容与站点布局分离的方案。

## 四、iframe print-only 实现说明

### 4.1 方案概述

用 **dedicated print iframe** 替代 `window.print()`：

1. 用户点击"打印"按钮
2. 创建隐藏 `<iframe id="canvas-print-iframe">`
3. 将 `printRootRef` 内容（仅画布页面）克隆到 iframe
4. 注入所有父文档样式（`<style>` + `<link>`）
5. 注入 iframe 专用 print CSS（@page size、page-break、隐藏 UI）
6. 等待样式加载完成
7. 调用 `iframe.contentWindow.print()`
8. 打印完成后清理 iframe

### 4.2 关键代码

```typescript
const handlePrint = useCallback(() => {
    const printRoot = printRootRef.current;
    if (!printRoot) return;

    // Create hidden iframe
    const iframe = document.createElement("iframe");
    iframe.id = "canvas-print-iframe";
    iframe.style.position = "fixed";
    iframe.style.visibility = "hidden";
    document.body.appendChild(iframe);

    // Collect parent stylesheets
    const styleElements = Array.from(
      document.head.querySelectorAll("style, link[rel='stylesheet']")
    ).map(el => el.outerHTML).join("\n");

    // Build iframe HTML with ONLY canvas content
    const iframeHTML = `<!DOCTYPE html>
<html><head>
  ${styleElements}
  <style>
    @page { size: ${paperWidthMm}mm ${paperHeightMm}mm; margin: 0; }
    [data-testid="canvas-print-page"] { page-break-after: always; }
    [data-testid="canvas-print-page-count"],
    [data-testid="canvas-print-page-sequence"],
    [data-testid="canvas-grid-overlay"],
    .print\\:hidden { display: none !important; }
  </style>
</head><body>
  ${printRoot.innerHTML}
</body></html>`;

    iframeDoc.write(iframeHTML);
    iframeDoc.close();

    // Wait for styles, then print
    setTimeout(() => {
      iframe.contentWindow.focus();
      iframe.contentWindow.print();
      setTimeout(() => document.body.removeChild(iframe), 2000);
    }, 750);
}, [canvas.paper.widthMm, canvas.paper.heightMm]);
```

### 4.3 为什么这能解决问题

| 问题 | 解决方案 |
|------|----------|
| 打印包含 footer/nav | iframe 只包含 `printRoot.innerHTML`（画布页面），没有 Header/FooterNew |
| 标签裁切/错位 | iframe 有独立的 `@page size` 和 `page-break-after: always` |
| 序号重复 | iframe CSS 显式隐藏 `canvas-print-page-count` 和 `canvas-print-page-sequence` |
| 整页打印 | `iframe.contentWindow.print()` 只打印 iframe 内容 |
