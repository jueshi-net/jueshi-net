## 修复完成项

### ✅ P1: 打印明显缩小问题 — 已修复

**根因：**
- `renderPage` 使用 `getScaledPaperDimensions(canvas.paper, scale)` 计算纸张尺寸
- `scale` 是预览缩放比例（通常 < 1），导致打印时纸张被缩小
- 打印 DOM 继承了预览的缩放尺寸

**修复方式：**
1. 添加 `printPaperDimensions` 使用未缩放的原始尺寸：
   ```typescript
   const printPaperDimensions = {
     width: mmToPx(canvas.paper.widthMm),
     height: mmToPx(canvas.paper.heightMm),
   };
   ```

2. 在 `renderPage` 中添加双层结构：
   - **打印层**（`print:block`）：使用 `printPaperDimensions`（未缩放）
   - **屏幕层**（`print:hidden`）：使用 `paperDimensions`（已缩放）

3. 打印时只显示未缩放层，屏幕预览时只显示缩放层

**验证结果：**
```

Visible on screen (should be false): false
✓ PASS
```
