## 修复内容

### 1. 重写 handlePrint 函数

**修复前（v6.43 及之前）：**
- 使用 `printRoot.querySelectorAll` 获取页面
- 使用 `cloneNode(true)` 克隆 preview DOM
- 依赖 `canvas-print-unscaled-paper` 标记
- 闭包问题：依赖项不完整，导致使用旧的 canvas state

**修复后（v6.44）：**
- 直接从 `canvas.elements` 数据生成打印 DOM
- 不再 clone preview DOM
- 使用 `data-element-id` 和 `data-element-type` 标记
- 完整的依赖项：`[canvas.paper.widthMm, canvas.paper.heightMm, canvas.elements, canvas.batch, companyData, productData]`

### 2. 更新 iframe CSS

**修复前：**
- 包含 `canvas-print-unscaled-paper` 样式
- 包含 `print\:hidden` 样式
- 包含 `canvas-sequence-hidden` 样式

**修复后：**
- 移除所有不再需要的样式
- 只保留基本的页面布局和分页样式

### 3. 坐标映射

**公式：**
```
xPx = element.x * 3.7795275591  // mm to px at 96 DPI
yPx = element.y * 3.7795275591
widthPx = element.width * 3.7795275591
heightPx = element.height * 3.7795275591
```
