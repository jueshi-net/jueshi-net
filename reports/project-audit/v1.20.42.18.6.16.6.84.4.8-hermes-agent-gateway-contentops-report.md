## PHASE 2: Hermes Gateway Client 实现

### 新增文件

**文件**: `scripts/contentops/hermes-gateway-client.ts`

**核心功能**:
1. ✅ 调用 Hermes Gateway API（如果启用）
2. ✅ Fallback 到直接 DeepSeek API
3. ✅ 返回 HermesRunResult，包含：
   - hermesRunId: 唯一运行 ID
   - gatewayUsed: 是否使用 Gateway
   - planningUsed: 是否使用 AI planning
   - fallbackUsed: 是否使用 fallback
   - inputMode, contentType, schemaType
   - title, targetAudience, targetCountries
   - content, seo, geo, structuredData
   - qualityGate

**配置**:
```typescript
const GATEWAY_CONFIG = {
  enabled: process.env.HERMES_GATEWAY_ENABLED === 'true',
  gatewayUrl: process.env.HERMES_GATEWAY_URL || 'http://localhost:3001',
  apiKey: process.env.HERMES_GATEWAY_API_KEY,
  timeoutMs: 30000,
  cooldownMs: 30 * 60 * 1000, // 30 minutes
  maxRetries: 2,
};

const AI_CONFIG = {
  enabled: process.env.AI_ENABLED === 'true',
  apiBaseUrl: process.env.AI_API_BASE_URL || 'https://api.deepseek.com/v1',
  apiKey: process.env.AI_API_KEY,
  model: process.env.AI_MODEL || 'deepseek-chat',
  timeoutMs: 30000,
};
```

let hermesPlan: HermesRunResult | null = null;
try {
  hermesPlan = await analyzeAndPlan(text, mode as GatewayInputMode);
  
  if (hermesPlan && hermesPlan.planningUsed && !hermesPlan.fallbackUsed) {
    // AI planning succeeded
    return this.handleHermesPlan(chatId, hermesPlan, mode);
