## 1. Build 失败根因分析

### 根因 #1: Prisma Client 未重新生成

**症状:** `Property 'checklist' does not exist on type 'PrismaClient<…>'`

**原因:** v18.4.7 在 schema.prisma 中新增了 Guide 和 Checklist model，但未执行 `npx prisma generate` 重新生成 Prisma Client 类型定义。

**修复:** 执行 `npx prisma generate`（本地 + VPS）。生成后 `get checklist()` 和 `get guide()` 存在于 `.prisma/client/index.d.ts`。

### 根因 #2: Admin 页面缺少 force-dynamic

**症状:** `Can't reach database server at 127.0.0.1:5432` during build prerender

**原因:** v18.4.7 新增的 6 个 admin content Server Component 页面缺少 `export const dynamic = "force-dynamic"`，导致 Next.js build 时尝试 prerender 这些页面并访问数据库。本地无数据库连接导致 build 失败。

**修复:** 给以下 6 个文件添加 `export const dynamic = "force-dynamic";`:

1. `src/app/(admin)/admin/content/page.tsx`
2. `src/app/(admin)/admin/content/guides/page.tsx`
3. `src/app/(admin)/admin/content/checklists/page.tsx`
4. `src/app/(admin)/admin/content/guides/[id]/edit/page.tsx`
5. `src/app/(admin)/admin/content/checklists/[id]/edit/page.tsx`
6. `src/app/(admin)/admin/topics/page.tsx` (pre-existing, 附带修复)

### 根因 #3: VPS 目录结构不一致

**症状:** `Module not found` 大量错误

**原因:** VPS 使用根目录结构（`app/`, `lib/`, `components/`），但本地使用 `src/` 目录结构。rsync 未同步 `src/` 和 `public/` 目录。

**修复:** 重新 rsync `src/`、`public/`、`scripts/` 到 VPS。
