## 12. npm run build 结果

**本地 build 失败（需要 DB），但 staging build 成功。**

**本地 build 失败原因:**
```
P1001: Can't reach database server at 127.0.0.1:5432
```

这是历史遗留问题，其他页面（如 /admin/levels, /tools/postal-code, 首页等）需要数据库连接。UI V4 页面本身是纯静态的，不依赖 DB。
