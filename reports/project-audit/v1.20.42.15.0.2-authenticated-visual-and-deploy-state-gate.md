**失败原因：** CSRF token 缺失（`MissingCSRF`）

**详细分析：**
1. 登录 API 返回 302 重定向到 `/login?error=MissingCSRF`
2. 这是 NextAuth 的安全机制
3. Playwright 应该自动处理 CSRF token，但可能因为某些原因没有正确携带
4. 可能原因：
   - 登录表单的 action URL 不正确
   - NextAuth 配置问题
   - 浏览器 cookie 策略问题
