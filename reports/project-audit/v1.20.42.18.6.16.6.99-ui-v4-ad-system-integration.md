## 三、V4 广告系统集成

### 3.1 新增组件

**JueshiV4AdPlacementGrid.tsx**

```typescript
interface JueshiV4AdPlacementGridProps {
  placements: string[];
  columns?: number;
  showLabel?: boolean;
  title?: string;
  description?: string;
}
```

**功能：**
- 调用现有 `AdSlot` 组件
- 支持矩阵布局（2-6 列）
- 每个 placement 独立渲染
- 无广告时自动折叠
- 显示"推广"标识

### 3.2 V4 Placement 映射

| 位置 | Placement | 说明 |
|------|-----------|------|
| Hero 下方 | `home-hero`, `home-after-tools` | 首屏广告位 |
| 工具区后 | `home-after-tools`, `tool-bottom` | 工具推荐广告位 |
| 任务链后 | `home-before-footer`, `footer` | 流程服务广告位 |
| Footer 前 | `home-before-footer`, `footer` | 商业合作广告位 |

### 3.3 广告 UI 规则

1. ✅ 所有广告必须有"广告"或"推广"标识
2. ✅ 图片广告和文字广告都必须标识
3. ✅ 后台 disabled / inactive 的广告不显示
4. ✅ 没有广告数据时该广告位折叠
5. ✅ 整个广告组为空时广告组折叠
6. ✅ 移动端减少展示量，避免广告刷屏
7. ✅ 广告不进入首屏核心操作区
8. ✅ 不接第三方广告脚本
9. ✅ 不接第三方追踪
10. ✅ click 追踪只使用现有系统

## 四、Staging 首页替换状态

### 4.1 当前状态

**未替换 staging 首页**

原因：
1. V4 首页使用的 placement（home-hero, home-after-tools, home-before-footer, tool-bottom, footer）当前没有广告数据
2. 广告位会显示为空（自动折叠）
3. 需要先通过后台添加广告数据，再替换首页

### 4.2 替换条件

要替换 staging 首页，需要：
1. 通过 `/admin/ads` 后台添加 V4 首页广告
2. 配置 placement 为 V4 使用的 placement
3. 验证广告在前台正确显示
4. 确认广告 enabled/disabled 功能正常

### 4.3 替换方案

如果满足条件，替换方案：
1. 修改 `src/app/(public)/page.tsx` 使用 V4 Shell
2. 保留 `/ui-lab/jueshi-v4-home-candidate-v4` 路由
3. 保留旧版本可回滚
4. 只替换 i.jueshi.net，不替换 jueshi.net production
