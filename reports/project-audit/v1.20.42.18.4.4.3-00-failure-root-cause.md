## 一、核心问题

### 1.1 根本原因

**工具写回使用了错误的存储机制：**

- `src/lib/task-chain.ts` 的 `saveTaskChain()` 函数只保存到 **localStorage**
- 测试期望的是**数据库级别的任务链 context**（通过 API GET/PATCH）
- 两者不匹配，导致测试失败

### 1.2 两套系统并存

**系统 A：localStorage 轻量级上下文**
- 文件：`src/lib/task-chain.ts`
- 存储：浏览器 localStorage
- 用途：跨工具导航时传递参数（URL params + localStorage）
- 特点：无需登录，无需 API，临时性

**系统 B：数据库任务链 API**
- 文件：`src/app/api/task-chains/route.ts` 和 `[id]/route.ts`
- 存储：PostgreSQL `TaskChainDraft` 表
- 用途：持久化任务链草稿，支持多步骤工作流
- 特点：需要登录，需要 API 调用，持久性

**问题：工具混用了两套系统**
