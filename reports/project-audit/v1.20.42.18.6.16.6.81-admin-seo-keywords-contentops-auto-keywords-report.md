## PHASE 5 — 页面 metadata 输出规则

### 优先级

```typescript
// 1. 优先使用后台 metaKeywords
if (contentOps.seo?.metaKeywords) {
  keywords = contentOps.seo.metaKeywords;
}
// 2. 否则从 primaryKeyword + secondaryKeywords 生成
else if (contentOps.primaryKeyword) {
  // 生成逻辑
}
// 3. 否则 fallback 到 title
else {
  keywords = `${title},清单`;
}
```

### 规则

- ✅ 去重
- ✅ 最多 15 个
- ✅ 中文逗号分隔
- ✅ draft/preview 仍 noindex
- ✅ published 才 index
- ✅ staging 仍 noindex
