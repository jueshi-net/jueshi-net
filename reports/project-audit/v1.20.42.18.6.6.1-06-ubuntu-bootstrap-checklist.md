# Ubuntu 24.04 Bootstrap Checklist — v1.20.42.18.6.6.1

## 判定: READY_FOR_MIGRATION (重装后)

以下为重装 Ubuntu 24.04 LTS 后的完整初始化检查清单。

## 检查清单

### 1. OS 验证
```bash
cat /etc/os-release  # Ubuntu 24.04.x LTS
uname -r
```

### 2. deploy 用户
```bash
id deploy  # 确认用户存在
groups deploy  # 确认在 sudo 组
```

### 3. SSH key 登录
```bash
ssh -i ~/.ssh/jueshi-prod-v2 deploy@NEW_SERVER_IP
```
✅ 不需要密码，直接登录

### 4. sudo 验证
```bash
sudo -v  # 不需要密码
sudo whoami  # 输出 root
```

### 5. SSH 加固
```bash
# 确认 PasswordAuthentication no
sudo grep -E "PasswordAuthentication|PermitRootLogin" /etc/ssh/sshd_config
```

### 6. Node.js v22
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs
node -v  # v22.22.2
npm -v   # 10.x
```

### 7. PostgreSQL 16
```bash
sudo apt install -y postgresql postgresql-contrib
psql --version  # 16.x
sudo systemctl enable postgresql
```

### 8. Nginx
```bash
sudo apt install -y nginx
nginx -v  # 1.24.x
sudo systemctl enable nginx
```

### 9. PM2
```bash
sudo npm install -g pm2
pm2 --version
```

### 10. Certbot（如需 SSL）
```bash
sudo apt install -y certbot python3-certbot-nginx
```

### 11. 防火墙
```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
sudo ufw status verbose
```

### 12. Fail2ban
```bash
sudo apt install -y fail2ban
sudo systemctl enable fail2ban
```

### 13. 基础工具
```bash
sudo apt install -y curl git rsync build-essential ca-certificates gnupg
```

### 14. 目录结构
```bash
sudo mkdir -p /home/deploy/xixiong-saas
sudo mkdir -p /home/deploy/backups
sudo mkdir -p /home/deploy/xixiong-saas/public/uploads
sudo mkdir -p /home/deploy/xixiong-saas/public/uploads/badges
sudo mkdir -p /home/deploy/xixiong-saas/logs
sudo chown -R deploy:deploy /home/deploy
```

### 15. 时间同步
```bash
timedatectl status  # NTP synchronized: yes
```

### 16. 磁盘空间
```bash
df -h /  # 至少 50G 可用
```

### 17. 内存
```bash
free -h  # 至少 4G，推荐 8G
```

### 18. 构建验证
```bash
cd /home/deploy/xixiong-saas
npm ci
set -a && source .env.production && set +a
npx prisma generate
npm run build  # 必须成功
```

### 19. 数据库验证
```bash
# 创建数据库
sudo -u postgres createdb bxb_prod
sudo -u postgres createuser bxb_user
# 设置密码（不在报告中输出）

# 恢复 dump
pg_restore --clean --if-exists -d bxb_prod < /home/deploy/backups/migration_20260623_105136/db_dump.dump

# 迁移
npx prisma migrate deploy
npx prisma migrate status  # up to date
```

### 20. 安全验证
```bash
# 验证 admin
psql -c "SELECT email, role FROM users WHERE email='9833416@qq.com'"
# 验证 member = 0
psql -c "SELECT COUNT(*) FROM users WHERE role='member'"
```
