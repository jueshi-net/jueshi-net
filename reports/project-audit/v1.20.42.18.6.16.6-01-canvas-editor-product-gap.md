# v1.20.42.18.6.16.6 Canvas Editor Product Gap Analysis

**Date:** 2026-06-27  
**Model:** qwen3.7plus  
**Task Version:** v1.20.42.18.6.16.6

## 1. Current State

### Template Studio Current Capabilities

Template Studio 当前是**配置式模板编辑器**，支持：

- ✅ 结构化模板配置（字段显示/隐藏、列配置）
- ✅ 公司资料绑定
- ✅ 商品资料绑定
- ✅ 印章生成器
- ✅ 视觉预设（5 种风格）
- ✅ 纸张尺寸（A4、10×10、10×15）
- ✅ PNG/打印导出
- ✅ 保存/恢复
- ✅ 导航入口（工作台、工具中心、单据页）

### Configuration-Based Template Editor

配置式模板编辑器的特点：
- 基于预定义的结构（表头、公司信息、商品表格、总价区）
- 用户只能配置显示/隐藏、样式、颜色
- 元素位置由系统自动计算
- 适合标准化单据（报价单、发票、装箱单）

## 2. User Requirements Gap

### What Users Need

用户明确提出最终形态应该支持：
- ✅ 选择内容（元素选择）
- ✅ 拖动位置（自由定位）
- ✅ 放大缩小（尺寸调整）
- ✅ 自由排版（画布式设计）

### What Configuration Editor Cannot Do

配置式编辑器无法满足的需求：
- ❌ 高度定制的标签设计
- ❌ 客户专属表格布局
- ❌ 特殊面单格式
- ❌ 自定义收据样式
- ❌ 自由位置的文字、图片、印章
- ❌ 复杂的视觉层次

---

## 3. Canvas Editor Vision

### Canvas-Based Design Editor

画布式设计器应该支持：
- ✅ 元素选择（点击选中）
- ✅ 拖动定位（鼠标拖动）
- ✅ 尺寸调整（手柄缩放）
- ✅ 对齐辅助（网格吸附）
- ✅ 层级控制（zIndex）
- ✅ 纸张坐标（mm 单位）
- ✅ 属性面板（精确控制）
- ✅ 数据绑定（字段映射）
- ✅ 安全渲染（无 XSS）

### Target Use Cases

画布式编辑器的目标场景：
- 自定义标签设计（10×10、10×15）
- 客户专属单据格式
- 特殊面单布局
- 品牌化收据设计
- 自由排版的证书、奖状

## 5. Implementation Strategy

### Dual Mode Architecture

保留现有配置式编辑器，新增画布模式：

```
Template Studio
├── Structured Mode (existing)
│   ├── Field configuration
│   ├── Style presets
│   └── Auto layout
│
└── Canvas Mode (new)
    ├── Free layout elements
    ├── Drag & resize
    ├── Property panel
    └── Data binding
```

### Data Model Compatibility

- 新增 `CanvasTemplate` schema
- 不修改现有 `TemplateConfig` schema
- 模板保存时记录 `mode: "structured" | "canvas"`
- 两种模式可以共存

### Security Boundaries

画布模式必须保持安全：
- 所有元素由 React JSX 渲染
- 不允许 `dangerouslySetInnerHTML`
- 文本自动 escape
- style 只能来自白名单
- 不允许任意 CSS 字符串
- binding 只能来自允许路径

## 7. Risk Assessment

### Technical Risks

| Risk | Mitigation |
|------|-----------|
| 画布性能 | 限制元素数量，使用 CSS transform |
| 拖动精度 | 使用网格吸附，支持精确输入 |
| 保存恢复 | 使用 mm 坐标，不依赖 DOM |
| PNG 输出 | 只截取画布区域，排除编辑器 UI |
| 安全边界 | 严格白名单，无 dangerouslySetInnerHTML |

### Product Risks

| Risk | Mitigation |
|------|-----------|
| 用户困惑 | 明确区分两种模式，提供说明 |
| 功能不完整 | 标记 NEXT，持续迭代 |
| 性能问题 | 限制元素数量，优化渲染 |

---

## 8. Conclusion

本轮实现 Template Studio 画布式自由布局 MVP，满足用户对自由排版的需求，同时保持现有配置式编辑器的稳定性。通过双模式架构，用户可以按需选择结构化或画布模式，实现从标准单据到高度定制标签的全覆盖。
