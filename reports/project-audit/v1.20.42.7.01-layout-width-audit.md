## 三、修复计划

### 3.1 宽度统一规则

| 页面类型 | 建议宽度 |
|----------|----------|
| 首页模块 | max-w-7xl |
| 工具型页面 | max-w-7xl |
| 资源目录 | max-w-7xl |
| 文章/法务/FAQ | max-w-4xl（保持不变） |

### 3.2 布局优化规则

1. **运费计算页**: 桌面端双栏布局
   - 左侧：输入区（尺寸、重量、件数、计费方式、单价、汇率）
   - 右侧：结果区（CBM、体积重、实重、计费重、运费、换算结果、免责声明）

2. **集装箱页**: 卡片式横向选择
   - 每个货柜卡片展示关键容量、尺寸、适用场景
   - 桌面端 3 列布局

3. **首页**: 确保 4×2 网格合理
   - 高频工具入口：4 列
   - 外贸单据工具箱：4×2 或 3×2
