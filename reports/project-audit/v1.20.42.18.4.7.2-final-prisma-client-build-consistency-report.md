## 2. Build 失败根因

**两个根因：**

### 根因 1: Prisma Client 未重新生成
- v18.4.7 在 schema.prisma 中新增了 `Guide` 和 `Checklist` model
- 但未执行 `npx prisma generate` 重新生成 Prisma Client
- 导致 TypeScript 报错：`Property 'checklist' does not exist on type 'PrismaClient<…>'`

### 根因 2: Admin 页面缺少 force-dynamic
- v18.4.7 新增的 6 个 admin content 页面缺少 `export const dynamic = "force-dynamic"`
- Build 时 Next.js 尝试 prerender 这些页面，触发数据库查询
- 本地 build 时无数据库连接（SSH tunnel 未开），导致 `DatabaseNotReachable` 错误
- 附带发现：admin/topics 页面也缺少 force-dynamic（pre-existing）

## 3. Schema 是否有 Checklist model

**是。** `model Checklist` 在 schema.prisma line 1760，`@@map("checklists")`。
本地和生产 schema 完全一致。

## 4. Prisma Client 为什么没有 checklist

**因为未执行 `npx prisma generate`。** Schema 更新后，Prisma Client 需要重新生成才能包含新的 model 类型。

## 5. 修复方式

### 修复 1: prisma generate
- 本地执行 `npx prisma generate` → 成功
- VPS 执行 `npx prisma generate` → 成功
