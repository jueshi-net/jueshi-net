# Release Process Activation — v1.20.42.18.6.6.3-10

**Date:** 2026-06-23
**Effective:** 从 DNS 切换后立即生效

## 新发布流程声明

从 v1.20.42.18.6.6.3-production (2026-06-23) 起，以下流程正式生效：

### 1. Staging 先行
- 所有新功能先部署到 i.jueshi.net (staging)
- 在 staging 上完成 smoke test + 浏览器验证
- 用户确认后才可合并到 main 并部署到生产

### 2. 生产部署规范
- 生产只走 `scripts/deploy-safe.sh` 或等效流程
- 发布前必须执行 `scripts/backup-prod.sh`
- 有 migration 必须 `npx prisma migrate deploy` (禁止 db push)
- 构建必须 `set -a && source .env.production && set +a && npx prisma generate && npm run build`
- 构建失败则不重启 PM2、不更新 deploy-version

### 3. 发布后验证
- 必须执行 `scripts/smoke-test.sh`
- 必须生成发布报告到 `reports/project-audit/`
- 必须更新 `public/deploy-version.json`
- 必须记录 PM2 restart count (before/after)
- 必须确认 error log 无循环

### 4. 安全红线
- 禁止 `prisma db push`
- 禁止 destructive SQL (DROP/DELETE/TRUNCATE)
- 禁止修改 9833416@qq.com
- 禁止输出 secret/password/token/key
- 禁止扩大 Beta 范围 (未经用户确认)
- 禁止公开推广 (未经用户确认)

### 5. 回滚方案
- `scripts/rollback-production.sh` 必须始终存在
- DNS 回滚: Cloudflare 指回旧服务器 IP
- 旧服务器保留至少 7 天热备
- 回滚后必须执行 smoke test

### 6. 分支策略
- `main`: 生产代码
- `staging`: 预发布代码
- `feature/*`: 功能开发
- `hotfix/*`: 紧急修复
