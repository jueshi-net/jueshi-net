# SSH Key Strategy — v1.20.42.18.6.6.1

## 决策

新服务器使用**独立新建 SSH key**，不复用旧生产服务器 key。

## Key 规范

| 属性 | 值 |
|------|-----|
| 类型 | ed25519 |
| KDF rounds | 100 (高安全性) |
| 建议名称 | `jueshi-prod-v2` |
| Comment | `jueshi-prod-v2-20260623` |
| Private key 存储 | 用户本地 `~/.ssh/jueshi-prod-v2`，建议同步到安全密码管理器 |
| Public key 部署 | 写入新服务器 `/home/deploy/.ssh/authorized_keys` |

## 生成命令模板

```bash
ssh-keygen -t ed25519 -a 100 -f ~/.ssh/jueshi-prod-v2 -C "jueshi-prod-v2-20260623"
```

⚠️ 此命令由用户在本地执行，不在报告中输出 private key 内容。

## 隔离原则

| Key | 用途 | 复用? |
|-----|------|-------|
| 旧生产 key | 仅旧服务器 192.129.155.149 | 不用于新服务器 |
| jueshi-prod-v2 | 仅新服务器 | 不用于旧服务器 |
| CI/CD deploy key | 如需 CI/CD，单独创建 | 不与人工 key 混用 |

## 安全要求

- Private key **绝不**放入项目仓库
- Private key **绝不**出现在 Hermes 报告中
- Private key **绝不**发送给任何 AI 工具
- Public key 可以放入项目仓库（如 `.deploy-keys/`）或直接通过 SSH 写入
- 建议对 private key 设置 passphrase
- `~/.ssh/jueshi-prod-v2` 权限 600
- `~/.ssh` 权限 700

## SSH config 别名建议

```
# ~/.ssh/config
Host jueshi-prod-v2
    HostName NEW_SERVER_IP
    User deploy
    IdentityFile ~/.ssh/jueshi-prod-v2
    IdentitiesOnly yes
    Port 22
```
