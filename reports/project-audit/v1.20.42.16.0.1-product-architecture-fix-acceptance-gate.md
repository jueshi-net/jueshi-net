### 4.2 RewardItem 模型

**数据库模型：**
```prisma
model RewardItem {
  id          String       @id @default(cuid())
  code        String       @unique
  name        String
  description String?
  costPoints  Int
  rewardType  String
  rewardValue Int
  enabled     Boolean      @default(true)
  sortOrder   Int          @default(0)
  createdAt   DateTime     @default(now())
  updatedAt   DateTime     @updatedAt
  userRewards UserReward[]
}
```

**可用性结论：**
- ✅ API 端点存在且可用
- ✅ 从数据库读取 enabled=true 的奖励项
- ✅ 按 sortOrder 排序
- ✅ 返回 name, description, costPoints, rewardType, rewardValue

**当前状态：**
- ⚠️ 数据库中可能没有 RewardItem 记录（需要管理员在后台添加）
- ⚠️ 如果没有奖励项，前端显示："暂无可兑换的奖励项。请联系管理员添加奖励项。"

**P1 标记：**

## 五、BETA2026-001 语义确认

### 5.1 BETA2026-001 定义

**当前状态：**
- ✅ BETA2026-001 是公共 Beta 准入码
- ✅ 用于允许用户注册（不需要邀请码的公开注册已关闭）
- ✅ 不属于任何用户（ownerUserId 为空或不存在）

### 5.2 使用 BETA2026-001 是否奖励用户

**结论：**
- ❌ **不奖励任何用户**
- ✅ BETA2026-001 是系统级公共码，不是个人邀请码
- ✅ 使用 BETA2026-001 注册不会给任何用户发放邀请奖励

### 5.3 UI 是否明确说明

**验证结果：**
- ✅ /workspace/invites 页面将 BETA2026-001 放在 "Beta 公测准入码" 区域
- ✅ 明确标注："不计入个人邀请奖励"
- ✅ 个人邀请码放在 "我的邀请码" 区域
- ✅ 明确标注："邀请好友注册，获得会员奖励"

### 5.4 个人邀请码与公共邀请码区别

| 维度 | 公共 Beta 准入码 | 个人邀请码 |
|------|------------------|------------|
| 示例 | BETA2026-001 | 用户生成的唯一码 |
| ownerUserId | 无 | 有（生成者） |
| 用途 | 允许注册 | 邀请好友并获得奖励 |
| 奖励 | 无 | 邀请人获得会员天数 |
| 显示位置 | Beta 公测准入码区域 | 我的邀请码区域 |
