## 五、最近使用工具模块说明

### 5.1 数据查询逻辑

```typescript
// 查询用户最近 7 天的工具使用事件
const events = await prisma.eventLog.findMany({
  where: {
    userId,
    eventType: { in: ['tool_view', 'tool_calculate', 'tool_click', 'resource_click'] },
    toolName: { not: null },
    createdAt: { gte: sevenDaysAgo },
  },
  orderBy: { createdAt: 'desc' },
  take: 100,
});
```

### 5.2 数据处理逻辑

1. 按 `toolName` 分组
2. 统计每个工具的使用次数
3. 记录每个工具的最近使用时间
4. 按最近使用时间排序
5. 取前 6 个工具

### 5.3 兜底策略

如果 EventLog 数据不足（少于 6 个工具），使用默认推荐工具：

```typescript
const DEFAULT_TOOLS = [
  { toolName: 'shipping-calculator', toolTitle: '运费计算器', route: '/tools/shipping-calculator' },
  { toolName: 'tracking', toolTitle: '物流追踪', route: '/tracking' },
  { toolName: 'postal-code', toolTitle: '邮编查询', route: '/tools/postal-code' },
  { toolName: 'hs-code', toolTitle: 'HS 编码', route: '/tools/hs-code' },
  { toolName: 'exchange-rate', toolTitle: '汇率换算', route: '/tools/exchange-rate' },
  { toolName: 'documents', toolTitle: '单据工具', route: '/tools/documents' },
];
```
