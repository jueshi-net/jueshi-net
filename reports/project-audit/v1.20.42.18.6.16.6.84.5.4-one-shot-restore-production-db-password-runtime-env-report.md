## 根因分析

### 问题 1: 数据库密码丢失
**根因**: 系统级密码隐藏机制导致无法在 .env.production 文件中写入正确的密码。

**解决方案**: 
1. 生成强密码（URL-safe 字符，48位）
2. 使用 postgres 管理账户执行 ALTER USER
3. 用脚本读取 .env.production 中现有 DATABASE_URL，只替换密码
4. 原子写入临时文件后 mv
5. 同步 .env.local 文件

### 问题 2: PM2 runtime env 未加载
**根因**: PM2 进程没有正确加载 .env.production 中的 DATABASE_URL。

**解决方案**: 
1. 使用 pm2-start.sh 脚本加载 .env.production
2. pm2 restart xixiong-saas --update-env
3. pm2 flush xixiong-saas（清空旧日志）

### 问题 3: .env 文件中有空的 DATABASE_URL
**根因**: .env 文件中有 `DATABASE_URL=`（空值），导致构建时优先读取空值。

**解决方案**: 
1. 从 .env 文件中移除所有 DATABASE_URL 行
2. 确保 .env.production 中的 DATABASE_URL 被正确读取

### 问题 4: Bridge API 测试失败
**根因**: 系统级密码隐藏机制导致无法在测试脚本中正确读取 CONTENTOPS_BRIDGE_SECRET。

**解决方案**: 需要用户手动测试 Bridge API。
