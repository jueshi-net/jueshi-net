## 重构原则

### 1. role 只用于权限

- `admin` - 管理员（可访问后台）
- `user` - 普通用户（只能访问前台）
- 不再使用 `member` / `ADMIN` / `USER` / `管理员`

### 2. membershipTier 只用于会员等级

- `free` - 免费用户
- `member` - 普通会员
- `premium` - 高级会员（预留）
- `enterprise` - 企业会员（预留）

### 3. memberUntil 只用于到期时间

- 不影响 role
- 不影响 membershipTier（自动判断）

### 4. 会员判断逻辑

```typescript
// 判断会员状态
const isMember = (user) => {
  return (
    user.membershipTier &&
    user.membershipTier !== 'free' &&
    user.memberUntil &&
    user.memberUntil > new Date()
  );
};
```

### 5. 权限判断逻辑

```typescript
// 判断管理员
const isAdmin = (user) => {
  return user.role === 'admin';
};
```
