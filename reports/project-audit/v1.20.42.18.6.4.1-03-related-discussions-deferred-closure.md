## v18.6.4 的 DEFERRED 状态

v18.6.4 报告中 RelatedDiscussions 工具页集成标记为 DEFERRED，原因是：
- RelatedDiscussions 是服务端组件（async function）
- HS 编码工具页和 CBM 工具页是客户端组件（'use client'）
- 无法直接在客户端组件中导入服务端组件

## v18.6.4.1 闭环方案

### 1. 创建客户端版 RelatedDiscussionsClient
- 文件: `src/components/community/related-discussions-client.tsx`
- 使用 `useEffect` + `fetch` 从 API 获取数据
- 支持加载态、空态、有数据态
- 空态显示"发起相关讨论"链接，带 `?tool=` 参数跳转 `/community/new`

### 2. 创建 API 端点
- 文件: `src/app/api/forum/related-discussions/route.ts`
- GET `/api/forum/related-discussions?tool=xxx`
- 查询 `ForumPost WHERE relatedTool = tool AND status = 'published'`
- 返回帖子列表（标题/作者/评论数/分类名）

### 3. HS 编码工具页集成
- 文件: `src/app/(public)/tools/hs-code/page.tsx`

- 放置在 AdSlot 之后、TaskChainSelectDialog 之前
- 浏览器验证: "相关讨论" heading + "发起讨论" + "发起相关讨论" 链接全部可见 ✅
