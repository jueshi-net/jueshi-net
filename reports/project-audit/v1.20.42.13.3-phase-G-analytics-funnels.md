### 2. 邀请漏斗 ✅

**数据源**: EventLog 中的邀请相关事件

漏斗步骤：
1. 邀请码生成数 (`invite_code_generate`)
2. 邀请码复制数 (`invite_code_copy`)
3. 邀请链接复制数 (`invite_link_copy`)
4. 邀请注册成功数 (`invite_register_success`)
5. 奖励发放成功数 (`invite_reward_granted`)

转化率：
- 生成 → 复制
- 复制 → 链接复制
- 链接复制 → 注册
- 注册 → 奖励
- 整体转化率

空状态处理：
- 数据少时显示"样本不足"
- 不展示具体数字

### 3. 工具链漏斗 ✅

**数据源**: EventLog 中的工具链事件

漏斗步骤：
1. Quote → PI (`toolchain_quotation_to_proforma_invoice`)
2. PI → CI (`toolchain_proforma_invoice_to_commercial_invoice`)
3. CI → PL (`toolchain_commercial_invoice_to_packing_list`)
4. Container → PL (`toolchain_container_to_packing_list`)
5. 公司资料套用 (`company_profile_apply`)
6. 商品库插入 (`product_insert`)

转化率：
- Quote → PI
- PI → CI
- CI → PL

### 4. 商品库分析 ✅

**数据源**: Product 模型 + EventLog

展示：
- 商品总数
- 商品导入次数 (`product_import`)
- 商品插入次数 (`product_insert`)
- 导入失败数 (`product_import_failed`)

### 5. Resource 推荐分析 ✅

**数据源**: EventLog 中的推荐事件

展示：
- 推荐资源点击数 (`resource_featured_click`)
- 推荐资源 Top 10（按点击数排序）
- featuredGroup 表现（分组统计）

### 6. 广告权益分析 ✅

**数据源**: RewardGrant + AdApplication

展示：
- AD_SLOT_DAYS 发放总数
- 广告权益查看数 (`ad_entitlement_view`)
- 广告权益申请数 (`ad_entitlement_apply`)
- 审核通过数 (`ad_entitlement_approve`)
- 审核拒绝数 (`ad_entitlement_reject`)
- 使用状态（已使用/可用/已过期）

### 7. API 路由 ✅

**File**: `src/app/api/admin/analytics/growth-funnels/route.ts` (305 lines)

端点：`GET /api/admin/analytics/growth-funnels`

返回数据：
- `inviteFunnel` - 邀请漏斗数据
- `inviteConversions` - 邀请转化率
- `toolchainFunnel` - 工具链漏斗数据

- `resourceStats` - 资源推荐统计
- `adStats` - 广告权益统计

权限：
- 仅管理员可访问
- 检查 session.user.role === 'ADMIN'
