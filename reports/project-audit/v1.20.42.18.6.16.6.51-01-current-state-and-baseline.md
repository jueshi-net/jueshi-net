   - 引入 @react-pdf/renderer

   - 可能影响主链路

3. **Company Block 逻辑修改（v6.45）**
   - 尝试防止重复添加
   - 但可能引入新问题

4. **Print Iframe 多次修改（v6.41）**
   - 强制显示/隐藏元素
   - 可能导致样式冲突

## 恢复策略

### 方案 A: Git Checkout（推荐）

从 v6.38 基线直接恢复关键文件：

```bash
git checkout b9b32f1 -- src/app/\(public\)/tools/template-studio/canvas-editor-full.tsx
```

**优点:**
- 快速恢复
- 保留 v6.38 所有功能
- 不引入 v6.39-v6.50 的问题

**风险:**
- 可能丢失 v6.40-v6.51 中的非 print/PDF 修复
- 需要验证 v6.37 保存路由是否保留

### 方案 B: Git Revert

逐个 revert v6.39-v6.50 的 commit：

```bash
git revert 0233499 cc9185a eca7eeb ... 5a84c85
```

**优点:**
- 保留历史记录
- 可选择性 revert

**缺点:**
- 需要 revert 16+ 个 commit
- 可能产生冲突
- 耗时较长

### 方案 C: 手工恢复

对比 v6.38 和当前版本，手工合并差异。

**优点:**
- 精确控制
- 保留需要的修复

**缺点:**
- 工作量大
- 容易遗漏
