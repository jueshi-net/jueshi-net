## 二、状态说明

### 2.1 当前状态字段

| 状态 | 说明 |
|---|---|
| invited | 已发送邀请，尚未注册 |
| registered | 已注册，尚未登录测试 |
| testing | 正在测试中 |
| feedback-submitted | 已提交反馈 |
| paused | 暂停测试（遇到问题或等待修复） |
| completed | 完成所有测试任务 |

### 2.2 测试任务字段

| 字段 | 说明 |
|---|---|
| 任务链测试 | 是否完成任务链创建、工具写回、草稿生成 |
| 地址助手测试 | 是否完成地址搜索、邮编查询、加入任务链 |
| 奖励兑换测试 | 是否完成积分查看、奖励兑换、会员状态查看 |
| 是否提交反馈 | 是否填写并提交反馈表 |

### 2.3 Bug 统计字段

| 字段 | 说明 |
|---|---|
| P0数量 | 发现的 P0 级别 Bug 数量 |
| P1数量 | 发现的 P1 级别 Bug 数量 |
| P2数量 | 发现的 P2 级别 Bug 数量 |

## 三、使用指南

### 3.1 添加新用户

1. 复制空行
2. 填写用户信息
3. 更新状态为 `invited`
4. 发送邀请码

### 3.2 更新状态

1. 用户注册后：`invited` → `registered`
2. 用户开始测试：`registered` → `testing`
3. 用户提交反馈：`testing` → `feedback-submitted`
4. 用户完成所有测试：`feedback-submitted` → `completed`
5. 用户遇到问题暂停：`testing` → `paused`

### 3.3 统计反馈

1. 每周统计 P0/P1/P2 数量
2. 根据 Bug 数量决定是否暂停 Beta
3. 根据反馈优化测试流程

## 四、隐私保护

### 4.1 不得记录

- ❌ 用户密码
- ❌ 用户完整手机号
- ❌ 用户身份证号
- ❌ 用户银行卡号
- ❌ 其他敏感个人信息

### 4.2 可以记录

- ✅ 用户姓名/昵称
- ✅ 用户邮箱（用于联系）
- ✅ 测试进度
- ✅ 反馈内容
- ✅ Bug 统计
