# v1.20.42.18.4.4.3 统一工具写回协议

**任务版本：** v1.20.42.18.4.4.3  
**生成时间：** 2026-06-21

---

## 一、协议目标

统一所有工具（HS Code、CBM 计算器、地址邮编助手）写回任务链 context 的协议，确保：

1. 数据持久化到数据库（不是只保存到 localStorage）
2. 支持写入已有任务链或创建新任务链
3. 权限隔离（只能操作自己的任务链）
4. 数据合并（不覆盖已有数据）

---

## 二、API 端点

### 2.1 创建新任务链

**POST /api/task-chains**

**Request:**
```json
{
  "title": "发货任务 - Stainless Steel Vacuum Bottle",
  "sourceTool": "hs-code",
  "context": {
    "hsCode": "961700",
    "productDescription": "Vacuum flasks",
    "productName": "Stainless Steel Vacuum Bottle"
  }
}
```

**Response:**
```json
{
  "success": true,
  "taskChain": {
    "id": "cmqnjnmbz011r5v5p7fd8t1gz",
    "title": "发货任务 - Stainless Steel Vacuum Bottle",
    "sourceTool": "hs-code",
    "context": {
      "hsCode": "961700",
      "productDescription": "Vacuum flasks",
      "productName": "Stainless Steel Vacuum Bottle"
    },
    "status": "active",
    "userId": "user-id",
    "createdAt": "2026-06-21T10:00:00.000Z",
    "updatedAt": "2026-06-21T10:00:00.000Z"
  }
}
```

**权限：**
- 必须登录（401）
- 最多 100 个任务链（429）

---

### 2.2 更新已有任务链

**PATCH /api/task-chains/[id]**

**Request:**
```json
{
  "context": {
    "hsCode": "961700",
    "productDescription": "Vacuum flasks",
    "productName": "Stainless Steel Vacuum Bottle",
    "source": "hs-tool",
    "importedAt": "2026-06-21T10:00:00.000Z"
  }
}
```

**Response:**
```json
{
  "success": true,
  "taskChain": {
    "id": "cmqnjnmbz011r5v5p7fd8t1gz",
    "context": {
      "hsCode": "961700",
      "productDescription": "Vacuum flasks",
      "productName": "Stainless Steel Vacuum Bottle",
      "source": "hs-tool",
      "importedAt": "2026-06-21T10:00:00.000Z"
    },
    "updatedAt": "2026-06-21T10:00:00.000Z"
  }
}
```

**权限：**
- 必须登录（401）
- 必须是任务链 owner（404）

**合并策略：**
- API 必须 **merge** context，不得覆盖已有数据
- 实现：`updateData.context = { ...existing.context, ...newContext }`

---

**Response:**

```json
    "title": "发货任务",

```

**权限：**

**权限：**
- 必须登录（401）
- 只返回当前用户的任务链

## 三、工具写回数据格式

### 3.1 HS Code 工具

**写入字段：**
```typescript
{
  hsCode: string;           // "961700"
  productDescription: string; // "Vacuum flasks"
  productName: string;      // "Stainless Steel Vacuum Bottle"
  source: "hs-tool";
  importedAt: string;       // ISO timestamp
}
```

### 3.2 CBM 计算器

**写入字段：**
```typescript
{
  length: number;           // 30 (cm)
  width: number;            // 20 (cm)
  height: number;           // 20 (cm)
  cartons: number;          // 5
  grossWeight: number;      // 10 (kg)
  cbm: number;              // 0.06 (m³)
  chargeableWeight: number; // 12 (kg)
  source: "cbm-tool";
  importedAt: string;       // ISO timestamp
}
```

### 3.3 地址邮编助手

**写入字段：**
```typescript
{
  country: string;          // "Canada"
  city: string;             // "Toronto"
  postalCode: string;       // "M5V 3L9"
  province: string;         // "Ontario"
  addressLine: string;      // "123 Main St"
  source: "postal-helper";
  importedAt: string;       // ISO timestamp
}
```

## 四、前端交互流程

### 4.1 工具 → 任务链写回流程

```
1. 用户在工具中完成计算/查询
   ↓
2. 点击"加入任务链"按钮
   ↓
3. 弹出选择对话框：
   - 选择已有任务链（从列表中选择）
   - 创建新任务链（输入标题）
   ↓
4a. 如果选择已有任务链：
    - 调用 PATCH /api/task-chains/[id]
    - 传入工具数据
    ↓
4b. 如果创建新任务链：
    - 调用 POST /api/task-chains
    - 传入 title + sourceTool + context
    ↓
5. 成功后跳转到任务链详情页
   /workspace/task-chains/shipping/[id]
```

### 4.2 任务链步骤 → 工具数据展示

```
1. 用户进入任务链 HS/CBM/地址步骤
   ↓
2. 前端调用 GET /api/task-chains/[id]
   ↓
3. 从 context 中提取工具数据
   ↓
4. 在 UI 中展示：
   - HS Code: 961700
   - 商品描述: Vacuum flasks
   - 来源: hs-tool
   - 导入时间: 2026-06-21 10:00
```

## 五、权限隔离

### 5.1 API 层

- **未登录：** 401 Unauthorized
- **非 owner：** 404 Not Found（不暴露任务链存在）
- **owner：** 200 OK

### 5.2 前端层

- 未登录用户点击"加入任务链" → 跳转到登录页
- 登录用户只能看到自己的任务链列表

## 六、错误处理

### 6.1 网络错误

```typescript
try {
  const res = await fetch('/api/task-chains', { ... });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const json = await res.json();
  if (!json.success) throw new Error(json.error || 'Unknown error');
} catch (e) {
  alert('网络错误，请稍后重试');
}
```

### 6.2 权限错误

```typescript
if (res.status === 401) {
  router.push('/auth/signin?callbackUrl=' + encodeURIComponent(window.location.pathname));
} else if (res.status === 404) {
  alert('任务链不存在或无权访问');
}
```
