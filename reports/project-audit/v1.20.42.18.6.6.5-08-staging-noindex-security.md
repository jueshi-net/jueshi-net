# Staging Noindex & Security — v1.20.42.18.6.6.5-08

## Noindex 配置
- Nginx: `add_header X-Robots-Tag "noindex, nofollow" always;` ✅
- robots.txt: `User-agent: * Disallow: /` ✅
- Next.js metadata: noindex (APP_ENV=staging 触发)

## 邮件/通知
- staging .env.staging 中邮件发送默认关闭
- 无真实外部通知

## Basic Auth 建议
- **优点**: 防止未授权用户访问 staging
- **缺点**: 需要额外配置, 影响 CDN 缓存, API 测试不便
- **默认推荐**: 暂不加 Basic Auth, 依赖 noindex + DNS 隔离
- **用户决定**: 等待用户确认

## 环境标识
- deploy-version.json 显示 `environment=staging`
- Nginx X-Robots-Tag header 标识 staging
- PM2 app name = xixiong-staging

## 安全
- 敏感路径封锁: .env, .git, /reports → 404
- staging 不进入 sitemap
- staging 不对外推广
