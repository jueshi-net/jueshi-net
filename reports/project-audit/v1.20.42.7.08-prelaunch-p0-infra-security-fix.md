### 推荐方案

#### 1. 数据库模型设计

**新增表**: `password_reset_tokens`

```prisma
model PasswordResetToken {
  id        String    @id @default(cuid())
  email     String
  token     String    @unique
  expiresAt DateTime
  usedAt    DateTime?
  createdAt DateTime  @default(now())
  
  @@index([email])
  @@index([token])
  @@map("password_reset_tokens")
}
```

**字段说明**:
- `email`: 用户邮箱
- `token`: 随机生成的重置令牌（crypto.randomBytes(32).toString('hex')）
- `expiresAt`: 过期时间（建议 1 小时）
- `usedAt`: 使用时间（NULL 表示未使用）
- `createdAt`: 创建时间

#### 2. API 设计

**POST /api/auth/forgot-password**

请求:
```json
{
  "email": "user@example.com"
}
```

响应（无论邮箱是否存在）:
```json
{
  "success": true,
  "message": "如果邮箱已注册，您将收到重置密码的邮件"
}
```

逻辑:
1. 接收 email 参数
2. 查找用户（`prisma.user.findUnique({ where: { email } })`）
3. 如果用户存在：
   - 生成 token（64 字符随机字符串）
   - 创建 PasswordResetToken 记录（过期时间 1 小时）
   - 发送重置邮件（含链接：`https://jueshi.net/reset-password?token=xxx`）
4. 如果用户不存在：
   - 不发送邮件
   - 但仍返回成功（防止邮箱枚举）
5. 频率限制：每邮箱每小时最多 3 次请求

**POST /api/auth/reset-password**

请求:
```json
{
  "token": "abc123...",
  "password": "newPassword123"
}
```

响应:
```json
{
  "success": true,
  "message": "密码已重置，请使用新密码登录"
}
```

逻辑:
1. 接收 token 和 newPassword 参数
2. 查找 PasswordResetToken（`prisma.passwordResetToken.findUnique({ where: { token } })`）
3. 验证:
   - token 存在
   - 未过期（`expiresAt > now()`）
   - 未使用（`usedAt === null`）
4. 更新用户密码（bcrypt hash）
5. 标记 token 已使用（`usedAt = now()`）
6. 返回成功

#### 5. 安全措施

**防止邮箱枚举**:
- 无论邮箱是否存在，都返回相同的成功消息
- 不透露邮箱是否已注册

**频率限制**:
- 每邮箱每小时最多 3 次重置请求
- 使用 Redis 或数据库记录请求次数

**Token 安全**:
- 使用 crypto.randomBytes(32) 生成 64 字符随机字符串
- Token 一次性使用（使用后标记 usedAt）
- Token 1 小时后过期

**密码强度**:
- 最小长度 8 字符
- 建议包含大小写字母、数字、特殊字符
- 使用 bcrypt hash（salt rounds: 10）

#### 6. Migration 风险

**原因**:
- 新增表，不修改现有表
- 不影响现有数据
- 可安全回滚

**回滚方案**:
```bash

prisma migrate reset --name remove_password_reset_tokens
```
