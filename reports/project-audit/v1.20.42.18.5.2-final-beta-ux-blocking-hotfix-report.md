## 2. 修复详情

### 工作台移动端错位
- **根因**: `MobileStickyTabs` 作为 flex child 与主内容争夺宽度
- **修复**: 移到主内容区内（TopBar 下方）
- **文件**: `UserSidebar.tsx`, `layout.tsx`

### 任务链 CTA 404
- **根因**: v18.5.1 前路由不存在或浏览器缓存
- **验证**: 所有 task-chain 路由返回 200
- **代码修复**: 无需

### "从任务链生成"无反应
- **根因**: `absolute` 下拉框被父容器 `overflow-x-hidden` 裁剪
- **修复**: 改为 `fixed inset-0 z-50` 全屏 modal
- **文件**: `task-chain-generator-button.tsx`
- **浏览器验证**: 点击后 modal 正确打开，显示"选择发货任务" + "去登录"

### 会员权益/积分兑换入口拆分
- **修复**: hash 锚点导航 + 分区标题 + ad_slot_7day 过滤 + growth_50 标注
- **文件**: `member-client.tsx`, `api/rewards/items/route.ts`

### 邮编查询信息层级
- **修复**: "智能城市邮编查询" → "城市/地区邮编范围查询" + amber 提示 + hero 描述 + tab 文案
- **文件**: `postal-code-client.tsx`
- **浏览器验证**: 所有文案正确渲染
