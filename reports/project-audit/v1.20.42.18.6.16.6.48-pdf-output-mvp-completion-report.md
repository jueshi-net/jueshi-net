### ✅ PHASE 2 — 技术选型

**选择:** `@react-pdf/renderer` v4.5.1

**原因:**
- React/Next 技术栈接入成本低
- 支持 Document/Page/View/Text 组件
- 支持多页（repeat 模式）
- 支持绝对定位（mm 坐标）
- 支持中文字体嵌入（Noto Sans SC）
- 不依赖浏览器打印引擎

**安装:** v6.48 commit `5a84c85`

### ✅ PHASE 3 — PDF 渲染架构

**模块路径:** `src/lib/template-studio/pdf/`

**文件结构:**
```
src/lib/template-studio/pdf/
├── paper-spec.ts        # 纸张规格（10×10, 10×15, A4）
├── coordinate.ts        # 坐标转换（px → mm → pt）
├── token-resolver.ts    # Token 解析（[company.name], [sequence]）
├── render-label-pdf.tsx # PDF 渲染主逻辑
└── pdf-types.ts         # TypeScript 类型定义
```

**核心原则:**
1. ✅ 数据驱动 — 从 canvas state / template JSON 读取数据
2. ✅ 不读取 DOM — 不克隆 DOM，不使用 getBoundingClientRect
3. ✅ 不使用 iframe — 直接生成 PDF，不通过浏览器打印
4. ✅ 不注入样式 — 不使用 Tailwind CSS，不注入外部样式
5. ✅ 不使用 window.print — 不依赖 @page，不依赖 Safari 打印引擎

**实现:** v6.48 commit `5a84c85`

### ✅ PHASE 4 — 坐标适配层

**文件:** `src/lib/template-studio/pdf/coordinate.ts`

**功能:**
- `mmToPt(mm: number): number` — mm 转 pt（1mm = 2.83465pt）
- `normalizeElementForPdf(element, paperWidthMm, paperHeightMm)` — 元素坐标归一化
- 集中管理所有 px/mm/pt 转换
- 避免魔法数字散落

**实现:** v6.48 commit `5a84c85`

### ✅ PHASE 5 — PDF Renderer MVP 元素类型支持

**文件:** `src/lib/template-studio/pdf/render-label-pdf.tsx`

**支持的元素类型:**
1. ✅ **text** — 文本元素
2. ✅ **sequence** — 序号元素（1/N, 2/N, ...）
3. ✅ **company-info** — 公司信息组合块
4. ✅ **product-table** — 商品表格
5. ✅ **field** — 绑定字段
6. ✅ **多页支持** — repeat 模式，packageCount=11 → 11 页 PDF

**不新增（按要求）:**
- ❌ Logo 块
- ❌ 二维码
- ❌ 条形码
- ❌ 会员权限
- ❌ 批量 PNG ZIP

**实现:** v6.48 commit `5a84c85`, v6.49 commit `ddafad6`

### ✅ PHASE 6 — Token Resolver

**文件:** `src/lib/template-studio/pdf/token-resolver.ts`

**支持的 Token:**
- ✅ `[company.name]`
- ✅ `[company.companyName]`
- ✅ `[company.contactName]`
- ✅ `[company.phone]`
