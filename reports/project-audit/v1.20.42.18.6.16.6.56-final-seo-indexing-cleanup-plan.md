## 问题总结

### 🔴 根本原因

**`next.config.ts` 对 jueshi.net 所有页面设置了 `X-Robots-Tag: noindex, nofollow`**

```typescript
// next.config.ts 第 81-113 行
async headers() {
  return [
    {
      source: "/:path*",
      headers: [{ key: "X-Robots-Tag", value: "noindex, nofollow" }],
      has: [{ type: "host", value: "jueshi.net" }],  // ❌ 正式站被 noindex
    },
    {
      source: "/:path*",
      headers: [{ key: "X-Robots-Tag", value: "noindex, nofollow" }],
      has: [{ type: "host", value: "www.jueshi.net" }],  // ❌ www 也被 noindex
    },
  ];
}
```

**这是开发阶段的配置，正式站上线后忘记移除。**

---

## 修复方案

### 方案 1：修改 next.config.ts（推荐）

**修改内容：** 只对 staging (i.jueshi.net) 设置 noindex，正式站允许索引

```typescript
async headers() {
  return [
    // ✅ 只对 staging 设置 noindex
    {
      source: "/:path*",
      headers: [
        {
          key: "X-Robots-Tag",
          value: "noindex, nofollow",
        },
      ],
      has: [
        {
          type: "host",
          value: "i.jueshi.net",  // ✅ 只对 staging
        },
      ],
    },
  ];
}
```

**影响范围：**
- ✅ jueshi.net：移除 noindex，允许 Google 索引
- ✅ i.jueshi.net：保持 noindex，阻止索引
- ✅ 不影响 Template Studio 或任何功能代码

### 方案 2：完全移除 headers 配置

**修改内容：** 删除第 81-113 行的整个 headers 配置

**影响范围：**
- ✅ jueshi.net：允许索引
- ⚠️ i.jueshi.net：需要其他方式阻止索引（robots.txt 已配置 Disallow: /）
