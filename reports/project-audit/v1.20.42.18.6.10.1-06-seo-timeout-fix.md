# v1.20.42.18.6.10.1-06 — SEO Timeout Fix Report

## Problem
P3-001 (home page /) and P3-003 (/bbs) SEO tests timed out with `page.getAttribute: Timeout 30000ms exceeded`.

## Root Cause
AUDIT_SCRIPT_BUG — The audit script used `page.getAttribute('meta[name="description"]', 'content')` which is unreliable in Playwright for meta tags in SSR pages. The meta tags DO exist (confirmed via curl):
- Home page: title="绝世百宝箱 - 海外华人的实用工具箱", meta description exists
- BBS page: title="社区 | 绝世百宝箱", meta description="交流海外生活、工具经验、物流问题的社区"

## Fix
Changed from `page.getAttribute(selector, attr)` to `page.$eval(selector, el => el.content)` with try/catch fallback.

## Verification (rerun results)
- P3-001 (home /): PASS — title=Y desc=Y canonical=N og=Y http=200
- P3-002 (canada): PASS — title=Y desc=Y canonical=Y og=Y robots=index,follow http=200
- P3-003 (bbs): PASS — title=Y desc=Y canonical=Y og=Y http=200
- P3-004 (noindex): PASS — X-Robots-Tag: noindex, nofollow

## Conclusion
SEO meta tags exist on all pages. No product fix needed. Audit script fixed.

**Classification: AUDIT_SCRIPT_BUG (not a product defect)**
