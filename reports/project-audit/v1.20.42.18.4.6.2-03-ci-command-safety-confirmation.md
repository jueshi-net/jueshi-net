### 2.2 详细确认

#### test:regression — 不连接生产数据库 ✅

- **第一部分**: `vitest run tests/phase-g-analytics-funnels.test.ts`
  - 纯 mock 测试，使用硬编码的 mock 数据
  - 不导入 PrismaClient 或 DATABASE_URL
  - 不执行任何数据库查询

- **第二部分**: `npx tsx tests/v18.3.3-task-chain-e2e.ts`
  - 通过 HTTP fetch 请求 `https://jueshi.net` API
  - 使用测试账号 `e2e-task-chain-20260621@jueshi.net`
  - 不直接连接数据库，不导入 PrismaClient
  - 通过 NextAuth CSRF + cookie 进行认证

#### test:beta:gate — 不连接生产数据库 ✅

- `npm run lint` — ESLint 静态分析
- `npm run build` — Next.js 构建 (使用 CI 中的 dummy DATABASE_URL)
- `npm run test:unit` — 纯 mock 测试

#### test:vps — 手动命令 ✅

- 仅输出提示文本：`echo "Run on VPS: cd /home/deploy/xixiong-saas && npx tsx tests/v18.3.2-db-tests.ts"`
- 需要手动在 VPS 上执行

#### test:e2e:prod — 手动命令 ✅

- `BASE_URL=https://jueshi.net playwright test --reporter=list`
- 需要手动执行
- 通过浏览器 HTTP 交互，不直接连数据库

### 2.3 package.json 不默认 export 生产 secret ✅

- package.json 中无任何环境变量定义
- 所有环境变量通过 .env 文件或 CI 环境注入
- .env 文件未被 Git 跟踪
