### 5.1 检查 Role 分布

**命令（VPS）：**
```bash
export $(grep DATABASE_URL .env.production | xargs)
npx tsx -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
async function main() {
  const roles = await prisma.user.groupBy({ by: ['role'], _count: true });
  console.log('Role distribution:', JSON.stringify(roles, null, 2));
  const memberCount = roles.find(r => r.role === 'member')?._count || 0;
  if (memberCount > 0) {
    console.error('P0: role=member found:', memberCount);
    process.exit(1);
  }
  console.log('✅ No role=member users');
}
main();
"
```

**预期结果：**
- ✅ role=admin: 5
- ✅ role=user: 26
- ✅ role=member: 0

**阻断条件：**
- ❌ role=member > 0
