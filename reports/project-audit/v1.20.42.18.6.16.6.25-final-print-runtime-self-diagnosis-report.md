## 一、Runtime 诊断结果

### 根因分类（v6.23 → v6.25 修复的 6 个问题）

| # | 根因 | 严重度 | 修复方式 |
|---|------|--------|----------|
| 1 | iframe 克隆 `printRoot.innerHTML` 包含外层 wrapper div | P0 | 改为只查询 `canvas-print-page`/`canvas-paper` 元素 |
| 2 | CSS 转义错误：`.print\\\\:hidden`（4反斜杠）→ CSS 解析为 `print\` + `:hidden` 伪类 | P0 | 移除 CSS 隐藏规则，改为 DOM 级别直接删除元素 |
| 3 | iframe 尺寸 0x0 导致某些浏览器不渲染 | P1 | 改为 1px x 1px + overflow:hidden |
| 4 | `iframe.print()` 在 document 未 ready 时调用 | P1 | 改为轮询 `readyState === "complete"` 后再触发 |
| 5 | iframe 清理太早（2s）导致打印对话框被取消 | P1 | 延长到 5s |
| 6 | page-count/sequence 指示器在 iframe 中可能重复显示 | P0 | 在克隆 DOM 时直接 `remove()` 这些元素 |

1. SSH 到 staging 读取部署后的源码

3. 分析 CSS 转义链：template literal → CSS parser → class selector
4. 验证 `printRoot.innerHTML` 的内容结构
5. 检查 iframe 尺寸和 readyState 处理

## 二、v6.25 修复详情

### 修复 1：只克隆 canvas-print-page 元素

```typescript
// v6.23（旧）：克隆整个 printRoot innerHTML
${printRoot.innerHTML}

// v6.25（新）：只查询并克隆页面元素
const pages = printRoot.querySelectorAll(
  "[data-testid=\"canvas-print-page\"], [data-testid=\"canvas-paper\"]"
);
let pagesHTML = "";
pages.forEach((page) => {
  const clone = page.cloneNode(true) as HTMLElement;
  // 直接删除不需要打印的元素
  clone.querySelectorAll("[data-testid=\"canvas-print-page-count\"], ...")
    .forEach(el => el.remove());
  pagesHTML += clone.outerHTML;
});
```

### 修复 2：移除 CSS 转义规则

v6.23 的 `.print\\\\:hidden` 在 CSS 中被解析为 `class="print\"` + `:hidden` 伪类，完全无法匹配 `class="print:hidden"` 的元素。

v6.25 不再依赖 CSS 隐藏，而是在 DOM 克隆时直接删除这些元素。

### 修复 3：iframe 尺寸

```typescript
// v6.23（旧）
iframe.style.width = "0";
iframe.style.height = "0";

// v6.25（新）
iframe.style.width = "1px";
iframe.style.height = "1px";
iframe.style.overflow = "hidden";
```

### 修复 4：等待 iframe document ready

```typescript
// v6.25（新）：轮询 readyState
const checkReady = () => {
  if (iframeDoc.readyState === "complete") {
    setTimeout(() => {
      iframe.contentWindow!.focus();
      iframe.contentWindow!.print();
    }, 500);
  } else {
    setTimeout(checkReady, 100);
  }
};
checkReady();
```

### 修复 5：延迟清理

```typescript
// v6.23（旧）：2s
setTimeout(() => { document.body.removeChild(iframe); }, 2000);

// v6.25（新）：5s
setTimeout(() => { document.body.removeChild(iframe); }, 5000);
```

### 修复 6：DOM 级别删除重复指示器

```typescript
clone.querySelectorAll(
  "[data-testid=\"canvas-print-page-count\"], [data-testid=\"canvas-print-page-sequence\"]"
).forEach(el => el.remove());
```
