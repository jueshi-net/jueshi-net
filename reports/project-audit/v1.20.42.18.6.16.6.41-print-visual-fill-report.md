## Issues Fixed

### 1. Print Iframe Elements Not Visible

**Problem:** Elements in print iframe had `display: none`, causing 0 dimensions.

**Root Cause:** 
- Cloned elements retained `hidden` class from Tailwind
- Iframe CSS didn't override the hidden state
- Elements were in DOM but not rendered

**Solution:**
Added CSS rules to force visibility in print iframe:
```css
[data-testid="canvas-print-unscaled-paper"] {
  display: block !important;
  position: absolute !important;
  width: 100% !important;
  height: 100% !important;
}

[data-testid^="canvas-element"],
[data-testid="canvas-text-element"],
[data-testid="canvas-company-info-block"],
[data-testid^="canvas-company-field-"] {
  display: block !important;
  visibility: visible !important;
}
```

### 2. Binding Placeholders Visible in Print

**Problem:** Placeholders like `[company.companyName]` appeared in print output.

**Root Cause:**
- `resolveBinding()` returns empty string when no data
- Rendering code showed placeholder when resolved was empty
- Placeholders included in text content

**Solution:**
Removed placeholder rendering entirely:
```tsx
// Before
<span>{resolved || `[${field.binding}]`}</span>

// After
<span>{resolved}</span>
```

**Files Modified:**
- `src/app/(public)/tools/template-studio/canvas-editor-full.tsx`
