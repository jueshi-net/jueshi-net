# SSH Hardening Plan — v1.20.42.18.6.6.1

## 前提

⚠️ 以下配置**不得在新服务器上执行**，除非：
1. deploy 用户已创建
2. SSH key 登录已验证成功
3. sudo 已验证可用
4. 保留了 emergency access（console/root）

## sshd_config 推荐配置

```sshd_config
# /etc/ssh/sshd_config

# Authentication
PasswordAuthentication no
PubkeyAuthentication yes
PermitRootLogin prohibit-password
KbdInteractiveAuthentication no
PermitEmptyPasswords no
AllowUsers deploy

# Timing
LoginGraceTime 30
MaxAuthTries 3

# Forwarding (按需)
AllowTcpForwarding no
X11Forwarding no
```

## 执行步骤

1. **保持当前 SSH session 不关闭**
2. 修改 `/etc/ssh/sshd_config`
3. `sudo sshd -t` 验证语法
4. `sudo systemctl reload sshd`
5. **新 SSH session 测试**: `ssh -i ~/.ssh/jueshi-prod-v2 deploy@NEW_SERVER_IP`
6. 确认成功后才关闭旧 session

## Fail2ban

```bash
sudo apt install fail2ban
sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

配置 `/etc/fail2ban/jail.local`:
```ini
[sshd]
enabled = true
port = 22
maxretry = 3
bantime = 3600
findtime = 600
```

## 防火墙 (UFW)

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

## 当前生产环境参考

| 配置 | 当前生产值 |
|------|-----------|
| PermitRootLogin | no |
| PasswordAuthentication | yes ⚠️ (生产仍有密码登录) |
| Fail2ban sshd jail | 激活，已封 655 IP |
| UFW | 激活 (22/80/443) |
| sudo | deploy NOPASSWD: ALL |

**注意:** 当前生产仍有 PasswordAuthentication=yes，新服务器应更严格（no）。

## 禁止事项

- 不得在 key 登录验证前禁用密码
- 不得在 sudo 验证前关闭 root 登录
- 不得关闭 emergency access（console）
- 不得把 SSH 端口改成非标准端口（除非有明确安全策略）
