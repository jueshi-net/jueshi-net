## 二、问题修复

### 2.1 PATCH 方法缺失

**问题：** 工作台使用 `method: 'PATCH'`，但 API 路由只有 `PUT`

**修复：**
```typescript
// 添加 PATCH 方法
export async function PATCH(req: NextRequest, { params }: RouteParams) {
  return updateTaskChain(req, params);
}

// PUT 和 PATCH 共用同一个处理函数
export async function PUT(req: NextRequest, { params }: RouteParams) {
  return updateTaskChain(req, params);
}
```

### 2.2 Context 字段映射不一致

**问题：** 
- API 将 currentStep/completedSteps 存储在 context JSON 中
- 前端期望这些字段在顶层

**修复：**
1. API 端：在 updateTaskChain 中处理 currentStep/completedSteps，存储到 context
2. 前端列表页：从 context 中提取 currentStep/completedSteps 映射到顶层
3. 前端工作台：从 context 中读取 currentStep/completedSteps

**代码变更：**

**API (route.ts):**
```typescript
// 存储 currentStep 和 completedSteps 到 context
if (currentStep !== undefined || completedSteps !== undefined) {
  const currentContext = (existing.context as Record<string, unknown>) || {};
  const newContext = { ...currentContext };
  
  if (currentStep !== undefined) {
    newContext.currentStep = currentStep;
  }
  if (completedSteps !== undefined) {
    newContext.completedSteps = completedSteps;
  }
  
  updateData.context = newContext;
}
```

**前端列表页 (task-chains-client.tsx):**
```typescript
// 从 context 中提取字段映射到顶层
const chains = (data.taskChains || []).map((tc: any) => ({
  ...tc,
  currentStep: tc.context?.currentStep || 0,
  completedSteps: tc.context?.completedSteps || [],
}));
setTaskChains(chains);
```

**前端工作台 (shipping-workbench.tsx):**
```typescript
// 从 context 中读取
setCurrentStep(tc.context?.currentStep || 0);
setContext(tc.context || {});

// 完成步骤时更新 context
const currentCompletedSteps = context.completedSteps || [];
const completedSteps = [...new Set([...currentCompletedSteps, stepIndex])];
setContext(prev => ({ ...prev, completedSteps, currentStep: nextStep }));
```

### 2.3 响应数据结构不一致

**问题：**
- API 返回 `{ taskChain }` 或 `{ taskChains: [] }`
- 前端期望 `{ data: { id: ... } }` 或 `{ data: [] }`

**修复：**
- shipping-new-client.tsx: `data.taskChain.id` 替代 `data.data.id`
- task-chains-client.tsx: `data.taskChains` 替代 `data.data`
- shipping-workbench.tsx: `data.taskChain` 替代 `data.data`

### 4.1 TaskChainDraft Schema

```prisma
model TaskChainDraft {
  id                 String    @id @default(cuid())
  userId             String    @map("user_id")
  user               User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  // Core fields
  title              String
  status             String    @default("active") // active / completed / archived / deleted
  sourceTool         String    @map("source_tool")
  lastActiveTool     String?   @map("last_active_tool")
  
  // Context data (JSON) - 存储所有步骤数据
  context            Json      // { productName, hsCode, ..., currentStep, completedSteps }
  linkedDraftHints   Json?     @map("linked_draft_hints")
  
  // Timestamps
  createdAt          DateTime  @default(now()) @map("created_at")
  updatedAt          DateTime  @updatedAt @map("updated_at")
  completedAt        DateTime? @map("completed_at")
  
  @@index([userId])
  @@index([status])
  @@map("task_chain_drafts")
}
```

## 六、自动保存机制

### 6.1 工作台自动保存

```typescript
// 每次字段变更触发自动保存
const autoSave = useCallback(async (patch: Record<string, any>) => {
  setSaveStatus('saving');
  const newContext = { ...context, ...patch };
  setContext(newContext);

  try {
    const res = await fetch(`/api/task-chains/${taskId}`, {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        context: newContext,
        currentStep,
      }),
    });
    if (res.ok) {
      setSaveStatus('saved');
      setTimeout(() => setSaveStatus('idle'), 2000);
    } else {
      setSaveStatus('error');
    }
  } catch {
    setSaveStatus('error');
  }
}, [context, currentStep, taskId]);
```

### 6.2 保存状态指示器

```typescript

  )}
```
