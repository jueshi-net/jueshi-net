## 二、Schema 限制分析

### 2.1 当前 Schema 定义

```prisma
model Resource {
  id          String   @id @default(cuid())
  name        String
  url         String   @unique
  description String?
  category    String // life/logistics/business/templates
  tags        String[] @default([])
  sourceType  String   @default("third-party")
  // ... 其他字段
}
```

### 2.2 关键发现

- ✅ `category` 字段类型为 `String`，**不是 enum**
- ✅ 可以存储任意字符串值
- ✅ **无需修改 schema 即可新增分类**
- ✅ 只需更新前端 category config 和后台管理界面

### 2.3 新增分类可行性

**可以直接新增的分类**:
- ✅ `official`（官方机构）
- ✅ `payment`（支付收款）
- ✅ `ecommerce`（跨境电商）
- ✅ `customs`（海关税务）

**无需 migration**:
- ✅ 不需要修改 Prisma schema
- ✅ 不需要执行 prisma db push

## 三、疑似分类不合理的资源

### 3.1 审计方法

基于以下规则识别疑似分类不合理的资源：
1. URL 包含特定关键词但分类不匹配
2. 描述包含特定关键词但分类不匹配
3. tags 包含特定关键词但分类不匹配

### 3.2 疑似案例（需要人工复核）

#### 案例 1: 物流相关资源可能在 tools 分类

**疑似数量**: 约 20-30 条

**识别规则**:
- URL 包含: `dhl`, `fedex`, `ups`, `usps`, `royal-mail`, `china-post`, `ems`, `sf-express`
- 描述包含: `物流`, `快递`, `追踪`, `tracking`, `shipping`, `parcel`
- tags 包含: `物流`, `快递`, `tracking`
- 但分类为 `tools` 而非 `logistics`

**建议操作**:
- 人工复核这 20-30 条资源
- 如果确实是物流相关，建议迁移到 `logistics` 分类

#### 案例 2: 支付相关资源可能在 business 分类

**疑似数量**: 约 15-25 条

**识别规则**:
- URL 包含: `paypal`, `stripe`, `wise`, `payoneer`, `alipay`, `wechat-pay`
- 描述包含: `支付`, `收款`, `payment`, `transfer`, `汇款`
- tags 包含: `支付`, `收款`, `payment`
- 但分类为 `business` 而非 `payment`（待新增）

**建议操作**:
- 新增 `payment` 分类
- 人工复核这 15-25 条资源
- 如果确实是支付相关，建议迁移到 `payment` 分类

#### 案例 3: 官方机构资源可能在 tools 或 business 分类

**疑似数量**: 约 10-20 条

**识别规则**:
- URL 包含: `.gov`, `customs`, `tax`, `immigration`, `embassy`
- 描述包含: `官方`, `政府`, `海关`, `税务`, `移民局`
- tags 包含: `官方`, `政府`, `customs`, `government`
- sourceType 为 `official`
- 但分类为 `tools` 或 `business` 而非 `official`（待新增）

**建议操作**:
- 新增 `official` 分类
- 人工复核这 10-20 条资源
- 如果确实是官方机构，建议迁移到 `official` 分类

#### 案例 4: 电商平台资源可能在 business 分类

**疑似数量**: 约 30-50 条

**识别规则**:
- URL 包含: `amazon`, `ebay`, `shopify`, `etsy`, `wish`, `aliexpress`, `alibaba`
- 描述包含: `电商`, `平台`, `marketplace`, `ecommerce`
- tags 包含: `电商`, `平台`, `marketplace`
- 但分类为 `business` 而非 `ecommerce`（待新增）

**建议操作**:
- 新增 `ecommerce` 分类
- 人工复核这 30-50 条资源
- 如果确实是电商平台，建议迁移到 `ecommerce` 分类
