# v1.20.42.7.08.5 Telegram 与 Resend 配置指南

## 步骤 1: SSH 登录服务器

```bash
ssh deploy@192.129.155.149
```

## 步骤 2: 配置 Telegram 告警

```bash
cd /home/deploy/xixiong-saas
cp .env.production .env.production.backup.$(date +%Y%m%d_%H%M%S)
nano .env.production
```

在文件末尾添加以下 4 行（把 `你的BOT_TOKEN` 替换为 @BotFather 给的完整 token）：

```
# Telegram Alert Configuration
ALERT_CHANNEL=telegram
TELEGRAM_BOT_TOKEN=***
TELEGRAM_CHAT_ID=8602323654
```

保存退出（Ctrl+O, Enter, Ctrl+X）

设置权限：
```bash
chmod 600 .env.production
```

测试 Telegram：
```bash
source .env.production
curl -X POST "https://api.telegram.org/bot\${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d "chat_id=\${TELEGRAM_CHAT_ID}&text=✅ jueshi.net 告警配置成功"
```

预期返回：`{"ok":true,...}`

## 步骤 3: 配置 Resend 事务邮件

### 3.1 注册 Resend

1. 访问 https://resend.com
2. 用 GitHub 登录或邮箱注册
3. 免费额度：每月 3000 封，每天 100 封

### 3.2 添加发信域名

1. Resend Dashboard → Domains → Add Domain
2. 输入：`jueshi.net`
3. Resend 会显示 3 条 DNS 记录，类似：

```
类型    名称                      值
TXT     @                         v=spf1 include:_spf.resend.com ~all
CNAME   resend._domainkey         (Resend 会给出具体的 CNAME 值)
TXT     _dmarc                    v=DMARC1; p=quarantine; rua=mailto:dmarc@jueshi.net
```

**重要**：复制这些记录，下一步要用。

### 3.3 获取 API Key

1. Resend Dashboard → API Keys → Create API Key
2. 名称：`jueshi-net-production`
3. 复制 API Key（格式：`re_xxxxxxxxxxxxxxxxxxxxxxxxx`）

### 3.4 写入服务器环境变量

```bash
cd /home/deploy/xixiong-saas
nano .env.production
```

在文件末尾添加：

```
# Resend Transactional Email
RESEND_API_KEY=***
MAIL_FROM=hello@jueshi.net
MAIL_FROM_NAME=绝世百宝箱
```

保存退出，设置权限：
```bash
chmod 600 .env.production
```

### 3.5 配置 Cloudflare DNS

1. 登录 https://dash.cloudflare.com
2. 选择域名：`jueshi.net`
3. 进入 DNS → Records
4. **删除或修改**现有的 SPF 记录（`v=spf1 -all`）
5. **添加** Resend 提供的 3 条记录：

**SPF 记录**（替换现有的）：
- 类型：TXT
- 名称：`@`
- 内容：`v=spf1 include:_spf.resend.com ~all`

**DKIM 记录**（Resend 会给出具体的 CNAME 值）：
- 类型：CNAME
- 名称：`resend._domainkey`
- 目标：（Resend Dashboard 中显示的值）

**DMARC 记录**（可选，如果现有 DMARC 导致投递问题）：
- 类型：TXT
- 名称：`_dmarc`
- 内容：`v=DMARC1; p=quarantine; rua=mailto:dmarc@jueshi.net`

6. 保存所有记录

### 3.6 等待 DNS 生效

DNS 传播通常需要 5-30 分钟，最长可能需要 24 小时。

验证 DNS（在服务器上执行）：
```bash
# 检查 SPF
dig +short TXT jueshi.net | grep spf

# 检查 DKIM
dig +short CNAME resend._domainkey.jueshi.net

# 检查 DMARC
dig +short TXT _dmarc.jueshi.net
```

## 故障排除

### Telegram 测试失败

检查：
1. Bot Token 是否正确（从 @BotFather 复制完整）
2. Chat ID 是否正确（8602323654）
3. 是否给 bot 发送过消息（必须先 /start）

### Resend 邮件发送失败

检查：
1. API Key 是否正确（以 `re_` 开头）
2. 域名是否在 Resend Dashboard 中验证通过
3. DNS 记录是否已生效（等待 5-30 分钟）
4. SPF 记录是否包含 `include:_spf.resend.com`

### PM2 重启后环境变量未更新

使用 `--update-env` 参数：
```bash
pm2 restart xixiong-saas --update-env
```

或完全删除后重启：
```bash
pm2 delete xixiong-saas
pm2 start npm --name "xixiong-saas" -- start
```
