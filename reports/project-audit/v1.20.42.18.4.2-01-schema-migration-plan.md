## 字段语义定义

### 1. role 字段

**语义：** 只用于权限角色

**合法值：**
- `admin` - 管理员（可访问后台）
- `user` - 普通用户（只能访问前台）

**禁止值：**
- ❌ member
- ❌ ADMIN
- ❌ USER
- ❌ 管理员
- ❌ vip
- ❌ premium
- ❌ 任何会员等级值

**判断逻辑：**
```typescript
// 权限判断
const requireAdmin = (user) => {
  if (user.role !== 'admin') {
    throw new Error('无权限');
  }
};

const isAdmin = (user) => user.role === 'admin';
```

**写入规则：**
- 注册时默认 `user`
- 只有管理员可以通过后台修改
- 业务逻辑（奖励、邀请、会员）禁止写入

### 2. membershipTier 字段（新增）

**语义：** 只用于会员等级

**合法值：**
- `free` - 免费用户
- `member` - 普通会员
- `premium` - 高级会员（预留）
- `enterprise` - 企业会员（预留）

**判断逻辑：**
```typescript
// 会员判断
const isMember = (user) => {
  return (
    user.membershipTier !== 'free' &&
    user.memberUntil &&
    user.memberUntil > new Date()
  );
};

// 或者简化版
const isMember = (user) => {
  return user.memberUntil && user.memberUntil > new Date();
};
```

**写入规则：**
- 注册时默认 `free`
- 会员兑换时更新
- 根据 memberUntil 自动判断

### 3. memberUntil 字段

**语义：** 只用于会员到期时间

**类型：** DateTime?

**判断逻辑：**
```typescript
// 会员有效期判断
const hasValidMembership = (user) => {
  return user.memberUntil && user.memberUntil > new Date();
};
```

**写入规则：**
- 会员兑换时更新
- 邀请奖励发放会员天数时更新
- 不影响 role

## Migration 计划

### Step 1: 添加 membershipTier 字段

**Prisma Schema:**
```prisma
model User {
  // ... existing fields
  role                   String               @default("user")
  membershipTier         String               @default("free") @map("membership_tier")
  memberUntil            DateTime?            // 会员体验到期时间
  // ... rest
}
```

**Migration SQL:**
```sql
-- Add membershipTier column
ALTER TABLE "users" ADD COLUMN "membership_tier" TEXT NOT NULL DEFAULT 'free';

-- Backfill based on memberUntil
UPDATE "users" 
SET "membership_tier" = 'member' 
WHERE "member_until" > NOW();

-- Normalize role values
UPDATE "users" SET "role" = 'admin' WHERE "role" IN ('ADMIN', '管理员');
UPDATE "users" SET "role" = 'user' WHERE "role" IN ('USER');

-- Ensure 9833416@qq.com is admin
UPDATE "users" SET "role" = 'admin' WHERE "email" = '9833416@qq.com';
```

### Step 2: 数据回填

**回填逻辑：**
1. 所有用户默认 `membershipTier = 'free'`
2. 如果 `memberUntil > now`，设置 `membershipTier = 'member'`
3. 规范化 role 值

**预期结果：**
- role: 只保留 admin / user
- membershipTier: free / member
- memberUntil: 保持不变

### Step 3: 代码重构

**需要修改的文件：**
1. `src/lib/invite-rewards.ts` - 已修复，不再写 role
2. `src/app/api/rewards/redeem/route.ts` - 已修复，不再写 role
3. 所有 `role === "member"` 判断 - 改为 `membershipTier` 或 `memberUntil`
4. 所有 `isAdminRole` 判断 - 确保只检查 `role === 'admin'`

### Step 4: 添加防污染保护

**新增 helper:**
```typescript
// src/lib/role-protection.ts

export const VALID_ROLES = ['admin', 'user'] as const;
export type ValidRole = typeof VALID_ROLES[number];

export function normalizeRole(role: string): ValidRole {
  if (role === 'admin' || role === 'ADMIN' || role === '管理员') {
    return 'admin';
  }
  return 'user';
}

export function assertValidRole(role: string): asserts role is ValidRole {
  if (!VALID_ROLES.includes(role as ValidRole)) {
    throw new Error(`Invalid role: ${role}. Must be one of: ${VALID_ROLES.join(', ')}`);
  }
}

// 保护 9833416@qq.com 不被修改
export function isProtectedAdmin(email: string): boolean {
  return email === '9833416@qq.com';
}
```
