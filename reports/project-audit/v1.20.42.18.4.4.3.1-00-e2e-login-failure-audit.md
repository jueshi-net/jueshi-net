## 一、测试用户状态检查

### 1.1 原测试用户 e2e-task-chain-20260621@jueshi.net

**数据库查询结果：**
```
email: e2e-task-chain-20260621@jueshi.net
name: E2E Test User
role: user
emailVerified: null (空)
createdAt: 2026-06-21 03:28:28.328
```

**问题：**
- ✅ 用户存在
- ✅ role = user（正确）
- ❌ emailVerified = null（未验证）
- ❌ **accounts 表中没有 credentials 记录**

**根本原因：**
用户是通过直接插入 `users` 表创建的，没有通过注册 API，因此：
1. 没有设置密码（password 字段为空或无效）
2. 没有在 `accounts` 表中创建 credentials 记录
3. NextAuth 无法通过 credentials 方式登录

### 1.2 数据库连接问题

**发现的环境变量问题：**
- `.env.local` 中的 DATABASE_URL 端口错误（5555 而不是 5432）
- `.env.local` 中的数据库密码与 `.env.production` 不一致
- 导致应用无法连接数据库

**修复：**
```bash
cp .env.production .env.local
pm2 restart xixiong-saas --update-env
```

## 二、登录失败根因

### 2.1 主要原因

**测试用户没有 credentials 账号**

NextAuth credentials 登录流程：
1. 用户提交 email + password
2. NextAuth 查询 `accounts` 表，查找 `provider = 'credentials'` 的记录
3. 验证密码 hash
4. 返回 session

**实际情况：**
- `users` 表中有用户记录
- `accounts` 表中没有对应的 credentials 记录
- 登录失败，返回 401

### 2.2 次要原因

**环境变量配置错误**
- `.env.local` 端口错误（5555）
- 数据库密码不一致
- 导致应用无法连接数据库
