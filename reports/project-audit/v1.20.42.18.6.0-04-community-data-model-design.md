## 2. 新增模型（一期必须）

### ForumReaction — 点赞/有用

```prisma
model ForumReaction {
  id         String   @id @default(cuid())
  userId     String   @map("user_id")
  targetType String   @map("target_type")  // "post" | "comment"
  targetId   String   @map("target_id")
  type       String   // "like" | "useful"
  createdAt  DateTime @default(now()) @map("created_at")

  user       User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, targetType, targetId, type])
  @@index([targetType, targetId])
  @@index([userId])
  @@map("forum_reactions")
}
```

### ForumReport — 举报

```prisma
model ForumReport {
  id         String    @id @default(cuid())
  reporterId String    @map("reporter_id")
  targetType String    @map("target_type")  // "post" | "comment"
  targetId   String    @map("target_id")
  reason     String    // 举报原因
  status     String    @default("pending")  // pending / reviewed / dismissed
  reviewedBy String?   @map("reviewed_by")
  reviewedAt DateTime? @map("reviewed_at")
  createdAt  DateTime  @default(now()) @map("created_at")

  reporter   User      @relation("ForumReports", fields: [reporterId], references: [id])
  reviewer   User?     @relation("ForumReviews", fields: [reviewedBy], references: [id])

  @@index([status])
  @@index([targetType, targetId])
  @@map("forum_reports")
}
```

### ForumBookmark — 收藏

```prisma
model ForumBookmark {
  id        String   @id @default(cuid())
  userId    String   @map("user_id")
  topicId   String   @map("topic_id")  // ForumPost ID
  createdAt DateTime @default(now()) @map("created_at")

  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  post      ForumPost @relation(fields: [topicId], references: [id], onDelete: Cascade)

  @@unique([userId, topicId])
  @@index([userId])
  @@map("forum_bookmarks")
}
```

## 4. Migration 风险评估

### 操作
- 新增 3 个表（forum_reactions, forum_reports, forum_bookmarks）— **安全**
- ForumPost 新增 8 个字段 — **安全**（都有默认值）
- ForumComment 新增 1 个字段 — **安全**（默认值 0）
- User 模型新增关系字段 — **安全**（仅关系定义，不加列）

### 风险
- **零风险**：所有新增都是 additive（添加表/字段），不修改或删除现有数据
- **不影响现有 User / role / membershipTier**：新表通过 userId 外键关联，不修改 User 表结构
- **不需要 prisma db push**：使用 `prisma migrate dev` 创建 migration
- **回滚方案**：`prisma migrate resolve --rolled-back` 回滚 migration

### 对现有系统的影响
- ForumCategory: 不修改 ✅
- ForumPost: 只添加字段，不修改现有字段 ✅
- ForumComment: 只添加字段 ✅
- User: 只添加关系（不加列）✅
- 其他所有模型: 不受影响 ✅
