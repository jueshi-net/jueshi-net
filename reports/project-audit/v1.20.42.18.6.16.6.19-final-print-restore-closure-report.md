## 3. Root Cause Analysis

### 3.1 PNG Export Failure

**Root cause:** `html2canvas` v1.4.1 cannot parse CSS `lab()` and `oklch()` color functions used by Tailwind CSS v4. The error was:
```
Error: Attempting to parse an unsupported color function "lab"
```

**Fix:** Replaced `html2canvas` with `html-to-image`, which natively supports `lab()`/`oklch()` color spaces. The `filter` callback hides UI-only elements (grid, handles, selection rings) during capture.

**Commit:** `016ec34` (v18.6.16.6.18), `10ac138` (v18.6.16.6.19)

### 3.2 Draft Restore Failure

**Root cause:** On page reload, the component mounts and triggers a debounced draft save with an empty canvas, which overwrites the saved localStorage draft before the restore banner appears.

**Fix:** Added `hasDraft` guard — when `hasDraft` is true (restore banner visible), the debounced save is skipped, preserving the existing draft in localStorage.

**Commit:** `10ac138` (v18.6.16.6.19)

### 3.3 Print Extra Blank Page

**Root cause:** All print pages (including the last) had `page-break-after: always`, producing an extra blank page after the final label.

**Fix:** Added `:last-child` CSS rule: `page-break-after: auto !important` on the last `canvas-print-page`.

**Commit:** `3ad9e5c` (v18.6.16.6.17)

### 3.4 Print Shows Sequence Indicators

**Root cause:** `canvas-print-page-count` and `canvas-print-page-sequence` indicators were visible in print output.

**Fix:** Added `display: none !important` for both selectors in print CSS.

**Commit:** `3ad9e5c` (v18.6.16.6.17)
