# v1.20.42.18.6.4.12.2-01 — Postal Map Query No Postal

## Problem
Map reference links included postal code in the OpenStreetMap search query, causing many searches to fail.

## Fix
- Removed `r.postalCode` from map query in both locations:
  1. Main DB results (line 1104): `${r.postalCode}, ${r.city}, ...` → `${r.city}, ${r.province || r.adminName1 || ''}, ${r.country}`
  2. Advanced region results (line 1427): same fix
- Added disclaimer text: "地图参考按城市/地区搜索，不代表精确邮编位置。"

## Verification (browser)
- CA+M5V3L9: map query = `Toronto, Ontario, Canada` (no postal) ✅
- CA+M5V3L9: map query = `Toronto, ON, 加拿大` (no postal) ✅
- `containsPostal: false` for all map links ✅
