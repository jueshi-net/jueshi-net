## 本轮目标

彻底拆分 role 字段的权限语义和会员语义：
- role 只表示权限角色（admin/user）
- membershipTier 只表示会员等级（free/member/premium/enterprise）
- memberUntil 只表示会员到期时间
- 任何会员、邀请、奖励、签到、成长值逻辑都不得写 role
- 9833416@qq.com 永远保持 admin

---

## 修复前问题

### Role/Membership 混用

**问题：**
- role 字段同时承担权限和会员两个语义
- 邀请奖励、会员兑换等业务逻辑会修改 role
- 导致 9833416@qq.com 多次被改为 member

**根因：**
- `src/lib/invite-rewards.ts` 第 250 行：`role: 'member'`
- `src/app/api/rewards/redeem/route.ts`：会员兑换修改 role
- 其他业务逻辑也会修改 role

## 字段语义定义

### role 字段

**语义：** 只用于权限角色

**合法值：**
- `admin` - 管理员（可访问后台）
- `user` - 普通用户（只能访问前台）

**禁止值：**
- ❌ member
- ❌ ADMIN
- ❌ USER
- ❌ 管理员
- ❌ 任何会员等级值

**判断逻辑：**
```typescript
const isAdmin = (user) => user.role === 'admin';
const requireAdmin = (user) => {
  if (user.role !== 'admin') {
    throw new Error('无权限');
  }
};
```

### membershipTier 字段

**语义：** 只用于会员等级

**合法值：**
- `free` - 免费用户
- `member` - 普通会员
- `premium` - 高级会员（预留）
- `enterprise` - 企业会员（预留）

**判断逻辑：**
```typescript
const isMember = (user) => {
  return (
    user.membershipTier &&
    user.membershipTier !== 'free' &&
    user.memberUntil &&
    user.memberUntil > new Date()
  );
};
```

### memberUntil 字段

**语义：** 只用于会员到期时间

**类型：** DateTime?

**判断逻辑：**
```typescript
const hasValidMembership = (user) => {
  return user.memberUntil && user.memberUntil > new Date();
};
```
