## 结论

### 模型名称映射

| 内容类型 | 模型名称 | 表名 |
|---------|---------|------|
| Checklist | `Checklist` | `checklists` |
| Guide | `Guide` | `guides` |
| Topic | `Topic` | `topics` |

### 字段现状

| 检查项 | 结果 |
|--------|------|
| CHECKLIST_MODEL_NAME | `Checklist` |
| GUIDE_MODEL_NAME | `Guide` |
| TOPIC_MODEL_NAME | `Topic` |
| EXISTING_JSON_FIELD | **no** |
| MIGRATION_REQUIRED | **yes** |

### 推荐方案

**字段名称**: `metadataJson`  
**字段类型**: `Json?`  
**添加位置**: 
- `Checklist` 模型
- `Guide` 模型
- `Topic` 模型

**理由**:
1. 三个模型均无 ContentOps 元数据字段
2. 使用统一的 `metadataJson` 字段名，便于 API 和后台处理
3. JSON 类型支持灵活的结构，可存储所有高级字段
4. 可选字段（`Json?`），不影响现有数据
