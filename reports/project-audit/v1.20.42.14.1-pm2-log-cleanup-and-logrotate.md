## 三、logrotate 配置

### 配置文件内容

创建 `/etc/logrotate.d/pm2`：

```
/root/.pm2/pm2.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    copytruncate
}

/root/.pm2/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    copytruncate
}
```

**关键配置说明：**
- `daily` - 每天轮转
- `rotate 7` - 保留 7 天
- `compress` - 压缩旧日志
- `delaycompress` - 延迟一天压缩（避免压缩正在写入的文件）
- `copytruncate` - 复制后清空原文件（避免 PM2 日志句柄问题）

### logrotate 测试

**Debug 模式：**
```bash
sudo logrotate -d /etc/logrotate.d/pm2
```
结果：无错误

**强制轮转测试：**
```bash
sudo logrotate -f /etc/logrotate.d/pm2
```
结果：成功轮转
