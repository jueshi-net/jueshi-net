## "51+ 国家" Claim

The "51+ 国家" refers to SUPPORTED_COUNTRIES in the client config which provides:
- Address format info
- Official postal service links
- Common error reminders
- City range reference data

NOT all 51 countries have full postal code databases. The hero text has been corrected from "51+ 国家邮编数据库" to "51+ 国家地址/邮编资料".
