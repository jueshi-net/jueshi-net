## 3. 现有基础设施发现

**重大发现:** jueshi.net 项目已有论坛基础设施：

### 数据模型（已存在）
- `ForumCategory` — 5 个分类已 seed（overseas-life, tools, logistics, feedback, general）
- `ForumPost` — 完整字段：slug, title, content, status(pending/published/hidden/deleted), isPinned, isLocked, viewCount, commentCount, lastCommentAt, ipHash, userAgent, rewardGrantedAt
- `ForumComment` — 完整字段：content, status, ipHash, userAgent, rewardGrantedAt

### API 路由（已存在，7 个）
- `GET /api/forum/categories` — 分类列表
- `GET /api/forum/posts` — 帖子列表（支持 category 筛选 + 搜索）
- `POST /api/forum/posts` — 创建帖子（含 IP hash, auth guard）
- `GET /api/forum/posts/[slug]` — 帖子详情（权限检查）
- `GET /api/forum/posts/[slug]/comments` — 评论列表
- `POST /api/forum/posts/[slug]/comments` — 创建评论
- `GET /api/admin/forum/stats` — 管理统计
- Admin moderation API for posts and comments

### 数据库现状
- 5 个分类已激活
- 0 个帖子，0 个评论（空白状态，等待内容填充）

### 前端页面
- `/community` — 社区首页（当前显示 Topic 内容，未连接 ForumPost）
- `/community/[slug]` — 社区详情页（当前显示 Topic 详情，未连接 ForumPost）

## 4. 结论

社区论坛不是从零开始，而是基于现有 ForumCategory/ForumPost/ForumComment 模型和 7 个 API 路由进行扩展。本轮输出架构方案，为 v18.6.1 MVP 开发做准备。
