## 4. 三类模板

### 4.1 专题模板 (Topics)

**结构:**
```yaml
title: "2026 年海外必装 APP 推荐"
slug: "must-have-apps-2026"
template_type: "rating_list"

hero:
  badges: ["2026 最新版", "实测推荐"]
  title: "..."
  subtitle: "..."

items:
  - name: "WhatsApp"
    rating: "S"
    category: "通讯"
    description: "..."
    official_url: "..."

sections:
  - type: "intro"
  - type: "faq"
  - type: "cta"
```

**SEO:**
- JSON-LD: ItemList + SoftwareApplication
- Title: 50-60 字符
- Description: 150-160 字符

**视频:**
- YouTube 长视频 (8-10 min)
- Shorts 短视频 (60 sec)

### 4.2 指南模板 (Guides)

**结构:**
```yaml
title: "如何填写商业发票"
slug: "how-to-fill-commercial-invoice"
category: "shipping"

introduction: "..."

steps:
  - title: "准备卖方信息"
    description: "..."
    example: "..."

common_mistakes:
  - mistake: "..."
    correction: "..."

faq:
  - q: "..."
    a: "..."
```

**SEO:**
- JSON-LD: HowTo + Article
- 步骤结构化

**视频:**
- 教程视频 (5-7 min)

### 4.3 清单模板 (Checklists)

**结构:**

**SEO:**
- JSON-LD: ItemList

**视频:**
- 快速提示视频 (60 sec)

## 5. SEO/GEO Validator

### 5.1 SEO 验证 (25 分)

| 检查项 | 分值 | 标准 |
|--------|------|------|
| Title 质量 | 5 | 50-60 字符，包含关键词，有吸引力 |
| Description 质量 | 5 | 150-160 字符，包含关键词，有 CTA |
| H1 质量 | 5 | 唯一，包含关键词 |
| 内链数量 | 5 | ≥ 3 个内链 |
| 结构化数据 | 5 | 有效 JSON-LD |

### 5.2 GEO 验证 (15 分)

| 检查项 | 分值 | 标准 |
|--------|------|------|
| 直接回答 | 5 | 前 100 字有直接答案 |
| 结构清晰 | 3 | H2/H3 层级清晰 |
| 权威引用 | 3 | 引用 .gov/.edu/.org |
| FAQ 覆盖 | 2 | ≥ 3 个问题 |
| 地理定位 | 2 | 明确目标国家 |

### 5.3 使用方法

```bash
# 验证内容
node scripts/validate-seo-geo.ts content.yaml

# 输出
=== SEO/GEO Validation Report ===

Total Score: 88/100
Status: ✅ PASSED

--- SEO ---
Score: 23/25
Status: ✅ PASSED

Issues:
  - Description length 145 chars (recommended: 150-160)

Recommendations:
  - Adjust description to 150-160 characters
```

## 7. 发布包模板

### 7.1 jueshi.net 发布包

**包含:**
- 结构化内容 (YAML)
- SEO 元数据
- JSON-LD 结构化数据
- 关联内容
- 发布清单

**格式:**
```yaml
metadata:
  title: "..."
  slug: "..."
  type: "checklist"

content:
  steps: [...]

seo:
  title: "..."
  description: "..."
  canonical: "..."

json_ld: {...}

related:
  tools: [...]
  guides: [...]
```

### 7.2 微信公众号发布包

**包含:**
- 富文本 HTML
- 图片要求
- 手动发布步骤

**限制:**
- 只能创建草稿（不能直接发布）
- 图片必须上传到微信素材库
- 不支持外部链接

**格式:**
```yaml
metadata:
  title: "..."
  author: "绝世百宝箱"
  digest: "..."

content: |
  <section>
    <h2>...</h2>
    <p>...</p>
  </section>

images:
  - filename: "cover.jpg"
    size: "900x383"

manual_steps:
  - step: 1
    action: "登录微信公众号后台"
```

### 7.3 YouTube 发布包

**包含:**
- 视频元数据
- 视频文件要求
- 封面图要求
- API 请求模板

**格式:**
```yaml
metadata:
  title: "..."
  description: "..."
  category: "Education"
  tags: [...]

video:
  filename: "video.mp4"
  duration: "10:00"
  resolution: "1920x1080"

thumbnail:
  filename: "thumbnail.jpg"
  size: "1280x720"

api_request:
  endpoint: "POST https://www.googleapis.com/upload/youtube/v3/videos"
  body: {...}
```

## 10. 下一步：如何用技能生成第一篇内容

### 10.1 加载技能

```bash
# 在 Hermes 中
skill_view(name='content-publishing')
```

### 10.2 提供输入

```
请帮我创建一个清单：
- 主题：留学生出国前准备清单
- 目标受众：准留学生
- 目标国家：CA, US, UK, AU
- 粗略内容：签证、机票、住宿、行李、银行、手机卡、APP、保险
```

### 10.3 Hermes 执行

Hermes 会：
1. 加载清单模板
2. 生成结构化内容
3. 添加 SEO/GEO 字段
4. 生成视频脚本
5. 创建发布包
6. 计算质量评分

### 10.4 验证内容

```bash
# 运行 SEO/GEO 验证
node scripts/validate-seo-geo.ts output.yaml

# 运行质量评分
node scripts/calculate-quality-score.ts output.yaml
```

### 10.5 审核内容

- 检查内容准确性
- 调整步骤和描述
- 确认 SEO 字段
- 预览视频脚本

### 10.6 发布内容

**发布到 jueshi.net:**
```bash
# 使用 API 创建草稿
POST /api/admin/content-drafts
{
  "title": "留学生出国前准备清单",
  "slug": "student-pre-departure-checklist",
  "contentType": "checklist",
  "structuredContent": {...}
}
```

**创建视频:**
- 使用 YouTube 脚本录制视频
- 使用 Shorts 脚本录制短视频
- 上传到 YouTube

**发布到微信公众号:**
- 使用微信公众号发布包
- 手动在后台发布

### 10.7 监控效果

- 查看 Search Console 数据
- 监控关键词排名
- 跟踪流量变化
- 收集用户反馈
