## 失败根因分析

### 根因 1: Hermes Agent CLI 不支持长 prompt

- `-q` 参数有命令行长度限制
- stdin 模式不被 Hermes Agent 支持
- Python subprocess 调用超时（60秒）

### 根因 2: Hermes Agent 响应格式问题

- Hermes Agent 返回 ASCII art banner，不是纯 JSON
- 需要额外的解析逻辑来提取 JSON
- 即使成功调用，也可能无法正确解析响应

### 根因 3: 本地 Hermes Agent 配置问题

- 本地 Hermes Agent v0.16.0，可能不支持某些功能
- API provider 配置可能不正确
- 模型调用可能失败
