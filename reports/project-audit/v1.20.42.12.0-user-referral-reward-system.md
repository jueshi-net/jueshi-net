## 一、数据模型和 Migration

### 1.1 扩展 InviteCode 模型

**新增字段**:
- `ownerUserId`: 邀请码所有者（NULL=管理员公共码）
- `source`: 来源（ADMIN/USER）
- `status`: 状态（ACTIVE/PAUSED/EXPIRED）

### 1.2 新增 InviteRedemption 模型

**用途**: 记录邀请成功关系

**字段**:
- `inviteCodeId`: 邀请码 ID
- `inviterUserId`: 邀请人 ID
- `inviteeUserId`: 被邀请人 ID
- `status`: REGISTERED/QUALIFIED/REWARDED/REJECTED
- `qualifiedAt`: 符合条件时间
- `rewardedAt`: 奖励发放时间

**约束**:
- `@@unique([inviteeUserId])`: 一个被邀请人只能绑定一个邀请人

### 1.3 新增 RewardRule 模型

**用途**: 后台可配置奖励规则

**字段**:
- `name`: 规则名称
- `trigger`: 触发条件（INVITE_REGISTER_SUCCESS/INVITE_QUALIFIED）
- `rewardType`: MEMBER_DAYS/AD_SLOT_DAYS/POINTS/GROWTH/BADGE/CUSTOM_ENTITLEMENT
- `rewardValue`: 奖励数值
- `enabled`: 是否启用
- `startsAt/endsAt`: 活动时间
- `maxRewardsPerInviter`: 每个邀请人最多奖励次数
- `maxRewardsTotal`: 全局最多奖励次数

### 1.4 新增 RewardGrant 模型

**用途**: 奖励发放记录

**字段**:
- `userId`: 用户 ID
- `inviteRedemptionId`: 邀请关系 ID
- `rewardRuleId`: 奖励规则 ID
- `rewardType`: 奖励类型
- `rewardValue`: 奖励数值
- `status`: PENDING/GRANTED/FAILED/REVOKED
- `grantedAt`: 发放时间
- `expiresAt`: 权益过期时间

**约束**:
- `@@unique([inviteRedemptionId, rewardRuleId])`: 幂等性保证

## 二、奖励发放逻辑

### 2.1 核心文件

**文件**: `src/lib/invite-rewards.ts`

**功能**:
- `grantInviteRewards()`: 发放邀请奖励
- `executeRewardGrant()`: 执行具体的奖励发放
- `grantMemberDays()`: 发放会员天数
- `grantPoints()`: 发放积分
- `grantGrowth()`: 发放成长值

### 2.2 支持的奖励类型

| 类型 | 说明 | 实现状态 |
|---|---|---|
| MEMBER_DAYS | 会员天数 | ✅ 已实现 |
| POINTS | 积分 | ✅ 已实现 |
| GROWTH | 成长值 | ✅ 已实现 |
| AD_SLOT_DAYS | 广告位天数 | ✅ 已实现（只记录，不实际投放） |
| BADGE | 勋章 | ✅ 已实现（只记录） |
| CUSTOM_ENTITLEMENT | 自定义权益 | ✅ 已实现（只记录） |

### 2.3 幂等性保证

- ✅ 同一邀请关系只能发放同一规则一次
- ✅ 通过 `@@unique([inviteRedemptionId, rewardRuleId])` 约束保证
- ✅ 重试不会重复增加会员天数、积分或成长值

### 2.4 会员天数发放逻辑

```typescript
if (user.memberUntil && user.memberUntil > now) {
  // 当前是会员且未过期：在现有到期时间上 +N 天
  newMemberUntil = addDays(user.memberUntil, days);
} else {
  // 当前非会员或已过期：从当前时间开始 +N 天
  newMemberUntil = addDays(now, days);
}
```

## 五、反作弊规则

### 5.1 已实现的反作弊机制

1. **用户不能邀请自己**
   - ✅ 检查 `invite.ownerUserId !== user.id`

2. **同一被邀请用户只能绑定一个邀请人**
   - ✅ `@@unique([inviteeUserId])` 约束

3. **同一邀请码 maxUses 限制**
   - ✅ 注册 API 已检查 `invite.usedCount >= invite.maxUses`

4. **过期邀请码不可用**
   - ✅ 注册 API 已检查 `invite.expiresAt < new Date()`

5. **暂停邀请码不可用**
   - ✅ 注册 API 已检查 `!invite.isActive || invite.status !== 'ACTIVE'`

6. **每个用户每天生成邀请码次数限制**
   - ✅ 限制：每天最多生成 3 个邀请码

7. **每个用户最多持有的邀请码数量限制**
   - ✅ 限制：最多持有 3 个邀请码

8. **幂等性**
   - ✅ `@@unique([inviteRedemptionId, rewardRuleId])` 约束
