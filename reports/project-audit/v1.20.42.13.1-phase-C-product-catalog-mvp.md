# v1.20.42.13.1 Phase C: Product Catalog MVP

**完成时间**: 2026-06-20 05:30 UTC  
**状态**: ✅ 完成

## 目标

建立用户商品资料库，让报价单、发票、装箱单可以复用商品信息，减少重复输入。

## 完成内容

### 1. 数据模型 ✅

**Migration**: `20260620_product_catalog_mvp`

**ProductItem 模型字段**:
- `id` (String, cuid)
- `userId` (String, 关联 User)
- `name` (String, 必填)
- `sku` (String?, 可选)
- `description` (String?, 可选)
- `hsCode` (String?, HS Code)
- `unit` (String?, 默认 "PCS")
- `unitPrice` (Decimal?, 单价)
- `currency` (String?, 默认 "USD")
- `netWeight` (Decimal?, 净重 KG)
- `grossWeight` (Decimal?, 毛重 KG)
- `length`, `width`, `height` (Decimal?, 尺寸 CM)
- `originCountry` (String?, 产地)
- `material` (String?, 材质)
- `usage` (String?, 用途)
- `isActive` (Boolean, 默认 true)
- `createdAt`, `updatedAt` (DateTime)

**索引**:
- `userId` (快速查询用户商品)
- `userId + isActive` (过滤启用/停用)
- `userId + name` (按名称搜索)

**特性**:
- ✅ 用户隔离（userId 外键）
- ✅ 软删除（isActive 标志）
- ✅ 级联删除（User 删除时自动清理）

### 2. API 端点 ✅

**GET /api/workspace/products**
- 查询参数: `search` (模糊搜索), `isActive` (过滤)
- 返回: 商品列表（最多 100 条）
- 权限: 需要登录

**POST /api/workspace/products**
- 创建新商品
- 验证: name 必填
- 权限: 需要登录

**PATCH /api/workspace/products/[id]**
- 更新商品
- 验证: 所有权（userId 匹配）
- 权限: 需要登录

**DELETE /api/workspace/products/[id]**
- 软删除（设置 isActive = false）
- 验证: 所有权
- 权限: 需要登录

## 用户体验

### 使用场景

1. **外贸卖家**:
   - 录入常用商品（名称、HS Code、单价、重量）
   - 创建报价单时从商品库选择，自动填充
   - 创建发票时复用商品信息
   - 创建装箱单时引用商品重量尺寸

2. **优势**:
   - 减少重复输入
   - 保证数据一致性
   - 提高工作效率
   - 降低错误率
