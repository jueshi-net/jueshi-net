## SSH 故障诊断

### 故障现象

**症状**：SSH 连接在协议握手阶段被远程服务器关闭

```
debug1: Connection established.
kex_exchange_identification: Connection closed by remote host
Connection closed by 192.129.155.149 port 22
```

### 诊断步骤

#### 1. 网络连通性测试
```bash
ping -c 3 192.129.155.149
```
**结果**：✅ 成功
```
3 packets transmitted, 3 packets received, 0% packet loss
round-trt min/avg/max = 0.350/0.438/0.521 ms
```
**结论**：网络层连通，延迟 < 1ms

#### 2. 端口可达性测试
```bash
nc -zv -w 5 192.129.155.149 22
```
**结果**：✅ 成功
```
Connection to 192.129.155.149 port 22 [tcp/ssh] succeeded!
```
**结论**：SSH 端口 22 开放，TCP 连接可建立

#### 3. SSH 连接测试（chq 用户）
```bash
ssh -o ConnectTimeout=10 chq@192.129.155.149 "echo test"
```
**结果**：❌ 失败
```
Connection closed by 192.129.155.149 port 22
```

#### 4. SSH 连接测试（deploy 用户）
```bash
ssh -o ConnectTimeout=10 deploy@192.129.155.149 "echo test"
```
**结果**：❌ 失败
```
Connection closed by 192.129.155.149 port 22
```

#### 5. SSH 详细调试
```bash
ssh -vvv -o ConnectTimeout=10 deploy@192.129.155.149 "echo test"
```
**结果**：❌ 失败
```
debug1: Connection established.
debug1: Local version string SSH-2.0-OpenSSH_10.2
kex_exchange_identification: Connection closed by remote host
```
**分析**：
- TCP 连接成功建立（Connection established）
- SSH 协议版本交换开始（Local version string sent）
- 在密钥交换阶段被服务器关闭（kex_exchange_identification）

### 故障原因分析

**网络层**：✅ 正常
- 服务器可达
- 端口 22 开放
- TCP 连接可建立

**SSH 协议层**：❌ 异常
- SSH 服务在运行
- 但在密钥交换阶段拒绝连接

**可能原因**：

1. **SSH 服务器配置限制**（最可能）
   - `AllowUsers` 或 `AllowGroups` 限制了访问
   - `DenyUsers` 或 `DenyGroups` 阻止了特定用户
   - `Match Address` 限制了 IP 范围

2. **fail2ban 或类似工具**（可能）
   - IP 被 fail2ban 阻止
   - 但端口仍然开放（fail2ban 在应用层阻止）

3. **SSH 密钥不被接受**（可能）
   - 服务器的 `AuthorizedKeysFile` 配置问题
   - 密钥权限问题
   - 密钥格式不兼容

4. **服务器负载或资源限制**（不太可能）
   - SSH 服务负载过高
   - 系统资源不足
   - 但通常会显示不同的错误

5. **SSH 服务配置错误**（不太可能）
   - `sshd_config` 语法错误
   - 但服务仍在运行

### 无法远程诊断

**问题**：由于无法建立 SSH 连接，无法在服务器上执行以下诊断命令：

```bash
# 无法执行
sudo systemctl status sshd
sudo journalctl -u sshd -n 50
sudo cat /etc/ssh/sshd_config
sudo fail2ban-client status sshd
sudo cat /var/log/auth.log | tail -50
```

**结论**：需要其他访问方式（如云控制台、VNC、IPMI）来诊断服务器端问题。
