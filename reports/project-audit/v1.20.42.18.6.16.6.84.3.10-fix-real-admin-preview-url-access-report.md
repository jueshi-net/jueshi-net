## 问题概述

ContentOps Telegram Bot 在创建 draft 后返回的 admin/preview URL 存在以下问题：

1. **Admin URL 错误**: 使用了单数路由 `/admin/content/checklist/[slug]/edit`，但实际路由是复数 `/admin/content/checklists/[id]/edit`
2. **Admin URL 参数错误**: 使用了 slug 而不是 id
3. **Topic Admin URL 路径错误**: Topic 的 admin 路由是 `/admin/topics/[id]/edit`，不是 `/admin/content/topics/[id]/edit`
4. **Preview URL 错误**: 使用了单数路由 `/checklist/[slug]`，但实际路由是复数 `/checklists/[slug]`
5. **Post-Create Verification 缺失**: 没有验证创建的 draft 是否真实存在

---

## 根因分析

### 1. URL Builder 逻辑错误

**问题代码**:
```typescript
// 错误的 v1 版本
const adminEditUrl = `${baseUrl}/admin/content/${type}/${draft.slug}/edit`;
const previewUrl = `${baseUrl}/${type}/${draft.slug}?preview=true`;
```

**根因**:
- 使用了单数 `type` (checklist/guide/topic)，但实际路由是复数 (checklists/guides/topics)
- Admin 路由需要 `id` 参数，但使用了 `slug`
- Topic 的 admin 路由路径不同：`/admin/topics/[id]/edit`

### 2. 缺少 Post-Create Verification

**问题**: Bot 创建 draft 后直接返回 URL，没有验证：
- DB record 是否真实存在
- status 是否为 draft
- robots 是否为 noindex,nofollow
- metadataJson.contentOps 是否存在
- content 是否不为空

## 修复方案

### 1. URL Builder v3

**修复代码**:
```typescript
function buildUrls(type: 'checklist' | 'guide' | 'topic', id: string, slug: string) {
  const baseUrl = 'https://jueshi.net';
  
  // Admin routes use id, different paths for different types
  let adminEditUrl: string;
  if (type === 'checklist') {
    adminEditUrl = `${baseUrl}/admin/content/checklists/${id}/edit`;
  } else if (type === 'guide') {
    adminEditUrl = `${baseUrl}/admin/content/guides/${id}/edit`;
  } else {
    // Topics have different path structure
    adminEditUrl = `${baseUrl}/admin/topics/${id}/edit`;
  }
  
  // Preview and public routes use slug, plural routes
  const pluralType = type === 'checklist' ? 'checklists' : type === 'guide' ? 'guides' : 'topics';
  const previewUrl = `${baseUrl}/${pluralType}/${slug}?preview=true`;
  const publicUrl = `${baseUrl}/${pluralType}/${slug}`;
  
  return { adminEditUrl, previewUrl, publicUrl };
}
```

**关键改进**:
- ✅ Admin 路由使用 `id` 而不是 `slug`
- ✅ Admin 路由使用复数形式 (checklists/guides/topics)
- ✅ Topic 使用特殊路径 `/admin/topics/[id]/edit`
- ✅ Preview/Public 路由使用复数形式

### 2. Post-Create Verification v2

**新增功能**:
```typescript
async function verifyDraftRecord(type: 'checklist' | 'guide' | 'topic', id: string, slug: string) {
  const prisma = await getContentOpsPrismaClient();
  
  let record: any = null;
  
  if (type === 'checklist') {
    record = await prisma.checklist.findUnique({
      where: { id },
      select: { id: true, slug: true, status: true, robots: true, metadataJson: true, steps: true },
    });
  } else if (type === 'guide') {
    record = await prisma.guide.findUnique({
      where: { id },
      select: { id: true, slug: true, status: true, robots: true, metadataJson: true, body: true },
    });
  } else {
    record = await prisma.topic.findUnique({
      where: { id },
      select: { id: true, slug: true, status: true, metadataJson: true },
    });
  }
  
  // 验证逻辑
  if (!record) return { success: false, message: 'DB record not found' };
  if (record.slug !== slug) return { success: false, message: 'Slug mismatch' };
  if (record.status !== 'draft') return { success: false, message: 'Status is not draft' };
  if (type !== 'topic' && record.robots !== 'noindex,nofollow') {
    return { success: false, message: 'Robots is not noindex,nofollow' };
  }
  
  // 检查 content 不为空
  if (type === 'checklist' && (!record.steps || record.steps.length === 0)) {
    return { success: false, message: 'Steps is empty' };
  }
  if (type === 'guide' && (!record.body || record.body.length === 0)) {
    return { success: false, message: 'Body is empty' };
  }
  if (!record.metadataJson) {
    return { success: false, message: 'metadataJson is null' };
  }
  
  const meta = record.metadataJson as any;
  if (!meta.contentOps) {
    return { success: false, message: 'contentOps is missing' };
  }
  
  return { success: true, message: 'Verification passed' };
}
```

**验证项目**:
- ✅ DB record 存在
- ✅ Slug 匹配
- ✅ Status 为 draft
- ✅ Robots 为 noindex,nofollow
- ✅ Content 不为空 (checklist.steps / guide.body)
- ✅ metadataJson.contentOps 存在

### 3. 错误处理增强

**新增逻辑**:
```typescript
// Post-create verification
const verification = await verifyDraftRecord(type, draft.id, draft.slug);
if (!verification.success) {
  writeAuditLog({
    action: 'post_create_verification_failed',
    chatId,
    type,
    id: draft.id,
    slug: draft.slug,
    reason: verification.message,
  });
  throw new Error(`Post-create verification failed: ${verification.message}`);
}
```

**效果**: 如果 verification 失败，会抛出异常，触发 catch 块，返回错误消息给用户。
