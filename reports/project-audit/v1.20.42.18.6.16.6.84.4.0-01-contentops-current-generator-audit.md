## 核心问题总结

### 问题 1: 创建的是空壳 Draft

当前 bot 创建的 draft 内容几乎为空：
- Checklist: `summary: '', steps: []`
- Guide: `summary: '', body: ''`
- Topic: `summary: ''`
- 所有类型: `faq: [], internalLinks: []`

这意味着用户通过 bot 创建的 draft 没有任何实质内容，需要在后台手动填写所有内容。

### 问题 2: 无质量门槛

任何输入都能创建 draft，不管内容多简陋。没有 qualityScore 计算，没有 qualityGate 校验。

### 问题 3: 不支持长文本

用户粘贴长文本时，bot 只提取标题，丢弃所有其他内容。无法从资料中提炼事实、步骤、FAQ。

### 问题 4: 无改写能力

没有原创改写逻辑。如果未来支持长文本输入，可能直接复制原文，存在版权风险。

### 问题 5: Admin Edit URL Bug

```typescript
const adminEditUrl = `${baseUrl}/admin/content/${type}/${draft.slug}/edit`;
```

应该使用 `draft.id` 而非 `draft.slug`。

## V2-MVP 实施优先级

### P0 (必须)

1. **输入模式识别** — 区分 title/brief/long_text/reference/messy
2. **内容生成** — 生成实际内容 (FAQ, steps, body, pitfalls)
3. **质量门槛** — 拒绝低质量 draft
4. **Dry-run v2** — 完整展示质量信息
5. **Admin Edit URL 修复** — 使用 ID 而非 slug

### P1 (重要)

6. **Source Extraction** — 从长文本提取事实
7. **原创改写** — 结构重组 + 语言改写
8. **SEO/GEO 增强** — 完整字段
9. **QualityScore 计算** — 量化质量

### P2 (增强)

10. **InternalLinks 推荐** — 关联站内内容
11. **RelatedTools 推荐** — 推荐工具
12. **确认过期机制** — 10 分钟过期

## 结论

当前 bot 本质上是一个"标题提取 + 空 draft 创建器"，不具备内容生成能力。V2-MVP 需要完全重写核心逻辑，实现从输入识别到内容生成到质量校验的完整链路。
