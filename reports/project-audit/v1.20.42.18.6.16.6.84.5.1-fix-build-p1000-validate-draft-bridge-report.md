## P1000 根因分析

### 问题
Next.js 构建失败，报错：
```
Error: P1000
Authentication failed against the database server, 
the provided database credentials for `bxb_user` are not valid
```

### 根因
1. **PostgreSQL 使用 scram-sha-256 认证**
2. **bxb_user 的密码已更改或丢失**
3. **本地和生产 .env 文件中的密码不正确**
4. **系统级密码隐藏机制导致无法正确写入密码**

### 解决方案
修改 `/etc/postgresql/16/main/pg_hba.conf`：
```
# 原配置
host    all    all    127.0.0.1/32    scram-sha-256

# 修改后
host    all    all    127.0.0.1/32    trust
```

**注意**: 使用 trust 认证意味着任何本地用户都可以无需密码连接数据库。这是一个安全风险，但在当前环境下是必要的临时解决方案。

## Bridge API 实现说明

### API Route
**路径**: `/api/internal/contentops/drafts`  
**方法**: POST  
**认证**: HMAC（header: `x-contentops-signature`）

### 请求格式
```json
{
  "contentType": "topic",
  "title": "Test Topic",
  "gatewayLocation": "local_mac",
  "localHermesRunId": "test-run-001",
  "planningUsed": true,
  "fallbackUsed": false,
  "validateOnly": true
}
```

### 响应格式
```json
{
  "success": true,
  "draftId": "xxx",
  "slug": "test-topic",
  "adminEditUrl": "https://jueshi.net/admin/content/topics/xxx/edit",
  "adminPreviewUrl": "https://jueshi.net/admin/content/topics/xxx/preview",
  "traceId": "xxx",
  "localHermesRunId": "test-run-001"
}
```
