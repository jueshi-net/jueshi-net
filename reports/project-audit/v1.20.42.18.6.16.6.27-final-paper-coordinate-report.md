## 二、纸张坐标根因

### 根因 1：iframe CSS 损坏

v6.25-v6.26 的多次 patch 尝试导致 iframe 内 CSS 规则被逐行删除：
- `canvas-print-page` 的 `box-shadow`、`margin`、`page-break-after` 规则丢失
- `canvas-paper` 的规则丢失
- `.ring-2` 的规则丢失

### 根因 2：iframe 尺寸与内容不匹配

v6.26 设置了 `paperWidthPx + 20px` 的 iframe 宽度，但页面有 `mx-auto` 类会居中，导致内容在 iframe 内居中而非从左侧开始。

### 根因 3：未解析的公司 token

`[company.name]` 等 binding token 在打印时没有被替换为实际值。这是因为打印时直接克隆 DOM，而 DOM 中显示的就是原始 token 文本（用户未选择公司时）。

## 三、v6.27 修复

### 修复 1：恢复完整的 iframe CSS

```css
/* Canvas pages: page break after each */
[data-testid="canvas-print-page"],
[data-testid="canvas-paper"] {
  box-shadow: none !important;
  margin: 0 auto !important;
  page-break-after: always;
  break-after: page;
}
[data-testid="canvas-print-page"]:last-child,
[data-testid="canvas-paper"]:last-child {
  page-break-after: auto !important;
  break-after: auto !important;
}
/* Remove selection ring */
.ring-2 {
  box-shadow: none !important;
}
```

### 修复 2：iframe 尺寸精确匹配纸张

```typescript
const paperWidthPx = Math.ceil(paperWidthMm * 3.7795275591);
const paperHeightPx = Math.ceil(paperHeightMm * 3.7795275591);
iframe.style.width = `${paperWidthPx + 20}px`;
iframe.style.height = `${paperHeightPx * Math.max(pages.length, 1) + 20}px`;
```

页面在 iframe 内通过 `margin: 0 auto` 居中，iframe 比页面宽 20px（每侧 10px 边距）。

### 修复 3：公司 token 处理

`[company.name]` 等 token 在用户未选择公司时显示为原始文本。这是预期行为 — 用户需要选择公司才能看到实际值。打印输出会忠实反映当前画布状态。
