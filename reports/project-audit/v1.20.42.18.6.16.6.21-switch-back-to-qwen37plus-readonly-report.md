### 打印失败根因候选（只读分析）

通过只读搜索 `canvas-editor-full.tsx` 中的打印相关代码，确认以下根因：

**根因 #1（已确认）：`window.print()` 打印整页**

```typescript
// L759-761
const handlePrint = useCallback(() => {
  window.print();  // ← 打印整个页面，不是仅画布
}, []);
```

`window.print()` 打印整个 DOM，包括网站 layout（header/footer/导航），不仅仅是 canvas 编辑器内容。

**根因 #2（已确认）：`@media print` CSS 隔离不完整**

L771-832 的 `@media print` CSS 只隐藏了：
- 带 `print:hidden` Tailwind class 的元素
- Canvas 编辑器内部的 UI 元素（面板、按钮、手柄、网格）

但**没有隐藏**：
- 网站主 layout（header, footer, navigation）
- Canvas 编辑器外部的不带 `print:hidden` 的元素
- 页面整体 layout wrapper

这就是为什么用户 PDF 中出现 footer、工具中心、社区、帮助中心、联系方式。

**根因 #3（候选）：序号重复**

`canvas-sequence-hidden`（L882）是隐藏标记元素，在打印时可能仍存在于 DOM 中。同时 `canvas-print-page-sequence`（L1164）是打印页码指示器。两者可能同时可见导致 1/10 重复。

**根因 #4（候选）：标签裁切**

`@page` size 设为 `canvas.paper.widthMm x canvas.paper.heightMm`（L774），但如果浏览器打印边距或缩放设置不正确，标签内容可能被裁切。

### 推荐修复方向（供 Qwen 下一轮参考）

1. **Dedicated print iframe** — 创建隐藏 iframe，将标签内容克隆到 iframe，调用 `iframe.contentWindow.print()`
2. **Print-only route** — 创建 `/tools/template-studio/canvas/print` 路由，只渲染标签内容
3. **修复 @media print CSS** — 添加 `body > *:not([data-testid="canvas-print-root"]) { display: none !important; }` 隐藏所有非画布元素
