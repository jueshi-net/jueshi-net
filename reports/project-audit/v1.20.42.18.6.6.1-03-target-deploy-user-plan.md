# Target Server deploy User Initialization Plan — v1.20.42.18.6.6.1

## 前提

以下步骤**不得实际执行**，除非用户提供 NEW_SERVER_IP 和明确授权。
当前仅为方案文档。

## 步骤

### Step 1: 初始登录

通过服务商控制台或 root SSH 登录新服务器。

```bash
ssh root@NEW_SERVER_IP
```

### Step 2: 创建 deploy 用户

```bash
adduser deploy
usermod -aG sudo deploy
```

### Step 3: 配置 SSH key

```bash
mkdir -p /home/deploy/.ssh
# 将 jueshi-prod-v2.pub 内容写入
echo "ssh-ed25519 AAAA... jueshi-prod-v2-20260623" > /home/deploy/.ssh/authorized_keys
chown -R deploy:deploy /home/deploy/.ssh
chmod 700 /home/deploy/.ssh
chmod 600 /home/deploy/.ssh/authorized_keys
```

### Step 4: 配置 sudo（NOPASSWD，与当前生产一致）

```bash
echo "deploy ALL=(ALL) NOPASSWD: ALL" > /etc/sudoers.d/deploy
chmod 440 /etc/sudoers.d/deploy
visudo -c  # 验证语法
```

### Step 5: 验证 key 登录

在**新 SSH session** 中测试（不关闭 root session）：

```bash
ssh -i ~/.ssh/jueshi-prod-v2 deploy@NEW_SERVER_IP
```

### Step 6: 验证 sudo

```bash
sudo -v
sudo whoami  # 应输出 root
```

### Step 7: 确认后才可禁用密码登录

⚠️ 只有在 Step 5 和 Step 6 都成功后，才能修改 sshd_config 禁用密码登录。

## 安全要求

- 整个过程保留 root console access 作为 emergency fallback
- 不关闭当前 SSH session 直到新 session 验证成功
- 不在报告中输出 public key 完整内容（仅模板）
- 不在报告中输出 private key
