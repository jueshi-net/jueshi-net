# v1.20.42.18.4.7 — 内容页面数据模型设计

**设计原则**: 优先复用现有模型，避免大拆。最小可用，不追求一次性全量复杂关联。

## 一、模型设计

### 1. Guide 模型 (新增)

```prisma
model Guide {
  id                 String    @id @default(cuid())
  title              String
  slug               String    @unique
  summary            String?   @db.Text
  body               String    @db.Text
  category           String    @default("general") // shipping/customs/logistics/life/business/templates
  tags               String[]  @default([])
  relatedTools       String[]  @default([]) // Tool slugs
  relatedTopics      String[]  @default([]) // Topic slugs
  relatedChecklists  String[]  @default([]) // Checklist slugs
  relatedGuides      String[]  @default([]) // Guide slugs
  status             String    @default("draft") // draft / published / archived
  coverImage         String?
  author             String?
  seoTitle           String?
  seoDescription     String?   @db.Text
  canonicalUrl       String?
  robots             String    @default("index,follow") // index,follow / noindex,nofollow
  sortOrder          Int       @default(0)
  publishedAt        DateTime?
  createdAt          DateTime  @default(now())
  updatedAt          DateTime  @updatedAt

  @@index([status])
  @@index([category])
  @@index([slug])
  @@map("guides")
}
```

### 2. Checklist 模型 (新增)

```prisma
model Checklist {
  id                 String    @id @default(cuid())

  relatedTopics      String[]  @default([]) // Topic slugs
  status             String    @default("draft") // draft / published / archived
  coverImage         String?

  canonicalUrl       String?
  robots             String    @default("index,follow")
  sortOrder          Int       @default(0)
  publishedAt        DateTime?
  createdAt          DateTime  @default(now())
  updatedAt          DateTime  @updatedAt

  @@index([status])
  @@index([slug])
  @@map("checklists")

```

## 二、模型关系策略

一期采用 **JSON 数组引用** 而非关联表，理由:
1. 低风险 migration (只加表，不改现有表)
2. 查询简单，不需要 JOIN
3. 内容量小，JSON 数组足够
4. 未来如需关联表可平滑升级

关联引用使用 slug 而非 id:
- relatedTools: Tool slugs
- relatedTopics: Topic slugs
- relatedChecklists: Checklist slugs
- relatedGuides: Guide slugs

## 三、Migration 安全说明

### Migration 内容
- CREATE TABLE guides (新表)
- CREATE TABLE checklists (新表)
- 不修改任何现有表
- 不删除任何数据
- 不修改任何约束

### 风险评估
- 风险等级: **极低**
- 原因: 只新增表，不修改现有表结构
- 回滚: 如需回滚，DROP TABLE guides; DROP TABLE checklists; 即可
- 无需备份: 不修改现有数据，但 VPS 有定期备份

### 执行方式
- 本地: `npx prisma migrate dev --name add_guide_checklist_models` (仅生成 migration 文件)
- VPS: `npx prisma migrate deploy` (应用 migration)
- **严禁**: `prisma db push`
