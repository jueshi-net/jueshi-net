## A. 正文可读性修复

### 问题
- 正文文字使用 `text-gray-400`（过浅）
- Markdown 语法（## 标题、- 列表、> 引用）未渲染，显示为原始文本
- 锁定提示、举报说明使用低对比色

### 修复
| 位置 | 修复前 | 修复后 |
|------|--------|--------|
| 作者信息行 | text-gray-400 | text-slate-500 |
| 锁定提示 | text-gray-600 + bg-gray-50 | text-slate-700 + bg-amber-50 |
| 楼层号 #1 #2 | text-gray-400 | text-slate-500 |
| 回复时间戳 | text-gray-400 | text-slate-500 |
| 回复操作按钮 | text-gray-400 | text-slate-500 |
| 暂无回复提示 | text-gray-400 | text-slate-500 |
| 面包屑标题 | text-gray-400 | text-slate-500 |
| 话题信息标签 | text-gray-500 | text-slate-500 |
| 话题信息数值 | text-gray-700 | text-slate-700 |

### PostContent 升级 — Markdown 渲染
- **文件:** `src/components/bbs/post-content.tsx` — 248 行全重写
- 支持: #/##/### 标题, **加粗**, *斜体*, `代码`, > 引用, -/* 列表, 1. 编号列表, [链接](url), --- 分隔线, ``` 代码块
- 正文主色: `text-slate-700` (不低于 text-slate-700)
- 次要说明: `text-slate-500`
- 标题: `text-slate-900`
- 代码: `bg-slate-800 text-slate-100`
- 引用: `border-l-4 border-brand/40 bg-slate-50`
- **禁止** `text-slate-300`/`text-gray-300` 用于正文
