## 技术细节

### PNG 导出流程

1. **点击导出按钮**
   - 触发 `handleExportPng` 函数
   - 检查是否为多页模式（如果是，显示 guard 消息）

2. **生成 PNG**
   - 使用 `html-to-image` 库
   - 将画布 DOM 转换为 PNG
   - 创建下载链接

3. **下载 PNG**
   - 触发浏览器下载事件
   - 保存为 `{template-name}.png`

### 像素分析方法

使用 `pngjs` 库读取 PNG 文件：
```typescript
for (let y = 0; y < height; y++) {
  for (let x = 0; x < width; x++) {
    const idx = (width * y + x) << 2;
    const r = this.data[idx];
    const g = this.data[idx + 1];
    const b = this.data[idx + 2];
    
    // 非白色像素：RGB 不全为 255
    if (r !== 255 || g !== 255 || b !== 255) {
      nonWhitePixels++;
    }
  }
}
```
