
   - 粗稿输入 + AI 生成

## PHASE 3 — 三类内容模板

### 3.1 专题模板

**文档路径:** `docs/content-templates/topics-template.md`

**结构:**
```yaml
Topic
├── 基础信息 (title, slug, summary, cover)
├── SEO 元数据 (seoTitle, seoDescription)
├── 视频资产 (youtubeUrl, youtubeVideoId)
├── TopicItem[] (子项，如 APP 列表)
│   ├── name, rating, category
│   ├── description, analogy
│   ├── officialUrl, riskTip
│   └── suitableFor, beginnerAdvice
└── TopicSection[] (章节，如 FAQ、CTA)
    ├── type (intro/notice/faq/cta)
    └── title, content, sortOrder
```

**SEO 字段:**
- Title: 50-60 字符，包含主关键词
- Description: 150-160 字符，有 CTA
- Canonical URL
- JSON-LD: ItemList + SoftwareApplication

**视频脚本:**
- YouTube 长视频 (8-10 分钟)
- Shorts 短视频 (60 秒)

### 3.2 指南模板

**文档路径:** `docs/content-templates/guides-template.md`

**结构:**
```yaml
Guide
├── 基础信息 (title, slug, summary, body)
├── 分类标签 (category, tags)
├── SEO 元数据 (seoTitle, seoDescription, canonicalUrl)
├── 关联内容 (relatedTools, relatedTopics, relatedChecklists)
└── 发布控制 (status, publishedAt, sortOrder)
```

**SEO 字段:**
- Title: 包含"如何"、"教程"等关键词
- Description: 直接回答标题问题
- JSON-LD: HowTo + Article

### 3.3 清单模板

**文档路径:** `docs/content-templates/checklists-template.md`

**结构:**
```yaml
Checklist
├── 基础信息 (title, slug, summary)
├── 步骤列表 (steps: Json[])
│   ├── title, description
│   ├── completed, optional
│   └── toolLink (关联工具)
├── 关联内容 (relatedTools, relatedGuides, relatedTopics)
└── SEO 元数据 (seoTitle, seoDescription, canonicalUrl)
```

**SEO 字段:**
- Title: 包含"清单"、"检查"等关键词
- Description: 列出步骤数量
- JSON-LD: ItemList + HowTo

## PHASE 4 — Agent 工作流

**文档路径:** `docs/content-publishing-agent-workflow.md`

### 工作流概览

```
[粗稿输入] → [内容理解] → [选题分类] → [关键词提取] → [资料补全]
    ↓
[内容生成] → [SEO 检查] → [GEO 检查] → [重复检查] → [内链推荐]
    ↓
[视频脚本] → [草稿入库] → [人工审核] → [定时发布] → [发布监控]
    ↓
[旧文刷新]
```

### Agent 角色

1. **SEO Agent** — 关键词研究、SEO 优化、排名监控
2. **Content Agent** — 内容生成、质量检查、内链建议
3. **Video Agent** — 脚本生成、封面提示词、多平台适配
4. **Analytics Agent** — 流量监控、排名监控、刷新建议

### API 设计

```typescript
POST /api/admin/content-drafts — 创建草稿

POST /api/admin/content-drafts/:id/publish — 手动发布

GET /api/admin/content-publish-logs — 发布日志
```

## PHASE 5 — 数据模型与 API

### 5.1 建议新增模型

#### ContentDraft (内容草稿)

```prisma
model ContentDraft {
  id                 String   @id @default(cuid())
  title              String
  slug               String   @unique
  contentType        String   @map("content_type") // topic / guide / checklist
  roughContent       String   @map("rough_content") @db.Text
  structuredContent  Json     @map("structured_content")
  seoTitle           String?  @map("seo_title")
  seoDescription     String?  @map("seo_description")
  status             String   @default("draft") // draft / pending_review / approved / published / archived
  qualityScore       Int?     @map("quality_score")
  seoScore           Int?     @map("seo_score")
  geoScore           Int?     @map("geo_score")
  scheduledAt        DateTime? @map("scheduled_at")
  publishedAt        DateTime? @map("published_at")
  createdBy          String   @map("created_by")
  reviewedBy         String?  @map("reviewed_by")
  reviewedAt         DateTime? @map("reviewed_at")
  reviewComments     String?  @map("review_comments") @db.Text
  createdAt          DateTime @default(now()) @map("created_at")
  updatedAt          DateTime @updatedAt @map("updated_at")
  
  videoAssets        ContentVideoAsset[]
  publishLogs        ContentPublishLog[]
  
  @@map("content_drafts")
}
```

#### ContentVideoAsset (视频资产)

```prisma
model ContentVideoAsset {
  id               String   @id @default(cuid())
  contentDraftId   String   @map("content_draft_id")
  contentDraft     ContentDraft @relation(fields: [contentDraftId], references: [id])
  platform         String   // youtube / shorts / tiktok / bilibili
  title            String
  script           String   @db.Text
  durationSeconds  Int      @map("duration_seconds")
  thumbnailPrompt  String?  @map("thumbnail_prompt") @db.Text
  status           String   @default("draft") // draft / ready / published
  publishedUrl     String?  @map("published_url")
  createdAt        DateTime @default(now()) @map("created_at")
  updatedAt        DateTime @updatedAt @map("updated_at")
  
  @@map("content_video_assets")
}
```

#### ContentPublishLog (发布日志)

```prisma
model ContentPublishLog {
  id              String   @id @default(cuid())
  contentDraftId  String   @map("content_draft_id")
  contentDraft    ContentDraft @relation(fields: [contentDraftId], references: [id])
  action          String   // scheduled / published / failed / refreshed
  details         String?  @db.Text
  executedAt      DateTime @default(now()) @map("executed_at")
  
  @@map("content_publish_logs")
}
```

## PHASE 6 — SEO/GEO 质量评分器

**文档路径:** `docs/content-quality-score-spec.md`

### 评分维度

| 维度 | 分值 | 检查项 |
|------|------|--------|
| SEO 优化 | 25 | Title, Description, H1/H2, 关键词密度, 内链, 结构化数据 |
| 内容质量 | 25 | 无 AI 套话, 独特价值, 结构清晰, 实操性, FAQ 质量 |
| 用户价值 | 20 | 解决实际问题, 具体建议, 覆盖目标受众 |
| 技术实现 | 15 | 页面速度, 移动端友好, 结构化数据有效 |
| GEO 优化 | 15 | 直接回答, 结构化清晰, 权威引用, FAQ 覆盖, 地理定位 |

### 评分等级

| 分数 | 等级 | 发布建议 |
|------|------|----------|
| 90-100 | A | 立即发布 |
| 80-89 | B | 可发布，建议优化 |
| 70-79 | C | 需要优化后发布 |
| 60-69 | D | 大幅修改 |
| < 60 | F | 重写 |

### 发布门槛

```yaml
minimum_score: 80
blocking_issues:
  - "Title 缺失"
  - "Description 缺失"
  - "H1 缺失"
  - "结构化数据无效"
```
