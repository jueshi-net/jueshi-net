## 二、P0 根因复述

### 2.1 问题代码位置

**文件：** `src/app/api/rewards/redeem/route.ts`

**问题代码：**
```typescript
// Auto-upgrade for member_trial: set role to member and update memberUntil
if (rewardItem.rewardType === "member_trial" && expiresAt) {
  await tx.user.update({
    where: { id: userId },
    data: {
      role: "member",  // ← 问题：覆盖原有 role
      memberUntil: newMemberUntil,
    },
  });
}
```

### 2.2 问题流程

1. 9833416@qq.com 兑换了 member_trial 类型的奖励

3. 导致 9833416@qq.com 无法访问后台管理页面

## 三、修复内容

### 3.1 redeem/route.ts 修复

**修复前：**
```typescript
await tx.user.update({
  where: { id: userId },
  data: {
    role: "member",  // ← 覆盖 role
    memberUntil: newMemberUntil,
  },
});
```

**修复后：**
```typescript
// Auto-upgrade for member_trial: ONLY update memberUntil, NEVER touch role.
// Role is for permission (admin/user), not membership status.
// Membership is determined by memberUntil > now.
await tx.user.update({
  where: { id: userId },
  data: {
    memberUntil: newMemberUntil,  // ← 只更新 memberUntil
  },
});
```

### 3.2 membership.ts 修复

**修复前：**
```typescript
// Check explicit member role
if (user.role === "member") return true;
```

**修复后：**
```typescript
// Check memberUntil expiration — this is the canonical membership check
if (user.memberUntil && user.memberUntil > new Date()) return true;
```

### 3.3 permissions.ts 修复

**修复前：**
```typescript
const role = dbUser.role?.toLowerCase();
if (role === "admin" || role === "管理员") return "admin";
if (role === "member") return "member";
if (role === "user") return "user";
```

**修复后：**
```typescript
const role = dbUser.role?.toLowerCase();
if (role === "admin" || role === "管理员" || role === "administrator") return "admin";
if (role === "user" || role === "member") {
  // For user/member roles, check if they have active membership via memberUntil
  const fullUser = await prisma.user.findUnique({
    where: { id: userId || "" },
    select: { memberUntil: true },
  }).catch(() => null);
  if (fullUser?.memberUntil && fullUser.memberUntil > new Date()) return "member";
  return "user";
}
```
