## 二、内容类型定义

### 2.1 CountryPage（国家页）

**用途：** 为特定国家提供完整的跨境贸易资源聚合页

**内容结构：**
```
CountryPage
├── 国家基本信息（名称、国旗、时区、货币）
├── 相关工具（HS编码、运费计算、地址格式）
├── 相关指南（地址格式、清关流程、关税计算）
├── 相关专题（该国热门话题）
├── 相关清单（发货检查清单）
├── 相关文章（该国贸易新闻、政策解读）
├── 网址资源（该国海关、邮政、物流商官网）
├── FAQ（常见问题）
├── 官方链接（政府网站）
├── 任务链入口（发往该国的发货任务）
└── 广告位（运营配置）
```

**实现方式：**
- **Phase 1（当前）：** 使用 JSON 配置文件
  ```typescript
  // content/countries/us.json
  {
    "code": "US",
    "name": "美国",
    "relatedTools": ["hs-code", "shipping-calculator"],
    "relatedGuides": ["address-format", "customs-clearance"],
    "relatedTopics": ["us-tariff", "fba-shipping"],
    "officialLinks": [...]
  }
  ```
- **Phase 2（未来）：** 使用数据库模型
  ```prisma
  model CountryPage {
    id String @id
    code String @unique // US, CA, UK
    name String
    content Json // 灵活的内容结构
    relatedToolIds String[]
    relatedGuideIds String[]
    // ...
  }
  ```

### 2.2 Topic（专题）

**用途：** 围绕特定主题的深度内容集合

**示例：**
- "美国 FBA 发货指南"
- "英国 VAT 税务合规"
- "日本进口清关流程"

**内容结构：**
```
Topic
├── 专题标题和描述
├── 相关文章列表（按时间/热度排序）
├── 相关工具推荐
├── 相关任务链模板
├── 用户讨论（未来：论坛集成）
└── 相关专题推荐
```

**实现方式：**
- **当前：** 使用现有 `Topic` 模型（已存在）
- **增强：** 添加 `relatedTaskChainTemplates` 字段

### 2.3 Checklist（清单）

**用途：** 可勾选的操作清单，帮助用户完成特定任务

**示例：**
- "跨境发货检查清单"
- "FBA 入仓准备清单"
- "海关申报文件清单"

**内容结构：**
```
Checklist
├── 清单标题
├── 清单项目（可勾选）
│   ├── 项目名称
│   ├── 说明
│   ├── 相关链接（工具/指南）
│   └── 完成状态（用户维度）
├── 进度追踪（X/Y 已完成）
└── 相关任务链（从清单创建任务）
```

**实现方式：**
- **Phase 1（当前）：** 使用 JSON 配置
  ```typescript
  // content/checklists/shipping.json
  {
    "id": "shipping-checklist",
    "title": "跨境发货检查清单",
    "items": [
      {
        "id": "hs-code",
        "label": "查询 HS 编码",
        "description": "确定商品的海关编码",
        "relatedTool": "/tools/hs-code"
      },
      // ...
    ]
  }
  ```
- **Phase 2（未来）：** 使用数据库模型 + 用户进度表
  ```prisma
  model Checklist {
    id String @id
    title String
    items Json // [{ id, label, description, relatedTool }]
  }
  
  model ChecklistProgress {
    userId String
    checklistId String
    completedItems String[] // [item ids]
    @@id([userId, checklistId])
  }
  ```

### 2.4 LandingPage（落地页）

**用途：** 营销导向的单页面，引导用户转化

**示例：**
- "跨境电商新手指南"
- "免费运费计算工具"
- "一键生成商业发票"

**与 Guide 的区别：**
- **LandingPage：** 营销导向，CTA 强，内容简洁
- **Guide：** 教育导向，内容详细，步骤清晰

**实现方式：**
- **当前：** 使用现有 `LandingPage` 模型（已存在）
- **增强：** 添加 A/B 测试支持

### 2.5 Guide（指南）

**用途：** 详细的教育内容，帮助用户学习特定技能

**示例：**
- "国际地址格式指南"
- "HS 编码查询教程"
- "商业发票填写指南"

**与 LandingPage 的区别：**
- **Guide：** 教育导向，内容详细，多步骤
- **LandingPage：** 营销导向，CTA 强，内容简洁

**实现方式：**
- **当前：** 使用静态页面（/guides/[slug]）
- **未来：** 使用数据库模型，支持 CMS 管理

## 三、内容关系图

```
CountryPage (美国)
    ├── relatedTools: [HS编码, 运费计算]
    ├── relatedGuides: [地址格式, 清关流程]
    ├── relatedTopics: [FBA发货, 关税计算]

    ├── relatedArticles: [FBA入仓流程, FBA费用计算]
    ├── relatedTools: [运费计算, CBM计算]
    ├── relatedChecklists: [FBA入仓准备清单]

Checklist (发货检查清单)
    ├── items: [查询HS编码, 计算运费, 生成发票, ...]
    ├── relatedTools: [每个item关联的工具]
    └── relatedTaskChains: [从清单创建任务]
```

## 六、结论

### 6.1 设计原则

1. **内容聚合：** CountryPage 作为国家级资源聚合页
2. **深度内容：** Topic 提供专题深度内容
3. **可操作性：** Checklist 提供可勾选的操作清单
4. **营销转化：** LandingPage 引导用户转化
5. **教育导向：** Guide 提供详细教程

### 6.2 实施策略

1. **Phase 1（当前）：** 使用 JSON 配置，不引入新模型
2. **Phase 2（下一版本）：** 数据库模型 + 后台管理
3. **Phase 3（长期）：** CMS + A/B 测试 + UGC

### 6.3 本轮不实施

- ❌ 不创建 CountryPage 数据库模型
- ❌ 不创建 Checklist 数据库模型
- ❌ 不实施 CMS 系统

**原因：** 风险可控，先用 JSON 配置验证需求，再决定是否引入数据库模型。
