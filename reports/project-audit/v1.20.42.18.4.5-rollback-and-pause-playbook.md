## 一、停测条件

### 1.1 立即停测条件（任一触发）

- [ ] **任一 P0 Bug**
  - 登录失败
  - 管理员变普通用户
  - 普通用户能进后台
  - 用户能看到别人任务
  - 任务链保存丢数据
  - 奖励扣积分不到账
  - 生产 500/白屏
  - 数据库/权限异常

- [ ] **2 个以上用户遇到同一 P1 阻塞**
  - 工具写回失败
  - 发票/装箱单数据缺失
  - 移动端主流程难用

- [ ] **后台不可访问**
  - 后台 500 错误
  - 后台白屏
  - 后台超时

- [ ] **任务链保存失败**
  - 任务链无法创建
  - 任务链无法保存
  - 任务链数据丢失

- [ ] **权限隔离失败**
  - 用户能看到别人任务
  - 用户能编辑别人任务
  - 未登录能访问 API

- [ ] **奖励扣积分不到账**
  - 积分扣除但会员未增加
  - 积分扣除但成长值未增加
  - 积分扣除但兑换记录未创建

- [ ] **管理员权限异常**
  - 管理员无法访问后台
  - 管理员权限被降级
  - 管理员操作失败

## 二、停测流程

### 2.1 停测决策

```
1. 发现停测条件触发
   ↓
2. 评估影响
   - 影响范围
   - 影响程度
   - 是否可快速修复
   ↓
3. 决定停测
   - 立即停测
   - 通知所有测试用户
   ↓
4. 执行停测
   - 在后台显示停测公告
   - 暂停新用户注册
   - 暂停现有用户测试
```

### 2.2 停测通知

**通知内容：**
```
【Beta 暂停通知】

尊敬的用户：

由于发现 [问题描述]，我们决定暂停 Beta 测试，预计修复时间为 [预计时间]。

给您带来的不便，我们深表歉意。

修复完成后，我们会第一时间通知您继续测试。

感谢您的理解和支持！

绝世百宝箱团队
```

**通知方式：**
- 邮件通知
- 微信通知
- 后台公告


## 五、数据库回滚流程

### 5.1 数据库回滚步骤

**警告：** 数据库回滚是高风险操作，必须谨慎执行。

```bash
# 1. SSH 到 VPS
ssh deploy@192.129.155.149

# 2. 进入项目目录
cd /home/deploy/xixiong-saas

# 3. 查看最近的备份
ls -lh /home/deploy/backups/ | tail -10

# 4. 选择要恢复的备份
# 假设备份文件为：backup-2026-06-21-10-00-00.sql.gz

# 5. 解压备份
gunzip /home/deploy/backups/backup-2026-06-21-10-00-00.sql.gz

# 6. 恢复数据库
source .env.production
export DATABASE_URL
psql $DATABASE_URL < /home/deploy/backups/backup-2026-06-21-10-00-00.sql

# 7. 验证恢复
psql $DATABASE_URL -c "SELECT COUNT(*) FROM users;"

# 8. 重启 PM2
pm2 restart xixiong-saas --update-env

# 9. 验证生产环境
curl -I https://jueshi.net
```

## 六、严禁操作

### 6.1 严禁无备份回滚数据库

- ❌ 不得在没有备份的情况下回滚数据库
- ❌ 不得删除备份文件
- ❌ 不得覆盖备份文件

### 6.2 严禁直接删除数据

- ❌ 不得使用 DELETE 语句删除数据
- ❌ 不得使用 TRUNCATE 语句删除数据
- ❌ 不得使用 DROP 语句删除表

### 6.3 严禁使用 prisma db push

- ❌ 不得使用 `prisma db push`
- ❌ 不得使用 `prisma migrate reset`
- ❌ 必须使用 `prisma migrate deploy`

### 6.4 严禁暴露 secret

- ❌ 不得在报告中输出密码
- ❌ 不得在报告中输出 token
- ❌ 不得在报告中输出完整 DATABASE_URL
- ❌ 不得在报告中输出 API key
