# v1.20.42.18.6.4.12.2-02 — Real Badge Icon Upload

## Upload API
- **Path**: `POST /api/admin/badges/[id]/icon`
- **Auth**: admin-only (requireAdmin)
- **Unauthenticated**: returns 401 "Unauthorized" ✅
- **Content-Type**: multipart/form-data

## File Security
| Check | Rule |
|-------|------|
| Allowed types | PNG, JPG/JPEG, WebP |
| Forbidden types | SVG, HTML, JS, PHP, EXE, SH (all rejected) |
| Max size | 512KB |
| Filename | crypto.randomUUID() + extension |
| Storage | public/uploads/badges/ |
| Server path exposure | None (returns /uploads/badges/uuid.ext) |

## Client Implementation
- File input with accept="image/png,image/jpeg,image/webp"
- Upload button with loading spinner
- Client-side validation (size + type)
- Preview uploaded icon
- Replace icon (upload new file)
- Old file deletion: DEFERRED (not deleted, just replaced)

## Workflow
1. Create badge (POST /api/admin/badges) → get badge ID
2. Edit badge → upload icon (POST /api/admin/badges/[id]/icon)
3. Icon URL saved to UserBadge.iconText field
4. List page renders <img> when iconText starts with /uploads/
5. Edit page shows current uploaded icon
