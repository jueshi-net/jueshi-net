# v1.20.42.18.4.7 — 内容与页面架构现状审计

**审计时间**: 2026-06-21

## 一、现有内容模型

### 1. LandingPage 模型 (已有，完整)
- slug, title, seoTitle, seoDescription
- pageType: country / tool / topic / guide / city / postal / landing / checklist
- status: draft / published / hidden
- heroSection (JSON), primaryTool, relatedTools[], relatedTopics[], relatedArticles[]
- faqItems (JSON), officialLinks (JSON), adPlacements (JSON), ctaConfig (JSON)
- blockVisibility (JSON), blockOrder (JSON)
- **结论**: 已支持 FAQ、官方链接、广告位、模块排序

### 2. Topic / TopicItem / TopicSection 模型 (已有，完整)
- Topic: slug, title, subtitle, summary, status, templateType, seo fields, youtube fields
- TopicItem: name, alias, rating, category, iconText, description, officialUrl, sortOrder
- TopicSection: type (intro/notice/faq/cta/custom_text), title, content, sortOrder
- **结论**: 完整的专题聚合系统，已有 CRUD admin

### 3. Article 模型 (已有，被 guides 复用)
- title, slug, content, excerpt, coverImage, author, status, views
- category, seoTitle, seoDescription, relatedTools[]
- **问题**: Article 模型缺少 relatedTopics, relatedChecklists, relatedGuides 字段
- **结论**: 需新增 Guide 模型，或在 Article 基础上扩展

### 4. Resource 模型 (已有)
- 站点资源收藏，非内容页
- **结论**: 与本轮内容架构无关

## 六、差距总结

### 需要新增:
1. **Guide 模型** — 独立指南模型，带 category, relatedTools, relatedTopics, relatedChecklists, relatedGuides, seo fields, canonicalUrl, robots
2. **Checklist 模型** — 独立清单模型，带 steps JSON, relatedTools, relatedTaskChain, seo fields
3. **/admin/content** — 内容中心总览
4. **/admin/content/guides** — Guide CRUD
5. **/admin/content/checklists** — Checklist CRUD
6. **/api/admin/guides** — Guide API
7. **/api/admin/checklists** — Checklist API
8. **/countries/[country]** — 国家页路由 (LandingPage type=country)

### 需要扩展:
- LandingPage 添加 canonicalUrl, robots 字段 (可选，一期可跳过)
- /guides/[slug] 优先查询 Guide 模型，fallback 到硬编码

### 已有可复用:
- LandingPage 模型 — 作为 CountryPage/CityPage 容器
- Topic 模型 — 完整可用
- Admin landing-pages — 完整 CRUD
- Admin topics — 完整 CRUD
- /destinations/[slug] — 可与 /countries/[country] 共存

## 七、审计结论

项目已有约 70% 的内容架构基础设施。主要差距是:
1. 缺少独立的 Guide 和 Checklist 模型
2. 缺少 /admin/content 内容中心总览
3. 缺少 /countries/[country] 路由
4. 硬编码指南页需要 fallback 兼容

本轮将通过最小 migration + 复用现有模型来补齐这些差距。
