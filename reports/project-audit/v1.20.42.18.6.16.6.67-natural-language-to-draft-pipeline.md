## 3. 是否自动判断内容类型

**答案：是**

**判断逻辑：**
```typescript
// 检测关键词
const hasChecklistKeywords = /清单|步骤|准备|检查/.test(input);
const hasGuideKeywords = /如何|怎么|教程|指南/.test(input);
const hasTopicKeywords = /推荐|对比|评测|TOP/.test(input);

// 自动判断类型
if (hasChecklistKeywords && !hasGuideKeywords && !hasTopicKeywords) {
  contentType = 'checklist';
} else if (hasTopicKeywords && !hasChecklistKeywords) {
  contentType = 'topic';
} else {
  contentType = 'guide';
}
```

**示例：**
- 输入包含"清单"、"准备" → 判断为 `checklist`
- 输入包含"如何"、"教程" → 判断为 `guide`
- 输入包含"推荐"、"对比" → 判断为 `topic`
