# v1.20.42.18.6.0 — Phase 2: jueshi.net 社区定位

**生成时间:** 2026-06-22

---

## 1. 社区定位

jueshi.net 社区不是普通论坛，而是：

**海外华人实用问题社区** — 围绕跨境发货、清关、地址、邮编、物流工具的实用问答和经验分享平台。

### 与普通论坛的区别

| 普通论坛 | jueshi.net 社区 |
|---------|----------------|
| 话题宽泛，无明确主题 | 聚焦跨境物流/生活实用问题 |
| 纯用户交流 | 工具 + 内容 + 社区三位一体 |
| 独立系统 | 与任务链/工具/指南深度集成 |
| 内容自生自灭 | 优质内容沉淀为指南/清单 |
| 用户等级为虚荣指标 | 成长值联动实际权益 |

## 2. 社区角色

- **跨境发货/清关/地址/邮编/物流工具讨论区** — 用户在使用工具过程中遇到的问题
- **国家/城市生活经验社区** — 海外生活实用信息
- **工具反馈和 Beta 问题反馈区** — 用户反馈直接进入社区，admin 可追踪
- **指南、清单、任务链的讨论承接区** — 每个指南/清单可以有相关讨论
- **内容和用户经验沉淀区** — 优质帖子可被提升为指南

## 3. 一期频道设计（10 个）

基于现有 5 个分类扩展为 10 个：

| # | key | 名称 | 说明 | 现有? |
|---|-----|------|------|-------|
| 1 | announcements | 公告与更新 | 官方公告，仅 admin 可发帖 | 新增 |
| 2 | beta-feedback | Beta 反馈 | Beta 用户反馈专属区 | 新增 |
| 3 | cross-border-shipping | 跨境发货 | 跨境物流、发货流程讨论 | 新增（拆分 logistics） |
| 4 | hs-code-customs | HS 编码与申报 | HS Code 使用经验、报关问题 | 新增（拆分 logistics） |
| 5 | address-postal | 地址邮编与收件格式 | 地址格式、邮编查询问题 | 新增（拆分 overseas-life） |
| 6 | country-city-life | 国家/城市生活 | 海外生活经验、城市指南 | 新增（改名 overseas-life） |
| 7 | tools-help | 工具使用问题 | 工具操作问题、bug 反馈 | 改名 tools |
| 8 | experience-sharing | 经验分享 | 成功案例、经验总结 | 新增 |
| 9 | q-and-a | 问答求助 | 快速问答 | 新增 |
| 10 | suggestions-voting | 建议与投票 | 功能建议、投票 | 改名 feedback |

### 分类调整说明
- 原 `logistics` 拆分为 `cross-border-shipping` + `hs-code-customs`（更精细）
- 原 `overseas-life` 改名为 `country-city-life` + 新增 `address-postal`
- 原 `tools` 改名为 `tools-help`
- 原 `feedback` 改名为 `suggestions-voting` + 新增 `beta-feedback`
- 新增 `announcements`（仅 admin）、`experience-sharing`、`q-and-a`

### 频道权限
- `announcements`: 仅 admin 可发帖，所有用户可回帖
- `beta-feedback`: 登录用户可发帖（Beta 期间）
- 其他频道: 登录用户可发帖，guest 可浏览

## 4. 内容与工具联动

### 工具 → 社区
- 工具页面显示"相关讨论"区，筛选 `relatedTool` 字段匹配的帖子
- 工具使用遇到问题时，引导用户到 `tools-help` 频道发帖

### 社区 → 工具
- 帖子可关联工具入口（`relatedTool` 字段）
- 帖子详情页显示"使用此工具"CTA

### 指南/清单 → 社区
- Guide/Checklist 页面显示"相关问答"
- 帖子可关联 Guide/Checklist（`relatedGuideId`, `relatedChecklistId`）

### 任务链 → 社区
- 任务链完成页引导"分享经验"
- 帖子可关联任务链类型（`relatedTaskChainType`）

## 5. 用户价值闭环

```
用户使用工具 → 遇到问题 → 社区提问 → 获得回答 → 经验沉淀
     ↑                                              ↓
     ← ← ← 优质帖子提升为指南 ← ← ← ← ← ← ← ← ← ←
```
