## 二、问题诊断

### 用户反馈的问题

用户实测发现：
- 点击"流量分析"后，页面单独成为一个页面
- 左侧后台菜单栏消失
- 页面没有继承后台管理 Layout
- 管理员无法在后台框架中继续切换其他模块

### 根因分析

**问题根源**：文件位置错误

```
错误位置：src/app/admin/analytics/dashboard/page.tsx
正确位置：src/app/(admin)/admin/analytics/dashboard/page.tsx
```

**原因说明**：
1. Next.js 的 route group `(admin)` 用于组织共享 layout 的页面
2. `src/app/(admin)/layout.tsx` 包含后台框架（左侧菜单栏、顶部 header 等）
3. 所有在 `src/app/(admin)/admin/` 下的页面都会继承这个 layout
4. 但是 `src/app/admin/analytics/dashboard/` 没有使用 `(admin)` route group
5. 因此该页面不会继承后台 layout，导致左侧菜单栏消失

**对比其他后台页面**：
- ✅ `/admin/feedback` → `src/app/(admin)/admin/feedback/page.tsx`
- ✅ `/admin/invites` → `src/app/(admin)/admin/invites/page.tsx`
- ✅ `/admin/analytics` → `src/app/(admin)/admin/analytics/page.tsx`
- ❌ `/admin/analytics/dashboard` → `src/app/admin/analytics/dashboard/page.tsx`（错误）
