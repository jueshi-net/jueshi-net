# v1.20.42.18.6.4.11-04 — Admin Community Menu Entry

## Root Cause

Admin sidebar (`navSections` in `src/app/(admin)/layout.tsx`) had no "社区管理" section. Community admin routes existed but were only accessible via direct URL or front-end links.

## Fix

Added new "社区管理" section to `navSections` with 7 sub-menu items:

| Label | Route | Status |
|-------|-------|--------|
| 社区概览 | /admin/community | 200 ✅ |
| 帖子管理 | /admin/community/posts | 200 ✅ |
| 评论管理 | /admin/community/comments | 200 ✅ |
| 举报处理 | /admin/community/flagged | 200 ✅ |
| 荣誉管理 | /admin/community/reputation | 200 ✅ |
| 勋章管理 | /admin/community/badges | 200 ✅ |
| 用户社区资料 | /admin/community/users | 200 ✅ (redirects to /admin/users) |

## New File

Created `src/app/(admin)/admin/community/users/page.tsx` — redirects to `/admin/users` (general user management) since no separate community users list page exists yet.

## Access Control

- Admin layout checks: `session?.user` exists AND `role` is "管理员", "ADMIN", or "admin"
- Non-admins redirected to `/dashboard?error=not-admin`
- Unauthenticated users redirected to `/login?reason=no-session`
- Only admin can see the sidebar menu

## Verification

All 7 routes return HTTP 200 when accessed (admin session required for full page render).
