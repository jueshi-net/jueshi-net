## PHASE 2 — 根因分析

### 2.1 为什么 jueshi.net 不被索引？

**直接原因：** `X-Robots-Tag: noindex, nofollow` HTTP header

**代码位置：** `next.config.ts` 第 81-113 行

```typescript
async headers() {
  return [
    {
      source: "/:path*",
      headers: [
        {
          key: "X-Robots-Tag",
          value: "noindex, nofollow",  // ❌ 阻止索引
        },
      ],
      has: [
        {
          type: "host",
          value: "jueshi.net",  // ❌ 对正式站也生效
        },
      ],
    },
    {
      source: "/:path*",
      headers: [
        {
          key: "X-Robots-Tag",
          value: "noindex, nofollow",  // ❌ 阻止索引
        },
      ],
      has: [
        {
          type: "host",
          value: "www.jueshi.net",  // ❌ 对 www 也生效
        },
      ],
    },
  ];
}
```

**问题：** 
- 这个配置对 `jueshi.net` 和 `www.jueshi.net` 的所有页面都设置了 `noindex, nofollow`
- 这是开发阶段的配置，正式站上线后应该移除或修改

### 2.2 为什么 300zy.com 还在 Google 搜索结果中？

**可能原因：**
1. Google 缓存了旧页面（绝世百宝箱内容）
2. 300zy.com 没有 301 重定向到 jueshi.net
3. 300zy.com 的旧 sitemap 可能曾提交过 URL

**当前状态：**
- 300zy.com 页面内容已变为 "AI 玩家资源社区"
- 页面有 `<meta name="robots" content="noindex"/>`
- 但没有 301 重定向
