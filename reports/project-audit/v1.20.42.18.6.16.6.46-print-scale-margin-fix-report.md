## Root Cause Analysis

### Problem
Print output was smaller than design canvas with excessive white space around edges.

### Investigation Results

**Preview Canvas:**
- Paper size: 377.953px × 377.953px (100mm × 100mm)
- Element font-size: **16px** (12pt)
- Element position: left: 75.59px (20mm), top: 75.59px (20mm)
- Element size: width: 188.98px (50mm), height: 37.80px (10mm)

**Print DOM (Before Fix):**
- Page size: 378px × 378px (100mm × 100mm) ✓
- Element font-size: **12px** ❌ (should be 16px)
- Element position: left: 75.59px (20mm), top: 75.59px (20mm) ✓
- Element size: width: 188.98px (50mm), height: 37.80px (10mm) ✓

**PDF Output (Before Fix):**
- Page size: 100.16mm × 100.16mm ✓
- Text size: width=12.70mm, height=3.18mm ❌

### Root Cause
`canvas-schema.ts` defines `fontSize` in **pt** (points):
```typescript
export interface CanvasElementStyle {
  /** Font size in pt */
  fontSize?: number;
  // ...
}
```

But print renderer was treating it as **px**:
```typescript
// ❌ WRONG: 12pt treated as 12px
font-size: ${element.style.fontSize || 14}px;
```

12pt = 16px (1pt = 1.333px at 96 DPI)

---

## Fix Applied

### Code Change
**File:** `src/app/(public)/tools/template-studio/canvas-editor-full.tsx`

**Before:**
```typescript
font-size: ${element.style.fontSize || 14}px;
```

**After:**
```typescript
// Note: fontSize is in pt (points), not px
// 1pt = 1.333px at 96 DPI
const fontSizePx = (element.style.fontSize || 14) * 1.333;
// ...
font-size: ${fontSizePx}px;
```

Also fixed other unit conversions:
- `padding`: mm → px (× 3.7795275591)
- `borderWidth`: mm → px (× 3.7795275591)
- `borderRadius`: mm → px (× 3.7795275591)
