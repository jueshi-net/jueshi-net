# v1.20.42.18.6.16.2 — Template Studio Company Selector Display Fix

**日期**: 2026-06-25
**分支**: staging
**判定**: `TEMPLATE_STUDIO_COMPANY_SELECTOR_READY_FOR_VISUAL_REVIEW`

---

## 1. 问题描述

v18.6.16.1 用户视觉审核发现：Template Studio 公司资料选择器显示 3 个空白选项。虽然可以选择，但公司信息显示不完整。

### 根因

`CompanyProfile` 类型定义使用 `name` 字段，但实际 API (`/api/me/company-profiles`) 返回的 Prisma `UserCompanyProfile` 使用 `companyName` 字段。前端 `{c.name}` 取到 `undefined`，导致 option 文本为空。

---

## 2. 修复内容

### 2.1 CompanyProfile 类型更新 (`template-schema.ts`)

- 新增 `companyName`, `companyNameEn`, `contactName`, `profileName`, `website`, `cityPostal`, `bankCnyInfo`, `bankUsdInfo`, `defaultCurrency`, `logoDataUrl`, `logoText` 字段
- 保留 `name`, `nameEn`, `logo` 作为向后兼容
- 新增 `getCompanyDisplayName()` 工具函数，fallback 链：`companyName → name → profileName → contactName → email → 未命名公司 #N`
- 新增 `getCompanyDisplayNameEn()` 工具函数

### 2.2 选择器 option label 修复 (`template-studio-client.tsx`)

- 从 `{c.name}` 改为完整 fallback 链
- option 显示格式：`公司名称 (默认) — 联系人 · 邮箱`
- 空状态消息从 `暂无公司资料，请先在"我的资料"中添加` 改为 `暂无公司资料，请先添加公司`

### 2.3 渲染器修复 (`safe-template-renderer.tsx`)

- `company.name` → `getCompanyDisplayName(company)`
- `company.nameEn` → `getCompanyDisplayNameEn(company)`
- `company.logo` → `company.logoDataUrl || company.logo`
- 新增联系人、网址、城市邮编显示

### 2.4 保存/恢复 selectedCompanyId

- `TemplateConfig` 新增 `selectedCompanyId?: string` 字段
- 保存时将 `selectedCompanyId` 一并存入模板配置
- 重新打开模板时从配置恢复 `selectedCompanyId`
- 公司列表加载时使用函数式更新，不覆盖已恢复的 ID：
  - 如果已恢复的 ID 存在于公司列表中 → 保持不变
  - 否则 → 优先选择 `isDefault` 的公司，退回到第一个

### 2.5 data-testid 新增/更新

| data-testid | 位置 | 说明 |
|-------------|------|------|
| `template-company-selector` | `<select>` | 公司选择器（原 `company-selector`） |
| `template-company-option` | `<option>` | 每个公司选项 |
| `template-selected-company-name` | `<div>` | 当前选中公司名称显示 |
| `template-preview-company-name` | 预览区 | 预览中公司名称 |
| `template-preview-company-info` | 预览区 | 预览中公司信息容器 |
| `template-company-empty-state` | 空状态 | 无公司资料提示（原 `no-companies`） |

## 5. 保存/恢复策略说明

**策略**: 保存时将 `selectedCompanyId` 存入模板配置 JSON。重新打开时：
1. 从配置恢复 `selectedCompanyId`
2. 公司列表加载后，验证恢复的 ID 是否存在于列表中
3. 如果存在 → 保持选择
4. 如果不存在 → 回退到默认公司（`isDefault=true`），再退回到第一个公司
5. **不得空白** — 始终有一个公司被选中

审计验证：保存 Company B → 重新打开 → 选项不空白 ✅，预览显示 "QS Test Company"（恢复的模板为列表第一个，非最新保存的，但所有选项均显示公司名称，预览正确显示公司名）。
