## 字段缺口分析

### ❌ 不支持的字段（需要 DB migration）

以下字段在 Prisma schema 和 API 中**不存在**：

1. **videoPack** — 视频包（YouTube 脚本、缩略图提示词）
2. **qualityScore** — 质量评分（0-100）
3. **faq** — FAQ 结构化数据
4. **structuredData** — JSON-LD 结构化数据
5. **internalLinks** — 内链建议
6. **geoAnswerBlock** — GEO 优化答案块
7. **socialMediaPrompts** — 社交媒体推广提示词

### ✅ 当前支持的字段

- title, slug, summary, steps (必填)
- relatedTools, relatedTaskChain, relatedGuides, relatedTopics
- status (draft/published/archived)
- coverImage
- seoTitle, seoDescription, canonicalUrl, robots
- sortOrder
- publishedAt

## 阻塞原因

### ❌ 不建议立即发布

**原因:**
1. **高级字段无法持久化** — videoPack、qualityScore、faq、structuredData 等字段无法写入 DB
2. **发布后无法编辑** — 发布后无法在后台编辑这些高级字段
3. **SEO/GEO 不完整** — 发布后页面缺少 FAQ 结构化数据、HowTo 结构化数据
4. **视频包无法使用** — YouTube 脚本、缩略图提示词无法在后台查看
5. **质量评分无法追踪** — qualityScore 无法在后台显示

### ✅ 建议：先实现字段桥接

**字段桥接方案:**
1. **方案 A: 扩展 Prisma Schema** — 添加 metadataJson JSON 字段
2. **方案 B: 独立字段** — 添加 videoPack、qualityScore、faq 等独立字段
3. **方案 C: Review Pack 集成** — 发布时从 review pack 读取高级字段

**推荐方案:** 方案 A（metadataJson JSON 字段）
