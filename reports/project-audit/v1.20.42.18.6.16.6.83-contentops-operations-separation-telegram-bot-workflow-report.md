## PHASE 7 — 生产权限安全检查

### 7.1 安全清单文档

**文档**: `docs/ops/contentops-bot-security-checklist.md`

### 7.2 最小权限原则

**✅ 允许的权限**:
- 读取: 读取 draft 内容、SEO/GEO 字段
- 创建: 创建 draft（status=draft）
- 更新: 更新 draft 的 metadataJson
- 日志: 写入 audit log

**❌ 禁止的权限**:
- 发布: 不得将 draft 改为 published
- 删除: 不得删除任何内容
- SSH: 不得 SSH 到 production
- 数据库: 不得直接访问数据库
- 部署: 不得执行部署操作
- Git: 不得执行 git push/pull/merge
- NPM: 不得执行 npm install/build
- PM2: 不得执行 pm2 restart
- Prisma: 不得执行 prisma db push/migrate
- SQL: 不得执行 raw SQL（特别是 DELETE/DROP/TRUNCATE）

### 7.3 Rate Limit 配置

```typescript
const RATE_LIMIT_CONFIG = {
  perChatPerMinute: 5,
  perChatPerHour: 50,
  globalPerMinute: 100,
  globalPerHour: 1000
};
```

### 7.4 429 Cooldown 配置

```typescript
const COOLDOWN_CONFIG = {
  cooldownSeconds: 60,
  rejectDuringCooldown: true,
  resetAfterCooldown: true
};
```

### 7.5 Rollback / Disable Bot

**立即禁用 Bot**:
```bash
# 方法 1: 设置环境变量
export CONTENTOPS_BOT_ENABLED=false

# 方法 2: 停止 PM2 进程
pm2 stop contentops-bot

# 方法 3: 删除 PM2 进程
pm2 delete contentops-bot
```

## 用户下一步

### 如何创建新的 Telegram Bot

1. **创建 Bot**:
   - 打开 Telegram
   - 搜索 `@BotFather`
   - 发送 `/newbot`
   - 输入 bot 名称和用户名
   - 获取 bot token

2. **配置环境变量**:
   ```bash
   # .env.local
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   CONTENTOPS_BOT_ENABLED=true
   ```

3. **启动 Bot**:
   ```bash
   tsx scripts/contentops/contentops-telegram-bot.ts
   ```

### 如何用新 Bot 创建第一篇 Draft

1. **发送命令**:
   ```
   /create-draft {"type":"checklist","payload":{"slug":"my-first-checklist","title":"我的第一个清单","metadataJson":{"contentOps":{"seo":{"primaryKeyword":"测试","secondaryKeywords":["测试1","测试2"],"metaKeywords":["测试","清单","草稿"],"searchIntent":"informational","targetAudience":"测试用户","audienceStage":"准备阶段","targetCountries":["加拿大"],"targetSearchEngines":["google"]}}}}}
   ```

2. **Bot 响应**:
   ```
   Draft 创建成功！
   
   Draft ID: contentops-cli-xxx
   Slug: my-first-checklist
   类型: checklist
   
   编辑链接: https://jueshi.net/admin/content/checklists/contentops-cli-xxx/edit
   Preview: https://jueshi.net/checklists/my-first-checklist?preview=true
   ```

3. **用户操作**:
   - 登录后台
   - 点击编辑链接
   - 审核内容
   - 手动发布
