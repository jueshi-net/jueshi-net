**CanvasElement:**
```typescript
interface CanvasElement {
  id: string;
  type: "text" | "field" | "image" | "logo" | "seal" | "table" | "line" | "rect" | "qrcode" | "barcode";
  x: number; // mm
  y: number; // mm
  width: number; // mm
  height: number; // mm
  rotation: number;
  zIndex: number;
  locked: boolean;
  visible: boolean;
  binding?: string;
  text?: string;
  style: CanvasElementStyle;
}
```

**Supported Element Types:**
- text: 文本元素
- field: 数据绑定字段

- seal: 印章元素
- image, logo, line, rect, qrcode, barcode (MVP 未完全实现)

- 10×15: 100×150mm
- 支持网格吸附（默认 5mm）

## 5. Drag & Resize Verification

### 5.1 Drag Implementation

```typescript
const handleMouseMove = useCallback((e: React.MouseEvent) => {
  if (dragState) {
    const dx = pxToMm((e.clientX - dragState.startX) / scale);
    const dy = pxToMm((e.clientY - dragState.startY) / scale);
    
    let newX = dragState.startElementX + dx;
    let newY = dragState.startElementY + dy;
    
    if (canvas.grid.snap) {
      newX = snapToGrid(newX, canvas.grid.sizeMm, true);
      newY = snapToGrid(newY, canvas.grid.sizeMm, true);
    }
    
    updateElement(dragState.elementId, { x: newX, y: newY });
  }
}, [dragState, resizeState, scale, canvas.grid, updateElement]);
```

**Verified:**
- ✅ Drag updates element position in real-time
- ✅ Grid snapping works (5mm default)
- ✅ Position saved in mm coordinates
- ✅ Position restored after save/load

if (resizeState) {
