## PHASE 7: 撤销/重做按钮实现

### 实现内容

**文件**: `src/app/(public)/tools/template-studio/canvas-editor-full.tsx`

**添加的状态**:
```typescript
const [history, setHistory] = useState<CanvasTemplate[]>([]);
const [historyIndex, setHistoryIndex] = useState(-1);
```

**添加的函数**:
- `pushHistory(newCanvas)` — 推送状态到历史记录
- `undo()` — 撤销到上一个状态
- `redo()` — 重做到下一个状态

**UI 按钮**:
```typescript
<button
  onClick={undo}
  disabled={historyIndex <= 0}
  className="flex-1 px-3 py-2 bg-gray-100 text-gray-700 rounded hover:bg-gray-200 text-sm disabled:opacity-50 disabled:cursor-not-allowed"
  data-testid="canvas-undo-button"
>
  ↶ 撤销
</button>
<button
  onClick={redo}
  disabled={historyIndex >= history.length - 1}
  className="flex-1 px-3 py-2 bg-gray-100 text-gray-700 rounded hover:bg-gray-200 text-sm disabled:opacity-50 disabled:cursor-not-allowed"
  data-testid="canvas-redo-button"
>
  ↷ 重做
</button>
<div className="text-xs text-gray-500 mb-4" data-testid="canvas-history-state">
  历史: {historyIndex + 1}/{history.length}
</div>
```

### 审计结果

**TS-CANVAS-UNDO-REDO-VISIBLE**: ✅ PASS
- 撤销/重做按钮存在
- disabled 状态正确

**TS-CANVAS-UNDO-REDO-WORKS**: ❌ FAIL (P1)
- 按钮可见但功能测试超时
- 原因：等待按钮 enabled 状态超时
