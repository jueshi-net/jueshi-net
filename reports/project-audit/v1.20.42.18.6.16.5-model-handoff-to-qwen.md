## 4. 已完成修复说明

### 4.1 印章生成器 (`seal-generator.tsx`)

- **底部弧路径方向修正**：`M 96,62 A 38,38 0 0,1 24,62`（右→左 sweep=1），文字正面朝上不倒置
- **CJK/ASCII 字符宽度计算修正**：全角 CJK 字符宽度 1.0，ASCII 字符 0.55，长中文名自动缩字号不裁切
- **印章尺寸**：130×130px，2 个 circle（外圈 r=50, 内圈 r=44），2 个 textPath（顶部公司名 + 底部"专用章"）

### 4.2 商品加载 bug 修复 (`template-studio-client.tsx`)

- **根因**：API `/api/workspace/products` 返回 `{ success: true, products: [...] }` 但代码检查 `data.data` → 键名不匹配
- **修复**：`const items = data.products || data.data || []`
- **验证**：2 个真实商品加载成功（Bluetooth Speaker Mini, LED Light Bulb 12W）

### 4.3 样式预设系统 (`template-schema.ts`)

- **5 个预设**：classic-blue / minimal-black / warm-earth / forest-green / royal-purple
- **新增 style tokens**：
  - `companyBlockStyle`: none / subtle / card / bordered（默认 subtle）
  - `totalBlockStyle`: minimal / table / card（默认 minimal）
  - `tableStyle`: clean / bordered / striped（默认 clean）
  - `guideOutline`: boolean（默认 true）
  - `stylePreset`: string（预设名称）

### 4.4 渲染器重写 (`safe-template-renderer.tsx`)

- **公司信息区**：`2px solid` 粗蓝框 → `3px left border` subtle 样式
- **总价区**：`2px solid` 粗蓝框 → `0px border` minimal 样式
- **商品表格**：统一细线表头 + `tableStyle` (clean/bordered/striped)
- **guideOutline**：编辑器中显示浅虚线辅助框，PRINT_CSS 和 PNG 导出均隐藏

### 4.5 审计脚本 (`audit-template-studio.ts`)
