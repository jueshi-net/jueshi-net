## PHASE 5 — HSTS 检查

### 当前状态

**响应头检查**:
```bash
curl -sI https://jueshi.net | grep -i strict-transport
# 无输出
```

**结果**: ❌ 缺少 Strict-Transport-Security (HSTS) 头

### HSTS 重要性

HSTS (HTTP Strict Transport Security) 告诉浏览器：
- 只能通过 HTTPS 访问该网站
- 自动将 HTTP 请求升级为 HTTPS
- 防止 SSL stripping 攻击
- 提高安全性

**缺失 HSTS 的影响**:
- 某些浏览器或客户端可能首次访问时使用 HTTP
- 可能导致混合内容问题
- 降低安全性

### 待完成的修复（需要 Cloudflare 配置）

1. ❌ **启用 HSTS**: 需要在 Cloudflare Dashboard 中启用
   - 路径: Cloudflare Dashboard → SSL/TLS → Edge Certificates → HSTS
   - 建议配置:
     - Max Age: 31536000 (1 year)
     - Include Subdomains: Yes
     - Preload: No (除非确定要加入 HSTS Preload List)

### 临时解决方案（Next.js 配置）

如果无法立即修改 Cloudflare 配置，可以在 Next.js 中添加 HSTS 头：

**文件**: `next.config.ts`

```typescript
async headers() {
  return [
    {
      source: '/(.*)',
      headers: [
        {
          key: 'Strict-Transport-Security',
          value: 'max-age=31536000; includeSubDomains',
        },
      ],
    },
  ];
},
```

**注意**: 这需要重新构建和部署。
