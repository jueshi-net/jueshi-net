## 二、历史 Skipped 测试分析

虽然当前无 skipped 测试，但历史报告中经常出现 "23 passed / 9 skipped" 的情况。以下是可能的原因分析：

### 情况 1: Playwright 测试中的 skip

**原因：**
- 某些测试需要特定环境（如生产环境）
- 某些测试需要特定账号（如 admin 账号）
- 某些测试在 CI 中无法运行

**处理方式：**
- ✅ 使用 `test.skip()` 或 `test.fixme()`
- ✅ 在测试标题中说明原因
- ✅ 文档化 skipped 原因

**示例：**
```typescript
test.skip('admin dashboard', async () => {
  // Skipped: requires admin account, not available in CI
});
```

---

### 情况 2: 数据库测试中的 skip

**原因：**
- 某些测试需要真实数据库
- 某些测试需要特定数据
- 某些测试在 CI 中无法运行

**处理方式：**
- ✅ 使用条件跳过
- ✅ 文档化 skipped 原因
- ✅ 提供手动运行命令

**示例：**
```typescript
const hasDb = !!process.env.DATABASE_URL;
test.skip(!hasDb, 'requires DATABASE_URL');
```

---

### 情况 3: 环境限制导致的 skip

**原因：**
- 某些测试需要特定浏览器
- 某些测试需要特定设备
- 某些测试需要特定网络环境

**处理方式：**
- ✅ 使用 Playwright projects
- ✅ 文档化环境要求
- ✅ 提供替代方案

**示例：**
```typescript
test.describe('mobile', () => {
  test.skip(process.env.CI === 'true', 'requires real mobile device');
});
```
