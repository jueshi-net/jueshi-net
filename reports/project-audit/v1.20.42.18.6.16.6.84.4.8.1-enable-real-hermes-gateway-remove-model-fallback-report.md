## PHASE 4: 移除模型 fallback 作为成功路径

### 修改文件

**文件**: `scripts/contentops/hermes-gateway-client.ts`

**修改内容**:
1. ✅ 移除 `analyzeAndPlan` 中的所有 `callDeepSeekDirect` 调用
2. ✅ 移除 `modifyPlan` 中的所有 `callDeepSeekDirect` 调用
3. ✅ 当 Hermes Job Bridge 未启用时，返回 `buildUnavailableResult`
4. ✅ 当 Hermes Job Bridge 不健康时，返回 `buildUnavailableResult`
5. ✅ 当 job 提交失败时，返回 `buildUnavailableResult`
6. ✅ 当 job 执行失败时，返回 `buildUnavailableResult`

**关键代码**:
```typescript
// Check if Hermes Job Bridge is enabled
if (!GATEWAY_CONFIG.enabled) {
  console.log('[HermesGateway] Hermes Job Bridge not enabled, returning unavailable');
  return buildUnavailableResult(hermesRunId, timestamp, inputMode, 'Hermes Job Bridge not enabled');
}

// Check bridge health
const health = checkBridgeHealth();
if (!health.healthy) {
  console.log('[HermesGateway] Hermes Job Bridge unhealthy:', health.message);
  return buildUnavailableResult(hermesRunId, timestamp, inputMode, health.message);
}

// Submit job to Hermes
let jobId: string;
try {
  jobId = submitJob('contentops_generate', inputMode, text);
  console.log('[HermesGateway] Job submitted:', jobId);
} catch (error: any) {
  console.error('[HermesGateway] Failed to submit job:', error.message);
  return buildUnavailableResult(hermesRunId, timestamp, inputMode, `Failed to submit job: ${error.message}`);
}

// Poll for result
try {
  const result = await pollJobResult(jobId);
  
  if (!result) {
    return buildUnavailableResult(hermesRunId, timestamp, inputMode, 'Job returned empty result');
  }

  console.log('[HermesGateway] Job completed successfully');
  return {
    ...result,
    hermesRunId,
    gatewayUsed: true,
    planningUsed: true,
    fallbackUsed: false,
  };
} catch (error: any) {
  console.error('[HermesGateway] Job failed:', error.message);
  return buildUnavailableResult(hermesRunId, timestamp, inputMode, error.message);
}
```

### 选项 1: 配置 Hermes Job Bridge

1. 创建 jobs 目录：
   ```bash
   sudo mkdir -p /var/lib/jueshi-contentops/jobs/inbox
   sudo mkdir -p /var/lib/jueshi-contentops/jobs/outbox
   sudo chown -R deploy:deploy /var/lib/jueshi-contentops
   ```

2. 更新 .env.contentops：
   ```
   HERMES_GATEWAY_ENABLED=true
   HERMES_JOBS_DIR=/var/lib/jueshi-contentops/jobs
   ```

3. 配置 Hermes Agent 监听 jobs（需要实现 Hermes Agent job processor）

4. 重启 bot：
   ```bash
   pm2 restart jueshi-contentops-bot
   ```
