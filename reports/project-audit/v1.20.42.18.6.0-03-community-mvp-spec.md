# v1.20.42.18.6.0 — Phase 3: 社区一期 MVP 功能设计

**生成时间:** 2026-06-22

---

## 1. MVP 原则

一期只做最小闭环，不做大社交平台。目标：用户能发帖、回帖、互动、反馈问题，admin 能审核管理。

## 2. 现有基础（已实现）

| 功能 | 状态 | 备注 |
|------|------|------|
| ForumCategory 模型 | ✅ 已有 | 5 分类已 seed |
| ForumPost 模型 | ✅ 已有 | slug, status, isPinned, isLocked, viewCount, commentCount, ipHash |
| ForumComment 模型 | ✅ 已有 | status, ipHash, rewardGrantedAt |
| 帖子列表 API | ✅ 已有 | GET /api/forum/posts (分页+分类筛选+搜索) |
| 创建帖子 API | ✅ 已有 | POST /api/forum/posts (auth guard + IP hash) |
| 帖子详情 API | ✅ 已有 | GET /api/forum/posts/[slug] (权限检查) |
| 评论 API | ✅ 已有 | GET/POST /api/forum/posts/[slug]/comments |
| Admin 审核 API | ✅ 已有 | posts + comments moderation |
| Admin 统计 API | ✅ 已有 | /api/admin/forum/stats |
| 成长值奖励 | ✅ 已有 | rewardGrantedAt 字段防重复 |

## 3. MVP 需新增功能

### 3.1 前台页面（新增）

| 路由 | 功能 | 优先级 |
|------|------|--------|
| `/community` | 社区首页（改为 ForumPost 列表，当前显示 Topic） | P0 |
| `/community/c/[slug]` | 分类帖子列表页 | P0 |
| `/community/t/[slug]` | 帖子详情页（含评论） | P0 |
| `/community/new` | 发帖页 | P0 |
| `/community/search` | 搜索结果页 | P1 |

### 3.2 帖子功能（新增）

| 功能 | 实现方式 | 优先级 |
|------|---------|--------|
| 发帖 | 已有 API，需前端页面 | P0 |
| 回帖 | 已有 API，需前端组件 | P0 |
| 点赞/有用 | 新增 ForumReaction 模型 | P0 |
| 收藏 | 新增 ForumBookmark 模型 | P1 |
| 举报 | 新增 ForumReport 模型 | P0 |
| 标签 | ForumPost 增加 tags JSON 字段 | P1 |
| 置顶帖 | 已有 isPinned 字段，需后台管理 UI | P0 |
| 精华帖 | 新增 isFeatured 字段 | P1 |
| 关联工具 | 新增 relatedTool 字段 | P1 |
| 关联指南 | 新增 relatedGuideId 字段 | P1 |
| 关联清单 | 新增 relatedChecklistId 字段 | P1 |
| 关联任务链 | 新增 relatedTaskChainType 字段 | P1 |

### 3.3 后台管理（新增）

| 路由 | 功能 | 优先级 |
|------|------|--------|
| `/admin/community` | 社区管理首页 | P0 |
| `/admin/community/categories` | 分类管理（CRUD） | P0 |
| `/admin/community/posts` | 帖子管理（审核/隐藏/删除/置顶） | P0 |
| `/admin/community/comments` | 评论管理（审核/隐藏/删除） | P0 |
| `/admin/community/reports` | 举报审核队列 | P0 |
| `/admin/community/config` | 社区配置（敏感词、频率限制） | P1 |

### 3.4 用户权限

| 角色 | 浏览 | 发帖 | 回帖 | 点赞 | 举报 | 审核 |
|------|------|------|------|------|------|------|
| Guest | ✅ 公开帖 | ❌ | ❌ | ❌ | ❌ | ❌ |
| 登录用户 | ✅ | ✅ (频率限制) | ✅ (频率限制) | ✅ | ✅ | ❌ |
| Moderator | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ (所属分类) |
| Admin | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ (全站) |

### 3.5 发帖频率限制

- 新用户（注册 < 24h）: 每日 3 帖，每帖间隔 5 分钟
- 普通用户: 每日 10 帖
- 回帖: 每日 30 条
- 链接限制: 新用户每帖最多 1 个链接

## 4. MVP 不做

- ❌ 实时通知（二期 SSE）
- ❌ 关注用户
- ❌ 用户主页
- ❌ 推荐流
- ❌ 私信
- ❌ 图片上传（一期纯文本/Markdown）
- ❌ 多语言社区
- ❌ 专家认证
- ❌ 版主体系（一期 admin 兼任）
- ❌ 数据看板（一期用 admin stats API）
