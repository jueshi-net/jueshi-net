## 二、阻塞项分析

### 核心问题：Prisma 7.x 需要 Driver Adapter

**错误信息：**
```
PrismaClientInitializationError: `PrismaClient` needs to be constructed with a non-empty, valid `PrismaClientOptions`
```

**根因：**
1. Staging 使用 Prisma 7.8.0（最新版本）
2. Prisma 7.x 要求使用 Driver Adapter（如 `@prisma/adapter-pg`）
3. 当前 `src/lib/prisma.ts` 可能未配置 adapter
4. 导致 NextAuth 无法通过 Prisma 查询用户

**证据：**
- 使用 `pg` 模块直接连接数据库：✅ 成功
- 使用 `PrismaClient` 无参数：❌ 失败
- bcrypt.compareSync 验证密码：✅ 成功
- NextAuth 登录：❌ 失败（无法查询用户）

**日志：**
```
[AUTH] Login failed: incorrect password (test@jueshi.net)
[auth][error] CredentialsSignin
```

实际是 Prisma 查询失败，但被解释为 "incorrect password"。

### 选项 1：修复 Prisma Adapter（推荐）

修改 `src/lib/prisma.ts`，添加 Driver Adapter：

```typescript
import { PrismaPg } from '@prisma/adapter-pg';
import { PrismaClient } from '@prisma/client';

const adapter = new PrismaPg(process.env.DATABASE_URL!);
export const prisma = new PrismaClient({ adapter });
```

**需要：**
1. 安装 `@prisma/adapter-pg`
2. 修改 `src/lib/prisma.ts`
