## PHASE 2-4 — 实现

### 输入模式识别 (5 种)

| 模式 | 触发条件 | 示例 |
|------|---------|------|
| `title` | 短文本，简单请求 | 帮我创建一个"XXX清单" |
| `brief` | 含目标用户/国家等 | 目标用户是留学生，帮我写指南 |
| `long_text` | >500 字或多行 | 粘贴长文本资料 |
| `reference_rewrite` | 含"参考/改写/不要照搬" | 参考这段资料改写成我们的清单 |
| `messy_notes` | 短行 bullet 列表，<400 字 | 零散要点列表 |

### 内容类型判断

优先级：
1. 用户请求中的显式类型 ("帮我写一篇指南" → guide)
2. 关键词检测 (指南 → guide, 清单 → checklist, 专题 → topic)
3. 输入模式推断 (long_text → guide, messy_notes → checklist)

### 内容生成

| 类型 | 生成内容 |
|------|---------|
| Checklist | summary (>=150字), 4 groups, 14 items, 5 FAQ, 5 pitfalls, 5 links, 3 tools |
| Guide | summary, body (>=1500字, 7 sections), 5 FAQ, 5 pitfalls, 5 links, 3 tools |
| Topic | summary, 5 FAQ, 5 pitfalls, 5 links, 3 tools |

### 原创改写

- 不使用原文结构
- 不逐句照搬
- 添加绝世百宝箱风格解释
- 添加实用提醒和风险点
- 添加工具入口
