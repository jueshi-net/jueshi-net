## Root Cause Analysis

### 问题 1: 多个 bot 实例冲突

**症状:** Telegram 日志显示 `409 Conflict: terminated by other getUpdates request`

**根因:** 本地 Mac 上的 hermes gateway (PID 51180/51181) 配置了 Telegram bot，与 production server 上的 bot 使用同一个 token，导致两个实例同时 polling。

**修复:** 停止本地 gateway (`pkill -f 'hermes_cli.main gateway'`)

### 问题 2: DATABASE_URL 不一致

**症状:** Prisma 报错 `Authentication failed against the database server, credentials for bxb_user are not valid`

**根因:** 
- .env.production 中的 DATABASE_URL 使用了错误的密码（长度 70）
- 主站 xixiong-saas 使用了正确的密码（长度 57），来源不明（可能是 PM2 saved state）
- Bot 从 .env.production 加载了错误的 DATABASE_URL

**修复:** 
- 创建 wrapper script，从主站进程提取正确的 DATABASE_URL
- Bot 启动时使用主站的 DATABASE_URL

### 问题 3: Parser 解析错误

**症状:** title 被解析为"创建一个'新加坡留学生租房注意事项清单'"，slug 包含中文

**根因:** Parser 没有优先提取引号内内容

**修复:** 
- 优先匹配中文引号 `""` 和英文引号 `""`
- 中文 title 使用 hash-based slug（如 `checklist-18779a15`）

### 问题 4: 错误脱敏不完整

**症状:** Telegram 用户端显示 Prisma raw error

**根因:** 部分 catch 块没有统一返回脱敏提示

**修复:** 所有 create catch 块统一返回"创建草稿失败：内容服务暂时不可用，已记录给管理员处理。没有发布任何内容。"
