## PHASE 1: 问题诊断

### 用户报告问题

- iPad 上无法触控拖动元素
- iPad 上无法触控缩放元素
- 批量序号不可见

### 根因分析

**问题 1: iPad 触控不支持**

代码使用 `onMouseDown/Move/Up` 等鼠标事件，而不是 Pointer Events API。在 iPad 上，触摸事件不会触发鼠标事件。

**问题 2: 批量序号不可见**

序号元素需要正确渲染并显示 1/10 到 10/10 格式。

## PHASE 2: 触控修复实现

### 修复 1: Pointer Events API

**文件**: `src/app/(public)/tools/template-studio/canvas-editor-full.tsx`

**修改内容**:

```typescript
// 之前：鼠标事件
const handleMouseDown = useCallback((e: React.MouseEvent, elementId: string) => {
  e.stopPropagation();
  if (e.button !== 0) return; // 只处理左键
  // ...
});

// 之后：Pointer Events
const handlePointerDown = useCallback((e: React.PointerEvent, elementId: string) => {
  e.stopPropagation();
  // 支持鼠标左键和触控（pointerType === 'touch' 时 button 可能为 0 或 -1）
  const isTouch = e.pointerType === 'touch';
  const isLeftClick = e.button === 0;
  if (!isTouch && !isLeftClick) return;
  // ...
});
```

**修改点**:

1. `handleMouseDown` → `handlePointerDown` (React.MouseEvent → React.PointerEvent)
2. `handleResizeMouseDown` → `handleResizePointerDown`
3. `handleMouseMove` → `handlePointerMove`
4. `handleMouseUp` → `handlePointerUp`
5. JSX 事件绑定：`onMouseDown` → `onPointerDown`
6. JSX 事件绑定：`onMouseMove/Up/Leave` → `onPointerMove/Up/Leave`

### 触控检测逻辑

```typescript
const isTouch = e.pointerType === 'touch';
const isLeftClick = e.button === 0;
if (!isTouch && !isLeftClick) return;
```

**说明**:
- `pointerType === 'touch'` 检测触控事件
- `button === 0` 检测鼠标左键
- 两者任一满足即可触发拖动/缩放

### 坐标转换

Pointer Events 的 `clientX/clientY` 与 Mouse Events 相同，无需额外转换。现有的 `pxToMm` 和 `scale` 计算逻辑完全兼容。
