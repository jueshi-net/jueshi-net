## Icon Upload
- POST /api/admin/badges/[id]/icon — admin-only
- Allowed types: PNG, JPG, WebP (NO SVG, NO HTML/JS/EXE/PHP)
- Max size: 512KB
- Random filename: crypto.randomUUID()
- Stored: public/uploads/badges/
- Returns relative URL path (not absolute server path)
- Old files not deleted (replacement only, cleanup later)
