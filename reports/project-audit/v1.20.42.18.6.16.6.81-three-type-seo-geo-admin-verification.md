### ✅ 2. 数据存储

**存储位置**: `metadataJson.contentOps.seo`

**数据结构**:
```json
{
  "contentOps": {
    "primaryKeyword": "留学生出国前准备清单",
    "secondaryKeywords": ["出国留学清单", "留学生行前准备"],
    "seo": {
      "metaKeywords": "留学生出国准备,出国留学清单,留学生行前准备",
      "searchIntent": "informational",
      "targetAudience": "即将出国留学的学生和家长",
      "audienceStage": "准备出国阶段",
      "targetCountries": ["加拿大", "美国", "英国"],
      "targetSearchEngines": ["Google", "Baidu", "Bing"]
    }
  }
}
```

**优势**:
- ✅ 无需数据库 migration
- ✅ 灵活扩展
- ✅ 向后兼容

---

### ✅ 3. 页面输出

**优先级**:
1. 优先使用 `metadataJson.contentOps.seo.metaKeywords`
2. 否则从 `primaryKeyword + secondaryKeywords` 生成
3. 否则 fallback 到 `title + 页面类型词`

**规则**:
- ✅ 去重
- ✅ 最多 15 个
- ✅ 中文逗号分隔
- ✅ draft/preview 仍 noindex
- ✅ published 才 index
- ✅ staging 仍 noindex
