# v1.20.42.7.00 后台设置生效审计报告

**日期**: 2026-06-16
**状态**: ⚠️ 部分修复

## 问题描述

后台 /admin/settings 保存的站点名称、站点描述修改后，首页仍然没有变化。

## 审计结果

### 后台设置存储

- 设置保存到 `data/system-settings.json`（文件存储，非数据库）
- 无 Prisma Settings 模型
- 可保存字段：siteName, siteDescription, allowRegistration, maintenanceMode, branding.logo*

### 首页 metadata 来源

- **100% 硬编码** 在 `src/app/layout.tsx`
- 不读取 system-settings.json
- 不读取任何 API

### 修复措施

本轮已将 layout.tsx 中的硬编码从 "海外百宝箱" 修正为 "绝世百宝箱"。

### 根本问题

后台设置与前台 metadata 完全断开。要实现后台设置生效，需要：
1. 将 layout.tsx 改为动态 metadata（使用 generateMetadata）
2. 从 API 读取 system-settings
3. 或在 build 时注入环境变量

**本轮未做此改动**（需要较大重构，不在本版本范围内）。

### 替代方案

当前可通过直接修改 `src/app/layout.tsx` 中的硬编码值来更新站点名称和描述。
