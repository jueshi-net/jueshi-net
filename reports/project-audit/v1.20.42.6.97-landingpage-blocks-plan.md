## 二、方案设计

### 2.1 方案概述

**核心思路**: 新增 `blockConfig` JSON 字段承载 blockVisibility / blockOrder

**实现方式**:
1. 新增 `blockConfig` JSON 字段
2. 存储每个 block 的可见性和排序配置
3. 前台渲染时根据配置显示/隐藏 block 并排序

### 2.2 Schema 变更

**Prisma Schema**:
```prisma
model LandingPage {
  // ... 现有字段
  
  // Block 配置
  blockConfig Json? @map("block_config")

  //   "hero": { "visible": true, "order": 1 },
```

## 三、前台渲染逻辑

### 3.1 当前渲染逻辑

**文件**: `src/app/(public)/lp/[slug]/page.tsx`

**当前实现**:
```typescript
export default async function LandingPage({ params }) {
  const page = await prisma.landingPage.findUnique({
    where: { slug: params.slug, status: 'published' }
  });
  
  return (
    <div>
      <HeroSection data={page.heroSection} />
      <PrimaryTool slug={page.primaryTool} />
      <RelatedTools slugs={page.relatedTools} />
      <RelatedTopics slugs={page.relatedTopics} />
      <RelatedArticles slugs={page.relatedArticles} />
      <FAQ items={page.faqItems} />
      <OfficialLinks links={page.officialLinks} />
      <Ads config={page.adPlacements} />
      <CTA config={page.ctaConfig} />
    </div>
  );
}
```

**问题**:
- ❌ Block 顺序固定，无法调整
- ❌ 无法隐藏特定 Block
- ❌ 无法按页面类型定制 Block

### 3.2 优化后渲染逻辑

```typescript
export default async function LandingPage({ params }) {
  const page = await prisma.landingPage.findUnique({
    where: { slug: params.slug, status: 'published' }
  });
  
  // 解析 blockConfig
  const blockConfig = page.blockConfig || DEFAULT_BLOCK_CONFIG;
  
  // 过滤可见的 block 并按 order 排序
  const visibleBlocks = Object.entries(blockConfig)
    .filter(([_, config]) => config.visible)
    .sort(([_, a], [__, b]) => a.order - b.order);
  
  return (
    <div>
      {visibleBlocks.map(([blockKey, config]) => {
        switch (blockKey) {
          case 'hero':
            return <HeroSection key={blockKey} data={page.heroSection} />;
          case 'primaryTool':
            return <PrimaryTool key={blockKey} slug={page.primaryTool} />;
          case 'relatedTools':
            return <RelatedTools key={blockKey} slugs={page.relatedTools} />;
          case 'relatedTopics':
            return <RelatedTopics key={blockKey} slugs={page.relatedTopics} />;
          case 'relatedArticles':
            return <RelatedArticles key={blockKey} slugs={page.relatedArticles} />;
          case 'faq':
            return <FAQ key={blockKey} items={page.faqItems} />;
          case 'officialLinks':
            return <OfficialLinks key={blockKey} links={page.officialLinks} />;
          case 'ads':
            return <Ads key={blockKey} config={page.adPlacements} />;
          case 'cta':
            return <CTA key={blockKey} config={page.ctaConfig} />;
          case 'hotSearches':
            return <HotSearches key={blockKey} />;
          case 'checklist':
            return <Checklist key={blockKey} />;
          case 'taskChain':
            return <TaskChain key={blockKey} />;
          default:
            return null;
        }
      })}
    </div>
  );
}
```

```typescript
<div className="space-y-4">
  <h3>Block 配置</h3>
  {Object.entries(blockConfig).map(([blockKey, config]) => (
    <div key={blockKey} className="flex items-center gap-4">
      <input
        type="checkbox"
        checked={config.visible}
        onChange={e => updateBlockConfig(blockKey, { visible: e.target.checked })}
      />
      <input
        type="number"
        value={config.order}
        onChange={e => updateBlockConfig(blockKey, { order: parseInt(e.target.value) })}

      />

      <span className="text-sm text-gray-500">{config.description}</span>
    </div>
  ))}
```
