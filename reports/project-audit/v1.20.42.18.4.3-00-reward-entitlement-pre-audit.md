## 八、Schema 现状分析

### 现有模型

#### RewardItem
```prisma
model RewardItem {
  id          String       @id @default(cuid())
  code        String       @unique
  name        String
  description String?
  costPoints  Int
  rewardType  String
  rewardValue Int
  enabled     Boolean      @default(true)
  sortOrder   Int          @default(0)
  createdAt   DateTime     @default(now())
  updatedAt   DateTime     @updatedAt
  userRewards UserReward[]
}
```

**缺失字段:**
- ❌ stockLimit（库存限制）
- ❌ stockUsed（已使用库存）
- ❌ perUserLimit（每人限兑）
- ❌ cooldownHours（冷却期）
- ❌ startAt（开始时间）
- ❌ endAt（结束时间）
- ❌ requiresApproval（需要审核）
- ❌ fulfillmentType（履约类型）
- ❌ fulfillmentStatus（履约状态）

#### UserReward
```prisma
model UserReward {
  id           String     @id @default(cuid())
  userId       String
  rewardItemId String
  rewardType   String
  rewardValue  Int
  status       String     @default("active")
  expiresAt    DateTime?
  usedAt       DateTime?
  createdAt    DateTime   @default(now())
  user         User       @relation(...)
  rewardItem   RewardItem @relation(...)
}
```

**缺失字段:**
- ❌ auditStatus（审核状态）
- ❌ pointsCost（消耗积分）
- ❌ grantId（关联的 RewardGrant）
- ❌ failureReason（失败原因）

### 缺失模型

#### AdEntitlement（广告权益）
- ❌ 完全不存在
- 需要创建用于管理广告权益

#### CouponEntitlement（券类权益）
- ❌ 完全不存在
