# v1.20.42.18.6.4.10-05 — BBS Menu Contrast Fix

## Root Cause

Menu text used `text-gray-400/500/600` classes which provide insufficient contrast against white backgrounds.

## Files Fixed

1. `src/components/layout/header.tsx` — All `text-gray-*` → `text-slate-*` (700 for nav, 600 for secondary, 500 for icons)
2. `src/app/(public)/bbs/page.tsx` — All `text-gray-*` → `text-slate-*`
3. `src/app/(public)/bbs/[slug]/page.tsx` — All `text-gray-*` → `text-slate-*`

## Contrast Mapping

| Old Class | New Class | Usage |
|-----------|-----------|-------|
| text-gray-400 | text-slate-500 | Icons, subtle text |
| text-gray-500 | text-slate-600 | Secondary descriptions |
| text-gray-600 | text-slate-700 | Nav items, body text |
| text-gray-800 | text-slate-800 | Headings |
| text-gray-900 | text-slate-900 | Page titles |
| border-gray-200 | border-slate-200 | Borders |
