## 3. 本地/VPS 文件差异（修复前）

### 严重问题

| 问题 | 说明 |
|------|------|
| VPS 有 `app/` (旧) + `src/app/` (新) | 两个目录共存，490 个旧文件 |
| VPS 有 `lib/` (旧) + `src/lib/` (新) | 84 个旧文件 |
| VPS 有 `components/` (旧) + `src/components/` (新) | 136 个旧文件 |
| VPS 有 `data/`, `hooks/` (旧) | 旧残留 |
| VPS 有 `migrations/` (旧) + 无 `prisma/migrations/` | **prisma/ 目录完全缺失！** |
| VPS 根目录有 `schema.prisma` | 应在 `prisma/schema.prisma` |

### 根因

上一个 context window 的 rsync 命令使用了尾斜杠语法：
```
rsync -avz ... src/ ... prisma/ deploy@...:/home/deploy/xixiong-saas/
```
`prisma/`（带尾斜杠）将 prisma 目录的**内容**复制到 VPS 根目录，而非创建 `prisma/` 子目录。导致：
- `schema.prisma` 出现在 VPS 根目录
- `migrations/` 出现在 VPS 根目录
- `prisma/` 目录不存在

## 4. Module Not Found 根因

v18.4.7.2 build 时出现大量 "Module not found" 错误，根因是：
1. **prisma/ 目录缺失** — schema.prisma 在根目录，prisma generate 可能使用了错误路径
2. **旧 app/ 目录干扰** — Next.js 可能尝试从根目录 app/ 解析模块
3. **rsync 未同步完整项目** — 只同步了部分目录，缺少 prisma/、public/ 等

## 5. 是否 rsync 造成缺文件

**是。** rsync 尾斜杠语法错误导致 prisma/ 内容散落到 VPS 根目录。同时未同步 public/、scripts/ 等目录。

## 6. 是否 package/script 缺失

**是。** `scripts/check-build-env.mjs` 未同步到 VPS，导致 `npm run build` 失败（package.json 的 build 脚本依赖此文件）。
