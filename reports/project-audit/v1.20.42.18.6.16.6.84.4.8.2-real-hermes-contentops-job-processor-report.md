## 用户下一步操作

### 选项 1: 安装 Hermes Agent

如果需要在生产服务器上实现真实的 Hermes ContentOps Job Processor，必须先安装 Hermes Agent：

1. **安装 Hermes CLI**:
   ```bash
   # 在本地 Mac 上
   cd ~/.hermes/hermes-agent
   pip install -e .
   
   # 在生产服务器上（需要 SSH 访问）
   ssh jueshi-new
   cd /home/deploy
   # 安装 Hermes Agent（需要 Nous Research 提供安装方式）
   ```

2. **配置 Hermes profile**:
   ```bash
   hermes config set provider <provider>
   hermes config set model <model>
   ```

3. **创建 contentops 专用 profile**:
   ```bash
   hermes profile create contentops
   ```

4. **验证 Hermes Agent 可调用**:
   ```bash
   hermes --version
   hermes run "test"
   ```

### 选项 2: 使用其他 AI 服务

如果无法安装 Hermes Agent，可以考虑：
