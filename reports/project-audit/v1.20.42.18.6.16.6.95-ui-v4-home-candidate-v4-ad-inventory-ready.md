## 三、V4 核心改进

### 1. 广告库存系统 ✅

**新增组件：**
- `JueshiV4AdInventoryGroup` - 广告组渲染组件

### 2. 广告位类型定义 ✅

**AdItem 接口字段：**
```typescript
interface AdItem {
  slotKey: string;
  type: 'text' | 'image' | 'banner' | 'card';
  enabled: boolean;
  title: string;
  subtitle?: string;
  description?: string;
  imageUrl?: string;
  href: string;
  ctaText?: string;
  tag?: string;
  advertiserName?: string;
  startAt?: string;
  endAt?: string;
  sortOrder: number;
  displayDevices: ('desktop' | 'tablet' | 'mobile')[];
  nofollow: boolean;
  sponsored: boolean;
  trackingKey?: string;
}
```

**AdGroup 接口字段：**
```typescript
interface AdGroup {
  groupKey: string;
  title: string;
  description?: string;
  position: string;
  enabled: boolean;
  showLabel: boolean;
  maxTextRows: number;
  textColumns: number;
  imageColumns: number;
  mobileMode: 'full' | 'compact' | 'hidden';
  sortOrder: number;
  textAds: AdItem[];
  imageAds: AdItem[];
}
```

### 3. 广告组布局 ✅

**文字广告矩阵：**
- 响应式网格：2列(mobile) → 3列(sm) → 4列(md) → 5列(lg) → 6列(2xl)
- 支持行数限制（maxTextRows × textColumns）
- 每个文字广告显示：标题、副标题、标签、CTA、"广告"微标识

**图片广告矩阵：**
- 响应式网格：同上
- Mobile：横向滚动
- 每个图片广告显示：渐变占位图、标题、描述、CTA、"广告"徽章

### 4. 广告标识 ✅

**视觉要求：**
- 每个广告组右上角显示"推广"徽章（橙色背景）
- 每个文字广告右上角显示"广告"微标识（灰色）
- 每个图片广告图片区域右上角显示"广告"徽章（半透明黑色）
- 所有广告链接添加 `rel="nofollow sponsored"`

### 5. 开启/隐藏机制 ✅

**组级控制：**
- `group.enabled = false` → 整个广告组隐藏
- 空广告组（所有广告 disabled）→ 自动折叠，不留空白

**广告级控制：**
- `ad.enabled = false` → 单个广告隐藏
- 支持按设备过滤（displayDevices）

### 6. 后台管理字段预留 ✅

**文档路径：** `docs/ui-references/jueshi-ui-v4-ad-inventory.md`

**预留字段说明：**
- slotKey 命名规范
- 广告项字段定义
- 管理能力（enabled、sortOrder、startAt/endAt、displayDevices）
- 视觉规范
- 空广告处理
- 移动端适配
- 后端集成指南

### 7. SlotKey 命名规则 ✅

**文字广告：** `{groupKey_prefix}_text_{NN}`
- 示例：`home_after_hero_text_01`, `home_after_tools_text_15`

**图片广告：** `{groupKey_prefix}_image_{NN}`
