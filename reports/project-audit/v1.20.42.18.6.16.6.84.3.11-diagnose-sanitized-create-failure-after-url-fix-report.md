## 修复内容

### 1. Trace ID 生成

**新增功能**:
```typescript
function generateTraceId(): string {
  const date = new Date().toISOString().split('T')[0].replace(/-/g, '');
  const random = createHash('md5').update(`${Date.now()}-${Math.random()}`).digest('hex').substring(0, 4);
  return `COPS-${date}-${random}`;
}
```

**应用范围**:
- ✅ 所有用户消息（成功/失败）
- ✅ Audit log 记录
- ✅ 不包含敏感信息（DATABASE_URL, password, token, chatId）

### 2. Slug 冲突检测

**新增功能**:
```typescript
// Check if slug already exists
try {
  const prisma = await getContentOpsPrismaClient();
  
  let existing: any = null;
  if (type === 'checklist') {
    existing = await prisma.checklist.findUnique({ where: { slug }, select: { id: true, slug: true, title: true, status: true } });
  } else if (type === 'guide') {
    existing = await prisma.guide.findUnique({ where: { slug }, select: { id: true, slug: true, title: true, status: true } });
  } else {
    existing = await prisma.topic.findUnique({ where: { slug }, select: { id: true, slug: true, title: true, status: true } });
  }
  
  if (existing) {
    // Slug already exists, return existing draft info
    const urls = buildUrls(type, existing.id, existing.slug);
    
    writeAuditLog({
      action: 'slug_already_exists',
      chatId,
      type,
      slug,
      existingId: existing.id,
      existingTitle: existing.title,
      existingStatus: existing.status,
      traceId,
    });
    
    return {
      success: true,
      message: `该草稿已存在：

Draft ID: ${existing.id}
类型: ${type}
标题: ${existing.title}
Slug: ${existing.slug}
状态: ${existing.status}

管理后台编辑: ${urls.adminEditUrl}
（管理后台链接需要 admin 登录）

预览链接: ${urls.previewUrl}

⚠️ 草稿尚未发布。需要在管理后台审核后才能发布。

Trace: ${traceId}`,
      data: { draftId: existing.id, adminEditUrl: urls.adminEditUrl, previewUrl: urls.previewUrl, existing: true },
    };
  }
} catch (error: any) {
  writeAuditLog({
    action: 'slug_check_failed',
    chatId,
    type,
    slug,
    errorType: error.code || error.name || 'UNKNOWN_ERROR',
    traceId,
  });
  // Continue to create, will fail with unique constraint if slug exists
}
```

**效果**:
- ✅ 在创建前检查 slug 是否已存在
- ✅ 如果已存在，返回友好提示和现有 draft 信息
- ✅ 避免 P2002 错误
- ✅ 记录 audit log
