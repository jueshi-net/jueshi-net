## 三、运费计算器双栏工作台布局说明

### 3.1 布局结构

**桌面端 (≥1024px)**:
```
┌─────────────────────────────────────────────────────────────┐
│ Header (full width)                                          │
├──────────────────────────────────┬──────────────────────────┤
│ LEFT COLUMN (flex)               │ RIGHT COLUMN (420px)     │
│                                  │ sticky top-4             │
│ • Breadcrumb                     │                          │
│ • Disclaimer                     │ • Results Card           │
│ • Transfer Confirmations         │ • Breakdown              │
│ • Mode Selector                  │ • Fee Reference          │
│ • Row Inputs Table               │ • Measurement Guide      │
│ • Fee Settings                   │ • Packing Tips           │
│                                  │                          │
├──────────────────────────────────┴──────────────────────────┤
│ FULL WIDTH (below grid)                                      │
│ • Related Guides                                             │
│ • FAQ Section                                                │
├─────────────────────────────────────────────────────────────┤
│ Related Tools / Checklist / Task Chain / Ads                 │
└─────────────────────────────────────────────────────────────┘
```

**移动端 (<1024px)**: 保持单列，所有内容垂直堆叠。

### 3.2 技术实现

- 外层容器: `max-w-7xl mx-auto px-4 py-6`
- 网格容器: `lg:grid lg:grid-cols-[1fr_420px] lg:gap-6 items-start`
- 左栏: `space-y-6 min-w-0`（输入区）
- 右栏: `space-y-6 mt-6 lg:mt-0 lg:sticky lg:top-4`（结果区，桌面端 sticky）
- 全宽区: Related Guides / FAQ 在网格外

### 3.3 关键特性

1. **右栏 sticky**: 桌面端滚动左栏输入时，结果区始终可见
2. **min-w-0**: 防止左栏内容溢出
3. **响应式**: 移动端自动回退单列
4. **无横向溢出**: 所有表格使用 `overflow-x-auto` 或响应式栅格

## 四、运费计算公式验证

### 4.1 公式保持不变

```
单件 CBM = 长 × 宽 × 高 / 1,000,000
总 CBM = 单件 CBM × 件数
体积重 = 长 × 宽 × 高 × 件数 / 体积重系数
实重合计 = 用户输入值（不乘以件数）
二者取高 = max(体积重, 实重合计)
按公斤运费 = 计费重量 × 公斤单价
按立方运费 = 总 CBM × 立方单价
目标币种金额 = 原币种金额 × 手动汇率
```

### 4.2 测试样例验证

**输入**:
- 长：50 cm
- 宽：40 cm
- 高：30 cm
- 件数：10
- 实重合计：80 kg
- 体积重系数：6000
- 公斤单价：20
- 立方单价：1000
- 手动汇率：7.2

**预期结果**:
| 指标 | 计算过程 | 结果 |
|------|----------|------|
| 单件 CBM | 50×40×30 / 1,000,000 | **0.06 m³** ✅ |
| 总 CBM | 0.06 × 10 | **0.6 m³** ✅ |
| 体积重 | 50×40×30×10 / 6000 | **100 kg** ✅ |
| 实重合计 | 用户输入 | **80 kg** ✅ |
| 二者取高 | max(100, 80) | **100 kg** ✅ |
| 按公斤运费 | 100 × 20 | **2000 CNY** ✅ |
| 按公斤目标币种 | 2000 × 7.2 | **14400** ✅ |
| 按立方运费 | 0.6 × 1000 | **600 CNY** ✅ |
| 按立方目标币种 | 600 × 7.2 | **4320** ✅ |

**结论**: ✅ 所有公式验证通过
