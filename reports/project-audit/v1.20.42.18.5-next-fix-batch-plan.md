## 三、必须单独 P0 hotfix 的问题

### 3.1 P0 问题定义

**必须单独 hotfix：**
- 登录/登出失败
- 数据丢失
- 权限绕过
- 生产环境崩溃
- 9833416@qq.com 被修改
- role 被会员覆盖

### 3.2 P0 Hotfix 流程

1. **确认问题**
   - 用户报告 bug
   - 验证是否 P0
   - 评估影响范围

2. **最小修复**
   - 只改必要代码
   - 不引入新功能
   - 不修改无关模块

3. **测试验证**
   - 本地测试通过
   - 相关回归测试通过
   - 不影响其他功能

4. **紧急部署**
   - Build 新版本
   - 更新 deploy-version.json
   - PM2 restart
   - 验证生产

5. **写 Hotfix 报告**
   - 说明 P0 原因
   - 记录改动内容
   - 列出测试证据
   - 通知用户继续测试
