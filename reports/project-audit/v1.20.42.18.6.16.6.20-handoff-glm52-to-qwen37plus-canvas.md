## 二、为什么切回 Qwen

1. **GLM 5.2 在 Canvas 任务上消耗大但未收敛。** 从 v6.17 到 v6.19，经历了 html2canvas→html-to-image 替换、onclone 颜色修复、草稿恢复修复、打印 CSS 修复等多轮迭代，消耗大量上下文和工具调用，但用户真实测试仍然失败。

2. **多次报告 READY/PASS 与用户真实测试冲突。** GLM 5.2 基于自动化审计（Playwright headless）判定 100/100 PASS 并宣布 READY_FOR_VISUAL_REVIEW，但用户上传的打印 PDF 证明打印仍然包含网站 footer、导航等非画布内容，多页打印失败，第一页标签内容有裁切和重复序号。

3. **用户上传的 PDF 证明打印仍然失败。** 这是 ground truth。审计脚本的 100/100 PASS 不能覆盖用户真实 PDF 证据。

4. **Canvas 任务更偏视觉、DOM、打印、交互，适合切回 Qwen 3.7 Plus 重新小步处理。** 打印问题涉及 CSS @media print、print root 隔离、iframe 打印等前端视觉/布局问题，需要更精细的 DOM 和 CSS 处理。

5. **GLM 5.2 后续保留用于后端/API/长上下文分析，不再作为 Canvas 当前主力。**

Qwen 第一轮只能做只读检查：

3. 浏览 Canvas 相关文件（`canvas-editor-full.tsx`）
4. 浏览打印相关实现（搜索 `@media print`、`window.print`、`print:hidden`、`print-only`）
5. 总结打印失败根因候选
6. **不改代码**

### 5.3 根因候选方向（供 Qwen 参考）

基于用户 PDF 证据，打印失败的根因候选：

1. **`window.print()` 打印整页** — 当前可能使用 `window.print()` 而非 dedicated print iframe 或 print-only route，导致整个页面（包括 footer/导航）被打印。
2. **`@media print` CSS 隔离不完整** — `print:hidden` 可能没有覆盖所有非画布元素（footer、导航、侧边栏等）。
3. **print root 未正确隔离** — 需要检查是否有专门的 print container，还是直接在页面 DOM 上打印。
4. **多页渲染逻辑问题** — repeat 模式下 10 页标签的 DOM 结构可能在打印时被错误重复或裁切。
5. **序号重复** — `canvas-sequence-hidden` 和 `canvas-print-page-sequence` 可能在打印时都可见，导致 1/10 重复。

**建议 Qwen 优先检查：**
- `canvas-editor-full.tsx` 中的打印触发逻辑（搜索 `print`、`window.print`）
- `@media print` CSS 规则的完整覆盖范围
- 是否有 dedicated print route 或 print iframe
- staging 上实际打印预览的 DOM 结构

### 6.1 范围限制

| ✅ 修 @media print CSS | ❌ 不修字体 |
| ✅ 修多页渲染 | ❌ 不修表格 |

### 6.2 验收标准

1. 件数设为 10
2. repeat 多页模式
3. 打印输出必须**只有 10 张标签**
4. 第 1 张显示 `1/10`
5. 第 10 张显示 `10/10`
6. 每页都是标签内容
7. **不得出现** footer、导航、工具中心、社区、帮助中心、联系方式
8. **必须生成真实 PDF 或 print preview 截图证据**
9. **不允许只用 audit PASS 证明** — 必须有用户可见的真实打印输出证据

### 6.3 推荐技术方案

优先考虑以下方案之一（由 Qwen 评估选择）：

1. **Dedicated print iframe** — 创建隐藏 iframe，将标签内容克隆到 iframe 中，调用 `iframe.contentWindow.print()`
2. **Print-only route** — 创建 `/tools/template-studio/canvas/print` 路由，只渲染标签内容
3. **修复 @media print CSS** — 确保所有非画布元素在 `@media print` 中 `display: none`，画布元素 `display: block`
