## 根因分析

### Topic Admin Edit 404 根因

**根因**: `src/app/(admin)/admin/content/topics/` 目录不存在，topic admin edit 页面未实现。

**修复**: 创建 `src/app/(admin)/admin/content/topics/[id]/edit/page.tsx` 和 `topic-edit-client.tsx`。

### Topic Public URL 500 根因

**根因**: Topic 页面有 `generateStaticParams()` 标记为静态页面，但同时使用 `await searchParams` (preview mode) 使其变为动态。Next.js 检测到 "Page changed from static to dynamic at runtime" 错误，返回 500。

**日志证据**:
```
Error: Page changed from static to dynamic at runtime /topics/topic-22996ad5, 
reason: `await searchParams`, `searchParams.then`, or similar
```

**修复**: 
1. 移除 `generateStaticParams()`
2. 添加 `export const dynamic = "force-dynamic"`
3. 添加 empty-items preview fallback

### Topic 内容空问题

**现状**: Topic draft 由 bot 创建时内容为空 (0 items, 0 sections, empty summary)。

**修复**: 通过 SQL 安全更新 draft 内容字段 (subtitle, summary, tags, suitableFor, seoTitle, seoDescription, metadataJson)，不发布、不删除、不创建新 topic。
