## 一、项目定位

### 核心定位

**绝世百宝箱 / jueshi.net 是综合性海外华人 / 跨境实用工具平台**，不是：
- ❌ 物流垂直站
- ❌ 单纯网址导航站
- ❌ 论坛优先项目
- ❌ CMS 内容管理系统
- ❌ 广告展示站

### 平台方向

| 方向 | 说明 | 当前状态 |
|------|------|----------|
| 实用工具 | 汇率、邮编、地址格式化、单位换算等 | ✅ 已实现 |
| 外贸单据 | 商业发票、报价单、装箱单、形式发票 | ✅ 已实现 |
| 跨境电商 | 平台运营、独立站工具 | ✅ 部分实现 |
| 海外生活 | 生活、学习、工作相关资源 | ✅ 已实现 |
| 物流追踪 | 包裹追踪、国际快递查询入口 | ✅ 已实现（外部跳转） |
| 支付收款 | 跨境收款、支付、汇率结算 | ⚠️ 基础实现 |
| 官方资源 | 政府、海关、邮政、税务机构入口 | ✅ 已实现 |
| 邮编地址 | 邮编查询、地址格式、地址核对 | ✅ 已实现 |
| 资源导航 | 900+ 外部网站分类导航 | ✅ 已实现 |
| 国家/城市落地页 | 可配置落地页模板 | ⚠️ 样板阶段 |
| 工作台 | 用户文档保存、历史恢复 | ✅ 已实现 |
| 后台运营 | 资源管理、落地页配置、用户管理 | ✅ 已增强 |

### 目标用户

- 跨境电商 / SOHO
- 外贸新手 / 老手
- 物流从业者
- 留学生 / 数字游民（次要）

### 核心工具链路

```
工具入口 → 使用工具 → 本地暂存 / 登录保存 → Workspace → 复用 / 导出 / 下一步工具 → 会员转化
```

## 四、主工具功能审计

### 核心工具

#### 1. Exchange Rate 汇率助手

**路径**: `/tools/exchange-rate`

**当前定位**: 实时汇率查询与换算工具

**已实现功能**:
- ✅ 实时汇率查询（支持 150+ 货币）
- ✅ 金额换算
- ✅ 历史汇率走势图表
- ✅ 货币收藏列表
- ✅ 本地保存（localStorage）
- ✅ Workspace 保存（需登录）

**使用步骤**:
1. 选择源货币和目标货币
2. 输入金额
3. 查看换算结果
4. 可选：查看历史走势、添加到收藏、保存到 Workspace

**输入字段**: 源货币、目标货币、金额

**输出结果**: 换算结果、汇率、更新时间

**是否保存本机**: ✅ 是（localStorage）

**是否保存 Workspace**: ✅ 是（需登录）

## 八、使用说明

### 面向普通用户

#### 如何使用汇率助手

1. 访问 `/tools/exchange-rate`
2. 选择源货币和目标货币
3. 输入金额
4. 查看换算结果
5. 可选：查看历史走势、添加到收藏

#### 如何使用 HS Code 查询

1. 访问 `/tools/hs-code`
2. 输入商品名称或关键词（支持中英文）
3. 查看匹配的 HS Code 列表
4. 点击查看详情
5. 可选：添加到收藏

#### 如何使用邮编查询

1. 访问 `/tools/postal-code`
2. 选择国家/地区
3. 输入城市或地址
4. 查看匹配的邮编列表
5. 点击查看详情

#### 如何使用地址格式化

1. 访问 `/tools/address-formatter`
2. 输入地址信息（姓名、街道、城市、州/省、邮编、国家）
3. 选择目标国家/地区格式
4. 查看格式化结果
5. 复制结果

#### 如何使用报价单

1. 访问 `/tools/quote-sheet`
2. 填写报价基本信息（报价号、日期、客户信息）
3. 添加商品明细（描述、数量、单价）
4. 选择货币
5. 查看预览
6. 导出 PDF 或 Word
7. 可选：登录并保存到 Workspace

#### 如何使用商业发票

1. 访问 `/tools/commercial-invoice`
2. 填写发票基本信息（发票号、日期、买卖双方）
3. 添加商品明细（描述、数量、单价、HS Code）
4. 查看预览
5. 导出 PDF 或 Word
6. 可选：登录并保存到 Workspace

#### 如何使用装箱单

1. 访问 `/tools/documents/packing-list`
2. 填写装箱基本信息（装箱号、日期、收货人）
3. 添加商品明细（描述、数量、箱数）
4. 查看预览
5. 导出 PDF 或 Word
6. 可选：登录并保存到 Workspace

#### 如何使用物流追踪入口

1. 访问 `/tracking`
2. 输入运单号（支持多个，逗号分隔）
3. 点击"前往 17TRACK 查询"
4. 在新标签页查看物流轨迹

**注意**: 本站不提供实时物流轨迹，实际查询结果以 17TRACK 为准。

#### 如何使用网址导航

1. 访问 `/resources`
2. 浏览分类或使用搜索
3. 筛选分类、来源类型
4. 点击网站卡片跳转

**注意**: 所有链接均为外部网站，点击后将跳转至第三方平台。

#### 如何保存 / 打开 Workspace 文档

**保存到 Workspace**:
1. 在工具页面完成操作
2. 点击"保存到 Workspace"
3. 登录（如未登录）
4. 确认保存

**打开 Workspace 文档**:
1. 访问 `/workspace/documents`
2. 浏览文档列表
3. 点击文档查看或恢复

### 面向管理员

#### 如何管理 Resources

1. 访问 `/admin/resources`
2. 使用搜索、筛选、排序功能查找资源
3. 点击"添加网址"新增资源
4. 点击编辑按钮修改资源
5. 点击删除按钮删除资源
6. 使用批量操作功能批量管理

**筛选选项**:
- 搜索：名称/描述/URL
- 分类：tools/business/life/logistics/templates/education
- 来源类型：官方/第三方/内部
- 广告：广告/赞助 vs 普通
- 排序：最近更新/创建时间/排序权重/质量评分/名称

#### 如何配置 Landing Page

1. 访问 `/admin/landing-pages`
2. 点击"新增落地页"
3. 填写基本信息（slug、title、pageType）
4. 配置 Hero 区域（title、subtitle、hotCities）
5. 配置主工具和相关工具
6. 配置 FAQ 和官方链接
7. 配置 CTA
8. 设置状态（draft/hidden/published）
9. 保存

**状态说明**:
- draft: 草稿，不公开
- hidden: 隐藏，不公开
- published: 发布，公开可访问

#### 如何管理广告 / Sponsored

1. 访问 `/admin/ads`
2. 点击"新增广告"
3. 填写广告信息
4. 设置广告位
5. 保存

**在 Resources 中标记广告**:
1. 编辑资源
2. 勾选"这是一个广告 (Sponsored)"
3. 保存

#### 如何检查数据质量

1. 访问 `/admin/resources`
2. 查看统计卡片（总数、启用、隐藏、广告、分类数）
3. 使用排序功能按质量评分排序
4. 检查质量评分为 0 的资源
5. 使用死链检测功能检查链接健康

#### 如何避免误删资源

1. 删除前确认资源 ID
2. 使用批量操作前仔细检查选中项
3. 定期备份数据（`/admin/backup`）
4. 删除操作不可恢复，谨慎操作

#### 如何发布 / 隐藏页面

**Landing Page**:
1. 访问 `/admin/landing-pages`
2. 编辑落地页
3. 修改状态字段
4. 保存

**状态说明**:
- draft: 草稿，不公开
- hidden: 隐藏，不公开
- published: 发布，公开可访问

#### 如何处理外部链接

1. 所有外部链接必须使用 `rel="noopener noreferrer nofollow"`
2. 外部链接必须明确标识"外部网站"
3. 广告链接必须标注"广告"或"Sponsored"
4. 定期检查链接健康（`/admin/link-health`）
