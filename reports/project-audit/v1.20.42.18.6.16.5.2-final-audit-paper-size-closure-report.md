## 2. Code Changes

### 2.1 Audit Script Stability Fixes

**TS-011 Fix:**
- Added `waitForSelector` for template-preview
- Added `waitForFunction` to wait for preview content (length > 50)
- Timeout: 10 seconds

**Company Selector Fix:**
- Added `waitForSelector` for template-company-selector
- Added `waitForFunction` to wait for options (count >= 3)
- Timeout: 10 seconds

**TS-SEAL-SVG-SECURITY Fix:**
- Removed incorrect `renderedAsText` check
- Added multi-layer security assertions:
  - `noNewScripts`: scripts before/after count same
  - `noSvgScripts`: no script tags in SVG
  - `noEventHandlers`: no onerror/onload attributes
  - `noJsUrls`: no javascript: URLs

**TS-STYLE-PRESET-SAVE-RESTORE Fix:**
- Explicitly set preset to "minimal-black" before save
- Extract template ID from URL
- Find edit link by `data-testid="edit-template-${templateId}"`
- Fallback: find by template card name

### 2.2 Paper Size Feature Implementation

**Schema Changes (template-schema.ts):**
- Added `paperSize?: "A4" | "10x10" | "10x15"` to `TemplateStyleConfig`
- Added `paperSize: "A4"` to `defaultStyle()`
- Added `PaperSizeConfig` interface
- Added `PAPER_SIZES` constant with 3 sizes:
  - A4: 210×297mm, aspect ratio 0.707
  - 10x10: 100×100mm, aspect ratio 1.000
  - 10x15: 100×150mm, aspect ratio 0.667
- Added `getPaperSizeConfig()` helper function

**Client Changes (template-studio-client.tsx):**
- Imported `PAPER_SIZES` from schema
- Added paper size selector UI with `data-testid="paper-size-select"`
- Changed `PRINT_CSS` from constant to `getPrintCSS(paperSize)` function
- Updated `<style>` tag to use dynamic print CSS based on current paper size

**Renderer Changes (safe-template-renderer.tsx):**
- Imported `getPaperSizeConfig` from schema
- Calculate preview dimensions based on paper size aspect ratio
- Set preview width to 800px, height based on aspect ratio
- Added `aspectRatio` CSS property to preview container
- Added `overflow: hidden` to prevent content overflow
