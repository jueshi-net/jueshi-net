## 修复的代码问题

### 问题 1: Sitemap 不包含 checklist 模型

**文件**: `src/app/sitemap.ts`

**问题**: Sitemap 只查询 `landingPage` 表中的 checklist，不包含 `checklist` 模型

**修复**:
```typescript
// Published Checklists (from both landingPage and checklist tables)
const landingChecklists = await prisma.landingPage.findMany({
  where: { status: "published", pageType: "checklist" },
  ...
});

const modelChecklists = await prisma.checklist.findMany({
  where: { status: "published" },
  ...
});

// Merge and deduplicate
const allChecklistSlugs = new Map<string, Date>();
landingChecklists.forEach((c) => allChecklistSlugs.set(c.slug, c.updatedAt));
modelChecklists.forEach((c) => {
  if (!allChecklistSlugs.has(c.slug) || c.updatedAt > allChecklistSlugs.get(c.slug)!) {
    allChecklistSlugs.set(c.slug, c.updatedAt);
  }
});
```

**提交**: `9816553 fix: include checklist model in sitemap generation`

### 问题 2: 列表页不包含 checklist 模型

**文件**: `src/app/(public)/checklists/page.tsx`

**问题**: 列表页只查询 `landingPage` 表中的 checklist，不包含 `checklist` 模型

**修复**:
```typescript
async function getChecklists() {
  // Get checklists from both landingPage and checklist tables
  const landingChecklists = await prisma.landingPage.findMany({...});
  const modelChecklists = await prisma.checklist.findMany({...});

  // Merge and deduplicate by slug
  const allChecklists = new Map<string, any>();
  landingChecklists.forEach((cl) => allChecklists.set(cl.slug, {...}));
  modelChecklists.forEach((cl) => {
    if (!allChecklists.has(cl.slug)) {
      allChecklists.set(cl.slug, {...});
    }
  });

  return Array.from(allChecklists.values());
}
```

**提交**: `c3938a5 fix: include checklist model in checklists list page`
