**文件**: `src/components/workspace/EmptyState.tsx`

**功能**:
- 统一的空状态
- 图标 + 标题 + 描述
- 主按钮（CTA）
- 可选次按钮

**视觉**:
- 白色背景
- 大图标：`w-16 h-16`
- 居中布局
- 主按钮：`bg-teal-600`
- 次按钮：`bg-gray-100`

### 2.2 统一视觉系统

#### 颜色语义

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主色 | teal-600 | 品牌色，用于主要按钮和链接 |
| 积分 | amber-500 | 金色，用于积分相关 |
| 成长 | purple-500 | 蓝紫色，用于成长值相关 |
| 勋章 | orange-500 | 橙金色，用于勋章相关 |
| 会员 | violet-500 | 紫色，用于会员徽章 |
| 警告 | amber-500 | 琥珀色，用于警告 |
| 错误 | red-500 | 红色，用于错误 |

#### 卡片系统

- 背景：`bg-white`
- 圆角：`rounded-xl`
- 边框：`border border-gray-100`
- 阴影：默认无，hover 时 `hover:shadow-sm`
- 内边距：`p-4` 或 `p-6`

#### 页面背景

- 颜色：`bg-[#F5F5F7]`（浅灰）
- 避免大面积纯白

#### 间距

- 模块间距：`space-y-6`
- 卡片间距：`gap-4`
- 内容最大宽度：`max-w-6xl`
