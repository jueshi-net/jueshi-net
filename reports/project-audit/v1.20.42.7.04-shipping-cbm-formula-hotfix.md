## 一、Bug 原因

**问题描述**:  
运费计算器输入单位标注为厘米 (cm)，但实际计算时把厘米当成立方米，导致 CBM / 方数 / 按立方运费结果巨大错误。

**根本原因**:  
在 `calcResults()` 函数中，CBM 计算公式错误：

```javascript
// 修复前（错误）
const cbm = l * w * h * q;  // 直接相乘，没有除以 1,000,000 转换 cm³ 到 m³
```

这导致：
- 输入 50cm × 40cm × 30cm × 10 件
- 错误计算：50 × 40 × 30 × 10 = 600,000（当作 m³）
- 正确应该是：600,000 / 1,000,000 = 0.6 m³

---

## 二、修复前公式

### CBM 计算（错误）
```javascript
const cbm = l * w * h * q;  // cm³，未转换为 m³
```

### 体积重计算（正确）
```javascript
const volCm3 = l * w * h * q;  // cm³
const vw = volCm3 / divisor;    // kg
```

### 问题
- CBM 显示为 cm³ 而不是 m³
- 按立方计费时，使用错误的 CBM 值计算运费
- 结果比实际大 1,000,000 倍

---

## 三、修复后公式

### CBM 计算（正确）
```javascript
// Single piece CBM = L_cm × W_cm × H_cm / 1,000,000
const singleCbm = (l * w * h) / 1000000;
// Total CBM = Single CBM × quantity
const cbm = singleCbm * q;
```

### 体积重计算（保持不变）
```javascript
// VW = L_cm × W_cm × H_cm × quantity / divisor
const volCm3 = l * w * h * q;
const vw = volCm3 / divisor;
```

### 计费方式公式（全部正确）

1. **按实际重量**: 主运费 = 总实重 × 公斤单价
2. **按体积重量**: 主运费 = 总体积重 × 公斤单价
3. **二者取高**: 主运费 = max(总体积重, 总实重) × 公斤单价
4. **按立方**: 主运费 = 总 CBM × 立方单价

### 目标币种换算
目标币种金额 = 主运费 × 手动汇率
