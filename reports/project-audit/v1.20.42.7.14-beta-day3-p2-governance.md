## 二、PM2 日志 Warning 分析

### metadataBase Warning

**问题**: `metadataBase property in metadata export is not set for resolving social open graph or twitter images, using "http://localhost:3000"`

**原因**: layout.tsx 中没有配置 metadataBase

**修复**: 添加 `metadataBase: new URL("https://jueshi.net")` 到 metadata 对象

**状态**: ✅ **已修复**

### validate-sso Warning

**问题**: `UnknownAction: Cannot parse action at /api/auth/validate-sso`

**原因**: Auth.js 默认行为，validate-sso 路由不存在

**风险**: P2 低风险，不影响核心功能

**处理**: 不修复，观察

**状态**: ⚠️ **P2 观察**

### Server Action Warning

**问题**: `Failed to find Server Action "x". This request might be from an older or newer deployment.`

**原因**: 用户使用旧版本页面，Server Action ID 不匹配

**风险**: P2 低风险，刷新页面即可解决

**处理**: 不修复，正常现象

**状态**: ⚠️ **P2 观察**

### MissingCSRF Warning

**问题**: `CSRF token was missing during an action callback`

**原因**: 浏览器缓存或跨域问题

**风险**: P2 低风险，不影响核心功能

**处理**: 不修复，观察

**状态**: ⚠️ **P2 观察**

### CredentialsSignin Warning

**问题**: `CredentialsSignin`

**原因**: 用户登录失败（密码错误）

**风险**: P2 正常业务逻辑

**处理**: 不修复，正常现象

**状态**: ✅ **正常**
