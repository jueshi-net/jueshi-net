## 二、数据模型设计

### 2.1 扩展 InviteCode 模型

**新增字段**:
```prisma
model InviteCode {
  // 现有字段保持不变
  id        String    @id @default(cuid())
  code      String    @unique
  maxUses   Int       @default(100) @map("max_uses")
  usedCount Int       @default(0) @map("used_count")
  isActive  Boolean   @default(true) @map("is_active")
  createdAt DateTime  @default(now()) @map("created_at")
  expiresAt DateTime? @map("expires_at")
  createdBy String?   @map("created_by")
  note      String?

  // 新增字段
  ownerUserId String? @map("owner_user_id") // 邀请码所有者（NULL=管理员公共码）
  source      String  @default("ADMIN")     // 来源：ADMIN/USER
  status      String  @default("ACTIVE")    // 状态：ACTIVE/PAUSED/EXPIRED
  
  // 关系
  owner       User?   @relation("UserInviteCodes", fields: [ownerUserId], references: [id])
  redemptions InviteRedemption[]

  @@index([isActive, code])
  @@index([expiresAt])
  @@index([ownerUserId])
  @@map("invite_codes")
}
```

### 2.2 新增 InviteRedemption 模型

**用途**: 记录邀请成功关系

```prisma
model InviteRedemption {
  id             String    @id @default(cuid())
  inviteCodeId   String    @map("invite_code_id")
  inviterUserId  String    @map("inviter_user_id")  // 邀请人
  inviteeUserId  String    @map("invitee_user_id")  // 被邀请人
  status         String    @default("REGISTERED")   // REGISTERED/QUALIFIED/REWARDED/REJECTED
  qualifiedAt    DateTime? @map("qualified_at")     // 符合条件时间
  rewardedAt     DateTime? @map("rewarded_at")      // 奖励发放时间
  rejectReason   String?   @map("reject_reason")
  createdAt      DateTime  @default(now()) @map("created_at")

  // 关系
  inviteCode     InviteCode @relation(fields: [inviteCodeId], references: [id])
  inviter        User       @relation("InviterRedemptions", fields: [inviterUserId], references: [id])
  invitee        User       @relation("InviteeRedemptions", fields: [inviteeUserId], references: [id])
  rewardGrants   RewardGrant[]

  @@unique([inviteeUserId]) // 一个被邀请人只能绑定一个邀请人
  @@index([inviterUserId])
  @@index([inviteeUserId])
  @@index([status])
  @@map("invite_redemptions")
}
```

### 2.3 新增 RewardRule 模型

**用途**: 后台可配置奖励规则

```prisma
model RewardRule {
  id                   String    @id @default(cuid())
  name                 String    // 规则名称
  trigger              String    // 触发条件：INVITE_REGISTER_SUCCESS/INVITE_QUALIFIED
  rewardType           String    @map("reward_type")  // MEMBER_DAYS/AD_SLOT_DAYS/POINTS/GROWTH/BADGE
  rewardValue          Int       @map("reward_value") // 奖励数值
  rewardMetadata       Json?     @map("reward_metadata") // 额外元数据
  enabled              Boolean   @default(true)
  startsAt             DateTime? @map("starts_at")
  endsAt               DateTime? @map("ends_at")
  maxRewardsPerInviter Int?      @map("max_rewards_per_inviter") // 每个邀请人最多奖励次数
  maxRewardsTotal      Int?      @map("max_rewards_total")       // 全局最多奖励次数
  createdAt            DateTime  @default(now()) @map("created_at")
  updatedAt            DateTime  @updatedAt @map("updated_at")

  rewardGrants         RewardGrant[]

  @@index([enabled])
  @@index([trigger])
  @@map("reward_rules")
}
```

### 2.4 新增 RewardGrant 模型

**用途**: 奖励发放记录

```prisma
model RewardGrant {
  id                String    @id @default(cuid())
  userId            String    @map("user_id")
  inviteRedemptionId String?  @map("invite_redemption_id")
  rewardRuleId      String    @map("reward_rule_id")
  rewardType        String    @map("reward_type")  // MEMBER_DAYS/AD_SLOT_DAYS/POINTS/GROWTH/BADGE
  rewardValue       Int       @map("reward_value")
  rewardMetadata    Json?     @map("reward_metadata")
  status            String    @default("PENDING")  // PENDING/GRANTED/FAILED/REVOKED
  grantedAt         DateTime? @map("granted_at")
  expiresAt         DateTime? @map("expires_at")   // 权益过期时间
  failureReason     String?   @map("failure_reason")
  createdAt         DateTime  @default(now()) @map("created_at")

  // 关系
  user              User              @relation(fields: [userId], references: [id])
  inviteRedemption  InviteRedemption? @relation(fields: [inviteRedemptionId], references: [id])
  rewardRule        RewardRule        @relation(fields: [rewardRuleId], references: [id])

  @@index([userId])
  @@index([status])
  @@index([rewardType])
  @@unique([inviteRedemptionId, rewardRuleId]) // 幂等：同一邀请关系只能发放同一规则一次
  @@map("reward_grants")
}
```

## 四、邀请成功定义

### 4.1 邀请成功条件

**REGISTERED**: 被邀请人使用邀请码注册成功
- 创建 InviteRedemption（status=REGISTERED）
- 增加 InviteCode.usedCount

**QUALIFIED**: 被邀请人完成首次登录或验证（可选）
- 更新 InviteRedemption.status=QUALIFIED
- 记录 qualifiedAt

**REWARDED**: 奖励发放成功
- 创建 RewardGrant（status=GRANTED）
- 更新 InviteRedemption.status=REWARDED
- 记录 rewardedAt

### 4.2 默认流程

**MVP 简化流程**:
1. 被邀请人注册成功 → 立即触发奖励发放
2. 不需要等待首次登录或验证

## 五、奖励发放规则

### 5.1 默认规则

**规则 1**: 邀请新用户注册成功
- **触发**: INVITE_REGISTER_SUCCESS
- **奖励类型**: MEMBER_DAYS
- **奖励数值**: 3 天
- **说明**: 邀请人获得 3 天会员

**规则 2**（可选）: 邀请新用户注册成功
- **触发**: INVITE_REGISTER_SUCCESS
- **奖励类型**: POINTS
- **奖励数值**: 50
- **说明**: 邀请人获得 50 积分

**规则 3**（可选）: 邀请新用户注册成功
- **触发**: INVITE_REGISTER_SUCCESS
- **奖励类型**: GROWTH
- **奖励数值**: 10
- **说明**: 邀请人获得 10 成长值

### 5.2 奖励发放逻辑

**MEMBER_DAYS**:
```typescript
if (user.memberUntil && user.memberUntil > new Date()) {
  // 当前是会员且未过期：在现有到期时间上 +N 天
  newMemberUntil = addDays(user.memberUntil, rewardValue);
} else {
  // 当前非会员或已过期：从当前时间开始 +N 天
  newMemberUntil = addDays(new Date(), rewardValue);
}
await prisma.user.update({
  where: { id: userId },
  data: { memberUntil: newMemberUntil }
});
```

**POINTS**:
```typescript
await prisma.user.update({
  where: { id: userId },
  data: { points: { increment: rewardValue } }
});
await prisma.pointLedger.create({
  data: {
    userId,
    type: "invite_reward",
    points: rewardValue,
    reason: "邀请奖励",
    relatedId: rewardGrant.id
  }
});
```

**GROWTH**:
```typescript
await prisma.user.update({
  where: { id: userId },
  data: { growthValue: { increment: rewardValue } }
});
await prisma.growthLog.create({
  data: {
    userId,
    type: "invite_reward",
    value: rewardValue,
    reason: "邀请奖励",
    refType: "reward_grant",
    refId: rewardGrant.id
  }
});
```

## 六、反作弊规则

### 6.1 基础限制

1. **用户不能邀请自己**
   - 检查 inviterUserId !== inviteeUserId

2. **同一被邀请用户只能绑定一个邀请人**
   - InviteRedemption 表有 `@@unique([inviteeUserId])`

3. **同一邀请码 maxUses 限制**
   - 注册 API 已检查 `invite.usedCount >= invite.maxUses`

4. **过期邀请码不可用**
   - 注册 API 已检查 `invite.expiresAt < new Date()`

5. **暂停邀请码不可用**
   - 注册 API 已检查 `!invite.isActive`

6. **每个用户每天生成邀请码次数限制**
   - 限制：每天最多生成 3 个邀请码

7. **每个用户最多持有的邀请码数量限制**
   - 限制：最多持有 3 个邀请码

8. **每个邀请人可获得奖励次数受 RewardRule 限制**
   - RewardRule.maxRewardsPerInviter

9. **邀请奖励只给邀请人**
   - 被邀请人获得 500 积分（现有逻辑）
   - 邀请人获得 RewardRule 配置的奖励

10. **幂等性**
    - RewardGrant 表有 `@@unique([inviteRedemptionId, rewardRuleId])`
    - 同一邀请关系只能发放同一规则一次
