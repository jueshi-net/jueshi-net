# v1.20.42.18.5.2 — Phase 1: 工作台移动端错位修复

**生成时间:** 2026-06-22

---

## 问题

用户反馈手机端工作台主内容被挤到右侧，大面积空白，横向滚动。

## 根因

`MobileStickyTabs` 组件在 `UserNavSidebar` 中渲染，作为外层 `<div className="flex">` 的 flex child，与主内容区争夺宽度。在移动端（lg 以下），sidebar 隐藏但 MobileStickyTabs 仍作为 flex child 占用宽度，把主内容挤到右侧。

## 修复

1. 从 `UserNavSidebar` 中移除 `MobileStickyTabs` 渲染
2. 新增 `MobileNavTabs` 导出函数
3. 在 workspace layout 中将 `MobileNavTabs` 移到主内容区内（TopBar 下方，main 上方）

## 修改文件

- `src/components/user/UserSidebar.tsx` — 移除 MobileStickyTabs，新增 MobileNavTabs 导出
- `src/app/(workspace)/layout.tsx` — 在主内容区内渲染 MobileNavTabs
