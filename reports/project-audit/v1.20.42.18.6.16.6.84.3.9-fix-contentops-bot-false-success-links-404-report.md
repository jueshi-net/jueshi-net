## Root Cause Analysis

### 问题 1: URL Builder 使用单数路由

**症状:** Admin edit URL 和 preview URL 返回 404

**根因:** 
- Bot 生成: `/admin/content/checklist/xxx/edit`（单数）
- 实际路由: `/admin/content/checklists/xxx/edit`（复数）

**修复:** 
```typescript
const pluralType = type === 'checklist' ? 'checklists' : type === 'guide' ? 'guides' : 'topics';
const adminEditUrl = `${baseUrl}/admin/content/${pluralType}/${slug}/edit`;
const previewUrl = `${baseUrl}/${pluralType}/${slug}?preview=true`;
```

### 问题 2: Title 包含引号

**症状:** title 被解析为 `"新加坡留学生租房注意事项清单"`（包含引号）

**根因:** Parser 没有去掉引号

**修复:** 
```typescript
title = title.replace(/[""""]/g, '').trim();
```

### 问题 3: 空内容草稿

**症状:** checklist.steps=[], guide.body='', faq=[], internalLinks=[]

**根因:** Bot 只创建最小字段，没有生成完整内容

**修复:** 
- checklist: 生成 5 个 steps, 3 个 FAQ, 3 个 internalLinks
- guide: 生成完整 body, 3 个 FAQ, 3 个 internalLinks
- topic: 生成 intro, relatedContent, 3 个 FAQ, 3 个 internalLinks
