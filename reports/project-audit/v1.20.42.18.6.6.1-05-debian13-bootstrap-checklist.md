# Debian 13 Bootstrap Checklist — v1.20.42.18.6.6.1

## 判定: RECOMMEND_REINSTALL_UBUNTU

如果用户选择保留 Debian 13，必须完成以下全部检查后才可迁移。

## 检查清单

### 1. OS 验证
```bash
cat /etc/os-release  # 确认 Debian GNU/Linux 13 (trixie)
uname -r  # 内核版本
```

### 2. apt 源
```bash
sudo apt update && sudo apt upgrade -y
```
✅ 通过: 无错误，包列表可更新

### 3. 基础工具
```bash
sudo apt install -y curl git rsync build-essential ca-certificates gnupg
```
✅ 通过: 全部安装成功

### 4. Node.js v22
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs
node -v  # 必须 v22.22.2
npm -v   # 必须 10.x
```
⚠️ 风险: Debian 13 默认 Node 版本可能不同，必须用 NodeSource

### 5. PostgreSQL
```bash
# Debian 13 可能自带 PG 17，生产环境是 16
# 需要确认版本兼容性
sudo apt install -y postgresql postgresql-contrib
psql --version  # 检查版本
```
⚠️ **关键风险**: Debian 13 默认 PostgreSQL 可能是 17.x，与生产 16.14 不同。需要：
- 方案 a: 安装 PG 16 from PGDG repo
- 方案 b: 使用 PG 17 但确认 pg_dump/pg_restore 兼容性
- 推荐: 安装 PG 16 保持一致

### 6. Nginx
```bash
sudo apt install -y nginx
nginx -v
```
✅ 通过: 安装成功，版本与生产接近

### 7. PM2
```bash
sudo npm install -g pm2
pm2 --version
```

### 8. OpenSSL
```bash
openssl version  # 需要 >= 1.1.1
```

### 9. systemd
```bash
systemctl is-system-running  # 应为 running
```

### 10. 时间同步
```bash
timedatectl status  # NTP synchronized: yes
```

### 11. Locale
```bash
locale -a  # 需要 en_US.UTF-8
sudo locale-gen en_US.UTF-8
```

### 12. 防火墙
```bash
sudo apt install -y ufw
sudo ufw default deny incoming
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

### 13. Fail2ban
```bash
sudo apt install -y fail2ban
sudo systemctl enable fail2ban
```

### 14. 磁盘空间
```bash
df -h /  # 至少 50G 可用
```

### 15. 内存
```bash
free -h  # 至少 4G，推荐 8G
```

### 16. Swap（如内存不足）
```bash
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### 17. /home/deploy 可写
```bash
sudo mkdir -p /home/deploy
sudo chown deploy:deploy /home/deploy
```

### 18. 构建验证
```bash
# 克隆代码后
npm ci
npm run build  # 必须成功
```

### 19. Prisma 迁移验证
```bash
npx prisma migrate deploy  # 必须成功
npx prisma migrate status  # 必须显示 up to date
```

## 已知 Debian 13 vs Ubuntu 24.04 差异

| 项目 | Ubuntu 24.04 | Debian 13 | 风险 |
|------|-------------|-----------|------|
| PostgreSQL 默认版本 | 16 | 可能 17 | ⚠️ 中 |
| Node.js | 需 NodeSource | 需 NodeSource | 低 |
| Nginx | 1.24.0 | 类似 | 低 |
| systemd | 255 | 257 | 低 |
| apt 包名 | 相同 | 相同 | 低 |
| 默认配置 | Ubuntu 定制 | Debian 原版 | 低 |
| cloud-init | 有 | 可能有 | 低 |

## 结论

Debian 13 技术上可以运行项目，但 PostgreSQL 版本差异是最大风险。**建议重装 Ubuntu 24.04 LTS** 以消除所有差异风险。
