## 当前决策

### 不再继续主线修 CSS print

**原因**:
- 多轮修复均未通过用户验收
- Safari/macOS 下 @page + window.print 不适合作为精确输出
- 外部技术评估建议设计态和输出态分离
- 精确标签输出应走 PDF

### 改为新增 precise PDF output MVP

**目标**:
- 从模板数据生成固定尺寸 PDF
- 绕开 Safari/browser print 引擎
- PDF 作为正式标签输出主路径

### 浏览器打印保留为兼容模式

**定位**:
- 保留现有"打印"按钮
- 改文案为"普通浏览器打印"
- 提示用户正式标签使用"精确 PDF 导出"
- 不再宣称精确

## 技术路线

### PDF 输出方案

**使用库**: @react-pdf/renderer

**原因**:
- React/Next 技术栈接入成本低
- 支持 Document/Page/View/Text
- 支持多页、绝对定位
- 适合当前文本、公司信息块、商品表格、序号标签

**核心原则**:
- PDF 从模板数据生成，不依赖 DOM
- 不使用 iframe
- 不注入 Tailwind/外部样式
- 不依赖 window.print / @page
- 坐标从数据映射到 PDF 物理尺寸
