## 二、统一 draft schema 设计

```typescript
interface UnifiedDocumentDraft {
  id: string;
  type: string;               // document type slug
  userId: string;
  companyProfileId?: string;
  title: string;              // 用户可读标题
  data: Record<string, any>;  // 工具特定数据
  items?: ChainDocumentItem[];
  status: 'draft' | 'saved' | 'archived';
  sourceType?: string;        // 链路来源
  sourceId?: string;          // 链路来源 ID
  createdAt: string;
  updatedAt: string;
}
```

## 三、最小修复方案（staging 实现）

### 3.1 统一 localStorage key

```
jueshi:draft:{toolType}:{draftId}
jueshi:draft:list:{toolType}
```

### 3.2 统一 API

- 保存: `POST /api/documents/drafts` (已有)
- 列表: `GET /api/documents/drafts?type={type}` (已有)
- 恢复: `GET /api/documents/drafts/{id}` (已有)
- 删除: `DELETE /api/documents/drafts/{id}` (已有)
