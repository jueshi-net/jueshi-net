## 问题总结

### 当前问题

1. **缺少 membershipTier 字段**
   - 无法明确区分权限角色和会员等级
   - role 字段被混用

2. **role 值不统一**
   - admin / ADMIN / 管理员
   - user / USER
   - 需要规范化

3. **会员判断依赖 role**
   - 部分代码用 `role === "member"` 判断会员
   - 应该用 `memberUntil > now` 或 `membershipTier`

### 修复目标

1. **新增 membershipTier 字段**
   - 类型：String @default("free")
   - 合法值：free / member / premium / enterprise

2. **规范化 role**
   - 只允许：admin / user
   - 统一所有管理员为 admin
   - 统一所有普通用户为 user

3. **分离语义**
   - role 只用于权限
   - membershipTier 只用于会员等级
   - memberUntil 只用于到期时间

4. **代码重构**
   - 所有会员判断改用 membershipTier / memberUntil
   - 所有权限判断只用 role
   - 禁止业务逻辑写 role
