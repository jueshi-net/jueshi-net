## OLD_HTML_TO_IMAGE_PNG_ROOT_CAUSE

### 历史问题

v6.38-v6.52 期间使用 `html-to-image` 库截图 DOM：

```typescript
// OLD CODE (v6.38-v6.52)
const { toPng } = await import("html-to-image");
const dataUrl = await toPng(paperRef.current, {
  pixelRatio: 2,
  backgroundColor: "#ffffff",
  filter,
});
```

**问题：**
- 依赖 DOM 渲染，需要等待页面完全渲染
- 可能包含编辑器 UI 元素（如果 filter 不正确）
- 性能较差（需要序列化整个 DOM）
- 无法精确控制输出内容

## Data-Driven PNG Renderer 说明

### 新实现（v6.54）

创建了独立的 data-driven PNG renderer：

**文件：** `src/lib/template-studio/canvas-png-renderer.ts`

**核心功能：**
```typescript
export async function renderCanvasToPng(
  canvas: CanvasTemplate,
  options: RenderOptions = {}
): Promise<RenderResult>
```

**特点：**
- ✅ 直接从 canvas 数据渲染到 Canvas API
- ✅ 不依赖 DOM 截图
- ✅ 精确控制输出内容
- ✅ 性能更好
- ✅ 无编辑器 UI 污染

### 坐标映射公式

```typescript
// mm to px conversion at 96 DPI
const MM_TO_PX = 3.7795275591;

// Example: 100mm → 378px (at 1x), 756px (at 2x pixelRatio)
const widthPx = Math.ceil(canvas.paper.widthMm * MM_TO_PX * pixelRatio);
const heightPx = Math.ceil(canvas.paper.heightMm * MM_TO_PX * pixelRatio);
```

### 支持的元素类型

- ✅ `text` — 文本元素
- ✅ `field` — 数据绑定字段
- ✅ `company-info` — 公司信息块
- ✅ `sequence` — 序列号 (1/N, 2/N)
- ✅ `table` — 表格（占位符）
- ✅ `rect` — 矩形
- ✅ `line` — 线条
- ⚠️ `image`, `logo`, `seal`, `qrcode`, `barcode` — 占位符（待实现）
