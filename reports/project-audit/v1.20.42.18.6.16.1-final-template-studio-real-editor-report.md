## 16. 仍然不能做的功能和原因

| 功能 | 原因 |
|------|------|
| 模板 DB 持久化 (Prisma) | 当前使用 JSON 文件存储 (PARTIAL_STORAGE)，需要新增 Prisma model + migration |
| Word 导出 (模板配置 → .docx) | 标记 `WORD_TEMPLATE_EXPORT_NEXT`，需要将模板配置映射到 generate-docx.ts |
| 模板分享/市场 | 需要 DB 表 + 权限系统 + 审核流程 |
| 模板版本历史 | 需要 DB 表 + 版本控制逻辑 |
| 模板权限 (角色/会员限制) | 需要 DB 表 + 会员等级关联 |
| 拖拽排序 block | 当前使用 ↑↓ 按钮，拖拽需要 dnd-kit 或类似库 |
| 自定义 CSS 注入 | 出于安全考虑禁止，仅支持预设样式选项 |
| 模板预览多设备切换 | 当前只有桌面预览，需要响应式预览组件 |
