## 二、备份脚本修复

### 2.1 新备份脚本

**路径**: `/home/deploy/xixiong-saas/scripts/backup-db.sh`

**关键改进**:
1. ✅ 使用 `pg_dump "$DATABASE_URL"` 直接连接（避免密码提取问题）
2. ✅ 检查 pg_dump exit code
3. ✅ 验证备份文件大小（必须 > 1MB）
4. ✅ 失败时自动清理无效备份文件
5. ✅ 记录日志到 `/home/deploy/logs/backup_*.log`
6. ✅ 使用 pg_restore --list 验证备份可读性

**脚本内容**:
```bash
#!/bin/bash
# Database backup script for bxb_prod
# Usage: bash scripts/backup-db.sh [prefix]

cd /home/deploy/xixiong-saas
source .env.production
export DATABASE_URL

PREFIX=${1:-bxb_prod}
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="/home/deploy/backups/${PREFIX}_${TIMESTAMP}.dump"
LOG_FILE="/home/deploy/logs/backup_${TIMESTAMP}.log"

mkdir -p /home/deploy/logs

echo "=== Backup Start: $(date) ===" | tee "$LOG_FILE"
echo "Creating backup: $BACKUP_FILE" | tee -a "$LOG_FILE"

# Use DATABASE_URL directly (includes password)
pg_dump "$DATABASE_URL" -Fc -f "$BACKUP_FILE" 2>>"$LOG_FILE"

if [ $? -eq 0 ]; then
    FILE_SIZE=$(stat -c%s "$BACKUP_FILE")
    if [ "$FILE_SIZE" -gt 1048576 ]; then
        SIZE_MB=$((FILE_SIZE / 1048576))
        echo "✅ Valid backup created: ${BACKUP_FILE} (${SIZE_MB}MB)" | tee -a "$LOG_FILE"
        echo "Validating backup..." | tee -a "$LOG_FILE"
        pg_restore --list "$BACKUP_FILE" 2>>"$LOG_FILE" | head -10 >> "$LOG_FILE"
        echo "=== Backup Complete ===" | tee -a "$LOG_FILE"
        exit 0
    else
        echo "❌ Backup too small: $FILE_SIZE bytes" | tee -a "$LOG_FILE"
        rm -f "$BACKUP_FILE"
        exit 1
    fi
else
    echo "❌ pg_dump failed" | tee -a "$LOG_FILE"
    rm -f "$BACKUP_FILE"
    exit 1
fi
```
