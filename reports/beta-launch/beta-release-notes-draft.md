# Beta Release Notes Draft

**版本号**: v1.20.42.6.61-beta-ready  
**发布日期**: 2026-06-13 (待定)

## 发布概述

海外百宝箱 Beta 版本正式发布！本次 Beta 聚焦于**核心工具**和**文档保存**功能，为跨境电商从业者、SOHO、留学生、数字游民提供实用的出海基础设施。

---

## Beta 范围

### ✅ 核心工具 (32 个工具页面)

- **HS Code 查询**: 快速查询海关编码，支持中英文搜索
- **Postal Code 查询**: 全球邮编查询，支持地址解析
- **汇率换算**: 实时汇率查询与换算
- **运费计算器**: 国际物流运费估算
- **报价单 (Quote Sheet)**: 创建、保存、恢复报价单文档
- **商业发票 (Commercial Invoice)**: 创建、保存、恢复商业发票文档
- 更多工具...

### ✅ 文档保存

- **Workspace 工作台**: 统一管理所有文档草稿
- **保存/恢复**: 自动保存文档历史，随时恢复
- **版本管理**: 查看文档修改历史

### ✅ Admin Analytics MVP

- **任务链分析**: 查看用户任务链数据
- **CSV 导出**: 导出分析数据

### ✅ Forum 基础

- **发帖/评论**: 基础论坛功能
- **分类管理**: 按主题分类讨论
- **审核系统**: 管理员审核机制

---

## Beta 不包含

以下功能将在 Beta 后版本中实现：

- ❌ 评论回复功能
- ❌ @提及功能
- ❌ 会员/支付系统
- ❌ Flarum 数据库迁移
- ❌ 大规模 SEO 内容计划
- ❌ 高级论坛运营功能

## 已知限制

1. **bbs.jueshi.net legacy SSO fallback**: 1 处遗留引用，Beta 后清理
2. **Forum 不是主卖点**: 论坛作为辅助交流入口，不作为核心功能推广
3. **复杂社区功能暂缓**: 评论回复、@提及等社区功能暂缓
