## 三、监控脚本

### 3.1 基线检查脚本（T+0）

```bash
#!/bin/bash
# beta-monitor-baseline.sh

echo "=== Beta Monitor Baseline Check ==="
echo "时间: $(date)"

# 1. Runtime Guard
echo ""
echo "--- Runtime Guard ---"
cd /home/deploy/xixiong-saas
source .env.production 2>/dev/null
node scripts/verify-runtime-db-env.mjs 2>&1 | head -30

# 2. PM2 Status
echo ""
echo "--- PM2 Status ---"
pm2 status

# 3. PM2 Error Logs (last 50 lines)
echo ""
echo "--- PM2 Error Logs (last 50) ---"
pm2 logs xixiong-saas --err --lines 50 --nostream 2>&1 | grep -iE "(error|P1000|P2010|28P01|database)" | tail -10

# 4. DB Stats
echo ""
echo "--- DB Stats ---"
psql "$DATABASE_URL" -c "
SELECT 
  (SELECT COUNT(*) FROM users) as total_users,
  (SELECT COUNT(*) FROM users WHERE \"createdAt\" > NOW() - INTERVAL '1 hour') as new_users_1h,
  (SELECT COUNT(*) FROM \"ToolDocumentDraft\") as total_drafts,
  (SELECT COUNT(*) FROM \"ToolDocumentDraft\" WHERE \"updatedAt\" > NOW() - INTERVAL '1 hour') as new_drafts_1h,
  (SELECT COUNT(*) FROM \"ForumPost\") as total_posts,
  (SELECT COUNT(*) FROM \"ForumPost\" WHERE \"createdAt\" > NOW() - INTERVAL '1 hour') as new_posts_1h;
"

echo ""
echo "=== Baseline Check Complete ==="
```

### 3.2 定期检查脚本（T+1h, T+4h, T+24h）

```bash
#!/bin/bash
# beta-monitor-check.sh

CHECK_TIME=$1
echo "=== Beta Monitor Check: $CHECK_TIME ==="
echo "时间: $(date)"

cd /home/deploy/xixiong-saas
source .env.production 2>/dev/null

# 1. PM2 Status
echo ""
echo "--- PM2 Status ---"
pm2 status | grep xixiong-saas

# 2. Error Count (last hour)
echo ""
echo "--- Errors (last 1h) ---"
pm2 logs xixiong-saas --err --lines 200 --nostream 2>&1 | \
  grep "$(date -d '1 hour ago' '+%Y-%m-%d %H')" | \
  grep -ciE "(error|P1000|P2010)" || echo "0"

# 3. DB Stats
echo ""
echo "--- DB Stats ---"
psql "$DATABASE_URL" -c "
SELECT 
  (SELECT COUNT(*) FROM users WHERE \"createdAt\" > NOW() - INTERVAL '1 hour') as new_users_1h,
  (SELECT COUNT(*) FROM \"ToolDocumentDraft\" WHERE \"updatedAt\" > NOW() - INTERVAL '1 hour') as drafts_1h,
  (SELECT COUNT(*) FROM \"ForumPost\" WHERE \"createdAt\" > NOW() - INTERVAL '1 hour') as posts_1h,
  (SELECT COUNT(*) FROM \"ForumComment\" WHERE \"createdAt\" > NOW() - INTERVAL '1 hour') as comments_1h;
"

echo ""
echo "=== Check Complete: $CHECK_TIME ==="
```

## 四、节流要求

| 要求 | 值 |
|---|---|
| 是否做压测 | **否** |
| 是否做高频请求 | **否** |
| 每个请求间隔 | **3-5 秒** |
| 遇到 429 等待时间 | **90 秒** |
| 429 最多重试次数 | **1 次** |

## 五、告警规则

### 5.1 立即告警（P0）
