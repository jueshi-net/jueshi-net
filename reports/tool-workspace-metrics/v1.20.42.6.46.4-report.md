### 2. 根因分析

**P1 问题**: "保存到工作台" 按钮点击后没有触发 handler

**根因**:
1. 页面加载时，`usePermissions` hook 调用 `/api/me/permissions` API
2. 如果 API 返回 `authenticated: false`，按钮会被 disabled
3. 登录后需要硬刷新页面（Cmd+Shift+R）才能正确加载权限状态
4. 软刷新或导航不会重新获取权限状态

**验证过程**:
- 登录后页面显示 "未登录"
- `/api/me/permissions` 返回 `authenticated: true`
- 硬刷新后页面显示 "注册用户"
- 按钮变为可用状态
- 但点击按钮后仍然没有触发 handler

**直接调用 API 测试**:
```javascript

  headers: { 'Content-Type': 'application/json' },
```

## ⚠️ 发现的问题

### P1: "保存到工作台" 按钮点击后没有触发 handler

**问题描述**:
- 按钮状态正确（enabled）
- 权限正确（`authenticated: true`）
- 但点击按钮后没有触发 `handleSaveToWorkspace` 函数
- 没有 fetch 请求发出
- 没有 alert 消息

**根因**:
- 可能是 React hydration 问题
- 可能是事件绑定失败
- 需要进一步调查

**临时解决方案**:
- 直接调用 API 可以成功保存
- 用户需要硬刷新页面才能正确加载权限状态

### P2: 备注字段名不匹配

**问题描述**:
- Template 定义: `{ key: "remark", label: "备注" }` (单数)
- 保存时使用: `remarks: "KEEP-ME-CI-FRESH..."` (复数)
- 恢复时查找: `lineItems[0].remark` (空)

**影响**:
- 备注字段无法正确恢复
- KEEP-ME-CI-FRESH 标记无法验证

**建议修复**:
- 统一字段名为 `remark` 或 `remarks`
- 或者在保存/恢复时做字段名映射

### P2: `/api/user/documents` API 没有写入 EventLog

**问题描述**:
- `/api/me/tool-documents` API 会写入 EventLog
- `/api/user/documents` API 不会写入 EventLog

**影响**:
- 无法追踪文档保存事件
- 无法统计转化率

**建议修复**:
- 在 `/api/user/documents` API 中添加 EventLog 写入逻辑
