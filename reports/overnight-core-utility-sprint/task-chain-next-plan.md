## 一、跨境发货任务链 MVP 建议

### 核心任务链（最小可用）

```
商品信息录入
  → HS 编码查询
    → 运费估算
      → 汇率换算
        → 地址/邮编验证
          → Commercial Invoice 生成
            → Quotation 生成
              → Checklist 核对
```

### 当前状态
- ✅ 每个工具已独立可用
- ✅ 工具间已有"下一步推荐"入口
- ✅ 每个工具有 EventLog 追踪
- ❌ 工具间无数据传递（用户需手动复制粘贴）
- ❌ 无统一任务容器（Task Session）

## 三、串联方案（只做入口，不做大系统）

### 方案 A：URL 参数传递（推荐 MVP）
```
HS编码查询结果 → 点击"用于商业发票"
  → /tools/documents/commercial-invoice?hsCode=8429.51

报价单 → 点击"按当前汇率换算"
  → /tools/exchange-rate?from=USD&to=CNY&amount=1000

地址格式化 → 点击"验证邮编"
  → /tools/postal-code?q=M5V2T6
```

**优点**: 零数据库变更，纯前端实现
**缺点**: 用户需手动触发，无法自动回填所有字段

### 方案 B：localStorage 共享状态
```
用户在一个工具中填写的信息 → 写入 localStorage
其他工具读取 → 自动回填对应字段
```

**优点**: 用户体验更好，跨工具数据共享
**缺点**: 仅限同一浏览器，清除缓存后丢失

### 方案 C：登录用户 DB 持久化（暂不开发）
```
需要新增 TaskSession / TaskData 模型
用户登录后，工具间数据自动同步
```

**优点**: 完整任务链体验
**缺点**: 需要数据库模型、API、前端改造，工作量大
