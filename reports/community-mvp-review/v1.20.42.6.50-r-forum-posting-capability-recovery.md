## 四、主站 SSO 接口审计

### 4.1 /api/auth/sso 接口

**文件**: src/app/api/auth/sso/route.ts

**功能**: Flarum SSO JWT 签发端点

**流程**:
1. 检查主站登录状态
2. 未登录 → 302 到 /login?callbackUrl=/api/auth/sso
3. 已登录 → 从 DB 读取用户信息
4. 用 FLARUM_JWT_SECRET 签发 5 分钟有效期的 JWT
5. 302 重定向到 Flarum SSO 桥接页

**JWT 格式**: 符合 maicol07/flarum-ext-sso 插件标准

### 4.2 环境变量配置

```bash
grep -E 'FLARUM_JWT_SECRET|FLARUM_URL' .env.production
-- 结果: 空
```

**问题**: .env.production 中没有配置 FLARUM_JWT_SECRET 和 FLARUM_URL

### 4.3 安全风险

- ✅ JWT 使用 HS256 签名
- ✅ 5 分钟有效期，防重放攻击
- ✅ 需要主站登录才能签发
- ⚠️ FLARUM_JWT_SECRET 未配置，SSO 无法工作

## 九、论坛恢复路线评估

**必须评估**:
1. **安全风险**: 
   - Flarum 是独立 PHP 应用，需要维护 PHP/MySQL/Nginx
   - 需要定期更新 Flarum 和插件
   - 需要处理反垃圾/举报/审核

2. **运维复杂度**:
   - 需要修复 DNS（bbs.jueshi.net → 192.129.155.149）

   - 需要创建板块和种子内容

3. **SSO 风险**:
   - 需要确保主站和 Flarum 用户数据同步
   - 需要处理登录/登出状态同步
   - 需要处理密码策略一致性

4. **与主站用户体系关系**:
   - 主站用户通过 SSO 自动登录 Flarum
   - Flarum 用户数据独立存储
