## 九、SSO 集成审计

### /api/auth/sso 路由

**功能**: Flarum SSO JWT 签发端点

**流程**:
1. 检查主站登录状态
2. 未登录 → 302 到 /login
3. 已登录 → 从 DB 读取用户信息
4. 用 FLARUM_JWT_SECRET 签发 5 分钟有效期 JWT
5. 302 重定向到 Flarum SSO 桥接页

**JWT 格式**:
```json
{
  "user": {
    "id": "user_id",
    "attributes": {
      "email": "user@example.com",
      "username": "username",
      "isEmailConfirmed": true
    }
  },
  "remember": false
}
```

**环境变量**:
- `FLARUM_URL` - 未配置（默认 `https://bbs.jueshi.net`）
- `FLARUM_JWT_SECRET` - 未配置

**结论**: SSO 代码完整，但环境变量已删除，说明 Flarum 集成已废弃
