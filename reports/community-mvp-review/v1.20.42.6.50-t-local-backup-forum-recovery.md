## 一、找到的论坛系统

### 1.1 数据库模型

**ForumCategory (板块分类)**
```prisma
model ForumCategory {
  id          String        @id @default(cuid())
  key         String        @unique  // overseas-life / tools / logistics / feedback / general
  name        String        // 分类名称
  description String?       // 分类描述
  iconText    String?       // 图标文字/emoji
  color       String?       // 颜色
  sortOrder   Int           @default(0)
  isActive    Boolean       @default(true)
  
  posts       ForumPost[]
}
```

**ForumPost (帖子)**
```prisma
model ForumPost {
  id               String           @id @default(cuid())
  slug             String           @unique
  userId           String
  user             User             @relation(...)
  categoryId       String
  category         ForumCategory    @relation(...)
  title            String           // 帖子标题
  content          String           // 帖子内容
  excerpt          String?          // 摘要
  status           String           @default("pending")  // published / pending / hidden / deleted
  isPinned         Boolean          @default(false)      // 置顶
  isLocked         Boolean          @default(false)      // 锁定
  viewCount        Int              @default(0)
  commentCount     Int              @default(0)
  lastCommentAt    DateTime?
  lastCommentUserId String?
  ipHash           String?
  userAgent        String?
  rewardGrantedAt  DateTime?        // 成长值奖励已发放时间（防重复）
  
  comments         ForumComment[]
}
```

**ForumComment (评论)**
```prisma
model ForumComment {
  id        String     @id @default(cuid())
  postId    String
  post      ForumPost  @relation(...)
  userId    String
  user      User       @relation(...)
  content   String
  status    String     @default("published")  // published / pending / hidden / deleted
  ipHash    String?
  userAgent String?
  rewardGrantedAt DateTime?  // 成长值奖励已发放时间（防重复）
}
```
