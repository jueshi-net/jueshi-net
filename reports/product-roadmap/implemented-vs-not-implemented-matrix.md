## 七、关键区分

### "已实现" ≠ "功能完成"

| 误区 | 正确理解 |
|---|---|
| 页面 200 = 功能通过 | ❌ 必须真实验证功能 |
| 代码存在 = 功能通过 | ❌ 必须测试实际行为 |
| build 成功 = 功能通过 | ❌ 必须功能验证 |
| 字段存在 = 公司资料复用 | ❌ 必须有选择器 UI |
| 响应式 class 存在 = 375px 验证通过 | ❌ 必须真实 viewport 验证 |
| API 200 = 返回正确数据 | ❌ 必须验证返回数据 |

### "本地保存" ≠ "保存到工作台"

| 概念 | 含义 | 游客可用 | 登录可用 |
|---|---|---|---|
| 保存到本机 | localStorage | ✅ | ✅ |
| 保存到工作台 | 云端保存 | ❌ | ✅ |
