## 二、Prisma Model 变更

### 2.1 新增 TaskChainDraft 模型

```prisma
model TaskChainDraft {
  id                 String    @id @default(cuid())
  userId             String    @map("user_id")
  user               User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  // Core fields
  title              String
  status             String    @default("active") // active / completed / archived / deleted
  sourceTool         String    @map("source_tool")
  lastActiveTool     String?   @map("last_active_tool")
  
  // Context data (JSON)
  context            Json
  linkedDraftHints   Json?     @map("linked_draft_hints")
  
  // Timestamps
  createdAt          DateTime  @default(now()) @map("created_at")
  updatedAt          DateTime  @updatedAt @map("updated_at")
  
  // Optional lifecycle fields
  completedAt        DateTime? @map("completed_at")
  archivedAt         DateTime? @map("archived_at")
  expiresAt          DateTime? @map("expires_at")
  deletedAt          DateTime? @map("deleted_at")
  
  @@index([userId])
  @@index([userId, status])
  @@index([createdAt])
  @@index([updatedAt])
  @@map("task_chain_drafts")
}
```

**响应**:

```json
  "data": {
    "id": "cmq92bztq0003hb5psdpo5bqb",

    "status": "active",
    "sourceTool": "hs-code",
```

**限制**:
- 必须登录
- 免费用户最多 5 条 active 任务链
- 会员用户最多 50 条 active 任务链

**响应**:
```json

  "success": true,
  "data": [...]
}
```

## 九、归档/删除验证

### 9.1 归档

**逻辑**:
```typescript
const handleArchive = async (id: string) => {
  const response = await fetch(`/api/me/task-chains/${id}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ status: 'archived' }),
  });
  
  if (response.ok) {
    setTaskChains(prev => prev.filter(tc => tc.id !== id));
    trackEvent.custom('workspace', 'task_chain_workspace_archive');
  }
};
```

### 9.2 删除

**逻辑**:
```typescript
const handleDelete = async (id: string) => {
  if (!confirm('确定要删除这个任务吗？')) return;
  
  const response = await fetch(`/api/me/task-chains/${id}`, {
    method: 'DELETE',
  });
  
  if (response.ok) {
    setTaskChains(prev => prev.filter(tc => tc.id !== id));
    trackEvent.custom('workspace', 'task_chain_workspace_delete');
  }
};
```

### 9.3 测试结果

✅ **逻辑正确**

- 归档: status 更新为 "archived"，列表不再显示
- 删除: status 更新为 "deleted"，列表不再显示
- EventLog: `task_chain_workspace_archive` / `task_chain_workspace_delete`
