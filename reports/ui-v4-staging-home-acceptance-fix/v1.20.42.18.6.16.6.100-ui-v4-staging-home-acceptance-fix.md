## 二、广告矩阵实现

### 实现模式：模式 B（多 placement）

**选择原因：**
- 现有 dispatch API 只返回单个广告活动（`matched[0]`）
- 一个 placement 只能显示一个广告
- AdCreative 表存在但未被 dispatch API 使用
- 不能修改现有 API（安全限制）

**解决方案：**
- 创建多个 placement，每个广告一个
- 前台为每个 placement 创建一个 AdSlot
- 通过 AdPlacementGrid 组件实现矩阵布局
