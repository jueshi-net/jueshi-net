## 五、PostgreSQL 认证问题分析

### 5.1 错误日志
```
2026-06-11 23:33:59.751 UTC [2265425] bxb_user@bxb_prod FATAL:  
password authentication failed for user "bxb_user"

DETAIL: Connection matched file "/etc/postgresql/16/main/pg_hba.conf" 
line 125: "host all all 127.0.0.1/32 scram-sha-256"
```

### 5.2 可能的原因

1. **密码不匹配**：
   - 已重置密码为 `bxb_secure_2026`
   - 使用 scram-sha-256 加密
   - 但仍然无法连接

2. **PostgreSQL 配置缓存**：
   - 已执行 `pg_reload_conf()`
   - 可能需要完全重启 PostgreSQL

3. **密码编码问题**：
   - 连接字符串中的特殊字符可能需要 URL 编码
   - 但密码 `bxb_secure_2026` 没有特殊字符

### 5.3 尝试的修复

1. ✅ 重置密码为 scram-sha-256
2. ✅ 重载 PostgreSQL 配置
3. ✅ 验证密码哈希格式
4. ❌ 仍然无法连接
