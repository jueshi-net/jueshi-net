## 三、替代数据源 Preflight ✅

### 关键发现

| Country | GeoNames | Alternative Found | Recommendation |
|---|---|---|---|
| **VN** | ❌ 404 | ✅ datahub.io, GitHub dataset | **Proceed with datahub.io** |
| **TW** | ❌ 404 | ✅ youbianku.com (75K+), data.gov.tw | **Search data.gov.tw first** |
| **SA** | ❌ 404 | ⚠️ GeoPostcodes (commercial only) | **Defer — no free source** |
| **HK** | ✅ 1 record | N/A | **HK does NOT use postal codes!** |

### HK 特殊情况 🎯

**香港不使用邮政编码用于本地邮件。**

- Hongkong Post 认为邮编系统不必要
- 建议留空邮编栏或填写 "000" / "0000" / "000000" / "HKG"
- 仅用于中国大陆来信

**已实施**：
- HK coverage status 从 `minimal` 改为 `special`
- 图标：`ℹ️` (info)
- 标签：`特殊地区`
- 说明：`Hong Kong does not use postal codes for domestic mail. Hongkong Post advises leaving postcode field blank or using "HKG".`

### VN 推荐来源

**Priority**: HIGH  
**Source**: datahub.io (https://datahub.io/logistics/postal-codes-vn)  
**License**: Open Data (likely permissive)  
**Estimated records**: ~11,000  
**Risk**: LOW  
**Action**: Download sample → verify → import if quality good

### TW 推荐来源

**Priority**: HIGH  
**Source**: data.gov.tw (government open data)  
**License**: Government open data (likely permissive)  
**Estimated records**: ~8,000-75,000  
**Risk**: LOW  
**Action**: Search data.gov.tw → verify → import if found  
**Avoid**: Scraping youbianku.com (license/ToS risk)

### SA 推荐来源

**Priority**: MEDIUM  
**Source**: None free available  
**Options**:
1. GeoPostcodes commercial (paid)
2. Contact Saudi Post
3. Accept current limitation

**Action**: Defer import, show "暂未覆盖" in UI

### OSM 评估 ⚠️

**Do NOT use OSM as primary postal code source.**

- OSM is a map, not a postal code registry
- Postal code data is sparse and incomplete
- Nominatim is NOT for bulk queries (usage policy restricts)
- License: ODbL (requires attribution + share-alike)

**Acceptable uses**: Supplementary geocoding only
