## 一、Container / CBM 口径修正 ✅

### 修改内容

**文件**: `src/app/(public)/tools/container/page.tsx`

**问题**: 原代码显示"可装 X 件"，实际计算的是"可装同等批次"，存在误导。

**修正**:
1. 区分"单件体积"和"当前批次总体积"
2. 区分"理论可装件数"和"可装同等批次数"
3. 明确展示"当前批次占体积%"和"当前批次占重量%"
4. 添加警告说明"以上仅为体积/重量粗算"

### 计算验证（示例：60×40×50cm, 15kg, 100件）

| 指标 | 计算值 | 验证结果 |
|---|---|---|
| 单件体积 | 0.1200 m³ | ✅ 正确 |
| 当前批次总体积 | 12.0000 m³ | ✅ 正确 |
| 当前批次总重量 | 1500.0 kg | ✅ 正确 |
| **20GP 当前批次占体积** | **36.1%** | ✅ 正确 |
| **20GP 当前批次占重量** | **6.9%** | ✅ 正确 |
| **20GP 理论可装** | **276 件** | ✅ 正确（按体积） |
| 20GP 按体积可装 | 276 件 | ✅ 正确 |
| 20GP 按重量可装 | 1451 件 | ✅ 正确 |
| **20GP 可装同等批次** | **2 批** | ✅ 正确 |

### 展示文案验证

**修正前**:
```
可装: 2 件
体积利用率: 36.1%
重量利用率: 6.9%
```

**修正后**:
```
当前批次占体积: 36.1%
当前批次占重量: 6.9%
理论可装: 276 件
按体积: 276 件 | 按重量: 1451 件
可装同等批次: 2 批
```

**结论**: ✅ 不再存在误导性"可装 X 件"文案
