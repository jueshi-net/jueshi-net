## 五、Container / CBM 快速回归

### 5.1 计算逻辑验证

**代码位置**: `src/app/(public)/tools/container/page.tsx`

**计算逻辑**:
```typescript
// Line 23-28
const singleVolume = (cargoL * cargoW * cargoH) / 1000000;  // cm³ → m³
const totalVolume = singleVolume * quantity;
const totalWeight = cargoWeight * quantity;

// Line 38-56
const batchVolumeUtil = totalVolume / ct.volume * 100;  // 体积占比
const maxItemsByVolume = Math.floor(ct.volume / singleVolume);  // 理论可装件数
const batches = Math.min(batchesByVolume, batchesByWeight);  // 可装批次数
```

### 5.2 示例验证

**输入**: 60cm × 40cm × 50cm, 15kg, 100件

**预期结果**:
- 单件 CBM = 60 × 40 × 50 / 1000000 = **0.12 m³** ✅
- 总体积 = 0.12 × 100 = **12 m³** ✅
- 总重量 = 15 × 100 = **1500 kg** ✅
- 20GP 体积 = 33.2 m³
- 体积占比 = 12 / 33.2 × 100 = **36.1%** ✅
- 理论可装件数 = floor(33.2 / 0.12) = **276 件** ✅
- 可装批次数 = floor(33.2 / 12) = **2 批** ✅

**结论**: Container 计算逻辑完全正确，无"可装 2 件"误导。
