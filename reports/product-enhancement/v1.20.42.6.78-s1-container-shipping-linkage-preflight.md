## 三、S1 最小联动目标

### 3.1 目标定义

在 Container 结果区增加"带入运费计算"按钮，点击后将以下数据传给 Shipping Calculator：

| 字段 | Container 来源 | Shipping Calculator 用途 |
|---|---|---|
| `totalCbm` | 当前批次总体积 (m³) | 用于 CBM 计算参考 |
| `totalWeight` | 当前批次总重量 (kg) | 预填单件实重 |
| `quantity` | 数量 | 预填件数 |
| `packageDimensions` | 长×宽×高 (cm) | 预填长、宽、高 |
| `suggestedContainer` | 推荐柜型 | 仅供参考显示 |
| `utilizationRate` | 利用率 (%) | 仅供参考显示 |

### 3.2 非目标（明确排除）

- ❌ 不自动保存到 Workspace
- ❌ 不覆盖用户已有输入（除非用户确认）
- ❌ 不新增数据库表
- ❌ 不新增 migration
- ❌ 不保存敏感数据
- ❌ 不影响游客使用
- ❌ 不影响登录用户保存 Workspace
- ❌ 不影响 Commercial Invoice / Quote Sheet
- ❌ 不影响 HS Code
- ❌ 不影响 Workspace 单据复用
- ❌ 不影响 9833416@qq.com

### 3.3 用户体验流程

1. 用户在 Container 计算器中输入货物信息并计算
2. 结果区显示"带入运费计算"按钮
3. 点击按钮，数据保存到 localStorage
4. 页面跳转到 `/tools/shipping-calculator`
5. Shipping Calculator 检测到联动数据，显示提示
6. 用户确认后，数据预填到表单
7. 用户可继续编辑并计算运费

## 四、传参方案比较

### 方案 A: URL Query 参数

**实现方式**:
```
/tools/shipping-calculator?from=container&length=60&width=40&height=50&weight=15&quantity=100
```

**优点**:
- ✅ 简单直接，易于调试
- ✅ 可分享链接
- ✅ 无需 localStorage
- ✅ 游客和登录用户均可使用

**缺点**:
- ❌ URL 较长，不够美观
- ❌ 数据暴露在 URL 中（隐私风险）
- ❌ 只能传递简单数据，复杂结构不便
- ❌ 刷新页面后数据仍在（可能不符合预期）

**适用场景**:
- 游客用户
- 简单数据传递
- 需要分享链接的场景

**推荐度**: ⭐⭐⭐ (3/5)

## 五、推荐方案

### MVP 方案: localStorage

**理由**:
1. 可传递复杂数据结构（货物尺寸、重量、数量等）
2. URL 保持干净，用户体验好
3. 数据不暴露在 URL 中，隐私保护好
4. 游客和登录用户均可使用
5. 不会污染 Workspace
6. 易于测试和调试
7. 可设置过期时间，避免旧数据干扰

**实现细节**:

#### 5.1 localStorage Key

```typescript
const CONTAINER_TO_SHIPPING_KEY = 'jueshi.containerToShipping';
```

#### 5.2 数据结构

```typescript
interface ContainerToShippingData {
  version: 'v1';
  timestamp: number;  // 用于过期检测
  totalCbm: number;  // 总体积 (m³)
  totalWeight: number;  // 总重量 (kg)
  quantity: number;  // 数量
  packageDimensions: {
    length: number;  // 长 (cm)
    width: number;   // 宽 (cm)
    height: number;  // 高 (cm)
  };
  suggestedContainer?: string;  // 推荐柜型
  utilizationRate?: number;  // 利用率 (%)
}
```

#### 5.3 过期策略

```typescript
const EXPIRY_MS = 30 * 60 * 1000;  // 30 分钟过期

function isExpired(data: ContainerToShippingData): boolean {
  return Date.now() - data.timestamp > EXPIRY_MS;
}
```

#### 5.4 Container 侧实现

```typescript
const handleLinkToShipping = () => {
  const data: ContainerToShippingData = {
    version: 'v1',
    timestamp: Date.now(),
    totalCbm: totalVolume,
    totalWeight: totalWeight,
    quantity: quantity,
    packageDimensions: {
      length: cargoL,
      width: cargoW,
      height: cargoH,
    },
    suggestedContainer: recommendedContainer?.name,
    utilizationRate: recommendedContainer?.batchVolumeUtil,
  };
  
  localStorage.setItem(CONTAINER_TO_SHIPPING_KEY, JSON.stringify(data));
  router.push('/tools/shipping-calculator');
};
```

#### 5.5 Shipping Calculator 侧实现

```typescript
useEffect(() => {
  const raw = localStorage.getItem(CONTAINER_TO_SHIPPING_KEY);
  if (!raw) return;
  
  try {
    const data: ContainerToShippingData = JSON.parse(raw);
    
    // 检查是否过期
    if (isExpired(data)) {
      localStorage.removeItem(CONTAINER_TO_SHIPPING_KEY);
      return;
    }
    
    // 检查是否有已有输入
    const hasExistingData = rows.some(r => r.length && r.width && r.height);
    
    if (hasExistingData) {
      // 显示确认对话框
      setShowConfirmDialog(true);
      setPendingData(data);
    } else {
      // 直接预填
      applyContainerData(data);
    }
  } catch {
    // 解析失败，忽略
  }
}, []);

const applyContainerData = (data: ContainerToShippingData) => {
  setRows([{
    id: genId(),
    length: data.packageDimensions.length.toString(),
    width: data.packageDimensions.width.toString(),
    height: data.packageDimensions.height.toString(),
    quantity: data.quantity.toString(),
    actualWeight: (data.totalWeight / data.quantity).toString(),
  }]);
  
  // 清理 localStorage
  localStorage.removeItem(CONTAINER_TO_SHIPPING_KEY);
  
  // 显示提示
  setShowSuccessToast(true);
};
```
