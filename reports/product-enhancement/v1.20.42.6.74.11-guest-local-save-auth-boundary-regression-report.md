## 一、问题定位

### 工具分类

| 工具 | 保存逻辑 | 游客状态 | 问题 |
|---|---|---|---|
| `/tools/documents/[type]` (packing-list, proforma-invoice) | 独立实现 | ✅ 正常 | 无 |
| `/tools/commercial-invoice` | useDocumentToolEngine | ❌ 跳转登录 | **已修复** |
| `/tools/documents/quotation` (quote-sheet) | useDocumentToolEngine | ❌ 跳转登录 | **已修复** |
| `/tools/hs-code` | localStorage 查询历史 | ✅ 正常 | 无 |
| `/tools/container` | 计算工具，无需保存 | ✅ 正常 | 无 |

### 根因

**useDocumentToolEngine hook** 的 `handleSave` 函数在未登录时（401）会直接跳转到登录页面：

```typescript
if (res.status === 401) {
  window.location.href = '/login';  // ❌ 错误：直接跳转
  return;
}
```

这导致使用此 hook 的工具（commercial-invoice, quote-sheet）在游客模式下无法本地保存。

---

## 二、修复方案

### 修改文件

- `src/hooks/use-document-tool-engine.ts`

### 修复内容

1. **添加 usePermissions hook**：检查用户登录状态
2. **游客模式本地保存**：未登录时保存到 localStorage
3. **友好提示文案**：告知用户本地保存 vs 云端保存的区别
4. **401 错误处理**：从跳转登录改为显示错误提示

### 修复后逻辑

```typescript
// Guest mode: save to localStorage
if (!perms.authenticated && perms.role === 'guest') {
  const storageKey = `${toolKey}-draft`;
  localStorage.setItem(storageKey, JSON.stringify({
    data: serializedData,
    updatedAt: new Date().toISOString(),
  }));
  
  alert('💡 草稿已保存到本地浏览器\n\n未登录时，草稿只会保存在当前浏览器。\n登录后即可永久保存，并跨设备同步。');
  return;
}

// Authenticated mode: save to API
// ... 原有逻辑 ...

// 401 error handling
if (res.status === 401) {
  setError('请先登录后再保存到工作台');  // ✅ 不再跳转
  return;
}
```
