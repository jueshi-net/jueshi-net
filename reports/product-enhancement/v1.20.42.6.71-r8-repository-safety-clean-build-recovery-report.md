## 五、Build Failure 根因分析

### 错误信息

```
TypeError: Cannot read properties of null (reading 'useState')
    at <unknown> (.next/server/chunks/ssr/[root-of-the-server]__12dakxa._.js:2:1452)
```

### 可能原因

1. **Node.js 22.22.3 V8 引擎更新**
   - V8: 12.4.254.21-node.56 (local) vs .39 (VPS)
   - 可能与 Next.js 16.2.4 的 prerender 并发机制不兼容
   - 导致 React 实例在并发 prerender 时为 null

2. **并发/竞态条件**
   - 失败页面随机变化
   - 项目有 100+ 个页面需要 prerender
   - Node.js 22.22.3 的并发行为可能有变化

3. **本地缓存/状态问题**
   - 已清理 .next, node_modules, .turbo
   - 使用 npm ci 干净安装
   - 问题仍然存在

### 排除的原因

- ❌ 不是特定 commit 引入（50b7f69 也失败）
- ❌ 不是特定页面问题（失败页面随机）
- ❌ 不是缺少 "use client"（所有组件都有正确指令）
- ❌ 不是重复 React 实例（npm ls 显示只有一个）
- ❌ 不是代码问题（VPS build 成功）
