## 十、Batch A Dry-run 结果

### ⚠️ 关键发现

| Country | GeoNames 状态 | 结果 |
|---|---|---|
| **VN** | ❌ **404 Not Found** | GeoNames 不提供越南邮编数据 |
| **TW** | ❌ **404 Not Found** | GeoNames 不提供台湾邮编数据 |
| **SA** | ❌ **404 Not Found** | GeoNames 不提供沙特邮编数据 |
| **HK** | ✅ 可用 | 仅 1 条记录（与 DB 一致） |

**结论：GeoNames 无法用于 VN/TW/SA 数据导入。需要替代数据源。**

### 替代数据源建议

| Country | 替代源 | 可行性 |
|---|---|---|
| VN | OpenStreetMap / Vietnam Post API | 需研究 |
| TW | data.gov.tw 政府开放数据 | 需研究 |
| SA | Saudi Post / 商业数据 | 需研究 |
| HK | Hongkong Post | 无免费批量数据 |

### 建议

**暂缓 Batch A 导入**，等待替代数据源确认。当前前端已正确显示覆盖状态。
