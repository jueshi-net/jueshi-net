## Technical Details

### Data Source
- **URL**: https://download.geonames.org/export/zip/
- **License**: Creative Commons Attribution 4.0
- **Format**: TSV (tab-separated values)

### Schema Compatibility
✅ All imports use existing `postal_codes` table schema  
✅ No new columns needed  
✅ No Prisma schema changes  
✅ No `prisma db push` required  

### Field Mapping
```
GeoNames TSV → postal_codes
─────────────────────────────
Column 1 (country code)    → "countryCode"
Column 2 (postal code)     → "postalCode" + "normalizedPostalCode"
Column 3 (place name)      → city
Column 4 (admin name 1)    → province
Column 5 (admin code 1)    → "adminCode1"
Column 6 (admin name 2)    → district
Column 7 (admin code 2)    → "adminCode2"
Column 10 (latitude)       → latitude
Column 11 (longitude)      → longitude
Column 12 (accuracy)       → accuracy

Additional fields:
- country → ISO country name lookup
- source → 'GeoNames'
- "sourceUrl" → 'https://download.geonames.org/export/zip/'
- "sourceVersion" → download date (e.g., '2026-06-15')
- "isActive" → true
```

### Import Strategy
- **Approach**: Insert-Only with Dedup
- **Dedup Key**: `countryCode + normalizedPostalCode + city`
- **No Upsert**: Avoids overwriting existing data

## Safety Measures

### Pre-Import Backup
```bash
# Full table backup
pg_dump "$DATABASE_URL" -t postal_codes \
  -f postal_codes_backup_$(date +%Y%m%d).sql

# Or per-country backup
pg_dump "$DATABASE_URL" -t postal_codes \
  --where='"countryCode" IN (''VN'',''TW'',''HK'',''SA'')' \
  -f postal_codes_batch_a_backup.sql
```

### Rollback SQL
```sql
-- Rollback by source version
DELETE FROM postal_codes 
WHERE "countryCode" IN ('VN', 'TW', 'HK', 'SA')
AND "sourceVersion" = '2026-06-15';

-- Or per-country rollback
DELETE FROM postal_codes WHERE "countryCode" = 'VN';
DELETE FROM postal_codes WHERE "countryCode" = 'TW';
DELETE FROM postal_codes WHERE "countryCode" = 'HK';
DELETE FROM postal_codes WHERE "countryCode" = 'SA';
```

### Phase 2: Verify Files
```bash

# Expected: VN ~11000, TW ~8000, HK ~100, SA ~4500
```

### Phase 3: Import Script
```sql
-- Create staging table
CREATE TEMP TABLE import_staging (LIKE postal_codes INCLUDING ALL);

-- Load each country file (example for VN)
\COPY import_staging FROM '/tmp/geonames-batch-a/VN.txt' WITH (FORMAT csv, DELIMITER E'\t', HEADER false);

-- Insert with dedup
INSERT INTO postal_codes (...)
SELECT ... FROM import_staging s
WHERE NOT EXISTS (
  SELECT 1 FROM postal_codes p
  WHERE p."countryCode" = s."countryCode"
  AND p."normalizedPostalCode" = s."normalizedPostalCode"
  AND p.city = s.city
);
```

### Phase 4: Verify
```sql

FROM postal_codes 
WHERE "countryCode" IN ('VN', 'TW', 'HK', 'SA')

AND city ILIKE 'Ho Chi Minh%'
```
