## 一、Workspace documentType 命名修复 ✅

### 问题根因

1. **保存时**（`/tools/documents/[type]`）：
   - 使用 URL 参数 `type`，例如 `packing-list`（连字符）
   - 保存到 `DocumentHistory` 表，`documentType` 字段

2. **Workspace 显示时**（`/workspace/documents`）：
   - 调用 `/api/me/tool-documents` API
   - 查询 `ToolDocumentDraft` 表，`toolKey` 字段
   - 期望 `packing_list`（下划线）

**核心问题**: 保存到不同的表，且命名格式不一致。

### 修复方案

#### 1. 创建 document-type-utils.ts 工具函数

**文件**: `src/lib/documents/document-type-utils.ts`

```typescript
export function normalizeDocumentType(type: string): string {
  return type.replace(/-/g, '_');
}

export function documentTypeToHyphen(type: string): string {
  return type.replace(/_/g, '-');
}

export function getDocumentTypeLabel(type: string): string { ... }
export function getDocumentTypeHref(type: string): string { ... }
```

#### 2. 修改 /api/user/documents API

**文件**: `src/app/api/user/documents/route.ts`

**POST 方法**:
- 保存时 normalize documentType 为 underscore 格式
- `packing-list` → `packing_list`

**GET 方法**:
- 支持 hyphen 和 underscore 两种格式查询
- `where.documentType = { in: [normalizedType, hyphenType] }`

#### 3. 修改 /api/me/tool-documents API

**文件**: `src/app/api/me/tool-documents/route.ts`

**GET 方法**:
- 同时查询 `ToolDocumentDraft` 和 `DocumentHistory` 两个表
- 合并结果并去重
- 将 `DocumentHistory` 记录转换为 `ToolDocumentDraft` 格式

```typescript
// Query both tables
const drafts = await prisma.toolDocumentDraft.findMany({...});
const historyDocs = await prisma.documentHistory.findMany({...});

// Convert and merge
const historyAsDrafts = historyDocs.map(doc => ({
  id: doc.id,
  toolKey: normalizeDocumentType(doc.documentType),
  title: doc.documentNo || `${doc.documentType} - ${date}`,
  ...
}));

// Merge and deduplicate
const mergedDrafts = [...drafts, ...historyAsDrafts.filter(h => !draftIds.has(h.id))];
```
