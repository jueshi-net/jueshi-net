  if (typeof window === "undefined") return null;

  } catch {

}

### 3.4 Beta 缺口说明

**当前状态**:
- 公司资料可以在当前表单中手动填写
- 填写的公司信息会保存到 localStorage
- 下次打开同一工具时，会自动加载上次填写的公司信息
- **但是**：没有 UI 来从多个已保存的公司资料中选择

**缺失功能**:
1. 公司资料选择器（dropdown/select）
2. 从公司资料中心选择已有公司资料
3. 多套公司资料管理（代码已实现，UI 未实现）

**影响**:
- 用户每次都需要手动填写公司信息
- 无法快速切换不同的公司资料
- 对于有多个公司实体的用户不够方便

**建议**:
- 在 S1 或后续 Sprint 中实现公司资料选择器 UI
- 利用已有的 `getCompanyProfiles()` 函数
- 添加 dropdown 让用户选择已保存的公司资料
