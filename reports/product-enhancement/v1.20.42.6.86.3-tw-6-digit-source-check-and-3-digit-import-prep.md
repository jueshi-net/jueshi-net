## 一、6 码完整官方数据源检查

### 1.1 搜索结果

| 数据源 | URL | 结果 |
|---|---|---|
| **data.gov.tw/dataset/150689** | 3+3 碼郵遞區號 | ❌ **无完整 CSV 数据** |
| **中华邮政官网** | post.gov.tw | ❌ **只提供 Windows 应用程序** |
| **data.gov.tw/suggests/136487** | 民众建议 | ⚠️ 反映"中华邮政**没有提供 3+3 完整资料表**" |
| **data.gov.tw/dataset/25489** | 3 码邮递区号与行政区地理座标对照 | ✅ **找到经纬度数据** |

### 1.2 关键发现

#### 发现 1：data.gov.tw 民众反映

> "3+3即將滿2週年，但是中華郵政僅有提供線上查詢及轉碼程式，而**沒有提供資料表**，缺少基本資料對於加值運用不利"

**结论**: 中华邮政**没有提供 3+3 完整 CSV 数据表**，只提供：
- Windows 应用程序（Zip33USetup.exe）
- Web Service API
- 在线查询系统

#### 发现 2：找到官方经纬度数据

**data.gov.tw/dataset/25489**: 3 码邮递区号与行政区地理座标对照

| **下载 URL** | https://www.post.gov.tw/post/download/1050812_行政區經緯度(toPost).xml |

| **授权条款** | 政府資料開放授權條款-第1版 ✅ |
