## 1. 台湾显示修正（政治敏感性）

### 问题
台湾被错误地显示为独立国家：
```typescript
{ code: 'TW', name: '台湾', nameEn: 'Taiwan', flag: '🇹🇼' }
```

### 修正
```typescript
{ code: 'TW', name: '中国台湾', nameEn: 'Taiwan, China', flag: '🇨🇳' }
```

### 影响
- 前端国家选择器显示"中国台湾"
- 使用中国国旗 🇨🇳
- 符合一个中国原则

## 2. 覆盖状态配置文件

**文件**: `src/lib/postal-code-coverage-status.ts`

### 功能
- 定义 4 种覆盖状态：`full` / `partial` / `minimal` / `none`
- 提供 51 个支持国家的覆盖状态映射
- 提供状态图标和中文描述

### 示例
```typescript
import { getCoverageDisplay } from '@/lib/postal-code-coverage-status';

getCoverageDisplay('MY'); // "🟢 已覆盖"
getCoverageDisplay('VN'); // "⚫ 暂未覆盖"
getCoverageDisplay('ID'); // "🟡 部分覆盖"
```

### 覆盖状态分布
| 状态 | 数量 | 国家 |
|---|---|---|
| 🟢 Full | 36 | CA, US, GB, AU, NZ, JP, KR, MY, CN, IN, PH, TH, DE, FR, IT, ES, NL, BE, AT, CH, SE, NO, DK, FI, PL, CZ, PT, RO, HU, RU, UA, TR, BR, AR, CO, MX |
| 🟡 Partial | 5 | SG, AE, ID, IE, CL, KE |
| 🔴 Minimal | 1 | HK |
| ⚫ None | 8 | VN, TW, SA, GR, IL, ZA, EG, NG |
