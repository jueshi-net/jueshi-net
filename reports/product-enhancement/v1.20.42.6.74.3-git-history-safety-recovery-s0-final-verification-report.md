### 8.1 Git History Rewrite 历史

**问题**: 所有 5 个 pending commits 包含 Test123456!

**解决方案**: 使用 git-filter-repo 重写历史

```bash
# 创建替换规则
cat > /tmp/filter-expressions.txt << 'EOF'
Test123456!==>[REDACTED]
const PASSWORD='***';==>const PASSWORD='***';
EOF

# 执行历史重写
python3 -m git_filter_repo --replace-text /tmp/filter-expressions.txt --force

# 重新添加 origin
git remote add origin git@github.com-nnrwsm:nnrwsm-cloud/jueshibbx.git
```

**结果**: 
- Parsed 151 commits
- New history written in 0.22 seconds
