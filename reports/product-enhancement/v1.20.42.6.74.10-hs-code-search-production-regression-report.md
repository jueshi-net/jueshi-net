## 二、根因分析

### 数据库状态

| 项目 | 值 |
|---|---|
| 总记录数 | 51,838 |
| 中文描述字段 | `description` |
| 英文描述字段 | `descriptionEn` |

### API 代码问题

**修复前**:
```typescript
// Priority 2: Fuzzy match on nameCn (description)
results = await prisma.hSCode.findMany({
  where: {
    description: { contains: query }  // ❌ 只查询中文
  },
  take: 50,
  orderBy: { description: "asc" }
});
```

**根因**: API 只查询 `description`（中文名称），没有查询 `descriptionEn`（英文名称）。

---

## 三、修复方案

### 修改文件

- `src/app/api/tools/hs-code/route.ts`

### 修复后代码

```typescript
// Priority 2: Fuzzy match on nameCn (description) OR nameEn (descriptionEn)
const queryLower = query.toLowerCase();
results = await prisma.hSCode.findMany({
  where: {
    OR: [
      { description: { contains: query } },
      { description: { contains: queryLower } },
      { descriptionEn: { contains: query } },
      { descriptionEn: { contains: queryLower } },
    ]
  },
  take: 50,
  orderBy: { description: "asc" }
});
```

### 改进点

1. ✅ 同时查询中文和英文名称
2. ✅ 添加大小写不敏感匹配
3. ✅ 保持原有数字编码查询逻辑不变

## 七、已知限制

### 当前实现

1. **大小写敏感**: 已添加 `queryLower` 处理，但 PostgreSQL `ILIKE` 可能更优
2. **性能**: 使用 `OR` 查询可能影响性能，建议后续添加索引
3. **搜索结果限制**: 最多返回 50 条，可能需要分页

### 后续优化建议（非本轮范围）

1. 使用 PostgreSQL `ILIKE` 替代多个 `contains`
2. 添加 `descriptionEn` 字段索引
3. 实现搜索结果分页
4. 添加搜索历史记录（已有 localStorage 实现）
