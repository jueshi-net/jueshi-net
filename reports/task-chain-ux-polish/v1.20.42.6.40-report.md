## 四、预填横幅 UX 优化

### 4.1 横幅文案
- **标题**: "检测到跨境发货任务链数据"
- **字段摘要**: 商品名、HS编码、金额、币种、地址、邮编

### 4.2 三个按钮

| 按钮 | 行为 | EventLog |
|---|---|---|
| **使用这些数据** | 只填空字段，不覆盖已有字段 | `task_chain_prefill_accept` |
| **暂不使用** | 横幅本次隐藏，不删除 localStorage | `task_chain_prefill_reject` |
| **清除任务链数据** | 删除 localStorage，横幅消失 | `task_chain_clear` |

### 4.3 不覆盖逻辑
```typescript
// 只填空字段，不覆盖已有字段
if (taskChainData.productName && !first.description) {
  newFirst.description = taskChainData.productName;
}
if (taskChainData.declaredValue && !formData.totalAmount) {
  updates.totalAmount = parseFloat(taskChainData.declaredValue) || 0;
}
```
