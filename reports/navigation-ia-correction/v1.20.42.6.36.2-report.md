## Logo 后台配置方案

### 方案：复用 /admin/settings + 新增 branding 字段

**配置存储：** `data/system-settings.json` → `branding` 字段

**配置字段：**
| 字段 | 默认值 | 说明 |
|---|---|---|
| `logoUrl` | `/brand/jueshi-logo-placeholder.svg` | Logo 图片路径 |
| `logoAlt` | `绝世百宝箱 jueshi.net` | Alt 文本 |
| `logoWidth` | `168` | 显示宽度 (px) |
| `logoHeight` | `42` | 显示高度 (px) |

**安全校验：**
- ✅ logoUrl 必须是站内路径或 https URL
- ✅ 禁止 `javascript:` 和 `data:` URL
- ✅ alt 不能为空
- ✅ width 范围 50-500
- ✅ height 范围 20-200

**Admin 入口：** `/admin/settings` → 品牌设置区块
- Logo URL 输入框
- Logo Alt 输入框
- Logo 宽度/高度输入框
- 实时预览
- 保存按钮

**前台读取：** Header 通过 `/api/branding` 读取配置
- 有配置 → 使用配置值
- 无配置 → fallback 到默认值

**VPS 验证：**
- `/api/branding` → 200，返回 JSON ✅
- `/admin/settings` → 307（需登录），登录后显示品牌设置区块 ✅
