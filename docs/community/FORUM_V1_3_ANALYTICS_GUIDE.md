# Forum V1.3 Analytics & Growth Insights Guide

> 管理员运营数据分析指南：指标口径、数据限制、隐私规则、使用建议

## 一、指标口径说明

### 1.1 内容漏斗指标 (Content Funnel)

| 指标 | 计算口径 | 时间范围 | 数据来源 |
|------|---------|---------|---------|
| 草稿创建数 | `status=draft` 且创建时间在范围内 | 可配置（默认30天） | ForumPost |
| 草稿提交率 | `提交数 / (草稿数 + 提交数) × 100%` | 同上 | ForumPost |
| 审核通过率 | `approve操作数 / (approve+reject操作数) × 100%` | 同上 | ModerationLog |
| 审核驳回率 | `reject操作数 / (approve+reject操作数) × 100%` | 同上 | ModerationLog |
| 获得首条评论比例 | `有评论帖子数 / 已发布帖子数 × 100%` | 同上 | ForumPost.commentCount |
| 发布后互动率 | `有浏览或评论的帖子数 / 已发布帖子数 × 100%` | 同上 | ForumPost.viewCount/commentCount |
| 无回复率 | `无评论帖子数 / 已发布帖子数 × 100%` | 同上 | ForumPost.commentCount |
| 举报率 | `举报数 / 已发布帖子数 × 100%` | 同上 | ForumReport |
| 精华转化率 | `精华帖数 / 已发布帖子数 × 100%` | 同上 | ForumPost.isFeatured |

### 1.2 作者成长指标 (Author Growth)

| 指标 | 计算口径 | 注意事项 |
|------|---------|---------|
| 新作者数 | 当前周期活跃但上一周期不活跃的用户 | 基于发帖/评论活动 |
| 活跃作者 | 范围内发帖或评论的唯一用户数 | 不区分浏览行为 |
| 回访作者 | 当前和上一周期均活跃的用户 | 基于发帖/评论活动 |
| 首帖通过率 | 新作者首次发帖被通过的比例 | 样本量小时偏差大 |
| 作者平均互动 | `(帖子数+评论数) / 活跃作者数` | 仅含发帖评论 |
| 高贡献作者 | 互动得分前10名 | 得分=帖子×3+评论×1+点赞×0.5 |
| 沉默作者 | 上一周期活跃但本周期不活跃 | 非真实留存，仅近似 |
| 新作者留存 | 近似值，非真实登录行为 | 仅供参考 |

### 1.3 内容趋势指标 (Content Trends)

| 指标 | 计算口径 | 数据来源 |
|------|---------|---------|
| 每日帖子趋势 | 按天聚合非草稿帖子创建数 | ForumPost |
| 每日评论趋势 | 按天聚合评论创建数 | ForumComment |
| 搜索次数趋势 | 按天聚合 forum_search 事件数 | EventLog |
| 热门关键词 | forum_search 事件中 keyword 字段频次 | EventLog.metadata |
| 热门分类 | 范围内已发布帖子数排序 | ForumPost + ForumCategory |
| 热门标签 | 已发布帖子 tags 数组频次统计 | ForumPost.tags |
| Feed请求量 | 按天聚合 forum_feed_view 事件数 | EventLog |
| 分享点击量 | 按天聚合 forum_share 事件数 | EventLog |

## 二、数据限制

### 2.1 不记录的数据

- ❌ 帖子正文内容
- ❌ 用户密码、Token、Cookie
- ❌ 用户邮箱（分析输出中匿名化）
- ❌ 完整搜索内容中的敏感个人信息
- ❌ 用户真实IP地址（EventLog仅存储IP哈希）
- ❌ 第三方分析SDK数据

### 2.2 数据保留策略

- EventLog 数据保留 90 天
- 搜索关键词长度限制 50 字符
- metadata 字段值长度限制 200 字符
- 作者标识在导出时进行不可逆哈希

### 2.3 数据近似说明

以下指标为近似值，不应作为精确决策的唯一依据：

- **新作者留存率**：基于发帖/评论活动近似，不反映实际登录行为
- **平均审核等待时间**：基于帖子创建到审核操作的时间差，可能有偏差
- **24h互动率**：互动定义为有浏览或评论记录，不含点赞和分享
- **高贡献作者**：互动得分公式为经验值，不代表真实贡献排名

## 三、隐私规则

### 3.1 数据收集原则

1. **最小必要**：只收集运营分析所需的最少数据
2. **匿名化**：用户标识在分析和导出时进行不可逆哈希
3. **不记录正文**：事件追踪不记录帖子内容、评论内容
4. **关键词脱敏**：搜索关键词限制长度并去除控制字符
5. **支持退出**：设置 `FORUM_ANALYTICS_DISABLED=true` 可完全禁用

### 3.2 导出安全

- CSV 导出包含公式注入防护
- 不导出邮箱、Token、IP、Cookie、正文
- 作者标识在导出时匿名化
- 导出操作记录审核日志

### 3.3 禁止事项

- ❌ 不得用于用户画像或敏感属性推断
- ❌ 不得将匿名化数据重新关联到具体用户
- ❌ 不得将分析数据出售或提供给第三方
- ❌ 不得伪造 Google Search Console 数据
- ❌ 不得使用数据进行用户监控或跟踪

## 四、如何解读分析数据

### 4.1 内容漏斗

- **草稿提交率低** → 用户在草稿阶段放弃，检查发帖流程是否复杂
- **审核通过率低** → 内容质量或审核标准需要调整
- **无回复率高** → 社区活跃度不足，需要引导讨论
- **举报率高** → 内容质量或社区氛围问题
- **精华转化率低** → 高质量内容不足，需要激励机制

### 4.2 作者成长

- **新作者多但留存低** → 新用户体验需要优化
- **沉默作者多** → 需要重新激活策略
- **高贡献作者集中** → 需要培养更多活跃作者
- **首帖通过率低** → 新用户引导和内容规范需要加强

### 4.3 增长建议

- **分类缺内容** → 发布种子内容或引导用户发帖
- **搜索无结果** → 创建相关内容或调整分类
- **帖子值得更新** → 更新旧内容可重新激活讨论
- **适合设为精华** → 提升高质量内容的曝光

## 五、不应如何使用

1. **不要用分析数据惩罚用户** → 数据用于改进社区，不是惩罚依据
2. **不要用近似值做精确决策** → 近似指标仅作参考
3. **不要用匿名化数据追踪个人** → 违反隐私原则
4. **不要用搜索关键词监控用户** → 关键词仅用于内容改进
5. **不要将分析数据与个人身份关联** → 即使技术上可行也不应这样做

## 六、API 端点

| 端点 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/api/forum/admin/analytics/funnel` | GET | admin | 内容漏斗指标 |
| `/api/forum/admin/analytics/authors` | GET | admin | 作者成长指标 |
| `/api/forum/admin/analytics/trends` | GET | admin | 内容增长趋势 |
| `/api/forum/admin/analytics/recommendations` | GET | admin | 增长建议 |
| `/api/forum/admin/analytics/seo` | GET | admin | SEO监控面板 |
| `/api/forum/admin/analytics/export` | GET | admin | CSV报表导出 |
| `/api/forum/admin/analytics/privacy` | GET | public | 隐私政策 |

### 查询参数

- `days` - 回溯天数（1-90，默认30）
- `type` - 导出类型（content/category/author/search/summary）
- `dateFrom` - 起始日期（YYYY-MM-DD）
- `dateTo` - 结束日期（YYYY-MM-DD）

## 七、事件埋点

### 支持的事件类型

| 事件 | 触发场景 | 记录数据 |
|------|---------|---------|
| `forum_search` | 用户搜索 | 关键词(脱敏)、分类、结果数 |
| `forum_filter` | 用户筛选 | 分类、标签、排序方式 |
| `forum_post_view` | 查看帖子 | 帖子slug、ID |
| `forum_share` | 点击分享 | 帖子slug、平台 |
| `forum_feed_view` | 查看Feed | Feed类型、分类 |
| `forum_draft_create` | 创建草稿 | 分类ID |
| `forum_submit_review` | 提交审核 | 帖子ID、分类ID |
| `forum_moderation_complete` | 完成审核 | 操作类型、帖子ID |

### 禁止记录的数据

- 帖子正文内容
- 密码、Token、Cookie
- 完整搜索中的敏感个人信息
- 用户邮箱（metadata中会被过滤）
