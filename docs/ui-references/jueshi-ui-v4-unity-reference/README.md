# 绝世百宝箱 UI V4 参考设计

## 参考来源

Unity Gaming Platform (游戏直播平台)

## 设计分析

### 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│  Topbar (搜索、浏览、用户)                                    │
──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│ Sidebar  │  Main Content Area                               │
│          │                                                  │
│ - 导航   │  - Hero Banner (大卡片)                           │
│ - 关注   │  - 热门工具 (4 列网格)                             │
│ - 设置   │  - 常用场景 (圆形图标)                             │
│          │  - 推荐内容 (卡片)                                 │
│          │  - 留学指南 (内容卡片)                             │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

### 颜色系统

**主色：**
- 背景：#1b1d21 (深色)
- 次要背景：#2a2d35
- 边框：#3a3e45

**强调色：**
- 紫色：#6c5dd3 (主要 CTA)
- 紫罗兰：#ab99ff (次要)
- 橙红：#ff544d, #ff754c (Live/热门)

**渐变：**
- Hero 遮罩：linear-gradient(180deg, transparent, #1b1d21e6)
- CTA 按钮：linear-gradient(225deg, #5c8fff, #c14bff)

### 组件结构

1. **Sidebar**
   - 宽度：~240px (desktop)
   - 背景：深色
   - 导航项：图标 + 文字
   - 用户头像：圆形

2. **Topbar**
   - 高度：~60px
   - 搜索框：居中
   - 用户头像：右侧

3. **Hero Banner**
   - 高度：~400px
   - 背景图 + 遮罩
   - 标题 + 描述 + CTA

4. **Tool Cards**
   - 4 列网格 (desktop)
   - 2 列网格 (tablet)
   - 1 列 (mobile)
   - 圆角、阴影、悬停效果

5. **Scenario Icons**
   - 圆形图标
   - 横向滚动
   - 标签文字

### 响应式断点

- Desktop: ≥1280px
- Tablet: 768px - 1279px
- Mobile: <768px

### 绝世百宝箱适配

**品牌元素：**
- 红色赛博小螃蟹 ( mascot)
- 工具箱、地图、邮编、单据、汇率、物流、留学、官方资源场景插画

**内容替换：**
- 游戏直播 → 实用工具
- 热门频道 → 热门工具
- 游戏分类 → 工具分类
- 推荐视频 → 推荐内容/留学指南

**禁止元素：**
- Unity / League of Legends / Fortnite / Call of Duty 等第三方品牌
- 游戏直播相关内容
