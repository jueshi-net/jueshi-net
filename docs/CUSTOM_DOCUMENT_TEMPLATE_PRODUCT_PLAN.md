# Custom Document Template Product Plan

> **版本**: v1.20.42.18.6.15  
> **状态**: Product Planning  
> **目标**: 模板市场与定制服务的商业化路径

---

## 1. 产品愿景

**让每个外贸企业都能拥有符合自身品牌和业务流程的单据模板。**

从"统一工具"进化为"统一能力 + 个性化模板"：
- 统一能力：公司资料、商品、草稿、导出、审计 — 降低开发维护成本
- 个性化模板：视觉风格、布局结构、字段组合 — 满足企业差异化需求

## 2. 模板层级

### 2.1 官方模板库

| 属性 | 描述 |
|------|------|
| 来源 | 平台官方设计 |
| 数量 | 每种工具 3-5 个官方模板 |
| 风格 | 标准商务版、蓝色外贸版、物流仓储版、深灰专业版、简洁无边框版 |
| 可见性 | 全部用户可见 |
| 定价 | 免费 |
| 定制 | 不可修改 |

**官方模板列表（首批）**：

| 模板名 | 适用工具 | 风格 |
|--------|---------|------|
| 经典商务 | 报价单/发票/合同 | 黑白正式 |
| 蓝色外贸 | 报价单/PI/CI | 蓝色专业 |
| 物流仓储 | 装箱单/送货单/标签 | 绿色仓储 |
| 简约现代 | 所有标准单据 | 极简风格 |
| 集运专用 | 入库单/合箱清单/标签 | 橙色活力 |

### 2.2 企业自定义模板

| 属性 | 描述 |
|------|------|
| 来源 | 企业管理员创建 |
| 定价 | Pro 会员功能 |
| 限制 | 每企业最多 20 个模板 |
| 审核 | 平台安全审核 |
| 共享 | 企业内全员可用 |
| 品牌 | 支持企业 Logo、品牌色、印章 |

**企业模板功能**：
- 可视化模板编辑器（拖拽 block 组件）
- 品牌元素：Logo、品牌色、印章、签名
- 自定义字段：在标准字段基础上增加企业特有字段
- 布局模板：调整字段位置、表格列顺序
- 多版本管理：模板版本号、审核状态、发布/停用

### 2.3 个人模板

| 属性 | 描述 |
|------|------|
| 来源 | 个人用户创建 |
| 定价 | 免费用户 3 个，Pro 用户 10 个 |

| 审核 | 自动安全扫描 |

## 4. 模板关联

### 4.1 工具类型关联

每个模板关联一个或多个工具类型：

```
模板 "蓝色外贸报价单" → 关联工具: quotation, proforma-invoice
模板 "物流仓储装箱单" → 关联工具: packing-list, consolidation-packing-list
模板 "集运入库标签" → 关联工具: inbound-label, consolidation-label
```

### 4.2 国家/行业关联

模板可关联适用国家或行业：

```
模板 "中国外贸标准版" → 国家: CN | 行业: 通用
模板 "跨境电商版" → 行业: 电商
模板 "货代专用版" → 行业: 货代
```

用户创建单据时，系统根据用户国家和行业推荐合适模板。

## 5. 模板生命周期

```
创建 → 编辑 → 预览 → 提交审核 → 审核 → 发布 → 使用 → 停用/删除
                                                    ↓
                                                  版本更新
```

### 5.1 模板编辑器

**Phase 1（当前规划）**：JSON 配置 + 预览
- 管理员通过 JSON 配置模板
- 实时预览效果
- 保存为草稿 → 提交审核

**Phase 2（中期）**：可视化拖拽编辑器
- 左侧 block 组件库
- 中间画布拖拽排列
- 右侧属性面板
- 实时预览

**Phase 3（长期）**：AI 辅助设计
- 上传企业品牌素材
- AI 自动生成匹配模板
- 用户微调确认

## 7. 模板审核流程

### 7.1 自动审核（所有模板）

1. **XSS 扫描**：检测 JS 代码、危险 HTML
2. **变量白名单校验**：检测禁止变量路径
3. **CSS tokens 校验**：检测禁止 CSS 属性
4. **Block 白名单校验**：检测未知 block 类型
5. **文件安全扫描**：Logo/印章/签名图片安全检查

### 7.2 人工审核（企业模板）

1. 自动审核通过后进入待审核队列
2. 平台管理员人工审核（1-2 个工作日）
3. 审核标准：
   - 无违法内容
   - 无品牌侵权
   - 无安全风险
   - 符合平台规范
4. 审核结果：通过 → 发布 / 拒绝 → 退回修改

|------|------|
