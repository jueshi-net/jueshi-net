## 缺陷等级定义

| 等级 | 定义 |
|------|------|
| P0 | 生产打不开、登录/后台不可用、数据丢失、权限绕过、生产 DB 风险、支付/邮件/严重安全 |
| P1 | 核心功能不可用、邮编查询错误、BBS 发帖/回复失败、后台保存失败、国家页关键模块错误、SEO 严重错误 |
| P2 | UI 错位、文案错误、移动端体验问题、次要功能异常 |
| P3 | 小文案、间距、非关键视觉细节 |
