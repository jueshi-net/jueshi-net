## 邮编工具特殊检查

### M5V3L9 精确匹配验证
1. 输入 CA + M5V3L9
2. 预期：精确匹配 Toronto, ON, M5V3L9
3. 状态文案显示「精确匹配」或 equivalent
4. 地图链接指向 Toronto 区域

### M5V9O9 部分匹配验证
1. 输入 CA + M5V9O9
2. 预期：不应显示为完整匹配
3. 应显示「未找到精确匹配」+ 前缀参考
4. 不应误判为精确结果

### 地图链接验证
1. 查询任意邮编
2. 点击地图链接
3. 检查 URL 参数：不应包含 postal code
4. 应包含 city/region/country

### 国家切换验证
1. 查询 CA M5V3L9
2. 切换到 JP
3. 旧结果不应残留
4. 输入框清空或提示切换
