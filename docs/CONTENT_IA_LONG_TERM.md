## 一、专题栏目定位

**关键词：** 知识地图 / 资源集合 / 主题入口

专题（Topic）是面向某一出海主题的**知识导航入口**。

**职责：**
- 将散落在站内的工具、文章、目的地、外部资源按主题聚合
- 为用户建立结构化知识地图：「从入门到进阶，这里有哪些资源」
- 作为 SEO 长尾流量的主题入口页

**内容特征：**
- 宏观视角：覆盖面广，不深入到具体操作
- 资源聚合：工具卡片 + 文章推荐 + 官方链接 + 外部参考
- 导航属性：帮助用户找到下一步该看什么、该用什么工具

**示例专题：**
| 专题 slug | 标题 | 定位 |
|---|---|---|
| `us-shipping` | 美国寄送指南 | 汇总寄美国相关的所有工具、文章、目的地信息 |
| `uk-study` | 英国留学必备 | 留学生寄送、地址格式、邮编、生活相关工具集合 |
| `seller-logistics` | 跨境电商物流 | 卖家视角的物流工具、运费估算、报关、保险集合 |
| `digital-nomad` | 数字游民出国指南 | 翻墙、虚拟号、收款、寄送的全栈资源 |

## 二、清单栏目定位

**关键词：** 行动步骤 / 避坑核对 / 场景任务单

清单（Checklist）是面向某一具体场景的**行动指南**。

**职责：**
- 提供可执行的核对列表：出发前 / 经营前 / 寄件前需要做什么
- 降低用户的行动焦虑：按步骤逐一完成，不遗漏
- 作为专题的"下一步"：看完专题知道有什么，用清单知道怎么做

**内容特征：**
- 微观视角：聚焦单一场景，深入到具体操作
- 行动导向：每个条目都是可勾选的待办任务
- 工具嵌入：清单中的步骤直接链接到对应工具（用工具完成任务）

**示例清单：**
| 清单 slug | 标题 | 对应专题 | 转化目标 |
|---|---|---|---|
| `ship-to-us-checklist` | 寄件美国前核对清单 | `us-shipping` | 引导使用运费估算 + 地址格式化 |
| `uk-address-setup` | 英国地址设置清单 | `uk-study` | 引导使用邮编校验 + 地址格式化 |
| `seller-first-shipment` | 卖家首单发货清单 | `seller-logistics` | 引导使用报关单 + 商业发票 + HS编码 |

## 三、两者关系：转化路径

```
专题（知识地图）
  ↓ 用户想了解"这个领域有什么"
清单（行动指南）
  ↓ 用户想了解"我该怎么做"
工具（执行引擎）
  ↓ 用户需要"帮我完成"
用户资产 / 任务链（留存）
  ↓ 用户产生报价单、单据、收藏
```

**不是竞争关系，而是漏斗关系：**

- 专题 → 告诉用户"有什么"
- 清单 → 告诉用户"怎么做"
- 工具 → 帮用户"做到"
- 用户资产 → 让用户"留下来"

## 五、专题页标准格式（未来发布规范）

**AI 友好 + 搜索友好结构：**

```yaml
# 专题元数据
slug: us-shipping
title: 美国寄送全攻略
subtitle: 从工具到政策，一站式解决寄美国问题
status: published
coverImage: /images/topics/us-shipping.jpg
heroBadges: ["跨境电商", "留学生", "海外华人"]
suitableFor: ["跨境卖家", "留学生", "SOHO"]
tags: ["美国", "国际快递", "DHL", "FedEx", "USPS"]
seoTitle: 美国寄送全攻略 | 工具+政策+避坑 | 海外百宝箱
seoDescription: 汇集运费估算、地址格式化、邮编校验、报关单据等美国寄送必备工具，附 DHL/FedEx/USPS 线路对比和政策解读。
```

**页面结构：**
1. Hero 区：标题 + 副标题 + badges + CTA
2. 场景入口：按用户身份分流（卖家 / 留学生 / SOHO）
3. 必备工具卡：3-5 个核心工具，一键跳转
4. 政策解读：关键政策摘要 + 原文链接
5. 相关文章：2-3 篇深度文章
6. 避坑指南：常见错误 + 正确做法
7. 官方链接：USPS / CBP / 航空公司等
8. FAQ：3-5 个高频问答

## 六、清单页标准格式（未来发布规范）

**AI 友好 + 搜索友好结构：**

```yaml
# 清单元数据
slug: ship-to-us-checklist
title: 寄件美国前 10 项核对清单
subtitle: 出发前逐一检查，不漏项不踩坑
status: published
relatedTopic: us-shipping
estimatedTime: "15 分钟"
scenario: "首次寄件美国"
seoTitle: 寄美国前必做的 10 件事 | 核对清单 | 海外百宝箱
seoDescription: 寄件美国前的完整核对清单：地址格式、邮编验证、禁寄物品、关税预估、保险选择、报关单据，一步步核对不遗漏。
```

**页面结构：**
1. Hero 区：标题 + 场景描述 + 预计用时
2. 进度条：已完成 X/10
3. 核对列表：每项包含
   - [ ] 标题（动作导向）
   - 说明（为什么重要）
   - 工具链接（跳转到对应工具）
   - 完成状态（本地存储 or 登录用户持久化）
4. 完成后的 CTA：生成单据 / 分享给同事
5. 相关专题：返回专题了解更多

## 七、Hermes ContentOps 长期设想

**未来可规划的自动化内容管线（本轮不开发）：**

1. **AI 选题生成**：根据搜索趋势 + 站内搜索数据，自动建议新专题/清单选题
2. **AI 初稿生成**：根据选题生成结构化初稿（YAML 元数据 + 页面内容）
3. **AI 交叉引用**：自动将新内容与现有工具、文章、落地页建立关联
4. **AI SEO 优化**：根据目标关键词优化 title / description / 内容密度
5. **人工审核**：编辑审核 AI 初稿，确认发布
6. **自动发布**：审核通过后写入 DB，自动生成 /topics/[slug] 和 /checklists/[slug]

**Skill 名称建议：** `hermes-contentops`

## 八、暂不实施说明

**本轮及近期不实施的原因：**
- 当前优先级：v1.20.42.6.20 Landing Page Public Template MVP 正在进行中
- 专题/清单需要新的数据模型、Admin 页面、前台模板、SEO 管线
- 需要与现有 Topic 模型的关系梳理（现有 Topic 已有 slug/status/heroBadges 等字段）
- AI 内容生成需要先解决 seo-daemon 的修复
- 需要制定内容质量审核标准，避免 AI 生成低质量页面影响 SEO

**触发开发的条件：**
- Landing Page MVP 稳定后
- seo-daemon 修复完成
- 现有文章和工具有足够内容支撑专题聚合
- 团队确认专题/清单的 SEO 策略和发布频率
