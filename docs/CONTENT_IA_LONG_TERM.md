## 一、专题栏目定位

**关键词：** 知识地图 / 资源集合 / 主题入口

专题（Topic）是面向某一出海主题的**知识导航入口**。

**职责：**
- 将散落在站内的工具、文章、目的地、外部资源按主题聚合
- 为用户建立结构化知识地图：「从入门到进阶，这里有哪些资源」
- 作为 SEO 长尾流量的主题入口页

**内容特征：**
- 宏观视角：覆盖面广，不深入到具体操作
- 资源聚合：工具卡片 + 文章推荐 + 官方链接 + 外部参考
- 导航属性：帮助用户找到下一步该看什么、该用什么工具

**示例专题：**
| 专题 slug | 标题 | 定位 |
|---|---|---|
| `us-shipping` | 美国寄送指南 | 汇总寄美国相关的所有工具、文章、目的地信息 |
| `uk-study` | 英国留学必备 | 留学生寄送、地址格式、邮编、生活相关工具集合 |
| `seller-logistics` | 跨境电商物流 | 卖家视角的物流工具、运费估算、报关、保险集合 |
| `digital-nomad` | 数字游民出国指南 | 翻墙、虚拟号、收款、寄送的全栈资源 |

## 二、清单栏目定位

**关键词：** 行动步骤 / 避坑核对 / 场景任务单

清单（Checklist）是面向某一具体场景的**行动指南**。

**职责：**
- 提供可执行的核对列表：出发前 / 经营前 / 寄件前需要做什么
- 降低用户的行动焦虑：按步骤逐一完成，不遗漏
- 作为专题的"下一步"：看完专题知道有什么，用清单知道怎么做

**内容特征：**
- 微观视角：聚焦单一场景，深入到具体操作
- 行动导向：每个条目都是可勾选的待办任务
- 工具嵌入：清单中的步骤直接链接到对应工具（用工具完成任务）

**示例清单：**
| 清单 slug | 标题 | 对应专题 | 转化目标 |
|---|---|---|---|
| `ship-to-us-checklist` | 寄件美国前核对清单 | `us-shipping` | 引导使用运费估算 + 地址格式化 |
| `uk-address-setup` | 英国地址设置清单 | `uk-study` | 引导使用邮编校验 + 地址格式化 |
| `seller-first-shipment` | 卖家首单发货清单 | `seller-logistics` | 引导使用报关单 + 商业发票 + HS编码 |

## 三、两者关系：转化路径

```
专题（知识地图）
  ↓ 用户想了解"这个领域有什么"
清单（行动指南）
  ↓ 用户想了解"我该怎么做"
工具（执行引擎）
  ↓ 用户需要"帮我完成"
用户资产 / 任务链（留存）
  ↓ 用户产生报价单、单据、收藏
```

**不是竞争关系，而是漏斗关系：**

- 专题 → 告诉用户"有什么"
- 清单 → 告诉用户"怎么做"
- 工具 → 帮用户"做到"
- 用户资产 → 让用户"留下来"

## 五、专题页标准格式（未来发布规范）

**AI 友好 + 搜索友好结构：**

```yaml
# 专题元数据
slug: us-shipping
title: 美国寄送全攻略
subtitle: 从工具到政策，一站式解决寄美国问题
status: published
coverImage: /images/topics/us-shipping.jpg
heroBadges: ["跨境电商", "留学生", "海外华人"]
suitableFor: ["跨境卖家", "留学生", "SOHO"]
tags: ["美国", "国际快递", "DHL", "FedEx", "USPS"]
seoTitle: 美国寄送全攻略 | 工具+政策+避坑 | 海外百宝箱
seoDescription: 汇集运费估算、地址格式化、邮编校验、报关单据等美国寄送必备工具，附 DHL/FedEx/USPS 线路对比和政策解读。
```

**页面结构：**
1. Hero 区：标题 + 副标题 + badges + CTA
2. 场景入口：按用户身份分流（卖家 / 留学生 / SOHO）
3. 必备工具卡：3-5 个核心工具，一键跳转
4. 政策解读：关键政策摘要 + 原文链接
5. 相关文章：2-3 篇深度文章
6. 避坑指南：常见错误 + 正确做法
7. 官方链接：USPS / CBP / 航空公司等
8. FAQ：3-5 个高频问答

**AI 友好 + 搜索友好结构：**

```yaml
# 清单元数据
slug: ship-to-us-checklist
title: 寄件美国前 10 项核对清单
subtitle: 出发前逐一检查，不漏项不踩坑
status: published
relatedTopic: us-shipping
estimatedTime: "15 分钟"
scenario: "首次寄件美国"
seoTitle: 寄美国前必做的 10 件事 | 核对清单 | 海外百宝箱
seoDescription: 寄件美国前的完整核对清单：地址格式、邮编验证、禁寄物品、关税预估、保险选择、报关单据，一步步核对不遗漏。
```

**页面结构：**
1. Hero 区：标题 + 场景描述 + 预计用时
2. 进度条：已完成 X/10
3. 核对列表：每项包含
   - [ ] 标题（动作导向）
   - 说明（为什么重要）
   - 工具链接（跳转到对应工具）
   - 完成状态（本地存储 or 登录用户持久化）
4. 完成后的 CTA：生成单据 / 分享给同事
5. 相关专题：返回专题了解更多

## 十、SEO 与内链长期规划（v1.20.42.6.19.2）

**状态：** 长期规划（暂不实施）
**目标：** 确保专题、清单、工具、文章、落地页形成互相引用的内容网络，避免孤岛页面，明确各页面承担的搜索意图。

### 10.1 页面角色定义与搜索意图

| 页面类型 | 搜索意图 | 核心职责 | 关键词特征 |
|---|---|---|---|
| **专题（Topic）** | 信息探索型 | 知识地图 / 主题入口 / 资源聚合 | 长尾泛词：「美国寄送攻略」「英国留学必备」 |
| **清单（Checklist）** | 行动导向型 | 步骤核对 / 避坑指南 / 场景任务 | 动词短语：「寄美国前必做」「清关核对清单」 |
| **工具（Tool）** | 功能执行型 | 解决具体问题 / 生成单据 / 计算 | 功能词：「运费估算器」「HS编码查询」「地址格式化」 |
| **指南/文章（Guide）** | 深度解答型 | 政策解读 / 对比分析 / 案例教学 | 问题词：「DHL vs FedEx」「如何避免关税」 |
| **落地页（Landing）** | 场景转化型 | 特定国家/行业的一站式导航 | 场景词：「跨境电商物流导航」「留学生寄件入口」 |
| **工作台（Workspace）** | 用户留存型 | 收藏 / 历史 / 任务管理 / 资产沉淀 | 登录后可见，不直接参与 SEO |

**防冲突规则：** 同一关键词不得同时作为多个页面的核心 SEO 目标。专题做「攻略」，工具做「估算」，文章做「对比」，互不抢夺同一搜索词。

### 10.2 内链路径模型

```
专题（入口）
  ├── → 清单（下一步行动）
  │     ├── → 工具（执行任务）
  │     └── → 指南（深度理解）
  ├── → 指南（政策/对比）
  │     └── → 工具（文中推荐）
  └── → 落地页（场景导航）
        └── → 工具（直接跳转）

工具页
  ├── ← 专题（推荐入口）
  ├── ← 清单（任务节点）
  └── → 相关工具（横向拓展）

指南/文章页
  ├── ← 专题（推荐阅读）
  ├── → 工具（文中内嵌链接）
  └── → 相关指南（延伸阅读）
```

### 10.3 各页面内链规则

#### 专题页内链
- **必须包含：** 至少 2 个清单链接 + 至少 3 个工具链接 + 至少 2 个指南链接 + 1 个落地页链接（如有）
- **位置：** 每个链接必须出现在对应内容区块中（如"必备工具"区块下只放工具链接）
- **锚文本：** 必须具体描述目标页，如「使用运费估算器计算费用」，禁止使用「点击这里」「了解更多」

#### 清单页内链
- **必须包含：** 每个任务步骤必须链接到对应工具（如"核对地址格式" → 链接到地址格式化工具）
- **顶部链接：** 链接回所属专题（如「返回美国寄送全攻略」）
- **底部链接：** 推荐 1-2 篇相关指南（如「DHL 美国寄送注意事项」）

#### 工具页内链
- **顶部/侧边：** 链接到所属专题（如「更多美国寄送工具」）
- **结果页下方：** 推荐相关工具（如估算完运费后推荐「报关单生成器」）
- **禁止：** 在表单内部、结果核心区插入内链干扰操作

#### 落地页内链
- **模块间交叉：** 工具区块 → 工具页；文章区块 → 指南页；FAQ → 指南页
- **CTA 链接：** 必须指向明确的目标（工具列表 / 注册页 / 专题入口）
- **禁止孤岛：** 每个落地页必须被至少一个专题或导航页引用

### 10.4 锚文本规范

| 类型 | 示例 | 状态 |
|---|---|---|
| 描述性锚文本 | 「使用运费估算器计算包裹费用」 | ✅ 推荐 |
| 品牌/功能名 | 「HS编码查询工具」 | ✅ 可接受 |
| 行动指令 | 「立即生成报关单」 | ✅ 推荐 |
| 泛化锚文本 | 「点击这里」「了解更多」「查看」 | ❌ 禁止 |
| 关键词堆砌 | 「运费估算器 运费计算 运费查询 运费」 | ❌ 禁止 |

### 10.5 Hermes ContentOps Skill 的 internal_links 输入规范

未来开发 `hermes-contentops` Skill 时，生成内容必须同时输出 `internal_links` 配置：

```yaml
internal_links:
  - target_type: tool
    target_slug: shipping-calculator
    anchor_text: 使用运费估算器计算费用
    placement: section_tools
  - target_type: guide
    target_slug: dhl-vs-fedex-us
    anchor_text: 阅读 DHL vs FedEx 美国线路对比
    placement: section_articles
  - target_type: checklist
    target_slug: ship-to-us-checklist
    anchor_text: 查看寄美国前核对清单
    placement: section_cta
```

**规则：**
- 每个页面至少 3 个出站内链（指向不同类型的页面）
- 每个页面至少 1 个入站内链（来自专题或导航页）
- 锚文本必须人工审核或 AI 生成后校验
- 禁止循环引用（A→B→A 仅允许出现在"相关工具/文章"区块）

### 10.6 暂不实施说明

- 团队确认内链策略和锚文本规范
