## PNG 失败根因和修复证据

**根因:** `html2canvas` v1.4.1 不支持 CSS `lab()` 颜色函数。Tailwind CSS v4 默认使用 `lab()`/`oklch()` 颜色空间，导致 html2canvas 在解析计算样式时抛出异常：
```
Error: Attempting to parse an unsupported color function "lab"
```

**修复方案:**
1. 将 `html2canvas` 从静态导入改为动态导入（`await import("html2canvas")`），避免 SSR 问题
2. 在 `html2canvas` 的 `onclone` 回调中，遍历克隆文档的所有元素，将 `lab()`/`oklch()` 颜色替换为安全的 rgb 值：
   - `color: lab(...)` → `#000000`
   - `backgroundColor: lab(...)` → `#ffffff`
   - `borderColor: lab(...)` → `#e5e7eb`
3. 同时在 `onclone` 中隐藏 UI 元素（grid overlay、resize handles、edit buttons、page indicators、selection rings），不再直接修改原 DOM
4. 增加错误反馈：`paperRef` 为 null 时显示 "导出失败: 画布未就绪"，catch 块显示具体错误信息

**修复证据:**
- 修复前: 审计 `TS-CANVAS-PNG-EXPORT-ACTUAL-WORKS` FAIL — button: "导出失败"
- 修复后: 审计 PASS — button: "✓ 已导出"
- 浏览器控制台不再报 "unsupported color function" 错误

## 打印多余信息根因和修复证据

**根因 1 — 多余空白页:** 打印 CSS 对所有 `[data-testid="canvas-print-page"]` 元素设置 `page-break-after: always`，包括最后一页。这导致打印 10 页标签时输出 11 页（最后 1 页空白）。

**修复 1:** 添加 `:last-child` 规则：
```css
[data-testid="canvas-print-page"]:last-child {
  page-break-after: auto !important;
  break-after: auto !important;
}
```

**根因 2 — 件数指示器泄露:** 打印 CSS 只显式隐藏了 `canvas-print-page-count`（页码指示器），但未显式隐藏 `canvas-print-page-sequence`（件数指示器）。虽然 Tailwind 的 `print:hidden` 类应该生效，但为双重保险，将其添加到打印 CSS 中。

**修复 2:** 在打印 CSS 中同时隐藏两个指示器：
```css
[data-testid="canvas-print-page-count"],
[data-testid="canvas-print-page-sequence"] {
  display: none !important;
}
```

**修复证据:**
- 审计 `TS-CANVAS-PRINT-NO-EXTRA-BLANK-PAGE` PASS — "Print CSS has :last-child rule to prevent extra blank page"
- 审计 `TS-CANVAS-PRINT-HIDES-SEQUENCE-INDICATOR` PASS — "Print CSS hides both page-count and page-sequence indicators"
