## Dashboard 长期方向

| 模块 | 优先级 | 说明 |
|---|---|---|
| 常用工具 | P2 | 从 Favorites 工具分类升级为独立入口，支持快速启动 |
| 常用网址 | P2 | 从 Favorites 网址分类升级为独立入口，支持快捷访问 |
| 备忘录 | P3 | 用户个人笔记/备忘，需 Prisma UserMemo 表 |
| 汇率提醒 | P3 | 关注特定货币对，到达阈值时通知 |
| 任务链入口 | P2 | 链式任务导航，引导用户完成多步骤操作 |
| 等级/勋章 | P2 | 独立展示页，显示已获勋章与升级进度 |
| 黄页信用入口 | P3 | 用户信用分/评价展示 |
| 通知中心 | ✅ 已实现 | v1.20.42.6.10 MVP 已上线 |
| 用户资产中心 | P3 | 统一展示积分、成长值、勋章、会员状态 |

## 广告系统长期方向

| 规则 | 说明 |
|---|---|
| 广告不能破坏工具操作体验 | 广告位不得遮挡核心操作区域 |
| 会员可减少广告 | 付费会员享有广告减免权益 |
| 广告位后台可配置 | 通过 /admin/ads 管理广告位、素材、投放状态 |
| 统一规划 | 首页、工具页、文章页、落地页、黄页页、任务链页统一广告位规范 |
